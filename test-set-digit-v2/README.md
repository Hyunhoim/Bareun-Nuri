# 숫자 치환 기법 측정 사이트

`index.html`을 브라우저로 열면 4개 공공기관형 게시판과 112개 사례 페이지를 확인할 수 있습니다. HTML 파일 직접 열기는 화면·DOM 확인용입니다. 크롤러로 수집하려면 이 디렉터리만 정적 서버의 루트로 지정하고 `http://127.0.0.1:<포트>/`를 입력합니다. 프로젝트 루트 전체를 웹으로 제공하지 마세요.

예를 들어 Python이 설치되어 있다면 이 디렉터리에서 `python -m http.server 8791 --bind 127.0.0.1`로 실행할 수 있습니다. 프로젝트에 새 서버 의존성을 설치할 필요는 없습니다. 외부 공개는 필요하지 않습니다.

## 구성과 정답 분리

- 개발 56개와 평가 56개: 각각 숫자 치환 24개, 정상 표기 20개, 근거 부족 12개입니다.
- 24개 단어 계열마다 같은 표기를 광고·예방 인용·정확한 식별자·불확실 문맥에 배치했습니다. 추가로 16개 영숫자 규격·식별자 대조 사례를 포함합니다.
- 분할당 같은 토큰을 사용하는 식별자 12개 중 6개는 실제 광고 문맥이고, 불확실 사례의 절반은 짧은 중립 문구만 제시합니다. 광고 여부와 문자 치환 여부는 서로 다른 정답입니다.
- 개발·평가의 단어 계열, 실제 문장 템플릿, 사이트는 분리되어 있습니다. 본문과 댓글에 대상이 배치됩니다.
- 공개 HTML에는 정답 라벨·기대 복원 문자열·분할 메타데이터를 넣지 않았습니다. 화면에 있는 설명은 판정 대상의 실제 문맥입니다.
- 비공개 정답, 입력, 해시는 프로젝트의 `.runtime/digit-generalization-data-v1/`에 별도로 보관합니다. 이 폴더를 정적 서버로 제공하지 마세요.

## 해석 범위

이 자료는 명시적인 문맥에 따라 치환과 정상 식별자를 구분하는 합성 진단입니다. 치환 사례는 한국어 의미 단서가 있는 도박 관련 문맥에 한정되며, 정상 식별자는 정확한 코드라는 설명이 있습니다. 자연 공공사이트의 표현 분포나 암묵적인 제품명 해석 전체를 대표하지 않습니다. 개발 표준명 일부는 과거 진단 자료와 겹칩니다.

평가 자료는 사전 고정된 최초 실행 전에는 미사용 자료이지만, 그 결과를 열람한 뒤에는 관찰한 평가·회귀 자료입니다. 동일 자료를 반복 수정하면서 얻은 점수를 새로운 홀드아웃 일반화 성능으로 보고하지 않습니다. 운영 채택은 별도의 실행 시간·비용·회귀 검증이 필요합니다.

파일로 직접 열면 루트 메인 헤더의 `시민 소통` 링크 한 개가 상위 디렉터리를 가리킵니다. 위처럼 이 폴더를 HTTP 루트로 제공하면 해당 링크도 `/index.html`로 해석됩니다. HTTP URL 기준 233개 링크의 로컬 파일 대응을 검사했고 누락은 없었습니다. 실험 파일의 해시를 보존하려고 동결 HTML은 수정하지 않았습니다.
