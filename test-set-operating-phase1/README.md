# 운영 테스트 phase 1 — v1.2

> **평가 이력 추가(2026-09-30):** 현재 운영으로 첫 측정을 실행했으나 160번째 응답의 후보 1개 누락으로 14분 18초에 중단됐다. 지정 위치 686개 판정, 새 공공웹 보강 240개는 미판정이다. 이제 미사용 홀드아웃이 아닌 관찰 자료다. [평가 보고서](../docs/phase1-operating-report.md). 아래 0회 표기는 자료 생성 당시 기록이며, 최신 상태는 `private/status.json`을 따른다.

**평가 전용 2,240개. 모델 평가·학습·HCX/API 호출은 0회다.** 이번 변경은 사용자가 제시한 공공기관 배너 게시판과 추가 웹 탐색에서 확인한 광고 형식을 반영한 자료 보강이다. 운영 코드는 변경하지 않았다.

추가 검색에서 서울교육청 도메인의 홍보성 검색 결과와 대전시 게시판의 수익·가입 유도 결과도 나왔지만 현재 직접 열람을 확인하지 못했다. **확인 보류로 기록하고 정답 사례의 출처로 사용하지 않았다.** 검색에 나타났다는 이유만으로 기관의 현 상태나 침해 사고를 단정하지 않는다. 경찰청·서산시의 정상 문의·정책 논의 검색 결과는 위험 단어 자체가 광고를 뜻하지 않는다는 참고로만 기록했다.

출처 목록은 `sources.json`의 27개 기록이다. 개인정보·광고 서비스 연락처·실제 영상은 복제하지 않았고 외부 광고 사이트로 이동하지 않았다. 기관 사이트에 올라온 제3자의 게시글이며 해당 기관의 권고·운영 서비스로 해석하지 않는다.

## 구성

| 구분 | 기존 | 추가 | 합계 |
|---|---:|---:|---:|
| 광고 의도 양성 | 1,000 | 120 | 1,120 |
| 정상 대조 | 1,000 | 120 | 1,120 |
| 광고의 주 기법: H/J/T/O 각각 | 250 | 24 | 274 |
| 광고이나 필수 4종 기법이 없는 일반 표기 | 0 | 24 | 24 |
| 합계 | 2,000 | 240 | 2,240 |

H=HOMOGLYPH, J=JAMO, T=TRANSPARENT, O=OFFSCREEN. 복합 적용까지 센 광고의 각 기법 양성은 354개다. 복합 광고 240개는 기존 자료이며 이번 추가분은 일반 표기 및 단일 기법 대조다.

추가 자료는 **24개 시나리오 × 광고/정상 2종 × 일반 표기 및 4종 변형 5개 = 240개**다. 240개 독립 실수집 광고가 아니다. 도박 형식 20쌍, 성인물 홍보 형식 4쌍이며 웹에서 확보한 근거에 맞춰 보강했다. 부족한 마약·성매매 실제 공공기관 광고를 새로 수집했다고 주장하지 않는다.

기존 도메인별 400개에 도박 200개·성인물 40개가 추가된다. 전체 사이트 124페이지와 iframe 문서 200개다. 추가 24페이지는 일반 표/본문 및 댓글 목록 구조이며 iframe으로 광고를 넣지 않았다. 같은 페이지의 카드·댓글은 각기 독립된 작성자 범위를 갖는다. 본문/댓글 위치를 광고·정상 양쪽에 배치했다.

## 추가 시나리오의 핵심

- 안전·피해 예방·계정 보안 설명 뒤 현금 도박 가입 권유
- FAQ·후기 비교·추천·모바일 안내·상담 재개 공지를 통한 홍보
- 외부 링크 대신 검색어를 제시해 방문을 유도하는 문구
- 정상 인사나 일상·영어 문장 끝에 붙은 광고
- 카지노 검색어를 반복하는 댓글과 이스케이프된 HTML 링크 코드
- 광고 옆 별도의 정상 문의, 피해 상담, 삭제 요청과 교육 목적의 언급
- 광고와 정상 양쪽에 500~650자대 장문 포함. 실제 농사로에서는 약 1만 자 댓글도 관측했으나 이번 자료가 그 전체 길이를 재현하지는 않는다.

외부 검색 실행 기능을 추가한 것이 아니다. 검색을 유도하는 **문장**을 평가자료에 넣은 것이다. 성인 사이트 원문에서는 광고 의도는 확인했지만 실제 영상의 동의 여부나 법적 불법성을 확인하지 않았다. 성인물 합성 양성에 들어간 무동의 유포·불법촬영 설정은 작성자가 추가한 조건이며 실제 게시물의 사실로 주장하지 않는다.

## 관찰 사실과 합성 기법의 분리

확인한 실제 광고에 4종 위장이 모두 있었다고 주장하지 않는다. 일반 표기 대조는 `primary_stratum=PLAIN`, `techniques=[]`, `evaluation_track=ad_intent_without_four_technique`다. 광고인데 4종이 없다는 이유로 정상 정답을 주거나 임의 기법을 강제하지 않는다.

나머지는 같은 원문의 기존 영문 표기에 시각 치환, 한글에 자모 분해, HTML에 투명/은닉 스타일을 적용한 **요강 기반 합성**이다. 원문을 보존하고 변경 전후 문자·UTF-16 위치·CSS·적용 범위를 gold에 남겼다. 농사로에서 관찰한 U+00AD(SOFT HYPHEN)는 자모 분해나 닮은꼴 치환으로 강제 분류하지 않았으며 별도 기능을 만들지 않았다.

일반 표기·투명·화면 밖 대조는 의도적으로 문장이 같다. 텍스트/문맥 중복 96개는 CSS만 바꾼 대응 자료이고, 텍스트/문맥/CSS까지 동일한 중복은 0개다. 파생본을 서로 독립 표본으로 해석하지 않는다.

## 파일과 실행 범위

- `inputs.jsonl`: 2,240개 입력 원문·같은 작성자 문맥·위치. 실제 운영 수집기 출력이 아닌 합성 HTML의 입력 원본.
- `private/gold.jsonl`: 광고 의도·기법·그룹·출처·위치·변형 이력. 사람 독립 검수 미완료.
- `publicweb-cases.json`: 새로 작성한 광고/정상 24쌍. 실제 게시글을 그대로 옮긴 파일이 아니다.
- `public/`: 정답 없는 HTML/CSS. 이 폴더만 로컬 서버로 제공한다.
- `sources.json`: URL·확인 수준·관측 내용·사용 범위·확인 보류 기록.
- `quality.json`: 자료 정합성만 검사한 결과. F1·추론 성능 결과가 아니다.
- `private/publicweb-audit.json`: 기존 2,000개·운영 코드 보존 및 추가분 검증.
- `private/status.json`: 평가 0회·학습 0회·학습 사용 금지.
- `manifest.json`: 파일 해시와 버전. 모델 실행 후 같은 버전을 덮어쓰지 않는다.

기존 v1.1 전체는 프로젝트 `.runtime/phase1-before-publicweb-v12.zip`, v1.0은 `.runtime/phase1-data-before-revision1.zip`에 보존했다. 기존 80원문 보강 자료 800개와 기본 사례 1,200개는 별도 계층으로 유지했다. `private/revision-audit.json` 및 `private/review-samples.json`은 v1.1 당시 감사·발췌이며 v1.2 새 평가 결과가 아니다.

## 추후 평가 원칙

광고 의도 F1, 4종 기법 정확도, 위치 귀속을 분리한다. 일반 표기 48개는 의도 판정 대조이며 필수 4종 재현율 분모에 넣지 않는다. 기존/추가 자료·일반/4종·장문/단문·광고/정상·본문/댓글별 결과를 별도로 보고한다. 같은 쌍과 원문 파생본을 훈련과 평가로 나누지 않는다.

현재까지 모델 출력은 보지 않았다. 동일 제작자 편향, 문장틀 반복, 일부 원출처 의존, 실제 출현율과 다른 1:1 통제 비율이 남는다. 완전한 독립 최종평가 또는 현실 분포 대표 표본이라고 부르지 않는다. 메뉴 등 정답 밖에서 나온 탐지는 별도 검수해야 하며 바로 오탐으로 계산하지 않는다.

자료 정합성만 확인:

```powershell
.runtime/klue-venv/Scripts/python.exe -X utf8 test-set-operating-phase1/build.py --check
```

나중에 열람할 경우 public 폴더만 제공:

```powershell
.runtime/klue-venv/Scripts/python.exe -m http.server 8801 --bind 127.0.0.1 --directory test-set-operating-phase1/public
```

이번 작업에서는 서버·운영 수집기·모델 평가를 실행하지 않았다.
