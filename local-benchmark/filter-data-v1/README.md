# 필터 전용 학습 자료 v1

2026-09-29. 목적은 **명확한 정상만 제외하고 광고·근거 부족은 HCX로 전달**하는 것이다. 최종 불법광고 판정 모델용4분류 라벨과 다르다. 학습은 아직 실행하지 않았다.

## 구성

| 분할 | 독립 상황 계열 | 브라우저 수집 표현 변형 | 중복 제거한 모델 입력 | EXCLUDE / HCX |
|---|---:|---:|---:|---:|
| 훈련 | 40 | 336 | 96 | 48 / 48 |
| 개발검증 | 10 | 86 | 26 | 13 / 13 |
| 최종평가 예약 | 10 | 86 | 26 | 13 / 13 |
| 합계 | 60 | 508 | 148 | 74 / 74 |

**508개를 독립 학습 사례로 세지 않는다.** 투명/화면 밖 배치 및 복원된 자모는 의미 입력이 같은 경우가 있어 제거했다. 148입력도60상황의 파생 대조 자료다. 무작위 행 분할 없이 상황 계열 전체를 한 분할에 넣었다. 최종 자료는 별도 폴더에 두고 해시를 고정했으며 모델 평가0회다.

이는 **검수 가능한 소규모 합성 초기 자료**다. 순정 모델의 실사용 학습을 완성할 규모나 다양성이 확보됐다고 주장하지 않는다. 실제 게시물을 인용하거나 사람이 검수한 자료로 소개하지 않는다. 훈련/검증/최종은 모두 동일 작성자가 만들었고 문맥 대조 설계도 공유하므로 독립 실사이트 일반화 평가가 아니다. 사이트 이름 대신 합성 페이지 그룹을 쓰며 진짜 서로 다른 기관 출처 분할이라고 부르지 않는다.

## 라벨 계약

- `0 EXCLUDE`: 대상에 귀속된 근거로 정상 행정·합법적 이용·명확한 피해 문의·예방/보도 인용임을 확인할 수 있는 경우.
- `1 HCX`: 실제 거래/이용 권유 또는 판단에 필요한 근거가 부족한 경우. **HCX 라벨은 불법 확정이 아니다.** 목적을 모르는 모집/거래, 정상과 위험한 목적이 섞인 문장도 전달한다.
- 숨김/자모/숫자 치환 여부만으로 라벨을 정하지 않는다. 같은 변형이 양쪽 라벨에 있다.
- 예방 문구가 있더라도 현재 작성자가 추가로 광고를 권유하는 경우에는 전달한다. 실제 피해 문의라도 불법 서비스의 계속 이용을 문의해 게시 의도가 애매한 경우 보수적으로 전달한다.
- 문맥이 사라지거나 입력이 잘리면 기존 EXCLUDE 정답을 자동 재사용하지 않는다. 이번 입력은 최대51토큰으로 잘림 사례가 없다. 운영의512토큰 초과 강제 통과는 별도 코드 계약으로 유지한다.

## 내용과 수집

수강료/주차/도서관/접수/접근성/행정 식별자/합법 행사/피해 문의/교육 인용 등을 실제 권유·근거 부족과 대조했다. 도박, 비동의 성인 촬영물 거래, 성매매 알선, 마약류 거래, 위조 신분증·계좌 대여·대리시험 권유를 포함한다. 거래 연락처·접속 경로·실행 방법은 넣지 않았다.

동일 target에 safe/risky 문맥을 대응시킨 경우와, 대상 본문 자체에 의미 근거를 포함한 경우를 섞었다. 양쪽 라벨의 HTML 태그/스타일은 같다. seed의 EXCLUDE/HCX 메타데이터는 HTML에 넣지 않았다.

plain/JAMO/TRANSPARENT/OFFSCREEN을 전 상황에, 숫자로 읽을 수 있는 영문 문자가 있는 대상에만 HOMOGLYPH를 적용했다. 숫자 대응은 A→4/O→0/I→1/E→3/S→5/T→7이다. 모든 가능한 한글·영문 혼합이나 `0→ㅇ` 해석을 포괄하지 않는다. 숫자 변형을 위해 모든 한국어 문장에 억지로 영어를 붙이지 않았다.

60개 로컬 HTML 페이지를 실제 운영 Playwright 수집기로 읽어 `contract.initialEvidence`와 기존 scoped-context를 사용했다. 원문508/508, 기대한 귀속 문맥508/508, 반대 대조 문맥 누출0을 확인했다. 수작업 정답 설명을 수집 후 모델 입력에 추가하지 않았다. 표시 스타일/위치는 원본 snapshot에 보존한다. 분류기에는 target/context만 넣는다.

## 파일 사용

- `train-inputs.jsonl`, `train-labels.jsonl`: ID로 결합할 훈련 입력/라벨.
- `validation-inputs.jsonl`, `validation-labels.jsonl`: 개발검증. 임계값과 학습 설정 선택은 여기까지.
- `train-review.csv`, `validation-review.csv`: 원문과 귀속 문맥, 제안 라벨/근거, 빈 사람 검수 칸. 제안 라벨이 표시돼 있으므로 블라인드 검수가 아니다.
- `sealed-final/`: 개발 중 모델 추론/오류 분석 금지. 설정 고정 후 한 번 평가하고 평가 날짜·모델/설정 해시를 별도 기록한다. 폴더명은 암호화나 접근 통제를 뜻하지 않는다. 작성용 `seeds.tsv`에는 최종 원형도 있으므로 개발 모델/프롬프트/학습에 넣지 않는다.
- `manifest.json`, `audit.json`: 분포, 입력 필드 허용 목록, 분할/중복 검사, 해시, 미검수 상태.
- `.runtime/filter-data-v1/`: 실제 HTML, snapshot, 변형별 전체 records, collection audit. 이 자료를 무작위로 다시 분할하거나508행 그대로 학습하지 않는다.

`label`, `route`, `semantic_intent`, `group_id`, `mode`, `rationale`, `split`은 모델 입력 금지다. 기존 Nuri1.0/D의4분류 클래스 번호와 혼용하지 않는다.

## 품질 감사와 제한

기존 Nuri1.0/D/Nuri1.2 학습 파일, EXAONE 자료 및 이미 관찰한 평가·실수집 입력과 정규화된 전체 target/context의 완전 중복0을 확인했다. 문자4-gram Jaccard>=0.75의 근접 입력도0이다. 이는 의미적 유사성/패턴 과적합이 없다는 증명은 아니다. 다른 기존 파일 전체나 미개봉 최종 자료는 읽지 않았고 검증했다고 주장하지 않는다.

현재 안전한 문맥과 전달 문맥의 차이가 비교적 명확하고 짧다. 작성자가 의도를 과하게 설명하는 합성 지름길, 실제 정상 후보 비율과의 차이(본 자료50:50), 장문·동적댓글·미묘한 은어·복합 위장의 부족이 남는다. 특히 정상 자료를 대량 제외할 때의 실제 분포를 대표하지 않는다. 따라서 `training_ready=false`, `human_reviewed=false`로 남겼다. 이는 파일/수집 검사의 실패가 아니라 독립 라벨 검수와 실자료 보강이 완료되지 않았다는 뜻이다.

학습 전 검수로 EXCLUDE의 근거가 충분한지 우선 확인한다. 다음 확대는 검수된 서로 다른 출처의 실제 수집 정상과 짧은 권유/혼합 의도 대조 자료를 추가하는 방향이며 같은 틀을 반복 생성해 수천 개로 늘리지 않는다. 필터 선택은 단독F1보다 광고 통과율, 근거 부족 통과율, 정상 제외율, HCX 연결 정탐 및 CPU포함 시간으로 한다. 이 작은 최종26입력만으로 운영 채택하지 않는다.
