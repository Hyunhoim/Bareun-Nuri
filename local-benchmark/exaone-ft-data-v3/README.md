# EXAONE 학습 후보 자료 v3 — 다양성 보강

2026-09-29. 기존 v2 200개 원문과 정답 제안을 보존하고, 새로 작성한 **40개 문맥 × 대조 보기 2개 = 80개**를 추가했다. 총 280행이며, 독립적으로 수집한 게시글 280개가 아니다. 새 자료는 실제 불법광고를 수집·인용한 것이 아니라, 기존 sources.json의 공공 게시판 말투 참고를 바탕으로 새로 작성한 합성 문장이다.

|의미 분류|전체|비율|새 문맥 수|
|---|---:|---:|---:|
|0 실제 불법 거래·이용 권유|112|40%|16|
|1 예방·교육·보도 인용|42|15%|6|
|2 피해 문의·일반 정상·합법적 권유|84|30%|12|
|3 근거 부족|42|15%|6|

사용자는 기존 v2의 자연스러움을 검수했다고 확인했다. 이 기록은 자연스러움 승인으로 보존하며 정답 라벨의 최종 승인으로 확대 해석하지 않았다. 새 80행은 이번에 추가했으므로 사용자 검수를 받았다고 표시하지 않았다.

## 보강한 내용

- 숫자 관련 20개 문맥: 4→A, 0→O/o, 0 또는 o→한글 ㅇ을 포함한 음절 분할, 1→I/L, 3→E, 5→S, 7→T, 8→B, 9→G와 소문자 l. 한 글자/복수 글자, 대소문자 혼합을 포함한다. 변형 전후 보기는 동일한 문맥 그룹이다.
- BONUS 계열의 실제 권유·예방 인용·피해 문의, SAMPLE 계열의 위조 권유·교육 인용을 대비한다. S4V3는 실제 문자 치환이지만 정상 봉사 모집이다. 문자 치환 자체를 불법 의도와 동일시하지 않는다.
- A4/A3 용지, O2 측정기, B0 표시, B08 교실, ㅇ·0·o 교육 문구는 강제 복원하지 않는다. 식별번호 대조는 다른 유효 번호를 사용한다.
- C4RD/V1P처럼 문자 해석도 단정하기 어려운 사례는 기법 정답 제안에 ambiguous를 사용한다. 의미 보류와 기법 미확정은 별개 필드다.
- 나머지 20개 문맥에는 자모 분리 8개, 투명 6개, 화면 밖 배치 6개의 변형 보기를 추가했다. CSS만 바뀐 대조쌍의 의미 입력이 같을 수 있으므로 서로 다른 의미 학습 사례라고 주장하지 않는다.
- 예방 글 옆 실제 광고, 피해 문의 옆 판매 댓글, 정상 제목 아래 판매 권유, 권유 인용을 포함한 보도, 유료 정상 강좌, 대상이 삭제된 긴 신청 문맥을 포함한다.
- 새 모든 라벨에 본문·제목·작성자 소개·링크·댓글 배치를 배정했다. 인라인 span 분할과 앞뒤 순서도 바꾸되 대상 텍스트를 보존했다. 이는 직접 렌더링용 HTML이며 운영 수집기의 귀속 정확도를 검증한 결과는 아니다.

## 파일

- `dataset.json`: 기존 200 + 새 80. 모델에 전달할 후보 필드는 `input_draft`뿐이다. `plain_target`, `gold_rationale`, 문자 대응, 정답·범주·그룹 ID는 모델 입력이 아니다.
- `site/`: 280개 HTML 근거.
- `review-new.csv`: 새 자료의 정답 제안을 숨긴 검수 파일.
- `new-gold-proposals.json`: 제안 라벨·판단 이유·기법 판정. 학습 입력과 분리했다.
- `audit.json`, `near-duplicate-review.json`: 비율, 구조 분포, 중복 점검.
- `browser-audit.json`: 실제 headless Edge/Playwright의 원문·문맥·스타일 확인.
- `provenance.json`: 기존 v2 원본 SHA-256과 검수 범위.

## 검증 결과와 한계

280개 ID 고유, 기존 v2 필드 보존, 원문·문맥·스타일을 함께 비교한 완전 중복 0개. 서로 다른 그룹 간 문자 5-gram Jaccard 0.75 이상은 0쌍이다. 이 값은 의미적 중복이나 문장 틀 과적합이 없다는 증명이 아니다. 의도적으로 만든 대조쌍 때문에 새 자료의 정규화 대상 문자열 중복은 16개다.

새 40개 문맥의 모든 라벨에 다섯 배치가 존재한다. 새 자료의 평균 대상 길이는 권유 40.4, 인용 38.3, 정상 45.6, 근거 부족 43.5자다. 근거 부족 6문맥 모두 자기 문맥이 있으며, 권유·인용·정상에는 자기 문맥 없이 판정 가능한 사례도 넣었다. 여전히 합성 작성자의 어휘·설명 습관과 기존 200행의 반복 템플릿 편향은 남는다.

## 학습 시 지켜야 할 조건

1. 현재 전부 학습 후보이며 검증/최종 평가셋으로 지정하지 않았다. 행 무작위 분할은 금지한다. `group_id`와 `leakage_family`를 묶고 기존 v2와 공유하는 소재·어휘도 같은 쪽에 둔다. 별도 출처와 제작 방식의 검증 자료를 권한다.
2. `recommended_group_weight`는 기존 10행 그룹은 각 0.1, 새 2행 그룹은 각 0.5다. 같은 틀의 반복 개수가 학습 영향력을 결정하지 않도록 하는 권장값이며 아직 학습 코드에 적용하지 않았다. 실제 입력이 동일한 스타일 대조는 의미 학습에서 중복 제거 또는 한 보기 샘플링한다.
3. 모델 입력에 수동 복원 정답, 기법 정답, 문맥 설명용 정답 이유를 섞지 않는다. 직접 HTML 감사 통과를 운영 수집·귀속 검증으로 대체하지 않는다.
4. 동일 자료 점수로 일반화 개선을 확정하지 않는다. 이번 작업에서 모델 학습·API 호출·운영 변경·최종 평가셋 접근은 하지 않았다.
