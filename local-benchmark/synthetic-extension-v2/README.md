# 합성 문맥 보강 v2

초기 학습을 시작하기 위해 실제 원문에서 관찰한 위장 홍보·피해 진술·문맥 귀속 문제를 새 가상 사례로 보강했다. 기존 v1 파일은 보존했다. 현재 자료의 실제 출처 부족은 학습 시작 자체를 금지하는 조건이 아니지만, 합성 추가만으로 실제 분포에 충분하다는 증거가 생기지는 않는다.

## 결과

- 10개 범주, 24개 의미 대조 쌍 = 새 기본 사례 48개.
- 이 중 6쌍은 대상 문장이 완전히 같고 제목/같은 작성자 문맥에 따라 라벨이 달라진다.
- 효과 없는 변형과 중복을 제거한 추가 행 190개(양성 후보 94, 정상 문맥 96).
- 기존 766개와 합친 `combined-train-candidates.jsonl`: 956개.
- 별도 `review-only.jsonl`: 모호 사례 8개. 정상/양성 어느 쪽으로도 강제 학습하지 않는다.

`seeds.json`과 `semantic-base.jsonl`은 사람이 읽을 수 있는 증강 전 사례다. `addendum.jsonl`은 이번 추가분만 포함한다. `summary.json`은 검사 결과와 변경 전 원본 파일 해시를 기록한다.

## 보강한 판단 근거

제목에만 거래 대상이 명시된 광고, 위험 단어가 없는 대상 문구, 주의 문구 뒤 자체 서비스 모집, 따옴표를 사용한 실제 추천, 입금·연락·구매를 언급하는 피해자, 신고·삭제라는 말을 포함한 광고, 정상 예방 글 아래 별개 광고 댓글, 광고 글 아래 별개 삭제 요청, 성인 대상 합법 교육·일반 물품 판매 대조를 포함했다.

현재 v1 합성에는 ‘판매합니다’와 ‘신고합니다’ 같은 문장 틀이 반복된다. 이는 모델이 해당 표현을 정답 단서로 외울 가능성에 대한 우려이며, 실제 모델 과적합을 측정한 결과는 아니다. v2 역시 같은 assistant가 작성한 소량의 가상 사례이므로 편향을 제거했다고 주장하지 않는다. 실제 원문·댓글의 수가 늘어난 것도 아니다.

## 사용과 평가

모델 입력은 `input.target`, `input.context`만 사용한다. `reason`, `category`, `pattern`, ID, 라벨 등은 입력하지 않는다. 각 의미 대조 쌍과 모든 변형은 같은 `family_id`로 묶으며 같은 작성 계열 `group_id=synthetic-author-v1`을 유지한다. 표면 변형은 정상·양성 양쪽에 적용한다. 원문 1개에서 만든 변형 수를 독립 의미 사례 수로 세지 않는다.

라벨 1은 사용자 요청 범주의 광고 권유 선별 후보이며 법률 확정 정답이 아니다. 성인 관련 모든 표현을 양성으로 만들지 않는다. 새 자료는 전부 잠정 합성이며 사람 검수 완료나 독립 최종 홀드아웃이 아니다. 실제 수집 입력과의 동등성도 확인하지 않았다.

다음 학습 비교는 **동일 모델·학습 조건에서 v1과 v1+추가분을 비교**하는 개발 실험으로 한다. 알려진 원문/캠페인과 변형을 훈련·검증 양쪽에 섞지 않는다. 이미 관찰한 자료의 검증은 개발/회귀 결과로만 보고한다. 실제 문맥의 정상 오탐·기존 정탐 손실·보류량이 악화되면 추가분을 자동 채택하지 않는다. 새 독립 실자료가 없으므로 운영 일반화의 최종 통과는 판정할 수 없다.

검사: 동일 입력의 상충 라벨, ID/입력 중복, 대조 쌍 라벨 균형, 부모별 라벨·그룹 보존, 보류 학습 제외, 입력 필드 제한, 작동하는 URL/연락 계정 미생성, 기존 파일 해시 불변을 통과했다. 모델 학습·성능 평가는 실행하지 않았다.
