# 62개 원문 라벨·근거 작성

사용자가 전체 항목을 읽었다고 밝히고 개별 라벨과 근거 작성을 위임하여, 저장된 대상 문구와 수집 문맥을 AI가 읽고 작성했다. 사용자 전체 열람 진술과 AI의 개별 주석을 구분한다. 사람의 항목별 확정 정답이나 독립 검증셋으로 보고하지 않는다.

| 구분 | 광고 1 | 정상 0 | 근거 부족 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 기존 관찰 자료 | 11 | 13 | 7 | 31 |
| 훈련 후보 | 13 | 14 | 4 | 31 |
| 전체 | 24 | 27 | 11 | 62 |

- `labels.html`: 항목별 라벨·근거와 펼쳐 볼 수 있는 원문·문맥.
- `answers.json`: 원본 ID·목적·라벨·근거·대상 근거 구간·작성 주체. 구간은 Python 문자열의 0 기반 Unicode 코드포인트 위치이며 끝 위치는 제외한다.
- `audit.json`: 원본·결과 해시, 수량·ID·근거 구간 검사 기록.

라벨 1은 불법 서비스 이용·판매 유도 의심 광고의 의미 분류다. 법적 위법성 확정 판결을 뜻하지 않는다. 라벨 0에는 정상 정보, 피해 신고, 예방 교육, 일반 상업 홍보가 포함된다. 불명확한 링크 스팸이나 성인 관련 표현이라는 이유만으로 불법광고를 확정하지 않는다.

근거 부족은 4·6·9·11·15·24·31·38·45·46·47번이다. 입력에 없는 링크 목적이나 상품·거래 대상을 외부 지식으로 보충하지 않았다. 특히 38번은 성인 서비스 홍보 의도는 분명하지만 제공물의 위법 범위가 입력만으로 확정되지 않는 사례다.

61·62번은 이전 잠정 주석의 보류에서 광고로 변경했다. 같은 게시물의 추천코드·보너스 홍보를 자기지시하는 면책 문구와 정보형 서두로 해석한 문맥 의존 경계 사례다. 별개 게시물 제목인 59번과 공통 푸터인 60번은 정상으로 유지했다. 이는 주석 기준의 구체화이며 모델 개선이나 이전 정답의 객관적 오류 입증이 아니다. 18·28·38·45·61·62번에는 경계 사례 표시를 남겼다.

이번 작성에서는 모델 예측 파일을 조회하지 않았지만 이전 대화와 잠정 주석 노출이 있으므로 맹검·독립 평가로 주장하지 않는다. 기존 관찰 31개를 훈련 후보로 바꾸지 않았고, 근거 부족을 강제 이진화하지 않았다. 모든 주석은 전체 저장 입력에 대한 것으로, 토큰 또는 수집 문맥이 잘린 모델 입력의 정답 적합성을 자동 보증하지 않는다. 자동 학습 연결이나 운영 모델 변경은 하지 않았다. 기존 사용자 검수 전용 검증기의 사용자 내보내기 파일과는 별도 형식이다.

검증: 원본 SHA-256 일치, 62개 ID·목적 연결, 비어 있지 않은 근거와 유효한 대상 구간을 확인했다. 별도 브라우저에서 62개 항목 및 24/27/11 표시, 실행 스크립트·활성 외부 링크 없음, 가로 넘침 없음을 확인하고 `preview.png`를 시각 확인했다. 원본 검수 화면과 사용자 브라우저 저장값은 변경하지 않았다.
