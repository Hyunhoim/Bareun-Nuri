# 숫자 치환 대조 자료

첫 실제 평가를 완료했고 보완안은 미채택했다. 개발용/평가용 기법 오탐은 2개/5개, 모호 표기 검토 성공은 1/8·0/8이었다. 결과는 `docs/stage-3-digit-report.md`에 기록했다. 두 분할 모두 이제 진단 자료다.

개발용 `dev/index.html` 44개, 단어 계열을 분리한 평가용 `evaluation/index.html` 44개의 합성 게시글이다. HTML은 브라우저에서 열어 읽을 수 있다. 각 분할에 치환 16개·실제 식별자/숫자 20개·모호 표기 8개가 있다. 같은 표기의 광고/예방 문맥을 쌍으로 만들고, 일부 표기의 단어 용법과 제품 식별자 용법을 대조했다.

`labels.json`은 오프라인 채점용이며 모델 입력이나 웹 응답에 넣지 않는다. 수집 검증은 두 HTML 경로만 허용하는 임시 서버를 사용했다. `build.cjs`는 이미 생성한 폴더를 덮어쓰지 않는다.

평가용은 개발용과 단어 계열이 겹치지 않지만 동일 개발자가 작성한 합성 자료다. 실제 공공 웹사이트 독립 홀드아웃으로 취급하지 않는다. 이번 평가 후에는 모두 분석된 진단 자료로 취급한다. 모호 표기의 정답은 제공된 문맥에 원래 단어/고유 이름을 식별할 근거가 없으므로 `uncertain`이다.

평가 계획과 채택 기준은 `docs/stage-3-digit-plan.md`에 있다. 추론은 `agent/experiments/digit-run.cjs`, 오프라인 채점은 `agent/experiments/digit-score.cjs`를 사용한다. 유료 호출에는 API 키가 필요하며, 실행 파일은 기본 worker에서 호출되지 않는다. 입력·라벨·소스 해시 및 실제 호출 기록은 `.runtime/stage3-digit/`에 보존한다.
