## 4. 일반화 개선의 우선순위

1. **의미 단위 수집과 위치 보존**: article 밖 댓글과 작성자 등도 포함하고, 태그 이름에 덜 의존하는 텍스트 블록 추출과 인라인 span 결합을 적용합니다. 동적 로딩은 무조건 긴 대기 대신 제한된 안정화 조건으로 다룹니다. 목적은 특정 사례 ID가 아니라 다양한 페이지에서 문장을 보존하는 것입니다.
2. **문맥 증거 전달·귀속과 인용 의도 판정**: 댓글/게시글/인용 경계를 담은 상위 문맥, 링크 관계, 숨김에 기여한 조상 스타일을 전달하되 판정 대상과 주변 참고 문맥을 명확히 구분합니다. 설명이 빠진 오류, 설명을 받고도 무시한 오류, 주변 광고를 다른 후보의 증거로 옮긴 오류를 별도 실험으로 검증합니다.
3. **광고 의도와 관찰 기법의 분리**: 검증 가능한 DOM·스타일 근거를 코드에서 일관되게 판정하고, LLM은 이용 권유인지 예방 인용인지에 집중하도록 비교합니다. 숨김이나 자모 자체를 광고로 판정하는 규칙은 추가하지 않습니다.
4. **반복 판정과 출력 부담 절감**: 문맥·스타일까지 동일한 반복 후보를 재사용하고 근거를 압축합니다. 그 뒤 API 한도 내 소규모 병렬화를 비교합니다. 작성자·제목·메뉴를 일괄 제외하거나 signals가 없다는 이유만으로 모두 정상 처리하지 않습니다. 빈 근거와 불확실 판정의 처리 계약도 검토 부담과 함께 검증합니다.

Pipeline 골격을 유지하고 위 단계부터 개선하는 것이 타당합니다. 이번 결과만으로 추가 학습이나 더 큰 모델이 우선이라고 판단할 근거는 없습니다. 각 변경은 한 요인씩 비교하고 F1뿐 아니라 정상 오탐·기존 탐지 회귀·호출·지연을 함께 측정해야 합니다.
