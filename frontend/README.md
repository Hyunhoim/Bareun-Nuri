# Frontend

React + TypeScript + Vite + Ant Design입니다. URL 검사·진행 모니터·그래프·결과 JSON·이력·API 키 관리 화면을 제공합니다. 키 원문은 조회 화면에 전달하지 않습니다.

루트에서 백엔드를 실행한 뒤 `npm.cmd run dev --prefix frontend`로 개발 화면을 엽니다. `npm.cmd run build --prefix frontend`는 타입 검사와 배포 빌드를 수행합니다. API는 localhost 백엔드로 전달합니다. 이미지·글꼴·Orb 출처는 `licenses/`와 루트 `licenses/`에 보존합니다.
