# 공모전 4종 기법 대조 평가 사이트 v1

2026-09-28 작성. **광고 위치 1,000개(각 기법 250개) + 정상 대조 위치 1,000개**다. 생성 시에는 모델 판정·학습·점수 확인 없이 봉인했다. 이후 사용자 요청으로 기존 KLUE와 개선 후보의 최초 평가를 완료했다. 이제 관찰 자료이며 새 미사용 평가로 재사용하지 않는다. 후속 결과는 `../docs/klue-contest-report.md`를 참고한다. 운영 Agent 및 HCX 설정은 변경하지 않았다.

## 먼저 알아야 할 해석 범위

이 자료는 **250개 새 광고 원문 × 4종 기법 + 250개 새 정상 원문 × 4종 기법**의 짝 비교 평가다. 1,000개의 독립 광고 시나리오가 아니다. 25개 광고 계열과 25개 정상 계열에 각각 직접 작성한 10개 원문을 둔다. 같은 원문의 네 변형은 `group_id`로 묶는다. 기법 간 비교에는 유용하지만, 서로 비슷한 계열의 문구와 같은 제작자의 문체가 남는다.

실제 게시물을 수집해 정답을 사람이 검수한 코퍼스가 아니다. 실제 피해자의 내용·개인정보·운영 중인 불법 링크를 재현하지 않는다. 모든 외부 링크는 `reference.invalid`이며 기능하지 않는다. 주최 측 비공개 평가 사이트의 난이도·규모·시나리오를 재현했다고 주장할 수 없다.

이전 학습 생성기를 가져오거나, 기존 모델의 성공/실패를 보고 이번 문장을 고르지 않았다. 다만 동일한 광고 탐지 과제이므로 권유·피해 문의·인용이라는 의미 범주 자체는 겹친다. 문자 중복이 없다는 사실이 의미·문체 독립성을 보장하지 않는다.

## 구성

| 유형 | 광고 | 정상 대조 | 기법 변형: 각 라벨에서 50개씩 |
|---|---:|---:|---|
| HOMOGLYPH |250|250|키릴/유사문자 혼합, 전각, 숫자 치환, 그리스 문자 혼합, 부분 전각|
| JAMO |250|250|문장 NFD, 호환 자모, 일부 단어 호환 자모, 자모 사이 공백, 일부 단어 NFD|
| TRANSPARENT |250|250|투명색, 자체 opacity 0, 흰 배경+흰 글자, 조상 opacity 0, 글자 알파 0|
| OFFSCREEN |250|250|음수 left, 화면 밖 transform, 0px, 1px, display:none|

정상 대조도 같은 기법을 적용한다. **문자가 위장됐거나 숨겨졌다는 관찰 사실만으로 광고 양성이 되어서는 안 된다.** 정상의 `observed_transform`은 편집 내역이며 최종 `expected_findings`는 빈 배열이다. 정상 전각/자모 표기는 악의적 우회라고 단정하지 않는다. 숫자와 제품명 등 본래 표기가 정상인 사례도 포함한다.

광고에는 사설 스포츠 배팅, 라이브 카지노, 슬롯, 회차게임, 온라인 현금 포커, 충전·복귀 혜택, 후기·추천·총판·접속 주소 변경·일반 댓글 뒤 광고, 비동의 성인 촬영물 판매/유료방 유도 등을 넣었다. 광고가 스스로 ‘불법 서비스’라고 선언하는 공통 설명문을 붙이지 않았다. 짧은 파편부터 여러 문장까지 포함하되 장문 문맥 추론을 충분히 평가하는 자료는 아니다.

정상에는 피해 상담, 의심 게시물 민원, 신고된 문구의 언급뿐 아니라 공공 행사, 합법적인 유료 강좌/공공시설 결제, 장비·규격·접수번호, 문자 입력 오류, 접근성·로딩 안내, 일반 생활 민원, 댓글, 개인정보 문의 등을 넣었다. 긴 예방 설명만으로 정상을 구별하도록 만들지 않았다. 근거 부족을 별도 정답으로 갖는 독립 패널은 이번 이진 세트에 없다.

## 사이트와 실행

프로젝트 루트에서:

```powershell
node test-set-contest-v1/server.cjs
```

접속: <http://127.0.0.1:8792/>. 다른 포트는 마지막 인수로 지정한다.

- 메인 1개, 목록 25개, 상세 250개, iframe 문서 248개: 총 HTML 문서 524개.
- 상세 페이지마다 대상 8개. 광고와 정상은 전체에서 섞고, 각 페이지의 양성 수는 고정하지 않았다.
- 본문·제목·댓글·분할 span·표 목록·링크·답글·iframe 8가지 배치. 양성/음성의 역할별 개수는 같다.
- 프레임은 동일 출처다. 동적 댓글·외부 iframe·가상 스크롤·로그인·캡차는 이번 범위 밖이다.
- 부산 시민생각의 목록/상세/분야/댓글 등 공공 소통 게시판 관례를 참고한 **합성 HTML**이다. 실제 사이트 DOM 복제본이 아니며, 8개 배치 유형을 8개 독립 실사이트 템플릿이라고 부르지 않는다.
- 일반 탐색 링크는 로컬 페이지와 목록만 연결한다. 외부 `.invalid` 링크는 연결 대상 비교를 위한 비활성 표본이다.
- 524문서 규모를 주최 측 평가 규모로 예상하지 않는다. 25분 탐색 처리량과 저장 후보의 의미 판정 성능은 별도로 측정해야 한다.

## 파일

- `data/public/`: 실제 제공 HTML. 정답·라벨·기법명·복원 정답은 없음.
- `data/private/gold.json`: 정답 2,000개, 원문, 의미 원문, 기법, 문맥 계열, URL, 프레임 경로, 선택자, 그룹 ID.
- `data/private/routes.json`: 서버 경로 허용 목록. 요청 URL의 쿼리는 보존하고 순서만 정규화.
- `data/private/manifest.json`: 자료 수, 생성 설정, 파일 SHA-256. 생성기는 이미 있는 데이터 덮어쓰기를 거부한다.
- `bank.txt`: 새로 작성한 원문과 비공개 계열 정보. 서버에서 제공하지 않음.
- `verification.json`: 2,000개 실제 브라우저 DOM/스타일 검증 결과.
- `overlap-audit.json`: 과거 KLUE 학습·검증·관찰 자료와의 문구 중복 감사.

`gold.json`의 `base_text`, `is_violation`, `technique`, `scenario_family`, `group_id`는 **모델에 전달하지 않는다**. 운영 수집기가 실제 얻은 원문·주변 문맥·DOM 근거만 모델 입력으로 사용한다. 사람이 쓴 복원 정답이나 프레임 내부 문맥을 강제로 보완하지 않는다.

프레임 항목은 `url`이 상위 페이지이고 `frame_path`가 프레임 URL이다. 운영 결과와 대조할 때 실행 포트를 붙인 절대 프레임 주소와 `>>>`를 사용한다. CSS 문자열 자체보다 같은 요소를 가리키는지 확인해야 한다. 정답 파일은 제출용 `result.json` 자체가 아니라 평가용 메타데이터다.

## 검증 결과

```powershell
node test-set-contest-v1/verify.cjs
.runtime/klue-venv/Scripts/python.exe -X utf8 test-set-contest-v1/overlap.py
```

- Chromium 계열 브라우저에서 250개 상위 페이지와 248개 iframe의 **2,000개 대상 모두** 위치 유일성·원문 일치·문자 변화·계산된 투명도/색상/좌표/글자 크기 확인 통과.
- 각 유형 광고250/정상250, 세부 변형별 라벨당50 확인.
- 정답 경로·소스 파일 HTTP 접근 거부, 공개 HTML의 정답 표식 부재 확인.
- 기존 17개 자료 파일의 고유 대상문구 12,557개와 비교: 새 의미 원문500개 **완전 일치 0개**, 문자 3-gram Jaccard 최대0.267. 이는 문자 수준 검사이며 의미 독립성 검사가 아니다.
- 위 항목은 생성 시 모델 호출0인 DOM 검증 기록이다. 후속 KLUE 최초 평가와 실제 Agent 수집 결과는 별도 보고서에 보존한다. DOM 검증 자체를 Agent 수집 성공으로 해석하지 않는다.

## 봉인·평가 규칙

1. 현재 세트 전체를 새 평가용으로 유지한다. 훈련/검증에 일부를 먼저 사용하지 않는다.
2. 평가 전 모델/전처리/임계값/예산/지표를 고정한다. 모델별 1회 결과를 저장하고 원응답을 보존한다.
3. 광고 의도 F1과 `URL × 위치 × 기법` 최종 성능을 각각 보고한다. 보류도 광고의 미탐 처리에서 빠뜨리지 않는다.
4. 미방문·미수집·미판정 광고를 전체 1,000개 기준 FN에 포함한다. 저장 입력 완주 진단과 25분 종단 결과를 섞지 않는다.
5. 정상 1,000개 기준 오탐률도 별도 보고한다. 지정 대상 밖의 페이지 장식/헤더 등에 난 결과를 자동으로 TP/FP로 확정하지 말고 검수한다. 전체 사이트 정밀도라고 부르지 않는다.
6. 짝 변형은 `group_id` 단위로, 계열 일반화 분석은 `scenario_family` 단위로 묶는다. 같은 원문 네 개를 독립 표본으로 신뢰구간 계산하거나 train/test에 나눠 넣지 않는다.
7. 이미 평가/오류 분석한 뒤에는 관찰 자료로 내려놓는다. 같은 세트에 맞춰 모델을 수정하고 다시 ‘새 최종’이라고 부르지 않는다.
8. 사람이 검수하지 않은 합성 정답임을 밝힌다. 정답 논쟁은 모델 출력과 무관하게 근거를 기록하고, 원본 v1을 덮어쓰지 않는다.

## 출처와 근거의 경계

- 사용자 제공 `공공 웹사이트 불법광고 탐지 도구 개발 공모전 모집요강.hwpx`, 붙임1: 네 기법 정의와 게시글·댓글·iframe 탐지. 붙임4: 위치·기법 판정. 예시 문장을 그대로 학습/평가 원문으로 복제하지 않았다.
- [부산광역시 시민생각](https://www.busan.go.kr/siminopen/siminthink01): 목록, 분야, 제목/내용/작성자 검색, 공감/댓글/상태 등 공공 게시판 구성 참고. 시민의 실제 게시글 내용과 개인정보는 복사하지 않았다.
- [매일경제 공공기관 웹사이트 광고 보도](https://www.mk.co.kr/news/society/11469576): 검색 결과에 유입되는 키워드형 광고와 연락 경로 유도라는 현상 참고. 외부 검색 URL 발굴 기능을 구현하거나, 검색어 반사만으로 무조건 광고 정답을 부여하지 않았다.

모든 구체 문구는 출처 문장의 복사본이 아닌 합성이다. 현금 배팅·판돈/당첨금 정산·비동의 촬영물 판매의 모집은 양성으로, 민원·피해 문의·일반 서비스 설명은 정상으로 설정했다. 실제 법률 판단 또는 모든 성인 콘텐츠/상업 홍보를 불법으로 분류하는 기준이 아니다.

## 남은 편향

같은 작성자가 만든 50계열이며 광고의 도박 비중이 크다. 영문 토큰이 전 원문에 포함돼 닮은꼴 변형을 보장하지만 실제 게시물 빈도와 다르다. 숨김 정상 대조군도 실제 서비스 빈도보다 많다. 기법 난도와 정상 오탐을 통제해서 비교하는 장점과, 실제 발생률/문체/장문 문맥을 대변하지 못하는 한계를 함께 보고해야 한다. 이 세트의 높은 F1만으로 운영 모델 교체를 결정하지 않는다.
