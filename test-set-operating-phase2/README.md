# 운영 테스트 Phase 2 — v1.0

**평가 전용 1,000개: 정상 500 / 광고 500. 2026-10-01 최초 운영 평가 완료(일부 미판정), 학습 0회.**

결과: [Phase2 운영 보고서](../docs/phase2-operating-report.md). 최초 평가를 소비했으므로 이후에는 관찰/회귀 자료로 관리한다.

실제 공공웹 광고의 문맥과 게시 형식을 참고한 **새 합성자료**다. 원문 전문 복사 대신 구조 인용 방식을 사용했다. 100개 시나리오의 광고/정상 200개 원고에 각각 5개 기법 조건을 적용했다. 따라서 **1,000개의 독립 실수집 글이 아니며 독립 의미 원고는 200개**다. 같은 그룹의 파생본은 함께 분석해야 한다. 정상과 광고 모두 같은 기법 분포를 갖는다.

## 출처와 현실성

- **농사로:** 이번 웹 열람에서 반환된 댓글 텍스트를 확인했다. 정상 농업 본문 아래의 홍보, 검색어·링크 나열, 영어 문장 뒤 홍보 연결을 참고했다. 검색 도구의 저장 페이지이므로 실시간 현황이나 발생 빈도를 주장하지 않는다.
- **교육청 배너 게시판:** Phase 1의 기존 브라우저 관찰과 본문 근거를 재사용했다. 이번 웹 도구 재열람은 실패했다. 예방 설명에서 권유로 넘어가는 본문, 후기·FAQ·신규 혜택, 자료관·VIP·새 주소 안내 구조를 참고했다.
- **마약·성매매·통장 거래:** 별도 보도의 광고 형식과 거래/피해 관계를 참고했다. 이번에 이 모든 도메인의 공공웹 원문을 직접 확보한 것이 아니다. 출처의 연도·확인 수준은 `sources.json`에 명시했다.
- 성인물은 합법적인 성인 콘텐츠까지 불법으로 묶지 않도록 **불법촬영/비동의 유포 조건을 합성 문맥에 명시**했다. 그 조건은 실제 교육청 게시물에서 확인된 사실이 아니다. 모호한 실제 성인 배너의 합법성까지 이 자료의 점수로 증명할 수 없다.
- 실제 사이트/판매자 연락처·개인정보·영상은 복제하지 않았다. 로컬 링크는 페이지 이동 또는 `#contact`뿐이다. 외부 광고 사이트로 연결하지 않는다.

## 정상 사례의 목적

피해 후 상담·송금 중단 문의, 광고 삭제/계정 도용/재노출 신고, 교육·번역·자료 문의, 정상 용도와 혼동된 표현, 신고 화면의 이용 문제 등을 포함했다. 질문 자체가 위험 단어를 포함하거나 광고 문장을 언급해도 판매자의 권유로 라벨링하지 않는다. 일부는 대상 다음의 **같은 작성자 문맥**까지 읽어야 목적을 알 수 있게 분리했다. 다른 게시물의 문맥을 빌려 판정해서는 안 된다.

## 기법·HTML 계약

- H: 영문/키릴·그리스 문자 시각 대응, 전각, 숫자 0/1/3/4 시각 치환. `Ka지노`처럼 발음으로만 바꾸는 표기는 제외했다. 숫자 대응 전부가 Unicode 표준표에 있다는 주장은 하지 않는다.
- J: 호환 자모, NFD, 음절 간격, 부분 음절 분해. 원문과 실제 변경 문자를 gold에 보존한다.
- T: opacity 0, 투명 글자색, 동일한 글자/배경색.
- O: 음수 왼쪽 좌표, display:none, 글자 크기 0/1px. 요강에 맞춘 실험 정의다.
- 모든 문자 변형과 CSS는 **요강에 근거해 추가한 합성**이다. 원 사이트에서 그 스타일을 발견했다는 뜻이 아니다.
- 일반 HTML 102페이지(목록·메인 포함), iframe 20문서. 본문·제목·댓글·답글·링크를 섞고, 인라인 분할 및 120ms 뒤 삽입되는 댓글 40개를 포함한다. 글과 댓글의 작성자 범위는 독립이다.
- 대상 텍스트/좌표/스타일을 브라우저가 수집해야 한다. `inputs.jsonl`은 입력 명세이며 실제 운영 수집 결과가 아니다. 위치 셀렉터는 **비공개 평가 매칭용**이며 모델 입력의 정답 단서로 사용하면 안 된다.
- `techniques`는 정상에도 있는 관찰 기법, `finding_techniques`는 광고에만 적용되는 제출 탐지 정답이다. 의도와 기법을 분리한다.

## 파일

- `cases.txt`: 100개 광고/정상 원고 쌍. 정답 포함, 공개 서버에 올리지 않는다.
- `public/`: 정답 없는 검사 사이트.
- `private/gold.jsonl`: 1,000개 정답·근거·변환·출처·위치.
- `private/preview.md`: 대표 10개 원문/기법/문맥, 사람 검수용.
- `private/status.json`: 평가/학습 소비 이력. 평가 1회·학습 0회.
- `quality.json`, `private/dom-audit.json`: 정합성 및 실제 브라우저 스타일 검사. 탐지 성능 측정이 아니다.
- `manifest.json`: 데이터/HTML/생성기 해시. 실행 시 버전을 고정한다.

node test-set-operating-phase2/audit.cjs

## 해석 한계와 사용 규칙

사람 독립 정답 검수 전이다. 최초 생성 당시 모델 성능은 미측정이었으며, 이후 측정은 위 운영 보고서를 참고한다. Phase 1과 완전 동일한 대상 문장은 없지만 **같은 제작자·출처·의미 계열의 편향**은 남는다. 짧고 명확한 권유와 설명이 있는 정상 문의 중심이라 실제의 생략·암시·정상 글 비율을 모두 대표하지 않는다. 초기 원고에서 정상 쪽이 길었던 편향을 관찰해, 짧은 정상 문의와 더 긴 홍보/FAQ/피해 서술을 보강했지만 완전한 길이 균형을 주장하지 않는다. 영어 토큰과 거래 조건도 일부 명시적으로 배치했으므로 완전히 자연 발생한 글의 분포는 아니다. 정상 50%의 어려운 대조 비중은 실사이트 정밀도와 다를 수 있다. 5개 변형은 독립 문장으로 표본 수를 부풀려 해석하지 않는다.

운영/모델/임계값을 먼저 동결한 뒤 평가하며, 실패 문구를 그대로 학습하지 않는다. 소비 후에는 회귀 자료로 기록한다. 향후 평가는 전체 의도 F1, 각 기법/조합, 도메인, 문맥 분리, 100개 그룹별 손익을 따로 보고한다. 미방문·미판정은 전체 기준에서 누락으로 계산하고 25분과 재개 결과를 구분한다.
