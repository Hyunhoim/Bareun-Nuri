## v0.2 과거 기록

## 검증 범위

HCX-007 환경변수 연결, 실제 function calling, 조회한 근거의 최종 JSON 요청 전달, 동일 조건의 세 구조 실행을 검증했습니다. 수정은 `agent-experiments/`에 한정했습니다. 테스트 사이트의 정답 라벨은 런타임이나 모델에 전달하지 않습니다.

현재 소규모 실행은 **연동 검증이며 탐지율 평가가 아닙니다.** 개발 사이트 전체 13페이지에서 수집된 226개 후보 중 공개 DOM 힌트를 이용해 4종 기법별 서로 다른 후보 2개씩과 힌트 없는 후보 4개, 총 12개를 고정했습니다. 힌트는 정답이 아니므로 각 기법의 실제 광고 2개를 확보했다는 뜻은 아닙니다. 전체 개발셋에 대한 세 구조의 완주 및 정확도 비교는 아직 검증되지 않았습니다.

## 구현 및 공통 조건

- 인증: 기존 `.env`의 `CLOVASTUDIO_API_KEY`; 고정 모델 `HCX-007`. 공식 v3 API에 Bearer 인증으로 전송합니다.
- 요청: `thinking.effort=none`, `temperature=0`, `maxCompletionTokens=2048`. 추가 SDK 없이 Node의 fetch를 사용합니다.
- 소규모 검증: 구조당 최대 40회, API 요청당 60초, 구조당 전체 10분, 요청 시작 간격 30초, 배치 크기 12. 전문가 요청도 구조 내 공통 간격을 사용합니다.
- 입력: 세 구조가 동일한 원문·스타일·문맥·프레임 정보를 담은 고정 스냅샷을 사용합니다. 공통 모델 설정과 입력 해시를 비교합니다. 역할 프롬프트와 실제 추가 조회/호출 수는 구조에 따라 다릅니다.
- 조회 제한: 후보당 성공한 조회 최대 2회(전문가 역할 전체 공유), 대화당 최대 2라운드. 초과 조회에는 한도 소진 결과를 반환합니다. 임의 URL·파일·코드는 실행하지 않습니다.
- 최종 출력: HCX의 구조화 출력 요청은 도구 및 tool-call 이력과 함께 사용할 수 없어 분리했습니다. 최초 입력과 실제 도구 결과를 `additional_evidence` 데이터로 전달한 뒤 JSON 스키마로 판정합니다. 필수 요소 ID를 객체 키로 강제하고 공통 판정 배열로 변환합니다.
- 오류: HTTP 오류는 자동 재시도하거나 mock으로 바꾸지 않습니다. 판정 형식 오류는 최초 입력을 유지하여 한 번만 보정하며, 호출 수와 토큰 사용량에 포함합니다. 실패한 실행에는 성공처럼 보이는 result.json을 생성하지 않습니다.
- 불확실성: 빈 근거, 미해결 재검토 및 광고이지만 대상 기법이 없는 판정은 확정 검출과 구분하여 diagnostics.json에 보관합니다.

30초 간격은 이번 작은 검증에 적용한 값입니다. 일반 `run`의 기본 간격은 8초이며 환경변수로 조절합니다. 입력 크기에 따른 TPM이나 다른 프로세스의 사용량을 자동 계산하는 제한기는 구현하지 않았습니다. 한도를 낮춘 실험의 대기 시간을 모델 자체 응답 속도로 해석하면 안 됩니다.

## 확인된 문제와 해석

1. 전체 226개 개발 후보 실행은 응답 개수 누락, 빈 근거, 불확실성 판정 처리, 중복 ID 문제로 여러 차례 중단됐습니다. 공통 검증기와 ID 기반 JSON 스키마를 수정했지만, 수정 후 전체 226개 세 구조 실험을 완료한 기록은 없습니다. 기존 실패 기록은 `outputs/hcx-dev-20260921*`에 그대로 남아 있습니다.
2. 12개 후보를 8초 간격으로 실행한 첫 비교에서는 Pipeline/Adaptive가 완료됐고 Specialists가 HTTP 429로 실패했습니다. 기록: `outputs/hcx-validation-1789974753819`. 이에 세 구조 모두 30초 간격으로 다시 실행했습니다.
3. Pipeline이 “예방 교육 … 가입하지 마세요”라는 인용 문구를 광고로 판단한 사례가 있습니다. 이는 실제 문맥 오판이며 JSON 파싱 성공으로 해결되지 않습니다. 결과를 본 뒤 해당 예제만 맞추도록 프롬프트를 수정하지 않았습니다.
4. 전문가들이 공유 조회 한도를 먼저 소진하면 다른 전문가의 조회가 거절됩니다. 거절 횟수와 실제 근거가 반환된 횟수는 구분해야 합니다. 현재 구조 비교의 제한 조건이며 무제한 전문가 조사 결과가 아닙니다.
