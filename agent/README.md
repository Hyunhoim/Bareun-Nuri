# Agent Core

운영 진입점은 `src/worker.cjs`입니다. 백엔드가 표준입력으로 작업 요청을 전달하며 진행 이벤트를 표준출력으로 반환합니다. 직접 실행하면 입력을 기다립니다.

FIFO·재사용 브라우저 수집 → 원문/귀속/정규화 보조 읽기 → Luna 연속 문맥 광고 의도 → DOM/문자 관찰 + CPU AntiSpoof → 저장/재개 순서입니다. 고정 설정과 설치 방법은 루트 README를 따릅니다.

`models/kcelectra-antispoof-v1`은 Git LFS 모델과 SHA-256 manifest를 포함합니다. API 키는 `.env`에만 저장하고 공유하지 마세요. `npm.cmd test --prefix agent`는 외부 API를 호출하지 않습니다.
