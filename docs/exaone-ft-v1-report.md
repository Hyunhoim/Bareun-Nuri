## 남은 일반화 병목

1. **제목/주변 문맥이 명시적 권유를 덮음.** ‘피해 상담 접수’ 문맥의 사설 도박 권유·비동의 영상 판매가 여전히 누락됐다. 같은 문맥의 긴 정상 서두 뒤 도박 권유도 새로 누락됐다.
2. **짧은 신청 문구와 뒤쪽의 불법 서비스 설명 연결 실패.** 실제 도박 모집 담당이라는 뒤 문맥이 있어도 예방 인용으로 오판한 새 정탐 손실1개가 있다.
3. **피해 문의/예방 표현의 미학습 소재 대응 부족.** 복권 피해 문의, 위조 입국 서류 상담, 판매 제안을 이용자 경고에 넣어 달라는 글이 오탐으로 남았다.
4. **정상 유료 거래 구별 부족.** 테니스장 대관료 분담과 본인이 촬영한 철새 사진 판매를 광고로 오판했다. 같은 사진 문구의 다른 문맥에서 새 오탐1개가 생겼다.
5. **보류 부족.** 근거 부족37개 중29개는 여전히 확정 판정(광고9/정상20)했다. 높은 광고 이진F1에 이 문제가 숨지 않게 별도 보고한다.

원인 해석은 관측된 입력/출력에 기초한 가설이며 내부 추론의 증명이 아니다. 이 실패 문구를 이번 학습에 다시 넣거나 추가 학습률 탐색을 하지 않았다.
