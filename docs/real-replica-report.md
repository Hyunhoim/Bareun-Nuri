# 실사이트 및 실제 DOM 복제본 비교 결과 — 2026-09-24

**최종 선택: FIFO 유지.** 이번 실험과 이전 합성 실험을 종합해도 운영 교체 관문을 통과한 후보가 없다. 새 알고리즘이 효율과 기존 위치 보존을 함께 개선할 것이라는 충분한 근거도 확보하지 못했으므로, 알고리즘을 계속 추가하는 세 번째 선택도 채택하지 않는다. FIFO의 수학적 최적성이나 실사이트 전체 광고 재현율을 입증한 결과는 아니다.

## 1. 실행 범위

사전 기준은 [real-replica-plan.md](real-replica-plan.md). FIFO/기존 문맥 Bandit/기존 URL 구조별 순환 FIFO의 코드는 변경하지 않았다. 운영 collector·worker·판정기 변경0, HCX/API 호출0, 토큰0. 공개 사이트 GET 관찰만 시행했고 광고는 로컬 복제본에만 넣었다. 원격 HTML/수집 근거/복제본은 Git 제외 .runtime/real-replica-v1에만 보관했다. push/공개 호스팅은 하지 않았다.

| 60초 | 2/40 | 33.33% | 37.50% | 18.75% |

60초 비교는 공통2조건뿐이라 채택 근거로 부족하다. 이 표 역시 수집시간 합계의 대용치이며 HCX 판정과 큐 계산 시간을 포함한 실제 종단 시간이 아니다.

최초 집계의 원격 URL 복원에서 로컬 포트가 남아 시간 조회가 실패하는 오류를 발견했다. 원본 rows.json을 보존하고 time-audit.cjs로 시간 필드만 재계산한 rows-audited.json을 위 표에 사용했다. 시간 외 모든 필드의 hash 일치를 확인했으며 정책·방문 순서·도달률·FIFO 손실·채택 관문은 바뀌지 않았다. 이를 정책 개선 재실험으로 세지 않는다.

## 8. 수집·무결성 검증

- 실제 복제 DOM 광고/정상 대조 128곳을 운영 collector로 검사: 통과, 누락/원문/신호 불일치 0곳. selector·분할 span 원문 결합·4종 signals를 확인했다. signals는 최종 기법/불법광고 판정과 다르다.
- 모든 링크 순서의 중복 제거 240회, 10→20 직렬화 재개 240회, 예산 접두부 480회 통과.
- 원래 링크 순서에서 전체 charged 방문 집합 24회 통과. 다른 순서의 전체 순회를 모두 반복한 것은 아니다.
- 독립 집계 480행 재계산 및 실제 core runner 12조건 중단/재개 일치. LLM 후보를 전달하지 않은 실행 제어 검사다.
- 원격에서 기록한 요청/최종 URL을 그대로 쓰는 별도 redirect-audit 12조건도 통과했다. 리다이렉트 시도21회가 포함됐고 최종 페이지 중복0, 연속 실행/10→20 재개 순서가 같았다. 이는 운영 core의 주소 처리 검증이며, 동결 복제 서버의 리다이렉트 미재현 한계를 없애지는 않는다.
- 원본/정책/평가 입력 해시 실행 전후 대조. 단위 검사에서 발견된 라벨 부족분 채우기 오류는 점수 산출 전에 수정했으며 결과에 맞춘 정책 변경은 없다.

## 9. 채택 판단

| 후보 | 조건별 평균 | FIFO 위치 보존 | 기관별 +5%p | 최저값 | 경계≤10% | 무결성 |
| --- | --- | --- | --- | --- | --- | --- |
| 문맥 Bandit | 실패 | 실패 | 실패 | 실패 | 실패 | 통과 |
| URL 구조별 순환 FIFO | 실패 | 실패 | 실패 | 실패 | 실패 | 통과 |

이전 v5 합성 비교에서도 후보들은 50페이지에서 기존 FIFO 광고 위치를 잃었다. 이번의 실제 DOM 복제본 결과와 합쳐 운영을 교체할 근거는 확보되지 않았다. 서로 다른 예산/자료의 점수를 하나의 평균으로 합치지 않는다.

새 알고리즘을 제안하지 않는 이유는 실패 원인에 수집 경계, JS 이동, 보상에 쓰이는 본문 표현, 광고 위치를 사전에 모르는 탐색의 상충이 섞여 있기 때문이다. 다른 우선순위 규칙이 어떤 미방문 페이지에 광고가 있는지 알아낼 수 있다고 예상할 근거는 없다. 관찰한 주소/템플릿에 맞춘 가중치 조정은 과적합 위험이 크다. 새로운 알고리즘의 우월성을 가정해 실험을 늘리기보다 FIFO를 유지하는 결론이 현재 증거에 맞다.

실사이트 실제 광고의 전체 정답·정밀도/F1, JS 클릭/로그인/늦은 댓글, 복제하지 않은 프레임, 종단 HCX 판정과 비용은 미검증이다. 현재 알려진 의미/기법 판정 오류도 해결됐다고 주장하지 않는다.
