# 네 가지 탐색 정책 얕은 비교 — 2026-09-23

결과 확인 전 고정한다. 운영 기본값 FIFO, 수집·판정·범위 계약은 유지한다.

## 가설과 정책

- FIFO와 기존 DOM 그룹 UCB는 기존 구현 그대로 사용한다.
- context-bandit: 링크별 문맥 특징을 사용하는 shared linear UCB. ridge lambda=1, alpha=0.5. 목적지 방문 전에는 출발 페이지에서 관측한 정보만 사용한다.
- best-first: 같은 ridge 예측기·특징·학습 순서를 사용하고 불확실성 가산 alpha=0만 적용한다. 두 정책 모두 매 5번째 FIFO, 동점은 최초 발견 순서. 초기 예측 0, 외부 사전학습 없음, 각 사이트/조건마다 모델 초기화.
- 특징: bias, content_scope, 출발 페이지 detail 여부, 링크 문자열 길이, 주변 블록 문자열 길이, 주변 블록 링크 수, 출발 페이지 링크 수 및 링크/주변 블록/출발 페이지 제목의 문자 bigram signed hashing 48차원. 총 55차원, 전체 L2 정규화. URL/ID/정답/목적지 내용은 특징에서 제외한다.
- 보상은 기존과 같은 중복되지 않은 상세 본문 발견 0/1. 광고 여부를 보상으로 바꾸지 않는다. 새 정책 둘 사이에는 불확실성 가산만 다르지만 기존 Bandit과는 특징·모형이 함께 달라지므로 순수 문맥 효과를 식별했다고 주장하지 않는다.
- 특정 태그·문구·깊이·누락 URL에 가산점 없음. 주변 문맥은 main 문서의 실제 렌더링 DOM에서 수집하며 탐지 LLM 입력에 추가하지 않는다.

## 데이터·비용·순서

- `.runtime/scope-trial-v2`의 기존 27/28페이지, 총 297개 후보, 정답 48개(광고24/정상24)를 고정해 재사용한다. 같은 사이트를 열어 링크 문맥만 보강하고 원본 링크 증거와 일치 검증한다. 평가 정답은 스케줄러와 LLM 입력에 전달하지 않는다.
- 이미 관찰한 합성 진단 자료이며 독립 홀드아웃이 아니다. 이 결과를 보고 특징/alpha/보상을 반복 조정하지 않는다.
- 오프라인 전체 탐색 및 6/12/18/24페이지 접두부: 광고 도달·깊은/프레임 도달·대기/미발견을 사후 채점. 정답과 전체 그래프는 사후 채점에만 사용.
- 실제 비교: 각 12페이지/2000후보/20호출/600초. 전체 80요청/500000토큰, 미응답은 예약량 포함. 기존 HCX-007, temperature0, seed42, reasoning none, 출력3072, 배치16, 순차 TPM52000. 미확인 전송 자동 재시도는 끄고 기존 제한된 429 및 형식 보정은 예산에 포함한다.
- mixed-0: FIFO→Bandit→context-bandit→best-first. mixed-1: best-first→context-bandit→Bandit→FIFO. 단회 실행, 순서 효과/모델 변동은 제거되지 않는다.
- 모든 조건에서 같은 브라우저 증거 캐시를 쓰고 판정은 새 API 호출. 시간은 캐시 기반 탐색+판정+저장이고 실제 사이트 브라우저 포함 종단 시간이 아니다. 문맥 수집 준비 시간을 별도 기록.
- 오류/예산 초과 시 해당 원본을 보존하고 실패를 보고한다. 성공할 때까지 유료 반복하지 않는다.

## 검증·채택·종료

- 기존 FIFO/Bandit 12페이지 순서가 이전 실험과 같아야 한다. 새 정책 모델 직렬화 재개, 방문 중복/범위, 전체 방문 집합, 후보/판정 입력 보존을 확인한다.
- 선형 갱신은 직접 행렬 관계로 검증. 선택에는 방문 이전 벡터만 사용하고 보상은 방문 후 반영. 저장 상태만으로 같은 순서를 재현해야 한다.
- 의미 P/R/F1과 위치×기법 P/R/F1, 전체 미방문 FN, 정답 밖 양성, 정상 검토, 기존 양성 손실, 호출/토큰/시간을 보고한다.
- 기존 채택 기준 유지: 사이트별 의미/최종 F1 비감소, 정밀도 하락≤2%p, FP 증가≤1, FIFO의 기존 의미/기법 정탐 손실0, 합산 최종 F1≥+2%p, 합산 토큰·시간≤+15%. 새 대안은 기존 Bandit과의 결과도 별도 비교한다. 미통과 시 FIFO 유지.
- 한 차례의 사전 고정 비교로 종료. 결과 보고 후 운영 정책 교체·가중치 튜닝·추가 유료 확대·push는 하지 않는다. 새 정책은 실험 파일에 격리한다.
