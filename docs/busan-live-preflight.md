# 부산 시민생각 실제 사이트 수집 사전 점검

2026-09-23. 사용자 제공 URL: https://www.busan.go.kr/siminopen/siminthink01

## 결론

실제 HTML·탐색 호환성을 검증하기에 유용한 공개 게시판이다. 일반 링크로 목록·게시글·페이지 이동을 발견할 수 있었다. 다만 현재 운영 수집기는 검사한 긴 게시글에서 중단되므로 전체 정확도 실험으로 확대하지 않았다. 실제 HCX 호출은 0회이며 광고 유무·F1·정밀도는 판정하지 않았다.

## 실제 확인

운영 수집기의 readDocument/observeDocument/settlePage, 동일 출처 GET 제한, 1440×1000 브라우저 조건을 재사용했다. 자동 재귀 탐색 대신 관찰한 링크만 소량 방문했다. 서로 다른 페이지는 목록 1·2페이지와 첫 목록의 상세 게시글 2개, 총 4개다. 목록 재확인과 운영 수집기 재현을 포함해 로컬 브라우저의 최상위 탐색은 7회였다.

| 페이지 | HTTP | DOM에서 추출한 텍스트 단위 | 가장 긴 상세 본문 |
|---|---:|---:|---:|
| 시민생각 목록 1페이지 | 200 | 225 | — |
| 목록 2페이지 | 200 | 225 | — |
| 상세 1754929 | 200 | 80 | 13,106자 |
| 상세 1753719 | 200 | 80 | 27,816자 |

브라우저 안정화 조건은 모두 통과했고 검사한 페이지에 지원 밖 iframe은 없었다. 위 텍스트 수는 DOM 검사 결과이며 운영 수집·LLM 판정을 완료한 후보 수가 아니다.

상세 URL과 `?curPage=2` 등 페이지 이동은 일반 a[href]로 제공된다. 현재 목록의 상세 링크는 tbody 안에 있어 사이트별 URL 예외 없이 구조 근거를 얻을 수 있다. 표본 두 상세 페이지에는 댓글 0건으로 표시돼, 실제 댓글 본문 수집 능력까지 검증한 것은 아니다. 댓글 작성·공감·검색 등 양식을 제출하지 않았다.

운영 정책에 따라 외부 스크립트와 비GET 요청이 차단됐다. 만족도·공감 관련 경로도 차단 목록에 있었으므로 이 동적 기능이 완전하게 로딩됐다고 주장하지 않는다. 차단을 없애거나 POST 요청을 허용하는 변경은 하지 않았다.

## 운영 경로에서 재현된 중단

첫 상세 URL을 실제 `collect`로 검사했다. `maxPages:1`, `maxNodes:10000`, `scope:'/siminopen/'` 조건에서 아래 오류가 발생했다. 페이지 한도 초과 오류가 아니라 본문 길이 제한에서 먼저 중단됐다.

```text
Paragraph exceeds 12000 characters; explicit chunking is required
```

이 오류는 `agent/src/core/collect.cjs`가 단일 텍스트 단위의 길이를 검증하는 기존 경로에서 발생한다. 실제 본문 일부를 버리거나 한도만 올려서 성공 처리하지 않았다. 긴 텍스트를 분할할 경우 원문 offset/selector, 주변 문맥, 분할 결과 통합과 중복 처리를 함께 검증해야 한다. 이 사례는 새로운 일반화 병목의 증거이며 특정 게시글 ID나 부산 경로에 대한 예외 처리 근거가 아니다.

## 다음 검증에 필요한 범위

1. 긴 텍스트의 원문·문맥·위치를 보존하는 일반적인 처리 계약을 독립 검증한다. 경계 양쪽 광고, 정상 인용, 제목·댓글 귀속과 기존 짧은 문장의 회귀를 포함한다.
2. 게시판 한정과 메인 홈페이지 시작을 구분한다. 현재 기본 범위는 `/siminopen/`이어서 자료실·시민토론도 탐색 대상이다. 메인에서 게시판에 빨리 도달하는 5단계 효과는 이 게시판 URL만 검사해서 알 수 없다.
3. 명시적인 탐색 예산과 중단/부분 결과 계약을 갖춘 뒤 고정 스냅샷을 수집한다. 운영 worker는 전체 수집 후 판정하며 페이지 한도에 걸리면 실패한다. 이번 사전 점검은 이 동작을 바꾸지 않았다.
4. 모델 결과와 별개로 정상·광고·불확실 정답을 검수한다. 현재 표본을 전부 정상으로 자동 라벨링하지 않는다. 알려진 광고나 4종 위장 기법의 양성이 없으면 해당 재현율/F1 검증 근거가 부족하다.

## 기록과 변경 범위

로컬 Git 제외 경로 `.runtime/busan-preflight/`에 제한된 검사 스크립트, 링크·텍스트·위치 증거, 차단 경로, 운영 오류 재현을 저장했다. 공개 보고서에는 게시글 원문과 작성자 정보를 복제하지 않았다. 운영 소스·실험 가중치는 변경하지 않았고 HCX에 원문을 전송하지 않았다. 모든 검사 브라우저는 종료했다.
