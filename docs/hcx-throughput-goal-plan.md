# HCX 처리량 Goal: 사전 계획

2026-10-01 사용자 승인. 현재 운영 HCX-007 동시3(3개 wave 완료 후 순서 커밋)를 동결하고, 테스트 API 한도 안에서 정확도와 영속성을 보존할 개선 후보를 찾는다. 목표 달성 전까지 Goal 상태와 실험 실패를 명확히 남긴다. 끝없이 같은 평가에 맞춰 수정하지 않는다.

## 고정 조건

HCX-007 none/temperature0/seed42/최대12후보/출력512, 공유58k TPM/61초 창/1초 발송 간격. 제공사 기본60k TPM/60RPM 범위이며 서비스 API 증설은 사용하지 않는다. FIFO/수집5/SRPT8/aging8/미완료8페이지/CPU AntiSpoof1.0 유지. 정상 후보 임의 제외, 판정문구·정답ID 맞춤 규칙, 학습, Phase2 평가 금지.

Phase1은 이미 관찰된 회귀·처리량 자료다. 여기서의 개선을 새로운 독립 일반화 입증으로 표현하지 않는다. 원래 전체 gold와 미판정 FN 처리 유지. 각 후보는 별도 파일이며 채택 전 운영 수정하지 않는다.

## 독립 병렬 진단

1. 실행: 느린 요청의 wave 대기 제거, 완료 결과의 조기 반영 또는 빈 요청 슬롯 보충. 같은 페이지 접두·배치·요청별 상태·전송불명 재호출 금지·durable 재개·마감 보존 검사. 실제 응답 지연을 재생한 속도는 모델링/재생으로 명시한다.
2. 저장/CPU: account/persist/store/output/publish와 CPU 시간을 구분해 계측. 필수 요청 상태·결과 저장을 유지하고 사용자용 전체 재출력 빈도를 제한하는 최소 후보부터 비교한다.
3. 요청량: 기존 축약 실패를 확인한 뒤 출력상한 또는 손실 없는 입력 축약의 여지만 감사. API0 재생으로 현재 출력이 들어간다는 사실은 새 생성의 완전성 증명이 아니다. 이득이 작거나 해석 위험이 크면 유료 확대하지 않는다.
4. 수집: 기존 readiness 계측에서 잠재 절감과 동적 콘텐츠 손실 위험을 대조한다. 근거 보존 가능성이 불명확하면 무조건 대기 축소 후보는 제외한다.

독립 작업은 병렬 진행하되 유료 API 조건은 한 계정의 할당량을 공유하므로 순서대로 수행한다. 무거운 CPU 측정도 서로 겹치지 않게 한다.

## 사전 채택·종료 기준

- 구조 변경 API0: 동일 응답 재생의 광고·기법·근거·최종 결과 100% 보존, 중단 재개 중복0, 미확인 자동 재전송0, 한도 위반0. 저장 호출 순서나 파일 타임스탬프 차이는 의미 결과와 구분한다.
- 속도 후보: 반복 재생에서 기존 대비5% 이상 단축 또는 실제 deadline 이전 완료 결과 회복이 명확할 때 확대. 효과 없으면 해당 방향 종료. 모사 결과를 실측 개선율로 보고하지 않는다.
- 입력/출력 변경: 동일 요청 집합 ABBA 소규모 최대96호출에서 각 쌍의 기존 정탐 손실0/새 오탐0/응답 오류 증가0 및 평균5% 이상 지연 감소를 요구한다. 기준 미달이면 종료하고 구조 개선에 집중한다.
- 최종 비교: 현재 운영과 최선 후보를 동일 Phase1 URL·25분씩 새 실행한다. 전체 광고 TP와 F1 증가, 정밀도 하락 1%p 이내, 공통 판정의 의미 변경은 손실·획득·정상오탐으로 별도 집계한다. 요청 동일성이 유지되면 의미 변동을 구조 자체 효과로 단정하지 않는다. 격리/전송불명/재개안전성 악화가 있으면 원인 해결 전 승격하지 않는다.
- 후보가 가망 없으면 무리한25분 확대를 하지 않는다. 결과를 보고 성공 기준을 낮추지 않는다. 동일 평가문구를 수정하여 성공시키지 않는다.

## 이번 라운드 자원 상한

유료 진단 최대96호출 + 새25분 기준선/후보 각각600호출 = 최대1296호출. 실제 사용 토큰은 각 요청에 기록하며 전체 약500만 토큰을 안전 상한으로 두고 다음 조건 시작 전에 잔여 예산을 확인한다. 단일25분 실행은 기존270초 정리 여유 외 추가 재개 없음. 이미 전송했으나 응답 불명인 요청은 자동 새 실행하지 않는다. 추가 라운드는 이번 결과를 근거로 범위를 다시 고정한다.

Goal 성공은 실제 검증된 개선 후보의 운영 채택 및 보고다. 안전한 개선을 찾지 못한 경우 성공으로 표시하지 않는다.
