# HCX 동시 2·3·4·5 비교 사전 계획

2026-10-01. 앞선 1대2 실험의 저장 요청24개/238후보를 변경 없이 재사용한다. 이미 관찰한 Phase1 회귀 자료이며 새로운 일반화 평가가 아니다. 정답과 대응되는95위치(광고50/정상45), 미라벨143후보를 구분한다. 정답은 요청에 전달하지 않는다.

- HCX-007 none / temperature0 / seed42 / 최대12후보 / 출력512 고정.
- 공유 예약58,000 TPM / 61초창 / 발송1초간격, 조건 사이61초 냉각.
- 조건 순서2→3→4→5→5→4→3→2, 총192회. 조건 내부의 원문·배치·발송 순서 고정.
- API 호출200회/확인 사용토큰700,000/30분 안전 상한. 다른 유료 실험을 동시에 실행하지 않는다. 미확인 요청·격리 묶음 자동 재호출0.
- 원응답, 요청별UUID/전역조건순번/본문SHA, 상태를 원자적 파일 교체로 저장한다. 일부ID누락은 기존 계약과 같이 묶음 전체 격리하고 다음 묶음으로 진행한다. 다른 오류는 확대 종료한다.

## 선택 기준

동시2 대비 두 반복 모두 라벨이 있는 정탐 손실·추가 오탐·응답 실패 증가가 없는 후보만 우선 적격으로 본다. 미라벨 판정 변동, 격리, HTTP429, 출력 잘림도 별도로 보고한다. 속도는 실제 wall을 사용하며 겹친 service/queue 합을 wall에 더하지 않는다.

적격 후보의 평균 처리시간 중 최선과5% 이내인 가장 낮은 동시성을 선택한다. 반복간 차이가 결론보다 크면 채택 근거 부족으로 동시2 후보를 유지한다. 결과를 보고 임계값을 변경하거나 동일 문구에 맞춰 프롬프트를 튜닝하지 않는다.

이번 결정은 요청 동시성의 후속 통합 후보 선택이다. 현재 운영의 단일 inflight 및 격리번호 귀속 한계가 있어 숫자만 바꿔 운영에 적용하지 않는다. 실제 중단·재개와25분 종단 검증 전까지 순차 운영을 유지한다. Phase2/학습/API모델교체/탐색정책변경은 수행하지 않는다.
