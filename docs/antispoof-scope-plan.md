# AntiSpoof 대상 귀속 개선 Goal 및 1차 실험

2026-09-30 사용자 요청. 목표는 AntiSpoof v1.0의 구간 밖 근거 혼입을 줄이고 기존 J/H 정탐과 정상 표기를 보존하는 것이다. Goal 도구는 기존 미완료 blocked Goal 때문에 새 목표 등록을 거부했다. 기존 목표를 성공으로 종료하지 않으며 이 문서에 새 작업 목표를 고정한다. 작업은 진행한다.

운영 v1.0 가중치/입력/코드는 유지한다. 1차는 학습자료 요인만 변경한다. 기존 가중치에서 (A) 기존2603행+동일 수 업데이트를 위한 기존행 재추출, (B) 기존2603행+새 구간대조를 비교한다. 학습 횟수 증가의 효과와 자료 효과를 분리한다. 두 조건 seed42/lr1e-5/batch8/전체학습/최대2epoch, 실행별30분 상한, GPU 순차 실행이다. H.20/Jargmax를 고정한다.

새 자료는 같은 문장에서 자모만/영문만/둘 다를 표시하며 주변 영문을 일반/치환으로 바꾸고 어순과 모집·교육·일반 문맥을 교차한다. 원문 파생 그룹·한글/영문 어휘·문장틀을 학습과 개발에서 분리한다. 기존 학교/c0ral 등 진단 문구와 기존 평가 표기는 학습하지 않는다. 새 자료는 동일 생성자의 합성이므로 외부 독립 검증으로 부르지 않는다. 기존 최종860은 열지 않는다.

개발은 기존624, 기존역할300, 새구간대조의 기법별 F1·구간밖 H오확정·보류·기존정탐손실을 본다. 개발선택은 세 패널의 두기법 양성 평균F1(기존역할300은H만)의 평균, 동률이면 작은기법F1/낮은오확정 순이다. 유망 기준은 새구간 H오확정 절반 이상 감소, 기존두 개발패널 각 F1 하락2%p 이하, 전체 개발 평균 향상이다. 결과를 보고 기준을 낮추지 않는다. 후보별 최선epoch를 고른 뒤 기존 관찰회귀에서 정탐 손실과 HCX연결을 확인한다. 실패시 운영 유지, 공통 원인을 검토해 다음 요인을 별도 계획한다.

개발에서 유망해도 즉시 운영 교체하지 않는다. CPU 속도·저장 입력 회귀와 최종 독립자료 확보 여부를 확인하며 실제25분 조건의 전체 기법결합 결과를 별도 검증한다. 새 최종을 연속 생성·소비하지 않는다. 분석 문구 직접학습·단어별예외·J/H 상호배타 규칙을 금지한다.
