# D 본체 보존 학습

2026-09-29. 가설: 작은 합성자료로 모델 전체를 재학습하면 기존 의미 표현을 잃는다. D의 roberta 본체를 고정하고 classifier만 학습한다. 기존160개 train만 사용, 새 평가문구 학습 금지. 3epoch/lr1e-5/seed42/batch8/AdamW .01/gradient clip1 고정. 새로운 라이브러리나 운영 변경 없음.

정상은 ordinary 확률을 높이고 필수전달은 ordinary 이외 확률을 높이는 이진 목적을 사용한다. 기존4분류 출력을 유지하는 KL을 동일 가중치로 더한다. 본체 dropout도 비활성화한다. 정상/인용 세분 의미가 훼손될 위험이 있으므로 기존4분류 모델 대체를 주장하지 않는다. 모든 epoch를 개발자료로 반복 선택하지 않고 3epoch checkpoint 하나만 비교한다.

개발50+관찰221+2000에서 일반정보 argmax 및 일반정보점수 .9 이상인 필수전달의 최소 광고점수0.8배로 경계를 고정한다. 경계보정 D와 동일 산식이다. 이후 공공수집5179개와 관찰32개를1회 확인한다. 알려진 광고/근거부족 손실이 있거나 D보다 정상제외 증가가 없으면 종료한다. 검수되지 않은 제외 증가만으로 채택하지 않는다. 합성자료에 대한 추가 조정/최종26개 재평가는 하지 않는다. 시간상한15분/API0.
