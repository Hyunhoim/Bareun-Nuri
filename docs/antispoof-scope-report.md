# AntiSpoof 구간 대조 학습 1차 결과

2026-09-30. 새 Goal은 사용자 삭제 후 재등록에 성공했으며 active다. `antispoof-scope-plan.md`의 등록 거부는 당시 이력이다. **구간대조 보강 후보는 개발 관문을 통과했고 저장 HCX 결합 F1도 개선됐지만, 정탐 손실과 근거 부족 오확정 때문에 아직 운영을 교체하지 않는다.**

## 비교 조건

운영 v1.0 동일 가중치에서 대조군/보강군을 시작했다. 양쪽3035행×2epoch, lr1e-5/seed42/batch8/전체학습/GPU 조건이 같다. 대조군은 기존2603행에432행을 재추출했고, 보강군은 기존2603행에 새 구간대조432행을 추가했다. 재추출은 독립 자료 추가가 아니다. 두 후보 모두 개발 점수로2epoch를 선택했다. H.20/Jargmax 고정, 추가 임계값 튜닝0이다.

새 학습12어휘쌍/개발6어휘쌍, 각각432/216행이다. 자모·영문·둘다의 표시범위, 영문 일반/치환, 두어순, 세문맥을 교차했다. 학습/개발 어휘·문장틀·표시문장 직접중첩0, 기존 관찰 기법입력과 학습표기 직접중첩0을 점검했다. 같은 작성자의 합성이며 외부 독립 평가가 아니다. 새 숫자변형은 여러 문자를 바꾸는 방식이므로 단일치환 다양성을 충분히 보강한 실험이라고 주장하지 않는다. 기존역할300으로 별도 진단했다.

## 결정과 다음 실험

`scope/model`을 유망 연구 후보로 보존하고 운영 v1.0 유지. 같은 문구의 재학습이나 새 최종 생성 없이 다음은 **표시된 구간의 표현을 판정층에 직접 사용하면 기존 문맥 능력 손실을 줄이면서 귀속을 학습할 수 있는가**를 독립 가설로 삼는다. 같은 보강자료·학습량에서 현재 문장 첫토큰 판정층과 비교한다. 주변 문맥은 식별자 판별에 필요하므로 전체 삭제하지 않는다. 근거 부족 상태도 따로 보존해야 한다. 새 학습량 증가나 임계값 하향부터 시도하지 않는다.

현재 단계에서 새25분 유료 검증이나 운영 승격은 하지 않았다. 최종860 접근0/API0/운영18파일 해시변경0이다. 과거 소비된 평가를 회귀로 사용했다. 최종 독립자료를 계속 만들어 점수에 맞추지 않는다. Goal은 미완료 active다.

자료/학습 `local-benchmark/antispoof-scope.py`, 회귀 `antispoof-scope-regression.py`, CPU진단 `antispoof-scope-cpu.py`. 산출물 `.runtime/antispoof-scope-v1/`에 입력/정답·해시·epoch별예측·선택·가중치·회귀·운영불변감사를 저장했다. CPU 결과는 `cpu.json`에 따로 기록하며 모델 로딩·브라우저·HCX를 제외한 개발216입력 토큰화+추론의 원래/역순/원래 반복이다. 종단25분 성능으로 대체하지 않는다.

CPU8threads/batch8의216개3회 중앙값은 운영24.917초, 보강25.000초(+0.33%)다. 이 작은 차이를 유의미한 지연 변화로 보지 않는다. 두 모델 모두 원래/역순/원래 판정 일치와 GPU/CPU 판정 일치를 확인했다. 실행 순서는 운영3회 뒤 보강3회여서 교차배치 시간 측정이나 통계적 동등성 검증은 아니다. 새 후보 SHA256은 `b75da5b8fdd8419314bc5c186590bd60f594d9d498d7cd59b9d97b3524fb6fa6`이다.
