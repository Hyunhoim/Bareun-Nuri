# 실제 수집 문맥 22개 추가의 대조 실험

2026-09-30. 사용자 위임으로 작성한 62개 AI 라벨 중 훈련 후보만 사용한다. 관찰31개는 훈련 금지다. 이전 turn은 라벨·근거 파일 생성이라는 진전이며, 현재 turn은 이 자료를 이용한 오류 집계와 다음 대조 실험이다. 독립 사람 검증과 운영 채택은 아직 미달이다.

## 가설과 변경 요인

합성·정적 발췌에 치우친 학습 입력에 실제 수집 대상/문맥을 추가하면 실제 입력의 광고 누락이 감소할 수 있다. 평가 실패 문구를 변형하지 않는다. 훈련 후보31개 중 AI 라벨이 확정형인27개에서 어느 모델이든512토큰 초과 또는 수집 문맥 잘림이 있는5개를 제외한22개를 추가한다. 나머지9개는 원래 자료로 보존한다. 광고9·정상13이며 도박과 카드깡 중심의 작은 추가분이다. 마약 판매 등 긴 양성은 제외돼 유형별 폭의 한계가 남는다.

기존956행과 추가978행을 각각 순정 KLUE-RoBERTa-base/KcELECTRA-base-v2022/KoELECTRA-base-v3에서 학습한다. 모든 모델은512토큰, 하위8층 및 embedding 동결, FP32, seed42, AdamW lr1e-5/weight_decay .01, micro2/effective8, gradient clip1,3epoch, 기존 family-balanced loss를 사용한다. 추가분의 기존 캠페인은 기존 family에 합치고 새 출처·캠페인만 새 family로 구분한다. 추가 증강·원문 마스킹·임계값 조정은 없다. 모델 입력은 기존 `판정대상`+`문맥`뿐이다. 학습 루프는 기존 `semantic-encoder.py`의 `train_one`을 재사용한다.

최초 CUDA 두 확인에서 unavailable이었으나 사용자의 RTX4060 재인식 요청 후 샌드박스 밖의 장치 재확인에서 Windows 장치 OK/오류0, `nvidia-smi -L`과 PyTorch CUDA 실제 텐서 연산이 성공했다. 드라이버 설치·재시작은 하지 않았다. 따라서 CPU 학습은 시작하지 않고 계획을 GPU 학습/CPU 추론으로 변경했다. CPU 준비 단계의 원래 계획과 소스는 `.runtime/semantic-real-addition-v1/prepared-plan.md`, `prepared-source.py`에 보존했다. 새 결과는 `.runtime/semantic-real-addition-gpu-v1`이다. CPU와 GPU가 섞인 비교는 하지 않는다.

기존956 대조군도 동일 GPU 환경에서 재학습하여 실행 재현성을 확인한다. 시간 상한은 각40분, 총6조건 최대4시간이다. 시작할 때 다른 Python 학습 프로세스 여부를 확인하고 순차로 실행한다. 외부 API0, 다운로드0, 운영 변경0이다. 첫 조건이 상한을 넘거나 성능상 실행이 불가능하면 중단 기록을 남기고 완료된 체크포인트·원본을 보존한다.

## 선택·평가·종료

선택은 기존 합성 개발90개의 고정 rank(기본/변형 최소F1, 평균F1, 정상FP)로만 한다. 보류10개와 변형40개의 독립성 한계를 그대로 유지한다. 실제 관찰31개를 보고 epoch나 임계값을 바꾸지 않는다. 각 조건 선택을 동결한 뒤 관찰31개 전체 및 잘림 없는 공통23개, 기존 HCX 저장204개와 표현2000개 회귀를 비교한다. 근거 부족은 binary F1에서 제외하고 광고/정상 확정 및 보류를 별도 집계한다. 정상/광고의 입력 잘림과 보류도 분리한다.

추가자료 가설의 개발상 유망 기준: 동일 모델 GPU 대조군 대비 실제 공통 확정형 자료에서 TP 증가, FP 증가 없음, 기존 의미204·표현2000에서 F1 하락 없음과 기존TP 손실0. 기존 개발 FP<=2 관문도 그대로 보고한다. 작은 실제 표본과 AI 주석, 이미 관찰된 자료이므로 통과해도 독립 일반화/운영 채택을 의미하지 않는다. 실패 시 같은31개에 맞춘 재학습·경계값 보정은 하지 않고 이번 데이터 추가 비교를 종료한다.

CPU 추론 시간과 프로세스 메모리를 같은 입력에서 측정하고 모델 로딩·토큰화·추론을 나눠 기록한다. HCX 시간은 과거의 네트워크 포함 저장 측정이므로 동시 속도 대조라고 부르지 않는다. 유망한 경우에도 새 독립 평가와25분 종단 채택 검증이 필요하다.

## 라벨 사용 범위

사용자 전체 열람 진술과 AI 개별 주석을 구분한다. `answers.json`의 자동 학습 불가 표시는 일괄 편입을 막기 위한 것이며, 이번 별도 계획·적격성 감사에서 선정한22개만 AI 주석 연구 자료로 편입한다. 사람 확정 정답으로 승격하지 않는다. 출처/권리 상태는 원래 표기를 보존하며 외부 공개·재배포하지 않는다. 61·62번의 문맥 의존 면책 문구 라벨은 새로운 의미 정답 증명이 아니며 해당 캠페인 전체와 같은 훈련 그룹에 둔다.
