# 세 분류모델 개발 Goal의 현재 충족 범위

2026-09-29. **세 모델의12개 학습 조건 비교와 저장 입력 기반 HCX 대조는 수행했지만, HCX를 대체할 품질이 검증된 후보는 아직 없다.** 모델을 더 학습했다는 횟수나 합성 개발F1로 완료를 선언하지 않는다. 현재 가중치와 원예측을 다시 확인했고, 미검수 실제62개를 한 검수 화면으로 연결했다.

## 현재 후보 해석

동결 연구 후보는 KLUE512/동결8 epoch2, Kc512/전체학습 epoch2, Ko512/동결8 epoch3다. 기존 의미204패널은 Kc가, 기존 표현2000패널은 KLUE가 더 좋았다. Kc는 사전 정상 FP 관문을 실패했고 세 후보 모두 기존 정탐 손실 또는 오탐 문제가 남았다. 이 결과로 앙상블이나 정상 제외 필터를 운영에 연결하지 않는다.

실제31개 HCX 비교에서는 공통23개의 일치가 KLUE16/23, Kc12/23, Ko13/23이었다. HCX 원래 순서 기준이며 정답률이 아니다. 높은 확률의 불일치도 있어 임계값만 조정하면 안전하게 해결된다는 근거는 없다. 기존 실패 문구를 학습시켜 같은 관찰 점수만 높이는 것은 이번 Goal의 일반화 목표와 맞지 않는다.

상세 근거는 `semantic-encoder-report.md`, `semantic-encoder-real-hcx-report.md`, `semantic-encoder-onnx-report.md`, `semantic-int8-trace-report.md`다. 보고서별 당시 미실행 항목은 후속 보고서의 실제 측정과 함께 읽어야 한다. 예컨대 최초 학습 보고서의 ONNX 미측정은 후속 변환 보고서로 보완됐지만, 실제 독립 정확도와25분 채택은 여전히 미완료다.

## 통합 검수 산출물

`local-benchmark/semantic-review-queue-v1/review.html`에 기존 관찰 평가31개와 두 추가 훈련 후보19+12개를 합쳤다. 입력은 원래 세 파일과 정확히 같으며 모델 예측·AI 잠정 라벨을 포함하지 않는다. 용도 필터로31개씩 볼 수 있고 각 항목에서 광고/정상/근거부족/수집·귀속 결함 및 근거를 기록한다. 브라우저 임시 저장과 JSON 내보내기를 지원한다. 원래 검수 파일과 답안은 덮어쓰지 않는다.

관찰31개는 검수 후에도 관찰 평가다. 훈련 후보31개는 검수했다고 곧바로 모두 학습 가능한 자료가 되는 것이 아니며 출처·권리·문맥 결손·그룹 점검이 남는다. 이62개를 새 독립 최종셋으로 부르지 않는다. 검수자의 신원·독립성을 JSON의 reviewer 문자열만으로 인증하지 않는다.

답안 파일은 다음 명령으로 구조와 입력 해시·ID·용도·판정 근거를 검사할 수 있다. 파일을 확인하는 명령이며 훈련/정답 파일로 자동 편입하지 않는다.

```powershell
& .runtime/klue-venv/Scripts/python.exe -X utf8 local-benchmark/semantic-review-queue.py --answers '검수답안의 실제 경로.json'
```

`--self-check`에서 잘못된 라벨/중복ID/용도변경/근거누락/검수상태 형식을 거부했다. 격리 브라우저에서62카드,용도 필터,임시저장,내보내기와 원상 복구를 검증했다. 테스트 답안의1개 선택은 UI 시험용이며 사람 정답이 아니다. `.runtime/semantic-review-queue-check-v1`에만 저장했고 어떤 훈련/평가에도 편입하지 않았다.

현재 세 지정 검수 폴더에는 빈 템플릿 외 답안 파일이 없었다. 사용자의 다른 폴더나 실제 브라우저 임시저장까지 없다고 단정한 것은 아니다. 검수 담당자 여부를 사용자에게 질문한 상태다. 학습 횟수를 추가하거나 또 같은 형식의 합성자료를 늘리는 것보다, 실제 정답·독립 출처를 확보하여 다음 가설을 고르는 것이 우선이다. Goal은 미완료이며 운영 HCX를 유지한다.

## 후속 차단 조건 재확인

직후 자동 계속 turn에서 지정 검수 폴더4곳과 Downloads의 `semantic-review-queue-answers*.json`, `semantic-encoder-real-human-answers*.json`을 확인했다. 실제 답안은 없었고 기존 빈 템플릿만 있었다. 브라우저 내부의 미내보내기 답안이나 다른 이름의 파일까지 검사한 것은 아니다.

동일한 실제 정답 부족은 INT8 중간 출력 진단, 추가 실제 후보 확보, 통합 검수 및 요구사항 감사의 연속된 세 turn에서도 확인됐다. 그동안 수치 진단·새 원문·검수 도구 등 독립 작업은 수행했으나, 현재 다음 품질 판단에 필요한 검수는 대체할 수 없다. 이번 turn은 새 성능 진전이나 실행 중 작업 대기가 아니라 차단 조건 재확인이다. 실행 중이라고 확인된 학습/API 작업도 없다.

완료 기준은 충족되지 않았다. 모델·토큰·동결 비교를 더 반복하거나 AI 잠정 라벨을 확정 정답으로 승격하지 않고, 실제 검수 답안 또는 검수 제공자의 확보를 필요한 외부 변화로 지정한다. Goal의 blocked 전환 조건을 충족한 것으로 판단한다. 답안이 제공되면 먼저 입력 해시·용도·근거를 검사하고 관찰31개의 오류 유형을 집계한 뒤, 훈련 후보의 사용 가능 범위와 다음 가설을 결정한다. 검수 답안 수령만으로 새 독립 최종 평가나25분 운영 채택까지 완료되는 것은 아니다.

## 사용자 라벨 작성 위임 후 재개 (2026-09-30)

사용자가 전체62개를 읽었다고 밝히고 개별 라벨·근거 작성을 위임했다. `local-benchmark/semantic-review-assistant-v1`에 AI 주석으로 기록했고 사람 독립 정답으로 승격하지 않았다. 위 blocked 문단은 위임 전 이력이다. Goal을 재개하여 관찰31개 오류 집계와 별도 훈련 후보의 적격성 점검을 수행했다.

훈련 후보31개 중 확정형·입력 보호 통과22개(광고9·정상13)를 기존956행에 추가한 대조 실험을 RTX4060에서 완료했다. 세 모델 모두freeze8/512/같은 학습·선택 조건의 기존/추가군6개를 학습하고 실제31개 및 기존204/2000개를 CPU 비교했다. `.runtime/semantic-real-addition-gpu-v1/completed.json`과 `docs/semantic-real-addition-report.md`에 근거가 있다.

KcELECTRA는 실제 광고 정탐0→3, 기존204/2000에서 정탐 손실0이라는 이득이 있지만 정상 오탐이 증가하고 문맥F1이96.12→94.12%로 하락했다. KLUE는 정탐 손실, Ko는 큰 정상 오탐 증가가 남아 세 추가군 모두 사전 기준 미달이다. 이번 비교는 종료하고 운영HCX는 유지한다. 새 독립 정답·실제 유형 다양성·25분 채택 근거가 부족하므로 전체Goal 완료로 표시하지 않는다. 새 주석으로 연구가 진행된 사실과 독립 검증 미달을 구분한다.
