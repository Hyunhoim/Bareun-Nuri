# 실사이트 수집 및 실제 DOM 복제본 탐색 비교 — 사전 계획

2026-09-24. 정책별 점수 산출 전에 고정한다. 운영 코드는 변경하지 않는다.

## 질문과 정책

FIFO 대비 기존 문맥 Bandit 및 URL 구조별 순환 FIFO가 실제 메뉴/주소/링크 구조에서도 유리한가? 기존 정책을 그대로 import한다. 깊이별 순환은 이전 회귀로 제외한다. 의미 판정/HCX/기법 판정 변경과 API 호출은 없다. 도달률은 탐지 F1이 아니다.

## 1단계: 실제 공개 페이지

부산 메인과 시민생각, 대전 메인과 시험정보 목록을 시작점으로 한다. 동일 기관의 두 시작점은 독립 사이트로 세지 않는다. GET 전용 운영 collector, 작업당 브라우저 재사용, 독립 context, 기본 대기·네트워크 경계를 유지한다. 각 시작점에서 세 정책을 각각 20개 URL 시도까지 실행하되, 기관별 공유 저장 응답으로 동일 URL의 재요청을 피하고 입력을 고정한다. 이는 각각 전체 온라인 크롤링을 반복하는 지연 시험이 아니라 실제 수집 후 캐시 재생이 섞인 탐색 진단이다. 최대 240개 고유 페이지 시도/전체 30분, 연속 실패 3회면 해당 시작점의 추가 네트워크를 중지한다. 실패·리다이렉트·중복 본문·JS/fragment 이동·프레임·차단·후보·수집 지연을 기록한다. 공개 사이트에 글을 쓰거나 광고를 삽입하지 않는다.

수집된 렌더링 DOM/원문은 git 제외 `.runtime/real-replica-v1`에만 저장한다. 로컬 복제본은 스크립트/폼 동작/외부 리소스를 비활성화하고 계산된 주요 스타일을 고정한다. 실제 동적 동작·픽셀 동일성·서버 기능 재현이라고 주장하지 않는다. 저장하지 않은 iframe은 미복제라고 표시한다.

## 2단계: 유한 복제본

수집에 성공한 실제 DOM을 복제하고 실제 pathname·query 값·태그·클래스·링크 순서를 보존한다. 동일 기관은 하나의 로컬 출처로 매핑한다. 저장 밖의 동일 출처 링크도 유지하고 방문 시 명시적인 410 미수집 경계 응답과 1회 예산을 소비한다. 실패와 미수집을 혼동하지 않는다. 경계는 실제 사이트의 막다른 길이 아니다. 경계 없는 내부 그래프만으로도 보조 비교하되, 이는 범위 축소 민감도 분석이며 운영 채택 근거가 아니다.

기관마다 정책 결과와 무관한 URL hash/실제 최단깊이/URL template로 24개 통제 광고 위치를 배치한다(얕은6/깊은6/템플릿 집중6/분산6). 깊은 후보가 부족하면 실제 최대 깊이로 정의하고 5단계 이상이라고 주장하지 않는다. 중복 페이지 허용, 요소는 독립적이다. 제목/본문/합성 댓글을 교대하며 4종 위장을 순환한다. 실제 본문은 정상 정답으로 자동 간주하지 않는다. 정답은 주입한 위치에만 존재한다. 두 번째 배치 seed는 첫 결과를 보기 전에 동일 규칙으로 고정해 위치 선택 민감도를 확인한다. 주입은 후보 DOM에만 적용하고 원격 사이트에는 적용하지 않는다. 인위적 댓글 추가와 스타일 고정이 결과에 미치는 한계를 보고한다.

FIFO/context-bandit/template-fifo, 링크 순서 seed 0/11/23/37/51, 광고 배치 seed 401/809, 네 시작점에서 @10/20 및 저장 수집시간 합계 기준 @30초/@60초를 비교한다. 로컬 DOM에서 profile/context를 다시 추출하여 주입 문구가 문맥 정책의 실제 관측 입력에 반영되게 한다. 미수집 경계 시간은 측정값이 없으므로 시간 비교는 해당 경계를 최초 만나는 시점까지만 유효하고 전체 시간 우위로 해석하지 않는다. 실제 실사이트 수집시간은 한 회 측정값이라 변동성 미검증이다.

전체 주입 광고를 분모로 하되 시작점에서 도달 불가능한 위치는 별도 보고한다. 기존 FIFO 위치 손실, 기관/시작점/배치별 평균·관측 최소·링크 순서 표준편차, 깊이/표면/배치별 손익, 주소 미발견/발견 후 대기, 경계 예산 소비를 계산한다. 전체 방문 집합·중복0·직렬화 재개·예산 접두부·브라우저의 주입 selector/문구/기법 수집을 검사한다. 정책에는 라벨과 미방문 페이지를 전달하지 않는다.

## 채택·종료 기준

후보는 (1) 모든 기관×시작점×배치의 @10/20 평균 비감소, (2) @20 모든 실행에서 FIFO 도달 광고 손실0, (3) 각 기관 @20 평균 +5%p 이상, (4) 각 시작점/배치의 최저값 비감소, (5) 무결성 통과, (6) 미수집 경계로 인한 비교 왜곡이 없어야 한다. 경계 방문률이 어느 조건에서든 10% 초과하면 외삽 한계로 운영 교체를 보류한다. 통과해도 HCX 포함 종단 정밀도/F1/지연 검증이 필요하므로 그 검증 없이 운영 교체하지 않는다.

실패하면 FIFO를 유지한다. 더 새로운 알고리즘은 단순한 점수 회귀가 아니라 이번에 관찰된 공통 원인과 독립 근거가 효율/보존 동시 개선을 구체적으로 뒷받침할 때만 제안한다. 알려지지 않은 페이지의 광고를 미리 아는 보장이나 FIFO 위치의 무조건 보존을 약속하지 않는다. 결과를 본 뒤 가중치·URL 예외·배치·채택 기준을 바꾸지 않는다. 같은 기관/수집 합집합에 의한 선택 편향과 이미 관찰한 자료의 과적합 위험을 명시한다.
