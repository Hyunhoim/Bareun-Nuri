# 페이지 내부 배치 순환 실제 검증 — 조건부 실행 계획

2026-09-26. `c-throughput-three-plan.md`의 후보1 후속. 원래 4개 이하 fitBatch의 동료와 내부순서는 고정하고, 페이지별 배치만 세 연속구간 앞/중간/뒤 순환으로 실행한다. 의미 프롬프트, C읽기, HCX none/출력512, FIFO, SRPT8·aging8, 활성8, 근거메모리2페이지,25분/600회/200페이지/768MiB는 고정한다.

관측한 기존467 service slots에서 판정기회21→22/28, 원정탐18위치기회보존이었다. 이는시간/F1효과가 아니며,300slots에서는교환손실도있다. 같은자료재사용의선택편향을명시한다. 별도 저장 scheduling16페이지의 기회손익과 실제 experimental core/store의 batch/coverage/index/중단재개 계약검사에서 치명적 실패가 없을 때만 아래 유료 실행에 진입한다.

실험clone은 snapshot에 원래배치의 실행순서목록만추가하며 원문/관찰/후보집합은보존한다. 마지막1~3개배치가중간으로이동하더라도다음배치와합치지않는다. 전체chunk가판정돼야원문완료로센다. 저장 index/coverage도실제work순서를사용한다. 운영 소스는 실행 전 바꾸지 않는다.

기존 C25분 `.runtime/jamo-context-live-c-v1`를 고정 과거 기준선으로 사용하고 후보25분1회만 실행한다. 시점차/장비상태/서비스변동을완전히통제한독립AB가아님을표시한다. 시작전61초사용량분리, HCX순차호출/공통52kTPM,추가한도150만확인+미확인예약토큰,30분정리포함hardstop,자동재시도없음. 프롬프트/사이트/정답은결과를본뒤수정하지않는다. 다른유료실험동시실행금지.

전체통제28광고를분모로F1/정탐/오탐,통제밖양성수동검토, 기존18정탐위치손익,각기법,최초탐지/300콜접두부,실제호출·토큰·수집·판정량·시간·peakRSS를비교한다. 의미판정기회만으로TP를추정하지않는다. 기존기회상실과모델변동에의한실패도구분한다.

전체25분F1/정탐의순이득이있고 기존정탐손실/새정상오탐이이득을상쇄하지않으며 저장재개/완주/범위안전검증을통과해야운영승격을검토한다. 1개문구회복만으로실사이트일반화개선을확정하지않고,별도기회진단의손실·시점차·운영복잡도를종합한다. 사전조건실패 또는 종단순이득이없으면 후보를기본경로에넣지않는다. 반복튜닝/후보결합없이종료한다.
