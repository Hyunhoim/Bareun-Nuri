# KLUE 학습 규모·입력 보존 실험 — 첫 사이클 완료

2026-09-28. Goal active: 더 넓은 일반화 목표는 미달성. 운영 변경/API호출/push 없음. 첫 사이클의 최종 평가는 모델당1회 완료했다. 이제 해당 자료는 관찰한 회귀 자료이며 재사용 점수를 새로운 최종 성능으로 부르지 않는다.

## 입력 결함 수정

기존137개 nearby.before/after 문자열을 방향과 함께 직렬화하고 중복 문자열은 제거했다. 원본 파일·대상·ID·정답137개는 보존했다. 비어 있지 않은 nearby 문자열66개가 새 입력에 모두 포함됨을 검증했다. 새로운 입력은 `.runtime/klue-scale-v1/corrected-regression.json`에 분리했다.

| 기존 모델 | 기존 입력 TP/FP/FN · F1 | 복구 입력 TP/FP/FN · F1 |
|---|---|---|
| 최초 pilot |24/6/36 ·53.33%|19/9/41 ·43.18%|
| 이전 보강 refined |37/6/23 ·71.84%|40/17/20 ·68.38%|

문맥 복구 자체는 판정 개선을 보장하지 않는다. 주변 광고의 귀속 혼동이 늘었으며 모델 변경 없이 같은 동결 가중치로 비교했다. 입력 복구로 줄어든 F1을 숨기지 않는다. 관찰한 회귀 자료이며 새 독립 평가가 아니다.

## 데이터와 과적합 제한

훈련50,000행/검증1,600행/봉인최종1,600행을 만들었다. 표면 어휘와 화면 표현을 분리했지만16가지 의미 사례 조립구조는 공유한다. 실제HTML 수집/사람검수 자료가 아니며, 기본 훈련 광고 표현18종·조합그룹2,592개다. 5만 독립 문장으로 주장하지 않는다. 정규화된 고유 입력 수와 전체 행 수를 구분한다.

훈련 분포 광고15,625/예방인용15,625/일반12,500/근거부족6,250. 검증/최종 각각500/500/400/200이다. 순서상 각16개 블록에 유형을 분산해5천→1만→2만→5만은 포함관계다. 학습 순서는 seed42로 매epoch 섞는다. 검증셋 재사용에 따른 선택 편향을 최종1회로 점검한다. 다음 사이클에서 이 최종 결과를 사용하면 해당 자료는 회귀로 전환해야 한다.

## 모델 입력 NFC 비교

원문5천 첫epoch 검증22오류 중21개는NFD 정상문장이었으며, 토크나이저에서 대부분UNK가 됐다. 모델 입력만NFC로 변환하는 독립5천 조건을 추가했다. 원문·라벨·수집자료는 변경하지 않는다.

| 조건 | 선택 epoch | 검증 광고F1 | macro4F1 | TP/FP/FN |
|---|---:|---:|---:|---|
| 원문5천 |1|97.85%|98.76%|500/22/0|
| NFC5천 |1|94.70%|97.19%|500/56/0|
| NFC1만 |1|100%|100%|500/0/0|
| NFC2만 |1|100%|100%|500/0/0|
| NFC5만 |1회 완료 후 중단|98.33%|99.14%|500/17/0|

NFC5천은 정상 자모 오탐을 없앴지만 예방인용 오탐56개가남아 점수는떨어졌다. 학습loss0.104→0.00046→0.00019에도 동일오류가유지돼과적합징후를보고했다. NFC1만은 첫epoch 검증천장에 도달했다. 같은 검증100%가 일반화100%를 뜻하지 않는다. 이후규모는 동일NFC조건으로만비교한다. 기준선최종도NFC를적용해정규화유무와가중치효과를혼동하지않는다.

## 최종 결과와 판단

검증동점시 작은조건/이른epoch 규칙으로1만첫epoch를선택했다. 5만은추가학습으로검증100%에도달해도동점규칙상선택될수없어두번째epoch중단/부분가중치폐기했다. 첫epoch완료596.12초를50k전체학습시간이나최고가능성능으로주장하지않는다. 1만선택checkpoint까지123.85초,전체3epoch372.87초;2만1epoch237.74초다.

| 자료 | 이전 보강 모델 F1 | 선택1만 F1 | 이전→선택 TP/FP/FN |
|---|---:|---:|---|
| 봉인 어휘분리1600 |74.60%|100.00%|398/169/102 →500/0/0|
| 봉인 다른문맥구조96 |67.53%|87.91%|26/11/14 →40/11/0|
| 입력복구+NFC 기존137 |67.80%|68.85%|40/18/20 →42/20/18|
| 입력복구+NFC 기존DOM152 |75.00%|65.12%|42/6/22 →42/23/22|

새1600의4분류macro80.34→97.63%,구조96은44.82→61.79%다. 새1600광고F1은정답이근거부족인200개를제외한정의다. 선택모델은이중26개를광고로확정했으므로전체완벽판정이아니다. 26개를오류비용상FP에가산한민감도F1은97.47%다(근거부족을실제정상정답으로바꾼것이아님). 구조96의근거부족8개는두모델모두정확히보류하지못했다. 선택모델의구조96정밀도78.43%/재현율100%,오탐11개는남는다.

새두패널합산기존정탐424개손실0/116개회복이지만,이는기존DOM회귀보존을뜻하지않는다. NFC후고유입력1574개로새1600을재집계해도광고F1은73.82→100%다. 합성공통구조·적은기본표현에의한낙관가능성은그대로남는다.

CPU8스레드/배치8의1696개판정은54.52→54.51초로사실상같다. 로드/토큰화/브라우저/네트워크시간은제외한다. 새평가잘림0. 추론속도개선으로주장하지않는다.

**사전 합성 F1 관문은 통과했지만 전체 일반화 목표 달성이나 운영 채택으로 처리하지 않는다.** 실제수집문맥을쓴기존152개에서약9.88%p회귀했고,일반설명·접근성문구·문자인코딩교육·합법행사·행정안내를광고로오인하는오류가늘었다. 새훈련의정상문장이거의모집형/메타정보형에치우쳤던범위부족과분포차이가원인가설이다. 같은18광고표현의조합을5만까지늘리는것만으로충분한일반화를확보했다고볼수없다.

다음사이클은문구별예외를넣지않고,서술/질문/상태/교육/예방/부가정보/짧은연결등담화유형과수집문맥을확장한다. 이전평가를새평가로재명명하지않고,새최종은분리해모델고정후1회만사용한다. 현재모델은연구용후보로보존하고HCX운영은유지한다.

`local-benchmark/klue-scale-audit.cjs`의독립재집계에서새패널/기존회귀지표,기존원본해시,최종동결모델·코드해시검사를통과했다. 원판정/원자료/선택이력은`.runtime/klue-scale-v1/`에보존했다.

최종 합성 광고F1>=90%, 기준선대비>=5%p, 재현율>=90%, macro4>=85%, 세문맥영역F1각>=80%를 사전에 고정했다. 결과를 보고 기준을 완화하지 않는다. 이관문을통과해도실사이트·독립HTML·25분운영검증을대체하지않으며운영승격은별도다.
