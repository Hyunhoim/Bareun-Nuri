# 실제 원문·합성956행의 세 분류모델 학습 결과

2026-09-29. **세 모델·12조건·36epoch 학습을 완료했다. KcELECTRA와 KLUE는 후속 연구 가치가 있지만 HCX 대체는 아직 미달이다. Goal은 진행 중이며 운영 HCX와 기존 Nuri 체크포인트는 유지한다.**

## 이번에 실제로 한 작업

KLUE-RoBERTa-base, KcELECTRA-base-v2022, KoELECTRA-base-v3-discriminator를 각각 순정 pretrained에서 새 이진 헤드로 학습했다. 새956행을 사용했고, 증강 전 행은210개·가족그룹은67개다. 실제 출처·캠페인 수와 독립 의미 사례 수는 이보다 작다. 956개를 실제 독립 광고956건으로 세지 않는다.

증강 전210행은 실제 원문/과거 수집60행과 합성150행이다. 실제60행 중 과거 사용자 검수 정상17행을 제외한 새43행은 assistant 잠정 라벨이다. 실제 양성22행은2도메인·7캠페인에 집중되어 있어, 모든 요청 범주의 실제 분포가 충분히 확보됐다고 볼 수 없다.

NFC 입력, 대상+문맥만 직렬화, 가족별 총 가중치 균등, seed42, FP32, AdamW lr1e-5, 유효batch8/micro2, 최대3epoch를 공통 적용했다. 과거 Nuri1.0의 성공했던 동결/학습률 방향을 참고했지만, 데이터8000→956·4분류→2분류가 다르므로 Nuri 재현 실험은 아니다. null 근거부족 자료는 정상으로 강제 학습하지 않았다.

최초9조건은 모델3×(512/하위8층 동결,256/하위8층 동결,512/전체학습)이다. 이후 아래 입력 결함을 발견해 문맥 보존256 조건을 모델별1개씩 추가했다. 사전 계획은 `semantic-encoder-plan.md`, 수정 가설은 `semantic-encoder-context-plan.md`에 기록했다. 이미 본 개발 오류 문구를 훈련에 추가하거나 최종셋을 반복 생성하지 않았다.

## 입력·검증에서 발견한 문제

**단순256의 높은 점수는 그대로 채택하지 않는다.** 대상 뒤 문맥이 잘리면서 정상/광고의 반대 라벨이 같은 토큰 입력으로 합쳐졌다.

| 모델 | 256 잘린 훈련 행 | 반대 라벨 충돌 그룹/행 | 512 충돌 | 문맥보존256 충돌 |
|---|---:|---:|---:|---:|
| KLUE |321|43/195|0|0|
| KcELECTRA |176|12/50|0|0|
| KoELECTRA |322|46/209|0|0|

후속은 초과 입력에만 문맥 최대96토큰을 우선 배정하고 나머지를 대상에 할당했다. 짧은 입력은 토큰 전체가 기존과 같다. 이 변경으로 충돌0은 확인했지만 의미F1 상승은 확인하지 못했다. 긴 두 부분의 뒤 근거 손실까지 해결한 것은 아니다. 512에서도 정상 원문4개와 파생16행의 긴 문맥이 잘려, 긴 입력 처리 과제는 남는다.

**표기변형40개는 전부 원문과 동일한 모델 토큰이었다.** NFC로 NFD가 합쳐지고 tokenizer가 zero-width를 처리한 결과다. 일치율100%는 전처리 일관성 확인이며 새로운 자모·닮은꼴 표현의 의미 일반화 증거가 아니다. 기본40+변형40을80개의 독립 의미 시험으로 합치지 않는다. 956훈련행도512기준 실제 고유 토큰 입력은 세모델 모두518개다.

검증은 같은 assistant가 만든 합성 개발 자료이며 사람 검수·실사이트 독립 최종 평가가 아니다. 모든36epoch 및 선택모델 CPU12회의 사용을 `semantic-validation-v1/usage.json`에 기록했다. 원래 훈련·검증 파일 해시는 그대로 유지됐다.

## 과적합·최적화 해석

KoELECTRA 전체학습은 loss .528→.175→.026인데 F1 85.00→78.79→70.97%로 하락했다. Kc 전체학습도2→3epoch에서 loss .0785→.0066, F1 90.48→87.80%다. KLUE 동결512도2→3epoch에서 loss가 줄었지만 누락3→5개로 늘었다. 훈련 패턴 과적합 우려이며, 원인을 모델 구조 하나로 확정하지 않는다.

반대로 모든 모델에서 전체학습이 나쁘다고 일반화할 수도 없다. Kc 전체학습의 선택 checkpoint는 동결512보다 F1이 조금 높지만 정상FP3/20으로 사전 FP<=2 관문을 실패했다. **후속 비교에 포함했다는 사실이 관문 통과나 운영 채택을 뜻하지 않는다.**

## 같은 저장 입력에서 HCX 비교

기존221개에서 이번 훈련에 사용한 실제 정상17개를 제외했다. 나머지204개는 정규화 동일 훈련 입력0개이며 확정167개(광고64/정상103)+근거부족37개다. 과거 관찰된 합성 문맥 회귀이고, 의미·작성자 독립성은 보장하지 않는다. 새 API 호출 없이 기존 HCX 단일/묶음12의 원요청·원응답과 동일 입력을 대조했다.

원래256은 위 입력 결함으로 후보 선택에서 제외했다. HCX 예측을 보기 전에 512/동결8,512/전체학습,문맥보존256 중 개발 rank로 하나씩 고정했다. KLUE=512/동결8 epoch2, Kc=512/전체학습 epoch2, Ko=512/동결8 epoch3다. 이 회귀 점수로 다시 선택하거나 튜닝하지 않았다.

| 모델 | TP/FP/FN | 정밀도 | 재현율 | F1 | 근거부족37개를 광고 확정 |
|---|---:|---:|---:|---:|---:|
| 새 KLUE |53/7/11|88.33%|82.81%|85.48%|20|
| 새 KcELECTRA |62/9/2|87.32%|96.88%|91.85%|17|
| 새 KoELECTRA |42/8/22|84.00%|65.63%|73.68%|29|
| 기존 Nuri1.0 |49/47/15|51.04%|76.56%|61.25%|20|
| HCX 단일, 저장 응답 |64/12/0|84.21%|100.00%|91.43%|7|
| HCX 묶음12, 저장 응답 |63/0/1|100.00%|98.44%|99.21%|6|

Kc는 HCX 단일보다 F1이0.42%p 높지만 정탐2개를 잃었다. 기존 오탐12개를 없앤 대신 별개 정상9개에서 새 오탐을 냈다. HCX 묶음 대비는 기존정탐2개 손실·기존누락1개 회복·새오탐9개다. 이 자료/단일 실행에서의 교환 관계이며 HCX 우월/열등을 전체로 확대하지 않는다. 묶음99.21%도 인접 대조문구·순서 구성의 영향을 분리하지 않은 과거 개발 결과다.

Kc의 오류에는 합법 사진 원본 판매, 공동구매 접수, 전자도서관 갱신의 정상 문맥 오탐이 있다. 불법 고금리 대출 권유와 금지 농약 판매는 누락했다. 위험 단어·거래 말투를 넘어 권유 대상과 합법 문맥을 구별하는 능력이 아직 부족하다. 같은 대상/반대 문맥4그룹 전체를 맞힌 그룹은 새 세모델 각각2개, Nuri0개였다. 작은 회귀 진단이며 별도 일반화 증명은 아니다.

사전고정 .2~.8 확률 보류를 적용해도 Kc는 근거부족37개 중3개만 보류하고14개를 광고로 확정했다. 확정167개의 보류는2개다. 이진모델의 높은 확률을 올바른 의미 판단이나 근거 충분성으로 취급하면 안 된다. 확률 임계값을 이 자료에 맞춰 추가 조정하지 않았다.

## 기존4종 표현2000개의 의미 보존

HCX204개 비교 후 동일 후보를 그대로 동결해 기존2000개 합성 회귀를 추가 확인했다. 추가 학습·후보 재선택은 없다. 정규화 동일 훈련 입력0, 모델 입력 잘림0이었다. 새 독립 평가나 CSS 기법·위치 검출 성능이 아니다.

| 모델 | TP/FP/FN | 광고 F1 | Nuri 기존정탐 손실 | Nuri 기존누락 회복 |
|---|---:|---:|---:|---:|
| 새 KLUE |972/61/28|95.62%|22|137|
| 새 KcELECTRA |923/62/77|93.00%|55|121|
| 새 KoELECTRA |975/181/25|90.45%|20|138|
| Nuri1.0 |857/63/143|89.27%|—|—|

Nuri는 정상이었던50개를 보류했으며, 이진 F1만으로는 이 부담이 드러나지 않는다. Nuri의2000개 원래4분류 예측은 과거 저장 결과와 모두 같았다. 새KLUE는 이전FP63개를 해소했지만 다른 정상61개에 새FP를 냈다. Kc는 이전FP62개 해소/새FP61개다. Ko는 새FP176개가 생겨 높은 재현율만으로 추천하지 않는다.

새KLUE의 HOMOGLYPH/JAMO/OFFSCREEN/TRANSPARENT 별 의미F1은96.81/94.49/96.06/95.15%, Kc는93.31/91.87/93.55/93.25%다. 이 시험에서는 KLUE가, 별도 문맥204개에서는 Kc가 좋았다. 이것을 전체 영역의 단일 승자로 정리하지 않는다. 특히 합계F1 향상에도 기존 정탐 손실이 남아 보존 기준은 미충족이다.

## 자원·비용과 남은 검증

학습 실행시간 합은 약914초이며 준비·다운로드·CPU평가를 포함한 종단시간이 아니다. RTX4060에서 PyTorch 최대 할당량은 조건별907~2492MiB였다. CPU90개 추론 중앙값2.65~3.35초, 선택 후보204개 단회 추론은 KLUE5.70/Kc4.82/Ko5.78초다. HCX 시간은 과거 실행이므로 동시에 통제한 속도비교가 아니다.

학습 후 CPU측정 프로세스 RSS는1572~2185MiB였지만 같은 프로세스에 학습/allocator 이력이 남아 있다. 이것을 깨끗한 CPU 배포 프로세스의 최소/최대 RAM 요구량으로 주장하지 않는다. ONNX/INT8, 별도 프로세스 메모리, 긴 실제 입력의 지연, 실제25분 종단은 아직 미측정이다.

이번 신규 유료API0, 운영코드 변경0, 기존 checkpoint 덮어쓰기0. 새 실제 출처·사람 검수·독립 최종 평가가 확보되지 않았다. 다음 작업은 새 실패 문구를 복제하는 대신, 출처가 분리된 실제 문맥에서 합법 권유/피해 문의/불법 권유/근거 부족을 검수하고 대상-문맥 근거 보존을 확인하는 것이다. Kc의 문맥 강점과 KLUE의 표현 보존을 함께 연구하되 이번 점수만으로 앙상블·필터·운영 대체를 연결하지 않는다.
