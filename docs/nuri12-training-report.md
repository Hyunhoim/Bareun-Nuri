# Nuri 1.2 첫 GPU 학습 결과

순정 KLUE RoBERTa-base에서 학습10,000행을3에포크 학습했다. A/D 가중치를 초기값으로 사용하지 않았고4분류층이 신규 초기화되었음을 로딩 기록으로 확인했다. RTX4060 Laptop GPU,전체110,621,188파라미터,FP32/batch8/lr2e-5/AdamW,seed42. 학습 및 개발 평가·재로딩 확인에652.07초(10분52초),최대GPU 할당2.39GiB. 모델 로딩/학습 전 A평가 시간은 이652초에 포함되지 않는다.

사전 기준인 개발 패널별 macro4 F1 평균 우선으로 **2에포크를 선택**했다. 실험 모델 저장에 성공했으나 A 대체/운영 승격은 권하지 않는다.

## 평가 범위와 검증

- 개발204개는 이미 관찰한 별도 자료다. 훈련10,000에서 무작위 분리한 자료는 아니지만 새로운 독립 홀드아웃도 아니다. 이번에는 새 개발/최종평가를 만들지 않았다.
- 훈련/개발 NFC 직렬화 입력 직접 중복0,그룹ID 교집합0. 그룹ID만 다르다고 의미·주제 독립을 주장하지 않는다.
- 데이터/순정가중치/실행코드 해시 불변 확인. 선택 모델을 다시 로딩한204개 예측이 저장된2에포크 예측과 완전히 일치했다.
- 기존2000회귀 및 봉인 최종평가는 실행하지 않았다. 4기법별 최종 탐지 일반화, DOM통합, HCX대체,25분 종단 성능은 미검증이다.
- A 및 HCX 운영은 변경하지 않았다. 합성 데이터는 아직 사람 정답 검수 미완료이며 실제 공공사이트 성능으로 소개하지 않는다.
