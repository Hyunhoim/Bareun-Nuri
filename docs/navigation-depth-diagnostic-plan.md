# 깊은 영역 발견 실패 진단 계획

2026-09-23. 목적은 원인 확인이며 운영 정책 개선·채택 실험이 아니다.

- 기준선: `.runtime/navigation-trial-v1`의 고정 소스·스냅샷·전체 방문 기록. 새 6사이트 × 5순서 × 4정책 120회를 재생하고 원래 순서 일치를 검증한다. 이미 관찰한 합성 진단 자료이며 독립 홀드아웃이 아니다.
- 가설을 분리한다: (1) 링크 수집/범위 처리로 경로가 끊김, (2) 경로는 있으나 중간 페이지 방문이 늦음, (3) 대상 주소는 발견했지만 대기열에 남음, (4) Bandit의 즉시 본문 보상과 DOM 그룹 공유가 중간 경로의 진행을 늦춤.
- 전체 링크 그래프의 최단 거리와 깊이별 폭, 실제 최초 발견 부모와 발견/방문 시점을 계산한다. 20/50/100요청에서 깊은 광고를 방문/발견 후 대기/주소 미발견으로 나누고, 대기 중인 경유 페이지와 선택 경쟁을 추적한다. 그래프·라벨은 사후 분석에만 사용한다.
- 보상의 영향을 분리하기 위해 Bandit에 제공하는 `detail`만 모두 false로 둔 보상 0 대조를 30회 실행한다. 원래 보상과 비교하되 그룹·링크·순서·예산·정책은 유지한다. 이는 진단용 제거 실험이며 새 정책 후보나 채택 근거로 취급하지 않는다. 결과에 맞춘 가중치·그룹·사이트 수정은 하지 않는다.
- 경로가 존재한다는 것과 예산 내 발견 가능성, 도달률과 최종 탐지 F1을 구분한다. 경유 방문 후 링크가 정상 등록되면 수집 누락으로 분류하지 않는다. 보상 0 대조만으로 깊은 경로 문제가 해소되지 않으면 보상만을 단독 원인으로 단정하지 않는다.
- 종료: 원래 120회 순서 재현, 상태 분해·경로 추적, 보상 대조와 자료 무변경 검증 후 보고한다. HCX·외부 사이트 호출, 기본 정책 변경, 새 평가셋 생성은 하지 않는다.
