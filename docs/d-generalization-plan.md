첫 단계는 저장2,000개 전체에서 D의 동일 입력 재현, 페이지 제목만 제외, 문맥 전체 제외, 사람이 만든 원래 표기를 제공하는 oracle 읽기를 각각 비교한다. oracle은 비공개 정답 파일의 base_text를 사용하는 원인 진단이며 운영 입력·학습·개선안으로 사용할 수 없다. 광고/정상 전체를 같은 방식으로 처리하며 실패76개만 골라 효과를 부풀리지 않는다. 원래표기 외 문맥은 유지한다. 라벨은 점수 집계에만 쓰고 모델 입력에 넣지 않는다.

제목/문맥 제거는 원인 대조이며 자동 운영 적용이 아니다. 예방 인용과 문맥 의존 광고의 손실을 함께 본다. 기존2,000개는 반복 관찰 회귀자료이므로 여기서 좋은 설정을 찾았다는 것만으로 일반화/채택을 확정하지 않는다. 기존120제목대조와44개발 입력에서도 같은 입력 변환의 손익을 별도 진단할 수 있지만 이미 관찰한 자료다.
