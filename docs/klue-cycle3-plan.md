# KLUE 세 번째 개발 사이클

관찰한 첫/두번째 최종·기존137/152는 이제 개발 검증이다. 같은점수상승을독립일반화로주장하지않는다. 이전회차검증의문법공유에의한낙관과전체가중치미세조정중표현의존을공통가설로둔다.

고정문장수십개의반복대신서비스/불법성/행동/대상/결제/권유와예방문장을여러문법으로조합한다. 정상서술길이와주변문맥길이도다양화해길이/위치만으로라벨을맞히는지줄인다. 실제판매인용과예방인용,인접광고와현재대상,근거부족을대조한다. 관찰한평가의정확한대상문구는학습에서제외한다. 사람검수/실사이트독립자료라고주장하지않는다.

동일자료와NFC,seed42,batch8,512,lr1e-5에서①전체가중치학습②임베딩과하위8개층고정(상위4개층+분류기학습)을각최대3epoch비교한다. 모델당30분안전상한. 모형선택은관찰개발패널별광고F1의최저값우선,동률평균F1,동률이른epoch다. 구조별성능평준화를확인한다. 보류정확도도별도보고한다.

새최종을열기위한조건은개발패널광고F1최저>=80%,모든4분류패널의보류정확도>=80%다. 통과하지못하면새최종을소비하지않고다른공통원인진단을한다. 최종성공기준은이전과같이광고F1>=90%·이전보강기준선대비>=5%p·재현율>=90%·macro4>=85%·보류>=80%,정상/인용오탐률<=10%,기존137/152의기준선대비F1하락<=2%p이다. 운영은계속HCX유지한다.

선택세부:개발관문을모두충족하는checkpoint가있으면이를우선한다. 그안에서최저패널F1/평균F1/이른epoch순이다. 모두실패하면같은F1순으로진단후보만남기고최종은열지않는다. 새8000훈련은6000조합문장+이전훈련2000이며정답기반선별은하지않았다.

새최종은새로운공공게시판형합성HTML96개대상을실제브라우저로수집한final-dom이다. 게시글/인용/분리댓글/날짜/작성자/정상예약/근거부족을포함하며,실사이트발생률이나전체페이지정답이아닌지정대상평가다. 목표대상96개원문보존,필요선행문맥존재,근거부족대상에다른댓글문맥이유입되지않음을예측전에확인했다. 모델선택에는사용하지않았다. 각모델1회판정후정답개봉,기존성공기준유지다. 동점관문을충족한frozen8첫epoch가개발최저F1기준으로선택됐다.
