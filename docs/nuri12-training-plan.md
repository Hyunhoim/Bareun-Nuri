# Nuri 1.2 GPU 초기 학습

순정 `.runtime/klue-base`의 KLUE RoBERTa-base에서4분류 head를 새로 초기화한다. A/D 가중치를 초기값으로 사용하지 않는다. 학습10,000행, 기존 별도 개발40+120+44행을 사용한다. 개발은 관찰 자료이며 새 독립 평가가 아니다. 별도 새 검증 없이 개발 점수만으로 일반화/운영 채택을 확정하지 않는다. 최종 봉인 자료/2000회귀는 이번 학습·선택에 읽지 않는다.

seed42, 전체 파라미터, AdamW lr2e-5/weight_decay.01, batch8, gradient clip1, FP32, 최대3epoch/60분. 에포크별 세 개발 패널 macro4 F1의 평균→광고F1 평균 순으로 체크포인트1개를 선택한다. 개발 결과로 학습 설정을 다시 조정하지 않는다. A의 동일 개발 입력 GPU 평가를 먼저 남긴다. 시간 제한이면 마지막 완료한 개발 선택을 보존하고 미완주를 명시한다.

훈련/개발의 NFC 입력 직접 중복 금지, 원래 그룹 분리, 각 파일/순정 모델/코드 해시 고정. 입력은 target/context만 사용하고 원문 복원 답·라벨·출처 메타데이터는 넣지 않는다. 데이터 audit의 의미 검수 미완료와 같은 제작자 편향을 유지해 보고한다. 손실·단계·시간·GPU메모리를 저장하고 오류시 진단을 남긴다. 기존 모델 삭제·운영 교체·최종평가·push는 하지 않는다.
