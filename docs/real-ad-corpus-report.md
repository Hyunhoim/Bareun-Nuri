# 실제 원문 기반 광고 판정 자료 v1 — 2026-09-29

실제 게시물 원문 보관본과 초기 학습 후보를 만들었다. **766개는 증강을 포함한 후보 수이며, 실제 광고 766건이 아니다. 전 유형의 충분한 실제 학습자료 확보는 아직 달성하지 못했다.** 새 라벨은 assistant 잠정 검수이며, 기존 사용자 검수 정상 17개 외에는 사람 정답으로 소개하지 않는다. 모델 학습·HCX 호출·운영 변경은 하지 않았다.

성인 영상과 유출 영상 홍보는 같은 홍보 계열에 속한다. 실제 양성 22개 전체의 광고 계열 합집합은 **7개**, 출처 도메인은 **2개**다. 사전에 정한 범주별 10개 계열·3개 출처 다양성 기준은 어느 주요 범주도 충족하지 못했다. 공개 원문 탐색만으로 모든 불법광고 유형을 충분히 모았다고 주장할 수 없다.

실제 웹에 게시됐다는 뜻이지 사람이 직접 작성했다는 뜻은 아니다. 반복 구조의 긴 홍보문이 많고 자동 생성 여부는 확인하지 못했다. 본문의 안전성·수익률·품질 주장을 사실로 검증하거나 받아들인 것도 아니다.

모델에는 **`input.target`과 `input.context`만** 전달한다. `label`, `reason`, `category`, 출처 URL, 사례 ID, 계열명, 증강 종류는 정답 누출을 막기 위해 입력에서 제외한다.

`label=1`은 사용자가 요청한 범주의 이용·구매·가입 권유 **선별 후보**, `label=0`은 해당 문맥의 비권유/정상 정보다. `label=null`은 학습에서 제외한다. 법률 판정 정답과 동일하지 않다. 특히 성인물은 성인 관련 단어 전체를 양성으로 만든 것이 아니라 영상 사이트 이용 권유를 선별했으며, 실제 영상의 합법성은 확인하지 않았다.

현재 운영 HCX 프롬프트는 도박·불법 성인물 서비스를 명시한다. 이번 자료에는 사용자 요청에 따라 마약·불법 금융 등 연구 범주를 추가했지만, 운영 프롬프트/정답 체계를 바꾸거나 기존 HCX와 곧바로 같은 지표로 비교한 것은 아니다.

## 증강과 품질 관리

1. 원문 URL·응답 바이트·본문 XPath·발췌 문자 오프셋·원문 해시를 보존했다. 원문에 없는 설명을 실제 수집 문맥으로 추가하지 않았다.
2. 새 실자료 입력은 최대 약 560자 본문 발췌와 실제 제목이다. **운영 브라우저 입력과 동일하다는 보장은 없다.** 기존 17개만 저장된 운영 입력을 기반으로 한다. 짧은 발췌 이후의 광고를 전체 글 정상으로 오라벨링하지 않도록, 보류 자료를 정상 학습에 넣지 않았다.
3. 제목·본문·다른 게시물의 귀속을 분리했다. 실제 독립 댓글 양성은 아직 확보하지 못했다. 댓글 대조 24개와 그 DOM은 새 합성임을 명시한다.
4. 실제 발췌를 예방 인용/서비스 홍보 문맥에 각각 배치한 역할 대조를 만들었다. 실제 기관이 쓴 문맥이나 댓글로 소개하지 않는다. 마약·성매매 신규 가상 문장은 분류용 짧은 권유/피해 문의이며 실제 판매처·가격·배송·구매 절차를 생성하지 않았다.
5. 표현 변형은 정상과 양성에 모두 적용했다. 효과가 없는 변형과 동일 입력은 제거했다. 원문당 변형 수를 독립 의미 사례 수로 계산하지 않는다. 혼동 문자는 제한된 예시 집합으로, 모든 숫자 치환이나 한국어 호환 자모 복원을 포괄하지 않는다.
6. 연락처·일반 URL·이메일·가입 코드 패턴을 학습 입력에서 처리했다. 모든 개인정보·우회 표기를 완전히 비식별했다고 주장하지 않으며 잔여 검수가 필요하다. 실제 원문은 별도 보관했다.
7. `family_id`는 캠페인/시나리오 단위, `group_id`는 출처 도메인 또는 합성 작성 계열이다. 모든 자료는 현재 `train_candidate`/`review_only`이고 최종 홀드아웃은 없다. 향후 분할은 행 무작위가 아니라 출처와 캠페인 연결 그룹을 먼저 고정해야 한다.
8. `family_weight`는 같은 계열의 행 수 역수이다. 단순 766행 균등 학습은 권장하지 않는다. 합성 문맥 틀과 사이트 말투를 외울 우려가 크므로 실제 원문/표현 증강/역할 합성을 분리한 소거 비교가 필요하다. 증강 파일의 크기를 학습량 목표로 삼지 않는다.

## 검증 결과와 남은 한계

`python local-benchmark/real-ad-corpus.py validate`로 원본 바이트/디코딩 해시, XPath 본문 재추출 일치, 발췌 오프셋, ID·입력 중복, 보류 제외, 입력 필드 제한, 부모 그룹 보존, NFD 가역성과 연락처 처리 예제를 검사한다. 수집기의 최초 읽기/캐시 읽기 간 스크립트 제외 불일치와 Windows 줄바꿈 변환 문제를 수정한 뒤 원본 바이트에서 다시 추출했다.

`node local-benchmark/real-ad-corpus-check.cjs`는 로컬 합성 DOM에서 운영 수집기로 대상 원문, 관찰 기법 신호, 다른 댓글의 문맥 혼입 여부를 확인한다. 이는 합성 DOM 수집 점검이며, 실제 사이트 전체에 대한 입력 동등성 또는 모델 정확도 검증이 아니다. HOMOGLYPH fixture의 전각 식별자는 양성과 정상 모두에 사용해 위장 기법 자체를 광고 정답으로 만들지 않았다.

최종 검사에서 **64/64 문서의 대상 원문·기법 신호·독립 댓글 문맥 분리**가 통과했다. 정상 대상 옆에는 광고 댓글을, 광고 대상 옆에는 비권유 댓글을 배치했다. 검수 HTML도 99개 카드·스크립트 미포함·원문 출처 링크만 포함함을 확인했다. 원문 정합성 검사는 통과했지만 의미 라벨 정확도를 측정한 것은 아니다.

요강의 HOMOGLYPH/JAMO/TRANSPARENT/OFFSCREEN과 의미 업종을 구분했다. 네 기법의 존재는 의미 양성의 충분조건이 아니다. 실제 페이지의 관찰 기법은 이 정적 발췌만으로 확인하지 않아 `null`로 남겼다. 요강 확인 파일은 `.runtime/official-contest-rules.pdf`이며 [공식 배포 파일](https://www.mois.go.kr/cmm/fms/FileDown.do?atchFileId=FILE_00148935YF51LUC&fileSn=1)의 5쪽·11쪽·13쪽을 대조했다.

추가로 필요한 것은 **마약 판매의 다른 캠페인·출처, 성매매 알선/불법 의약품의 실제 원문, 같은 주제의 실제 피해 문의·정상 상업 홍보, 실제 독립 댓글, 새 사람 검수**다. 이전에 공개됐던 광고의 검색 색인이나 기관 보도 속 인용을 원래 게시물인 것처럼 대체하지 않는다. 출처별 이용조건 및 제3자 게시물의 학습·재배포 권리는 미확인이다.

현재 이 패키지는 원문과 계보를 추적하며 검수·초기 실험을 시작할 수 있는 자료다. 전 유형 충분성, 법률 정답성, HCX 대체 성능, 최종 제출 성능은 검증하지 않았다.

## 재현

프로젝트 루트에서 설치된 Python과 Node를 사용한다. 추가 패키지 설치나 유료 API가 필요하지 않다.

```powershell
& 'C:\Users\alvin\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -X utf8 local-benchmark/real-ad-corpus.py capture
& 'C:\Users\alvin\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -X utf8 local-benchmark/real-ad-corpus.py build
& 'C:\Users\alvin\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -X utf8 local-benchmark/real-ad-corpus.py validate
node local-benchmark/real-ad-corpus-check.cjs
```

`capture`는 저장된 응답이 있으면 원래 바이트를 재사용한다. 새 수집시각으로 갱신한 척하지 않는다. `build`는 현재 라벨 설정에서 파생 파일을 재작성한다. 기존 모델·운영 코드·과거 평가 자료는 수정하지 않는다.
