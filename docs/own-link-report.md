# 운영 C 기준 자기 링크 근거 독립 실험

2026-09-26. 사전 계획 `docs/own-link-plan.md`.

**결론: 운영 C 유지. 자기 링크 보완은 수집 결손을 해결했으나 이번 의미 판정에서 추가 이득이 없어 운영 채택을 보류한다.** 운영 collector·판정기·FIFO·출력512·배치4는 수정하지 않았다. E/F/H 등 이전 미채택 안을 섞지 않았다.

## 가설과 구현

현재 후보 `links`는 대상의 하위 `a[href]`만 수집한다. 대상 자신이 anchor라면 자기 주소가 빠진다. 페이지 탐색용 전체 링크는 별도로 수집되므로 이는 탐색 주소 발견 실패가 아니라 판정 근거 결손이다.

실험 L은 자기 anchor를 기존 links 앞에 포함한다. 같은 DOM에 현재 `readDocument`와 이 표현만 바꾼 버전을 실행했다. 모델 계약은 C 그대로이고 L의 links만 보완 결과로 전달했다. 목적지 방문, 외부 검색, URL 단어 기반 광고 확정은 하지 않았다.

실험 파일은 `agent/experiments/own-link.cjs`, 원요청·원응답 감사는 `own-link-audit.cjs`에 분리했다. 기존 비교 실행기의 공통 사용량 제한과 중단 계약을 재사용했다.

## 수집 검증

새 HTML40개에서 노드120개를 대조했다. 자기 링크40개가 보완됐고 다른 노드의 links, 원문·문맥·스타일·좌표·selector·페이지 탐색 링크는 동일했다. 상대 URL/쿼리/fragment/인코딩 주소를 브라우저가 해석한 주소와 대조했다. 별도 fixture에서 부모의 하위 링크, 내부 span, href 없는 anchor, srcdoc 프레임을 검사했다. 외부 요청0회이며 클릭은 하지 않았다.

이는 실제 브라우저의 동일 DOM 추출 함수 검증이다. 전체 worker 수집·재개·동적 페이지·기법 F1 및 크롤링 시간의 종단 검증은 아니다. 운영에 연결하지 않았다.

## 의미 판정 비교

새 개발20/확인20은 각각 광고8·정상8·근거 부족4다. 광고와 정상/예방 사례에 같은 주소를 넣었다. 정답·분할·실험 필드는 모델 입력에서 제외했다. 순서를 바꿔 두 번 비교했다.

기존 복제본43개는 저장 근거에 자기 주소가 없으므로 추측하지 않았다. A/L 모두 동일한 기존 입력을 보내 판정 변동 대조로만 사용했다. 이43개 결과를 링크 보완의 효과로 해석하지 않는다.

조건은 HCX-007 none, temperature0, seed42, 출력512, 순차 배치4로 동일하다. 실험은 두 작업/공유48k TPM으로 교차 실행했다.

| 자료 | C: TP/FP/FN | C+자기 링크: TP/FP/FN | F1 |
|---|---|---|---|
| 새 개발20 × 두 회 | 16/0/0 | 16/0/0 | 양쪽100% |
| 새 확인20 × 두 회 | 16/0/0 | 16/0/0 | 양쪽100% |
| 기존 복제본43 × 두 회, 동일 입력 대조 | 37/1/5 | 37/1/5 | 양쪽92.50% |

이진 F1은 근거 부족을 제외한다. 새 자료의 근거 부족16회 중 명시적 판단불가는 C5→L7회, 광고 오확정은 양쪽0이다. 소규모 합성 자료의 두 건 차이만으로 보류 능력의 일반화 개선을 확정하지 않는다.

새 자료의 이진 판정은 모든 조건/순서에서 동일했다. 복제본의 이진 판정은 순서 변경시 두 위치가 바뀌었으며 A/L에서 동일하게 나타났다. 같은 순서의 A/L 간 회복·손실·추가 오탐은0이다. 순서/배치와 모델 변동의 기여는 분리하지 않았다.

## 지연·비용

링크가 실제 추가된 새40개×두 회만 비교하면:

| 항목 | C | C+자기 링크 |
|---|---:|---:|
| 호출 | 20 | 20 |
| 입력 토큰 | 27,098 | 28,598 (+5.54%) |
| 총 토큰 | 29,275 | 30,781 (+5.14%) |
| API 서비스 시간 합 | 41.006초 | 41.522초 |

약0.52초 차이를 유의미한 지연 효과로 해석하지 않는다. 사용량 대기·브라우저·저장 시간과 운영25분 처리량을 포함하지 않는다. 전체 실험은84호출/126,789확인 토큰, 예약251,772토큰이다. 재시도·미확인·형식실패0, 전부HTTP200/stop이다.

## 해석과 다음 우선순위

**자료의 천장 효과가 있다.** 새 자료의 명시적인 판매·예방 문맥만으로 C가 이미 모두 맞혔다. 따라서 '링크 보완이 실제 어려운 사례에도 효과가 없다'는 결론은 낼 수 없다. 확인 분할도 같은 작성자와 유사한 문장 틀의 합성이며 실사이트 일반화 자료가 아니다. 특정 주소/문구에 맞춰 결과가 좋아질 때까지 수정하지 않았다.

사전 관문의 새 확인 F1 개선과 순이득 조건이 충족되지 않아 확대 및25분 종단 비교를 하지 않았다. C를 유지한다. 수집 근거 완전성 측면의 버그 후보로는 남기되, 이번 결과를 광고 탐지 성능 개선 근거로 삼아 기본 모델 입력을 늘리지 않는다.

다음은 판정 프롬프트 누적보다 **25분 안에 수집됐지만 판정하지 못한 광고의 대기 원인**을 저장 실행 기록에서 분리하는 것이 우선이다. 페이지별 후보량·판정 대기·사용량 제한 대기를 먼저 측정해야 한다. 이번 실험은 해당 처리량 병목을 해결하거나 미판정 광고를 회복했다고 주장하지 않는다.

## 감사와 기록

`.runtime/own-link-v1/prepared.json`에 두 조건 수집 검증, `.runtime/own-link-v1/live`에 동결 소스/입력/정답/원요청/응답/판정/예산을 보존했다. `audit-summary.json`은332개 입력과84개 원응답의 저장 판정 일치, 실제 요청의 links 외 동일성, 라벨 필드 부재, 소스/입력 해시, 토큰/예약 합계를 재검증했다. 운영 소스의 해시는 유지했다. 네트워크 없이 감사를 재실행할 수 있다:

```powershell
node agent/experiments/own-link-audit.cjs
```
