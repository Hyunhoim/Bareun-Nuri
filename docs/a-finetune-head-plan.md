# A 표현 고정 후 출력층 비교

앞선 복습·증류도 회귀를 실패했다. 이번에는 언어 표현과 dense를 전부 고정하고 out_proj 3,076개 파라미터만 수정한다. 평가 원문을 훈련하지 않는다. 신규 훈련228개와 기존훈련에서 seed42로 뽑은1024개를 사용한다. eval 상태의 특징을 캐시하고 전체 forward와 수치 일치를 확인한다.

동일 배치 신규4(각라벨1)+기존28,256step, AdamW lr1e-4/weight_decay .01, seed42. 신규 CE와 기존 A teacher KL(T2,T²보정)을 더하며 KL 가중치1/4 두 조건만 비교한다. 64/128/256step 개발 평가. 기존 개발 선택·회귀·봉인 확인 기준은 그대로다. 선택은 개발 결과로만 하고 회귀에서 실패하면 이번 두조건 추가 조정은 종료한다. 인코더/dense의 모든 텐서 불변과 저장 후 실제 forward 예측 일치를 확인한다. 합성 개발 반복 선택 편향은 남으며 봉인 평가를 통과해도 HCX 대체 확정은 아니다.
