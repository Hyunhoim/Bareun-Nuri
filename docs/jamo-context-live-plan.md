# 자동 자모 읽기 후보의 종단 확인

2026-09-25. 선행 jamo-context-plan의 1차/104회귀 관문을 통과했을 때만 실행한다. 통과 전 준비 문서이며 성공을 전제하지 않는다.

- 기존 `.runtime/call-budget-600-v1`의25분 운영 실행을 보존하고 동일 복제본/진입점/페이지200/호출600/25분/순차4/none/출력512/SRPT8와 비교한다. 기준선은 이전 시점 실행이므로 서버/장비 시간 변동이 통제된 교차반복 비교는 아니다.
- 후보 C는 모델 입력 normalized_text만 일반 복원으로 바꾼다. 수집된 원문/저장된 정규화 필드/스타일·관찰기법/위치/프롬프트/출력 계약은 바꾸지 않는다. 실험 모듈을 명시적으로 주입하고 운영 파일을 수정하지 않는다.
- 실행1회/최대600호출/확인+미확인예약150만토큰/시간1500초, 종료 정리 별도 기록. 미확인 요청 자동재전송 금지. 기존 유료 실험과 동시에 API 호출하지 않는다.
- 주지표는 통제28광고 전체 기준 F1/정탐수, 통제정상FP, 기존TP보존, 미방문/미판정/판정실패 분리다. 통제 밖 양성은 별도 검토하며 임의 TP에 추가하지 않는다. 공통 요청 집합에서 의미 결과 및 입력 차이를 확인해 단순 방문량 변화와 판정 개선을 구분한다.
- 운영 채택 권고: 기존25분 의미F1/TP 순이득, FP/기존TP손실이 이득을 상쇄하지 않음, API형식/근거귀속/원문보존에 새 구조적 실패 없음. 시간·비용은 별도 보고한다. 개선 없으면 운영 유지. 이 한 실행을 속도나 실사이트 일반화의 확정 증거로 삼지 않는다.
- 이번 요청은 병렬 실험과 채택 검토이므로 검증된 후보는 채택 권고로 보고하고 운영 적용은 구분한다. 모든 실험 기록을 보존하고 추가 튜닝·유료 반복 확대·push는 하지 않는다.
