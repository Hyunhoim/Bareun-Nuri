# 코드포인트 보존·반복 대응 묶음 진단

2026-09-30. typed의 동일한 문자 대응을 원문 코드포인트/대응 코드포인트/위치목록으로 묶고, 표에 없는 비ASCII 문자도 원문 코드포인트와 위치를 제공한다. 원문·문맥·표기·skeleton은 그대로 둔다. 위치 단위는 Python Unicode code point이며 DOM의 UTF16 위치를 바꾸지 않는다. 문자 대응을 펼쳐 기존 근거와 일치하는지 검증한다. 기법 정답이나 광고 의도 라벨을 입력에 넣지 않는다.

먼저 기존개발과 저장44구간에서 길이와 문자probe155의 충돌을 확인한다. 충돌0, 저장44에서 새512초과0, 평균길이감소, 개발최대512이내일 때만 학습 검토로 확대한다. 해당 길이자료는 관찰 진단이며 독립 평가가 아니다. 실패하면 추가 형식조정/학습 없이 이번 후보를 종료한다.

학습 검토를 하더라도 운영v1.0 시작/동일3035자료/동일2epoch·선택기준·H.20이며 실제학습목록해시 확인이 필수다. 기존 typed 대비 개발패널별 정탐손실0/F1하락0/정상·모호오확정 합산증가0이어야 후속 회귀로 확대한다. 운영/HCX 호출/최종860 변경·접근은 하지 않는다.
