2026-09-30. Nuri1.0(A), D, KcELECTRA full을 사전에 지정한다. 새 학습/임계값 선택/HCX 재호출/운영 변경 없이 CPU8threads·batch8·512토큰·기존4분류 argmax를 비교한다. 모델 로딩·토큰화·추론 시간은 분리하며 CPU 자원 경합을 피하기 위해 모델은 순차 실행한다.

기준 자료는 `.runtime/phase1-full-1790774023853`의 불변 브라우저 근거5,070개와 저장 HCX 판정(마지막 재판정 포함)이다. 모든 모델에 기존 `klue-context.cjs`의 동일 target/context 직렬화·NFC를 사용한다. 운영 자모 보조 읽기를 재사용한다. HCX는 passage/링크/경계와12개 묶음, 분류기는 학습 당시 target/context와8개 독립 텐서 배치이므로 모델 순수 능력만의 완전 통제 비교는 아니다. 정답/URL/사례ID는 분류 입력에 전달하지 않는다.
