## 결정

운영 변경 없음. M/R 단독과 단일 판정은 채택하지 않는다. P/C는 관찰 F1 개선 가능성을 확인했지만 사전 유망 기준을 통과하지 못했다. 추가 검증을 한다면 낮은 입력 증가와 작은 구성별 변동을 보인 P를 먼저 동결 후보로 사용한다. 기존 정탐 손실과 신고 인용 오탐이 다른 문구·출처에서도 줄어드는지 확인한 뒤25분 조건으로 검증해야 한다. 이번 실패 문구에 맞춘 프롬프트 추가나 최종 평가의 반복 소비는 하지 않는다.
