# CANINE-S + Unicode 문자 근거 비교 (2026-09-30)

운영 변경 없는 제한 진단. 기존 최초 KLUE 기법 특화 모델을 기준선으로 둔다.
학습320/개발96은 기존 자료만 사용한다. 이미 소비한 final96 및 digit112는 회귀이며 새 최종 평가가 아니다. 같은 생성자/반복 형식/관련 어휘 한계는 유지한다.

## 비교와 통제
- 기존 KLUE 특화 모델 그대로 / 새 KLUE+Unicode / CANINE-S 원문 / CANINE-S+Unicode.
- 새 세 조건은 seed42, batch8, FP32, 전체학습 lr2e-5, weight decay .01, 최대3epoch, 각15분 GPU 안전 상한. 기존과 같은 개발 macro F1, uncertain 오확정, 빠른 epoch 순으로 선택한다.
- Unicode 공식 고정 버전 confusables의 단일 문자 대응과 NFD skeleton을 **보조 근거**로 제공한다. 정답 복원문이 아니며 대응 존재 자체를 치환 라벨로 삼지 않는다. 코드포인트/원문 위치 보존. 표준에 없는 leetspeak 대응을 추가하지 않는다.
- 기존 한국어 입력을 유지하고 모델용 문맥 끝에 대상 token의 표준 근거만 추가. 사례ID/group/URL/gold는 모델 입력 제외. 증강 없이 원래320개만 학습하여 모델/보조 근거 효과를 분리한다.
- 라이브러리는 설치된 Transformers4.57.3. 모델 revision/표준파일 SHA/학습·평가자료 SHA 기록. GPU는 순차 사용. 훈련·개발 입력 잘림 발생 시 무단 축약하지 않고 중단.

## 평가와 종료
- 모든 모델 동결 후 개발96/기존 final96/기존 digit112를 같은 코드 우선 계약으로 비교한다. final은 선택에 사용하지 않는다.
- 저장된 실제 HCX 의도 판정을 동일 적용: 광고로 판정된 대상의 기법 TP/FP/FN, HCX+HOMOGLYPH 제출 튜플 기준 F1, 기존 정탐 손실/회복. 의도 정답을 HCX 판정으로 대체하지 않는다.
- 전체 정상/불확실 기법 오확정은 별도 진단. 주 판단은 조건부 결과이나 HCX의 오탐에 기법을 잘못 덧붙이는 위험도 포함한다.
- CPU8threads/batch8, 워밍업 후 원래/역순 반복3회, tokenization+추론과 로딩 분리. 잘린 입력은 uncertain 처리; 실제 수집80개는 길이/처리 범위 진단 및 정답 알려진 주입 위치만 별도 집계한다. 미라벨을 정상으로 간주하지 않는다.
- 후속 독립 평가로 확대할 조건: HCX 고정 결합 회귀 합산F1 +2%p 이상, 개발/기존 final 각각 기존 정탐 손실0, 정상/모호 치환 오확정 증가 없음, CPU 중앙값 기존2배 이내. 실패 시 이번 비교 종료, 평가 문구 맞춤 재학습 금지.
- 위 기준은 운영 승격이 아니다. 독립 검수 자료 및25분 종단검증 없이는 운영 미채택. 새 API0, 데이터 외부 전송0.
