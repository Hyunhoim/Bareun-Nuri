# Phase2 일반화 병목 개선 사전 계획

2026-10-01. 사용자 승인: 프롬프트 조정 및 격리 자동 복구 실험 후 근거 있는 운영 채택. Goal active.

## 고정 비교

- A: 현재 K 운영 프롬프트. S: 불법 거래·유통·연락 유도까지 광고 정의만 포괄. R: S + 혼합 의도/자기 문맥 관계 명시. 정답 문구·ID·URL별 예외 없음.
- Phase2 이미 소비된 자료에서 정답 결과를 보지 않는 해시 순서 20시나리오(광고/정상×5변형=200위치), 기존 관찰172, 별도 새 작성 대조24를 저장 입력으로 고정한다. Phase2와 기존172는 회귀다. 새24도 동일 작성자의 합성으로 독립 실사이트 검증으로 주장하지 않는다.
- 12묶음·동시3·출력512·none·seed42·58k 예약 고정. A/S/R 두 순서 총198호출, 최대180만 예약토큰/1시간. 요청/응답 저장, 미확인 전송 재시도 금지. 입력·출력 계약은 불변.
- 개발 채택 후보: 두 순서 합산 F1 +1%p 이상, 각 순서 F1 비하락, 공통 완료 기존 광고 손실 <=2%, 정상 오탐 증가 <=정상100개당2개, 새 대조 자료 F1 비하락. 누락 회복·새 누락·오탐·보류·토큰·지연 모두 보고. 동률이면 S 우선. 실패하면 무조건 운영 변경하지 않는다.
- 같은 평가에 맞춘 반복 프롬프트 재작성은 하지 않는다. 유망안은 고정 뒤 남은 Phase2 위치 및 별도 개발 대조에서 확인한다. 최종 운영 채택은 동일25분 실행으로 전체 정답 기준 F1·정탐·비용·미판정을 검증한다. 과거 실행 비교의 인과 한계는 명시한다.

### 실행 감사 보충

- 기존 실행기의 S 접두 조건이 단일 판정으로 예약되어 S0/S1은 입력0·API0으로 건너뛰었다. A/R 132호출은 그대로 보존하고 별도 수정 실행기에서 동일 입력 S 66호출만 실행한다. 합계198호출이며 시간대 차이를 보고한다. 비어 있는 S 결과를 성능으로 집계하지 않는다.
- 해시 선택 Phase2 200개에는 gambling110/illegal_trade60/drugs20/sex_trade10, illegal_adult0이다. 새24와 기존172에는 성인 관련 대조가 있지만 Phase2 전체 확인에서 별도로 확인해야 한다. 결과를 보고 샘플을 교체하지 않는다.
- 종단 후보는 별도 소스 디렉터리에서 실행하고 첫25분 + 안전한 재개 최대25분, 합계1200호출 상한을 적용한다. 원래 Phase2 결과와 원래 운영 소스는 승격 전 보존한다. 일시적 미전송 prepared와 실제 전송 미확인은 구분한다.

## 확정 불완전 응답 복구

- HTTP200/stop/완전JSON·유효한 일부ID 반환만 대상으로 한다. 통신 미확인·잘림·중복ID·알 수 없는ID는 자동 복구하지 않는다.
- 일반 탐색/판정이 끝난 후 원래 격리 묶음을 최대4개씩 나눠 1회만 시도한다. 새 작은 묶음도 불완전하면 남겨두며 반복하지 않는다.
- 기존 원응답과 확정 판정은 불변. 별도 복구 기록으로 합친다. 동일한25분/호출/TPM 예산 안에서 실행하고 중단·재개 시 전송 여부/결과의 영속성을 검증한다. 같은ID가 이미 확정됐으면 재판정 금지.
- Phase2 격리108후보를 연구 경로에서 먼저 비교(27호출, 10분·20만 토큰 상한). 광고 회복뿐 아니라 기존 반환값 변화·새오탐·기법·지연을 보고한다. 부족한 정답은 정상으로 간주하지 않는다.
- 운영 승격은 분할 복구 효과, 실패/중단/재개/중복 방지/coverage·결과 일치 검사 후 한다. 과거 CP를 새 서명으로 자동 변환하지 않는다.
