# KLUE 단계적 데이터 확대 실험 사전 계약

2026-09-28. 사용자 목표: 새 최종 평가 1회에서 유의미한 광고 F1. 운영 HCX는 유지.

1. 기존137개 nearby 객체 직렬화 결함을 별도 입력으로 복구하고 두 동결 KLUE 모델을 재측정한다. 원본 보존, 모델 재학습 없음. 기존 결과 차이는 입력 수정 효과로만 보고한다.
2. 새 합성 자료는 어휘·문장 표현을 훈련/검증/최종으로 먼저 분리한다. 같은 의미의 표기 변형·대조쌍은 한 분할에 묶는다. 화면 표시 표현은 분리하나 의미 사례를 조립하는 구조는 공유한다. 따라서 독립 사이트/HTML/템플릿 평가가 아니라 같은 제작자의 어휘 분리 합성 진단이다. 사람 검수 또는 실제 광고 데이터로 주장하지 않는다. 5만행이 5만 독립 의미가 아님을 기록한다. 이 진단만으로 실제 일반화 목표 달성을 확정하지 않는다.
3. 최대 5천/1만/2만/5만행으로 각 원본 KLUE에서 학습한다. seed42, 학습률2e-5, batch8,512토큰, 최대4epoch, 검증 macro4 F1 우선(동률 광고F1, 동률 더 이른 epoch),2epoch 무개선 종료. 동일한 검증 자료를 사용한다. 각 규모60분 안전 상한. GPU 메모리 오류가 나면 기존 결과를 보존하고 인프라 조치로 기록한다.
4. 유의미함의 사전 기준: 새 평가 광고F1>=90%, 이전 보강 모델보다>=5%p 개선, 광고재현율>=90%, macro4 F1>=85%, 각 확정 문맥영역 광고F1>=80%. 최종은 아래 체크포인트 선택이 끝난 뒤 보강기준선과 선택후보 각각1회 예측하고 정답을 개봉한다. 기준 실패 시 성공으로 바꾸지 않는다. 인용/일반 오탐·보류 오류·CPU시간을 함께 보고한다.
5. 검증은 모델 선택 자료다. 최소5천 실행 후 각 규모 확대하며 개선 추이를 기록한다. 최대 규모 종료 후 검증 macro4 F1 우선으로 모델을 고정한다. 같은 점수면 작은 자료/이른 epoch 우선. 반복 seed 검증 없이 안정성을 확정하지 않는다. 이전137회귀는 선택 목적이 아니라 고정 후 회귀 손실 진단에 사용한다.
6. 최종 입력/정답은 생성 시 별도 파일과 SHA256으로 봉인하고 학습 프로세스에 넣지 않는다. 최종 결과를 본 사이클은 다시 그 최종으로 선택하지 않는다. 새 사이클은 새 분할을 만들어야 하며, 동일 생성기로 최종만 새로 찍어 반복하는 것은 독립 일반화 증명이 아니므로 금지한다. 실패 원인을 훈련/검증에서 다룰 수 있는 근거가 있을 때만 다음 사이클 진행한다.
7. 25분 종단 시험 없이 운영 승격하지 않는다. 이번 실험은 API0 로컬 GPU 학습/CPU 판정이며 크롤러·관찰기법·운영 프롬프트를 변경하지 않는다. 새 합성 자료의 성공을 실사이트 성능으로 주장하지 않는다.

영역 관문은 양성/음성을 포함하는 세 묶음으로 집계한다: 직접권유·일반글·경고본문(direct), 짧은연결·다른댓글경고·메타데이터·옆정상글(ownership), 실제권유인용·예방인용·신고기록(quotation). 광고가 없는 단일 정상 유형에 광고F1을 억지 계산하지 않는다. 보류는 별도 정확도와 광고 오인 수로 보고한다.

자료 생성 중 짧은 링크 유형의 고유 조합 한도가 요구 행 수보다 적은 것을 발견해, 생성 완료/학습 전 제목 문맥을 조합에 포함했다. 미완료 생성 프로세스를 중단했으며 모델 또는 평가 결과를 보고 수정한 것이 아니다. 최종5만행은2,592개 offer/CTA/예방문구 조합 그룹, 정규화된 고유입력43,248개이며 기본 광고 표현18개뿐이다. 규모 효과를 보는 조합 합성 진단으로 명확히 제한한다.

## 최종 개봉 전 검증 기반 입력 실험 추가
원문5천 검증의22오류 중21개가NFD 정상문장이고 토크나이저가단어를UNK로바꾸는 것을 확인했다. 최종은미개봉이다. 동일5천/검증/seed/학습설정으로 모델입력만NFC 정규화한 대조를 추가한다. 원문/봉인자료는변경하지않는다. 효과가있으면1만/2만/5만은NFC조건으로학습해규모효과를분리한다. 원문5천은별도원인진단으로보존한다. 기존보강모델의최종비교도동일NFC조건을사용해전처리차이를모델효과로오인하지않는다. 기존137입력복구결과는NFC추가전이며다음최종회귀에서구분한다.

## 대규모 학습의 동치 조기 종료
1만NFC 첫epoch 검증macro4=1.0을 관찰했다. 이후2만/5만은 정확히1.0이면 더 높은점수가불가능하고동점은이른epoch를유지하므로즉시종료한다. 이는선택모델이바뀌지않는계산절감이며채택기준완화가아니다. 진행중1만은기존2회무개선규칙으로완료한다. 검증천장으로규모효과를판별하지못하는한계를보고한다.

## 별도 구조 최종 점검 (모델 선택·최종 개봉 전 고정)
공통조립틀의검증천장때문에새최종에다른배치의96개구조점검자료를추가봉인했다. 날짜/별명/짧은링크/다른댓글/삭제기록/공백없는권유를포함한다. 학습·검증선택에사용하지않으며,기존최종1600개와한번에각모델1회예측후정답을개봉한다. 1600개와96개점수를따로보고하여쉬운다수자료가어려운소수오류를가리지않게한다. 사전채택조건에구조96광고F1>=80%를추가한다(강화,완화아님). 동일제작자의합성이므로실제HTML독립검증은아니다. 기본최종과같은광고어휘계열을공유하며독립1696개사례로통계추정하지않는다.

기존브라우저수집 semantic-eval-data-v2 80개와semantic-final-data-v1 72개를합친152개는추가회귀자료다. 원본레이블64광고/72정상/16모호와대상을유지하고nearby직렬화만복구했다. 새학습/선택에사용하지않고최종모델고정후두모델을비교한다. 새홀드아웃으로취급하지않는다.

## 검증 상한에 따른50k중단
50k첫epoch검증macro99.14/광고F198.33%였다. 10k가이미검증상한100%이고동점은작은조건을선택하므로50k의추가epoch가선택을바꿀수없다. 최종미개봉상태에서50k두번째epoch진행을중단하고부분가중치를폐기했다. 완료한첫epoch체크포인트와pruned.json을보존한다. 4epoch완료또는50k최고성능으로주장하지않는다. 최종선택은10k첫epoch로고정되며채택기준은변경없다.
