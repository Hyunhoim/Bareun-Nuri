# Independent wave commits: predeclared API0 experiment

Hypothesis: preserving the exact three-request wave while committing completed results across independent pages reduces result visibility delay. Same-page contiguous offsets remain ordered. It does not remove the barrier before the next wave and therefore must not be sold as higher API throughput.

Acceptance: same submitted batches and final decisions; page-prefix validation; durable restart without replay; unknown sent/responded restart refusal; cancellation and call/time bounds; quarantine retained. Delay test must show earlier independent results, not changed content. No paid API, Phase2 access, production changes or adoption. A rolling dispatcher is deferred unless this simpler candidate justifies complexity.
