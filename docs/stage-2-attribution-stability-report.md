# 2단계 근거 귀속·불확실성·안정성 개선 실험 — 미채택

검증일: 2026-09-22. **기존 광고 탐지는 유지했지만 정상 오탐·검토 부담과 불확실성 처리의 회귀가 발생했다. 전체 일반화 성능 개선으로 채택하지 않으며, 기본 웹 worker와 `isolated` 비교 기준을 유지한다. 3단계로 진행하지 않는다.**

## 구현과 확인 범위

`agent/experiments/attribution-contract.cjs`와 `run.cjs`의 `attributed` 모드를 추가했다. 기존 Pipeline의 최종 음성 판정 중 확정된 인용을 제외한 후보에만 적용한다. 기본 단계의 광고 판정은 그대로 보존한다.

- 대상 역할, 제공 서비스 종류, 후보 내부의 근거 위치, 대상과 서비스의 연결, 인용 목적을 분리해 출력한다.
- 모델이 근거 문장을 재작성하지 않도록 하고, 선택한 위치의 수집 원문을 코드가 가져온다. 대상 원문·위치·기본 판정도 보존한다.
- 서비스가 `unknown`이거나 근거 위치가 없거나 외부 문맥과의 연결이 미확정이면 검토 상태로 남긴다. 서비스 종류가 대상 자체에서 확인되는 경우에는 외부 연결을 요구하지 않는다.
- 형식·후보 ID·근거 위치·완전한 응답을 검사한다. 한 번의 형식 재요청, 호출 상한 300회, 실행 상한 1시간, 취소와 오류 기록을 유지한다. API 오류를 정상 결과로 바꾸지 않는다.

**근거 위치가 존재한다는 것은 그 근거의 의미가 대상에 귀속된다는 증명이 아니다.** 모델이 역할이나 서비스 종류 자체를 잘못 판단하면 이 구조도 오판한다. 특히 근거 부족을 모델이 `lawful`로 잘못 출력하는 문제까지 코드의 enum 검사로 해결할 수는 없다.

HCX-007, temperature 0, seed 42를 사용했다. 기존 단계는 추론 `none`, 배치 16, 출력 한도 3,072토큰이다. 추가 귀속 단계는 `low`, 배치 4, 출력 한도 5,120토큰이다. 원래 `contextual`의 문맥·역할·서비스 3단계를 이 한 단계로 비교한 실험이므로, 단일 프롬프트만 변경한 동등 비용 비교가 아니다.

## 남은 병목과 실험에서 제외한 변경

1. **의미상의 근거 귀속:** 진단 자료의 작성자 표지가 주변 도박 광고 때문에 광고로 바뀌었다. 회귀 자료에서는 표제, 교육 문구에 포함된 업종 단어, 예방 인용을 실제 권유로 해석하는 오류가 남았다. 후보 내부 위치 검증만으로는 이러한 오류를 막지 못했다.
2. **근거 부족의 인식:** 제공 상품·서비스가 특정되지 않은 거래 문구를 합법 서비스로 가정한다. 출력에서 불확실성을 인정하면 코드가 보류하지만, 모델의 잘못된 확신을 아직 안정적으로 식별하지 못한다.
3. **안정성:** 32개 역순 실행에서는 광고/정상 이진 지표는 같았지만 검토 여부가 3개 바뀌었다. 별도로 제시 목적만 바뀐 항목도 3개 있었다. **같은 순서의 반복에서도 검토 여부가 1개 바뀌었다.** 원래 순서 두 실행의 11개 API 요청 본문이 모두 동일함을 확인했다. 순서만의 문제로 단정할 수 없고 입력 정렬만으로 해결됐다고 볼 수도 없다. F1만으로 안정성을 판단해서는 안 된다.

근거 문장을 직접 생성하고 원문과 일치시키던 초기 방식은 모델의 임의 축약 때문에 요청 전체가 실패했다. 최종 후보에서는 근거 위치 선택과 코드의 원문 복원을 사용한다. 안전한 원문 보존을 위한 변경이며 의미 판정 정확도 자체를 증명하지 않는다.

주변 문구와 태그 이름을 가린 별도 역할 판정도 비교했다. 63개에서 광고는 유지됐으나 오탐 1개가 남고 정상 검토가 3개로 늘었다. 이 추가 단계는 미채택하고 실행 코드에서 제거했다. 해당 관측은 `.runtime/stage2-attribution/diagnostic63-final/`에 보존한다. 특정 문구·ID·URL 예외는 추가하지 않았다.

동일 진단 자료를 반복 조정하는 과적합 위험을 작업 중 보고했다. 새 32개의 최초 모델 실행 전 소스를 해시로 고정했으며, 이후 결과를 보고 판정 코드를 수정하지 않았다.

## 검증 방식과 비용

- 63개와 306개는 기존 수집 스냅샷·기본 단계 응답을 고정하고 추가 단계만 실제 호출했다. 마지막 자체 근거 연결 규칙은 같은 모델 관측을 새 코드로 재통합했다. 전체를 새로 연속 실행한 결과로 보고하지 않는다.
- 원래 순서·역순·원래 순서 반복의 32개는 매번 전 단계를 실제 호출한다. 저장 응답을 재사용하지 않는다. 순차 실행하며 코드·모델·설정·텍스트·DOM 근거를 유지한다.
- 32개는 새 문구와 HTML 조합을 브라우저로 수집한 55개 후보 중 사전에 지정한 대상이다. 제목·본문·메타데이터·버튼·링크·댓글 형태, iframe·동적 삽입, 광고/정상 문맥 쌍을 포함한다. 단독 inline 요소는 같은 원문을 가진 부모 의미 단위로 수집될 수 있어 원문과 유일성을 확인했다.
- 실제 공공 웹사이트나 독립 작성자가 만든 홀드아웃은 아니다. 작은 합성 평가로 전체 일반화를 확정하지 않는다. 이 결과를 분석한 뒤부터는 해당 32개도 진단·회귀 자료다.
- 소스 고정 기록은 `.runtime/stage2-attribution/independent-collected/inference-source.json`, 입력/정답 해시는 같은 폴더의 `seal.json`에 있다. 정답은 채점에만 사용했다.

| 실행 | 실제 호출 시도 | 보고된 토큰 | 경과 시간 |
|---|---:|---:|---:|
| 63개 추가 귀속 단계 | 13 | 37,865 + 사용량 미보고 1회 | 추가 단계 247.69초 |
| 306개 추가 귀속 단계 | 32 | 103,304 + 사용량 미보고 1회 | 추가 단계 543.42초 |
| 32개 원래 순서, 전체 | 11 | 29,301 | 139.37초 |
| 32개 역순, 전체 | 11 | 29,408 | 134.79초 |
| 32개 원래 순서 반복, 전체 | 11 | 30,026 | 148.75초 |

63개·306개의 일부 추가 단계는 다른 실험과 동시에 진행하면서 HTTP 429와 60초 재시도가 발생했다. 위 시간은 이 대기와 형식 수정 호출을 포함하며 순수 모델 추론 시간이나 실무 처리량으로 해석하지 않는다. 306개는 고정한 기본 44회에 추가 32회를 합한 구성상 76회이며, 새 전체 연속 시간은 측정하지 않았다. 신규 32개 실행은 서로 겹치지 않는다.

이번 작업 전체에서 실제 API 요청 시도는 **126회**, 보고된 토큰 합계는 **331,194토큰**, 사용량 미보고 시도는 **3회**다. 폐기한 후보의 호출도 포함하며, 저장 관측 재통합 산출물을 실제 호출로 중복 집계하지 않았다. 사용량 누락이 있어 총 토큰과 원화 비용은 확정하지 않는다.

## 코드 검사와 재현

`npm.cmd test --prefix agent` 통과. 후보 내부 근거 위치, 근거 부족 검토, 주변 불법 서비스만으로 독립 정보를 광고로 올리지 않는 통합 규칙, 기본 광고 보존을 검사했다. 기존 자모·수집·API 형식 수정·한도·취소 검사도 통과했다. 실제 runner의 성공/실패 기록은 HTTP 스텁으로 추가 확인했다. 이 검사는 모델의 의미 판단 성능을 보장하지 않는다.

실제 유료 호출:

```powershell
node agent/experiments/run.cjs attributed evidence.json NEW_OUTPUT_DIR
node agent/experiments/score-intent.cjs NEW_OUTPUT_DIR labels.json
```

최종 집계와 원자료는 `.runtime/stage2-attribution/summary.json`, `diagnostic63-selected/`, `panel306-selected/`, `independent-original/`, `independent-reverse/`, `independent-repeat/`에 있다. 개발·회귀 자료와 별도 평가를 구분해야 한다.

**다음 판단:** 검증 가능한 원문 보존은 유지하되, 모델의 역할·서비스 종류·인용 범위에 대한 오판을 해결하지 않은 채 추가 판정 단계를 계속 쌓거나 3~5단계로 확장하지 않는다. 현재 결과로 전체 일반화 성능 개선을 주장할 수 없다.
