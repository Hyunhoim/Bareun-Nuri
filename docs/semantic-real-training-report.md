## 산출물과 검증

`local-benchmark/real-context-supplement-v1/candidates.jsonl`은 근거·잠정 라벨·보류·그룹·길이 보호·출처를 포함한다. `review-inputs.json`과 `review.html`은 잠정 라벨/모델 예측을 표시하지 않는 검수용이다. `human-answers-template.json`은 빈 양식이며 사람 답안이 아니다. 외부 광고 URL은 텍스트로만 보이고 링크/스크립트로 실행되지 않는다. 검수 화면19카드/활성링크0/스크립트0과 실제 렌더링을 확인했다.
