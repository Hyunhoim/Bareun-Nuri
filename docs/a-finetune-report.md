# A 일반화 파인튜닝 비교 결과

2026-09-28. **새 채택 후보 없음. A와 운영 HCX 유지.** 사용자의 목표는 평가 문구 암기 없이 일반화가 개선된 후보를 찾는 것이었다. 11개 독립 학습 조건과 가중치 혼합·출력 경계 보정을 실제 실행했지만 목표는 달성하지 못했다. 성공할 때까지 같은 개발 점수에 맞춰 무제한 조정하는 것은 사용자 요구의 일반화 목표와 충돌하므로 이번 가설군은 종료한다. 봉인 확인 자료는 모델 평가 0회로 보존한다.

## 자료와 실행

- 새로운 훈련 228행: 다양한 맥락100, 같은 짧은 표현의 의도 대조48, 도박·성인물 등 영역 대조80. 기존 A의 훈련8000행에서 복습 표본을 사용했다. 새 개발40행과 기존120/44행은 학습하지 않았다.
- 회귀2000행의 문구·정답도 학습하지 않았다. 정확 입력 중복과 문자 trigram 근접도를 별도 감사했다. 세 신규 자료의 기존 회귀 최대 유사도는 각각.229/.167/.245이며 설정한.8 이상 쌍은 없었다. 이는 의미·생성자 편향까지 없다는 증명은 아니다.
- 신규 자료 작성, 봉인 자료 작성, 감사는 에이전트별로 병렬 분담했다. GPU 사용 불가로 실제 모델 학습은 CPU에서 순차 실행했다. API 호출0. A 원본과 자료 해시를 재검증했다.
- 신규 자료는 합성 정답이다. 증명서 대리 발급 등의 경계 사례가 있어 독립 사람 검수 부족을 한계로 남긴다. 봉인48도 별도 작성자의 합성이며 사람 검수 정답은 아니다.

## 비교 결과

기존2000은 이미 분석한 회귀 자료다. 그 점수 상승 자체를 새 일반화 증거로 사용하지 않는다.

|조건|정탐|오탐|누락|광고 F1|A 정탐 손실/회복|
|---|---:|---:|---:|---:|---:|
|A|857|63|143|89.27%|—|
|A와 대조학습 모델 50% 혼합|765|34|235|85.05%|92/0|
|혼합 + 개발에서 선택한 광고 경계 보정|800|36|200|87.15%|59/2|
|신규1 + 기존7 복습 CE|830|37|170|88.91%|42/15|
|동일 복습 + 강한 증류|811|42|189|87.53%|50/4|

11개 학습 조건은 기본 CE·증류·상위1층 학습(3), 광고 가중 CE·증류(2), 동일 표현 문맥 대조 CE·마진 손실(2), 기존7/8 복습 CE·강한 증류(2), 인코더/dense 고정 출력층 KL1·KL4(2)다. 별도로 혼합 비율2조건과 A/혼합 모델의 고정 logit 보정 후보를 개발에서 비교했다. 각 설정과 단계별 결과는 각 사전 계획 및 `.runtime/a-finetune-*`에 저장했다.

초기 학습들은 새 개발 F1을 개선했지만 광고 재현율이90%에서70~80%로 떨어지거나 문맥 귀속 패널을 회귀했다. 마지막 출력층 조건은 새 개발 최고64.29%지만 귀속 패널34.78%(A48%)로 떨어져 회귀 확대 대상이 아니었다. 선택된 저장 모델만 회귀 평가했으며 회귀에서 실패한 결과를 보고 해당 모델의 임계값을 다시 조정하지 않았다. 보정 실험은 별도 사전 고정 개발 후보에서 선택했다.

## 관측과 가설을 구분

**관측:** 오탐 감소는 반복해서 확인되지만 기존 광고 정탐 손실을 동반했다. 가장 근접한 복습 CE도 정탐15개 회복보다42개 손실이 컸다. 단순히 기존 자료를 더 복습하거나 증류를 강하게 하는 것으로 해결되지 않았다. 출력층만 변경해도 귀속 성능이 저하되어 언어 층 변화만이 유일한 원인이라는 가설은 지지되지 않았다.

**가능한 원인:** 신규 합성의 의도·설명 방식과 기존 A 학습 분포의 차이, 짧은 권유와 피해 문의의 경계 표현 부족, 기존 광고 확률을 낮추는 보수화다. 이번 비교는 이들 원인의 인과 비중을 확정하지 않는다. 수집 누락이나 크롤링 성능은 고정 입력 실험으로 검사하지 않았다.

**과적합 위험:** 개발 패널을 반복 사용해 선택 편향이 커졌다. 새 문구를 만들었어도 같은 AI가 생성한 설명 방식의 편향은 남는다. 신규 개발 F1 개선만으로 운영 승격하면 이미 관찰된 회귀를 숨기게 된다. 봉인 자료는 회귀 관문 전이므로 열지 않았다.

## 다음 작업에 필요한 변화

동일 합성자료의 에포크·학습률 확대보다 실제 대상에 속한 문맥으로 판단 가능한 권유/피해/정상/불확실 자료의 독립 검수를 우선한다. 기존 오류는 공통 실패 원인만 정의하는 데 사용하고, 훈련 예문은 별도 출처·문장 계열로 수집한다. 주제·템플릿·사이트를 그룹으로 분리하고 불명확 정답은 확정 라벨 학습에서 격리한다. 사람이 검수한 개발 자료를 확보한 뒤 제한된 새 비교를 재개하는 것이 타당하다. 결과를 보며 기존 회귀 원문을 학습하는 방식은 사용하지 않는다.

CPU 분류 모델의 추론 구조는 동일하며 이번 작업은 처리량 개선 실험이 아니다. HCX 동일 입력 정확도/25분 종단/수집 통합/재개 검증은 실시하지 않았고 HCX 대체를 주장하지 않는다.
