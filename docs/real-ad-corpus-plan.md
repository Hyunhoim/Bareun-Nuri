# 실제 광고 원문 기반 자료 구축 계획 — 2026-09-29

사용자 요청: 실제 기관 게시물과 한국어 불법광고 자료를 추가 탐색·수집하고 합성 증강을 포함한 초기 학습 자료를 만든다. 모델 학습·유료 API·운영 변경은 이번 범위에 포함하지 않는다.

## 기준

- 요강 5쪽의 필수 평가 축은 HOMOGLYPH/JAMO/TRANSPARENT/OFFSCREEN이다. 도박·마약·성매매·성인물 등은 별도 의미 범주이며 요강이 닫힌 업종 목록을 제시했다고 주장하지 않는다.
- 원문 게시물, 기관의 예방·보도 인용, 검색 색인, 합성 자료를 구별한다. 검색어 반사 페이지, 삭제/접근불가 페이지를 실제 양성으로 세지 않는다.
- 기관 출처를 우선하며 민간 게시판은 외부 보조자료로 구별한다. 광고 연결 사이트·판매자 연락처를 방문하지 않는다. 텍스트와 게시물 HTML만 읽고 이미지·첨부파일·성인 콘텐츠는 수집하지 않는다.
- 실제 제목/본문/독립 댓글 귀속을 보존한다. 부모 게시물의 라벨을 다른 댓글에 전파하지 않는다. 정황만 있는 성인·마사지·대출 홍보는 불법 확정 대신 보류한다.
- 원문은 원본 파일과 해시·수집시각·URL·추출 위치를 기록한다. 학습용 비식별본은 원문과 별도다. 사이트 라이선스 및 제3자 게시물 권리 미확인은 명시한다.
- 라벨은 assistant가 근거를 기록한 잠정 라벨이며 사람 검수 완료로 소개하지 않는다. 보류와 미검수 항목을 정상으로 바꾸지 않는다.

## 양과 분할

우선 실제 본문 100건 내외를 탐색하되 동일 홍보 캠페인 반복은 독립 원문으로 부풀리지 않는다. 각 주요 의미 범주에서 최소 10개 독립 계열·3개 출처를 초기 다양성 점검 기준으로 삼는다. 이는 충분한 통계적 학습량의 보장이 아니다. 기준 미달 범주는 미확보로 보고하고 합성으로 충족했다고 계산하지 않는다.

분할은 증강 전에 원문/유사문구/출처·캠페인 연결 그룹으로 고정한다. 현재 읽고 분석한 자료는 개발/학습 후보이며 독립 최종 홀드아웃이라고 부르지 않는다. 사람 검수·권리 확인 전 자동 운영승격은 없다.

## 증강과 검증

- 라벨 보존 표현 증강(자모·전각·일부 닮은꼴·공백/제로폭)은 양성과 정상에 모두 적용하고 부모 ID/변환 내역을 보존한다. 정상 텍스트의 변형도 정상 의미를 유지한다.
- 인용/피해문의/독립댓글 대조는 새 합성으로 표시하고 실제 원문 관측과 분리한다. 마약/성매매 등의 실제 거래를 돕는 신규 연락처·배송·가격·거래 지침을 생성하지 않는다.
- CSS 은닉은 텍스트 라벨과 분리한 로컬 HTML fixture에 적용한다. 실제 사이트에서 관측된 은닉 기법이라고 보고하지 않는다.
- 중복·분할 누출·원문 구간 정합성·연락처 노출·보류 학습 제외·라벨별 증강 균형을 기계 검사한다. CPU 모델 정확도/F1 개선은 모델 평가 전 주장하지 않는다.
- 학습 JSONL, 전체 출처 장부, 잠정 검수표, 증강 계보, 범주별 부족분과 재현 절차를 제공한다.
