# 운영 원문 숫자 7개 ICL 선별 진단

v6 전체192회 및 독립 감사 관문 통과 이후에만 실행한다. 동결 ICL 예시·프롬프트·스키마를 수정하지 않는다. `.runtime/throughput-hypotheses-v1/inputs.json`의 전체137후보에서 기존 digitQueries로 자동 추출한7토큰을 전부 사용한다. 정답이나 광고 판정으로 선별하지 않는다. 원래·역순 각각 단일7회, 총14회다. 이 자료는 이미 관찰한 회귀 진단이며 새 홀드아웃이 아니다.

target_text는 원문 raw_text 그대로다. context는 현재 judgment.initialEvidence의 page_title/passage/scope/links/unscoped_nearby를 JSON으로 전달한다. passage의 대상·주변 순서와 귀속 표시는 보존하고 가까운 문구는 unscoped_nearby로 명시한다. 중복 normalized_text와 내부 source_ids는 제외한다. 해당7개의 links는 비어 있고 주소가 포함되지 않는다는 사실을 검증한다. 원문을 임의 삭제하거나 치환하지 않는다. 기존 의미 판정·정답·URL·스타일은 모델 입력에 넣지 않는다. ID는 원래노드@원문시작:끝으로 고정하고 원본 노드·구간·원문 해시는 별도 메타데이터로 보존한다.

HCX-007 none/temp0/seed42/58k/단일후보/순차를 유지하되 출력512로 실행한다. 이는 v6의1024에서 변경한 명시적인 운영 연결 조건이며 순수 프롬프트 효과 실험이라고 하지 않는다. 최대20호출/예약상한100만 토큰, 예상44,076예약토큰, 조건10분/전체1시간, 시작·조건간61초, 요청180초를 적용한다. 자동 재호출 없이 오류에서 중단한다. 경로는 `.runtime/digit-icl-operating-screen-v1`이며 dry run은 쓰지 않는다.

두 조건 모두 완료 후 원응답·정규화 판정·요청 재구성과 입력 동일성을 감사한다. 각 순서에서 양성2개를 모두 S, 정상3개를 모두 L, 모호2개를 모두 U로 판정해야 이 작은 연결 관문을 통과한다. 숫자 기법 판정만 평가하며 단어 복원 정확도를 주장하지 않는다. 부모 광고 판정과 숫자 S가 같은 요소에 있다는 것만으로 그 숫자가 광고 구간에 속한다고 확정하지 않는다.

통과해도 운영 관찰이나 최종 findings를 수정하지 않는다. 원문 구간 귀속·혼합 인용/광고·장문 통합·정상 오탐 및 저장/재개·동일25분 운영 효과는 별도 검증 대상이다. 이7개의 점수를 보고 프롬프트나 예시를 고쳐 반복 최적화하지 않는다.
