# 광고 의도 encoder 교체 진단 결과

2026-09-29. **이번 후보는 운영 미채택. 다음 모델 교체 비교의 출발점은 Nuri 1.0(A)의 학습 자료·방향으로 잡는다.** 이번 자료 선택은 기존 최선의 분류기를 개선하려는 목적에 충분히 맞지 않았다. 아래 결과는 Nuri1.2자료 일부에서의 제한 진단이며 A의 학습을 재현한 모델교체 실험이 아니다.

## 조건

Nuri1.2의10,000행에서 seed42로200시나리오 그룹 전체2,000행(광고800/인용400/일반600/근거부족200)을 뽑았다. 새KLUE-base/KcELECTRA/KLUE-large에 동일 입력·lr2e-5·전체학습·3epoch·유효batch8·micro1·BF16·gradient checkpointing을 적용했다. 개발204개 패널의 macro4평균 우선으로 선택했다. CPU8threads/batch8/FP32에서기존4종2,000개를회귀평가했다. 학습/개발/회귀입력완전중복은없지만동일생성자합성·관찰자료편향이있다. 새홀드아웃은아니다.

A는8,000학습/lr1e-5/FP32/임베딩+하위8층고정/개발최저광고F1우선선택의기존모델이다. 이번 세모델과학습자료·설정이달라모델종류만의효과로비교하면안된다. A를새조건으로재학습한모델은표의'새base'이며 A자체와구별한다.

## 학습 해석

새base의학습손실 .652→.0867→.0063에도개발macro4가13.53→12.89→12.64%로하락했다. 형식과적합/분포차우려다. 선택epoch1의개발광고F1평균은4.17%다.

KcELECTRA는선택epoch3의개발광고F1평균76.80%,macro4평균22.90%. 정상과불확실성구분은여전히부족하다. 댓글사전학습때문이라고단독원인을확정하지않는다.

large는학습손실이약1.3수준에서머물고개발204개와회귀2000개를모두광고로판정했다. **이번최적화조건의미수렴/단일클래스쏠림이며large의잠재성능한계를증명하지않는다.** 동률인epoch1선택. 같은학습률을사용했다고각모델에최적조건인것은아니다.

세후보모두사전후속관문실패. 새base가매우약하므로그것보다높다는사실만으로유망함을부풀리지않는다. 평가결과에맞춰추가학습/설정변경/최종셋반복을하지않았다. 운영HCX·기존모델·수집코드변경없음,유료API0,push0.

## 바로잡을 후속 비교

4종균형의학습출발점은A다. D는같은2000개F188.27%로A보다낮지만문맥개발120/44개에서84.09/77.42%로A65.38/48.00%보다좋았다. 따라서A를모든문맥최고라고정의하지않는다.

먼저A의8,000개원자료·NFC입력·freeze방식·학습률·개발선택을재현한다. 그다음동일자료로KcELECTRA를우선비교하고D가강했던문맥패널을함께확인한다. large는학습수렴검증부터필요하다. 24층모델에8층을그대로고정하는것과하위2/3를고정하는것은다른변경이며별도명시해야한다. 이후속실험은이번에시행하지않았다.
