## 유지와 파인튜닝 판단

1. **현재 제출·운영은 HCX 유지.** 동일 조건에서 큰 F1 차이, 기존 정탐 보존, 오탐 감소가 확인됐다. 이 제한 실험의 수십~백원 수준 목록 비용만 줄이려고 검증되지 않은 EXAONE로 바꾸는 것은 합리적이지 않다. 다만 실제 사용 규모·문맥 길이에 따른 월 예산은 따로 정해야 한다.
2. **API 리스크는 남는다.** 실제 응답에서60RPM/60,000TPM을 확인했고, 실험은58RPM/58kTPM·61초창·최소1.05초 간격을 적용했다. 단일 조건 대기109.51초는 무시할 수 없다. 계정 공유·네트워크 장애·외부 전송 제한·누적비용은 정확도와 별개이며 호출/토큰 예산, 부분저장·재개가 필요하다. 이번에는 운영 코드를 변경하지 않았다.
3. **EXAONE 파인튜닝 가치는 조건부다.** 오프라인/CPU 운영과 API 의존 제거라는 목적에는 가치가 있다. 그러나 현재 재현율은 정상79개 오탐을 동반하므로 학습 후 보존되는 강점으로 가정하지 않는다. 기존 정탐을 유지하면서 정상 문맥 오탐을 크게 줄여야 HCX 단일F1 91.43%에 접근한다. 학습 효과를 측정하지 않았으므로 성공 확률이나 예상F1을 제시하지 않는다.
4. **후속은 제한된 LoRA 파일럿 정도가 적절하다.** 먼저 원본/양자화 및 출력 계약의 영향을 확인하고, 이번 평가 문구와 분리한 사람 검수 대조 자료를 학습한다. 개발자료 반복 조정으로99.21%에 맞추지 않는다. 미사용 자료에서 HCX와 정확도·보류·CPU속도를 비교하고 마지막에는 Q4 및25분 종단으로 확인해야 한다.
