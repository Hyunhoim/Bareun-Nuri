# HCX 입력·출력량 독립 감사

운영 변경·유료 API·Phase2 접근 없이 실행했다. 출력384만 제한 실호출 비교 후보로 남기며, 입력 공용표는 이번 목표에서 제외한다. 채택은 아직 아니다.

## 출력 상한

| 저장 자료군 | 응답 수 | 완전 ID·스키마 유효 | 출력 중앙값 / p95 / 최대 |
|---|---:|---:|---:|
| Phase1 전체 재개 | 516 | 510 | 282 / 300 / 314 |
| 동시3 실제25분 | 375 | 371 | 283 / 300 / 314 |
| 초기 운영 Phase1 | 160 | 159 | 284 / 298 / 308 |
| 최초 동시성 비교 | 96 | 92 | 280 / 298 / 302 |
| 동시3 반복 | 96 | 92 | 280 / 299 / 302 |
| 동시2·3·4·5 비교 완료 응답 | 95 | 91 | 279 / 298 / 302 |

합계1338응답은 같은 요청을 반복한 자료가 포함돼 독립 표본 수가 아니다. 모든 응답이384이내이고 최대314여서70토큰 여유가 있다. 384와448 모두 저장 응답의 용량 감사는 통과하지만, 새 생성의 길이·판정 동일성은 미확인이다. 낮은 상한으로 재생 결과를 자른 것이 아니며 API 출력을 모사하지 않았다. 기존 불완전ID응답은 길이가 작아도 여전히 실패한다. 출력 여유 감소가 ID누락을 해결한다는 근거도 없다.

실제 입력토큰+예약출력512 기준 384의 예약량 감소는 full516에서4.0186%, parallel375에서4.0121%다. 448은각2.0093/2.0061%다. 이는 사용요금이나 실측지연 감소율이 아니다. 생성한 출력 길이가 같으면 확인 사용량은 같을 수 있다. 큰 폭의 가속을 기대할 후보는 아니다.

`local-benchmark/payload-cap.cjs`는 maxCompletionTokens만512→384로 바꾸며, 원래 전체516요청에서 다른 모든 필드/프롬프트/ID/후보순서 불변을 assert했다. 실호출이 필요하다면 기존 균등선정24요청을512/384/384/512로96콜(약30만 확인토큰 예상, 실제 한도50만) 비교할 수 있다. 최종판정F1·기존정탐·FP·불완전응답·잘림·순서변동·시간을 함께 확인하고, 개선이 미미하면512를 유지한다. 본 하위작업은 실호출하지 않았다.

## 입력 공유표

기존 `phase1-speed-compact.cjs`를 그대로 재생했다. 전체516요청/5070후보의 역복원 동일, 실제변환222요청이다. 보수적 예약추정2582153→2557427로0.9576%만 감소했다. 코드 가역성과 HCX 의미 해석 동등성은 별개다. 다른 후보의 문맥 참조 해석 위험을 추가할 정도의 절감 근거가 없어 유료확대하지 않는다. 원문·문맥·정규화 읽기를 삭제하는 후보도 이번 정확도보존 목표에서는 보류한다.

## 검증·한계

실행: `node local-benchmark/payload-audit.cjs`, `node local-benchmark/payload-cap.cjs`. 기록 `.runtime/payload-audit-v1/audit.json`.

`local-benchmark/payload-live.cjs`는 기존 실호출 하니스에서 고정3 wave와512/384/384/512만 비교하도록 분리했다. `--selftest`와구문검사를 통과했고 `--live`는 실행하지 않았다. 동일wave의3응답이 끝난 뒤 다음3요청을 시작하므로 rolling실험이 아니다. 61초공유창/58k/1초발송간격/조건사이61초를 유지한다. 요청·원응답·unknown을보존하고 기존출력폴더 재실행을 거부한다. `--score`로 평가 재계산 가능하다. 판정손실/새FP/격리·응답실패 증가 없음 및 두쌍모두개선·평균5%초과를 소규모 후보선정조건으로 사전고정했다. 25분운영승격은 별도다.

현재 스키마·12묶음·none 기준이며 향후 설명출력·추론·큰묶음에는384를 자동승계할 수 없다. 이미관찰한 동일Phase1을 기반으로 하므로 일반화 향상 증명이 아니다. 출력 상한을 더 세밀하게 실패점에 맞추는 조정은 하지 않았다. 정상자료의 길이감사 통과만으로 정확도 보존을 선언하지 않는다.
