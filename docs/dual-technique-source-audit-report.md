# 후속 실제 문맥 자료 감사

2026-09-30. 기존 저장 자료의 출처와 중복을 확인했다. 새 학습·최종 평가·API 호출 없이 후속 자료의 적합성을 점검한 결과이며, 모델 성능 개선 결과가 아니다.

실제 공공페이지 8개에서 저장한 1,636후보는 공백만 정리해 중복을 묶으면 939개다. 그중 859개는 20자 미만, 71개는 20~350자, 9개는 350자 초과다. 길이는 문자 수이며 토큰 한도가 아니다. 짧다는 이유로 운영에서 제외하지 않는다. 독립적인 본문 문맥 1,636개가 확보된 것으로 보고하면 안 된다.

4개 호스트 사이에 같은 문구가 중복된 그룹도 17개다. 사이트별로만 분할하면 공유 메뉴·푸터가 양쪽에 들어갈 수 있으므로 원문 파생 그룹도 함께 관리해야 한다. 저장본 28개(실제8·복제본20)의 출처 해시는 전부 검증했고 자료 목록은 실제 후보만 사용했다. 기존 운영 소스 15개의 해시도 유지됐다.

`.runtime/dual-technique-v1/source-audit/review-bank.json`에 원문·문맥·URL·selector·중복 그룹을 보존했다. 기법 정답은 전부 미입력이다. 기존 사람 검수의 광고 의도 정상 판정을 JAMO/HOMOGLYPH 부재 정답으로 바꾸지 않았다. 원래 분해 자모가 포함된 첨부파일명처럼 광고가 아니어도 문자 관찰이 존재할 수 있다. 자료는 로컬 검수용이며 미사용 최종 자료가 아니다.

## 후속 학습 결정

현재 자료만 반복 변형해 대규모 학습을 재개하지 않는다. 직전 진단에서 학습 역할 대조는 이미 완전히 맞히지만 새 문장틀에 실패했다. 이번 원문 목록 역시 짧은 공통 UI 문구에 편중되어 있어 반복 생성으로 그 문제를 해결했다고 볼 근거가 없다.

다음 학습에는 실제 문맥에서 표기가 원래 식별자인지, 치환인지, 판단 불가능한지를 검수한 자료와 다른 출처의 충분한 본문 문맥이 필요하다. 통제 변형을 추가할 경우 원래 게시물과 인위적 변형을 구분하고, 원래 표기·문장 계열을 공유하는 변형은 한 분할에 둔다. 현재 목록의 원문에 정답 설명을 임의로 추가하거나 기존 최종 실패 문구를 학습하지 않는다.

KcELECTRA는 연구 후보로 보존하지만 기존 정탐 보존 목표는 여전히 미달이다. 현재 Goal 도구 상태는 blocked이며 완료로 변경하지 않았다. 다음 작업은 검수된 자료 확보로, 동일 합성 문구 추가 epoch는 시행하지 않았다. 기존 HCX+코드 운영을 유지한다.
