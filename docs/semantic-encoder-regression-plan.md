# 새 분류기의 저장 HCX 응답 비교

2026-09-29. 새9조건 학습 진행 중, 이 회귀의 모델 예측을 보기 전에 작성했다.

기존 `.runtime/slm-three/inputs.json` 221개 중 `human17`은 이번 훈련셋에 들어 있으므로 비교에서 제외한다. 나머지 개발204개와 저장된 `.runtime/exaone-hcx-v1`의 단일/12개묶음 HCX 응답을 사용한다. 새 API 호출0. 원요청·원응답·입력 해시를 다시 검사한다. 과거에 관찰된 합성 문맥 회귀이며 새 독립 실제 평가가 아니다.

9조건이 모두 완료된 뒤 모델별로 새 개발셋의 사전 rank가 가장 높은 조건1개를 선택한다. 동률은 기준512/freeze8,256/freeze8,512/full 순으로 먼저 실행한 조건을 유지한다. 이204개의 점수로 재선택·재학습·임계값 조정하지 않는다. 새 개발 관문 미통과 모델도 비교 표에는 실패 후보로 표시한다.

정규화 동일 훈련 입력이 발견되면 비교에서 제외하고 수를 보고한다. 원문이 다르다는 사실을 의미·작성자 독립성으로 해석하지 않는다. Nuri1.0도 같은 자료에서 회귀 기준으로 측정하되 학습자료/4분류헤드가 다른 역사적 모델임을 명시한다.

라벨 0(광고)을 새모델의1에, 1/2(인용/일반)을0에 대응시키고 근거부족3은 이진F1에서 제외한다. 새모델은 강제이진과 사전고정 .2~.8 확률보류 진단을 따로 표시한다. HCX의 정탐을 잃은 수, HCX가 놓친 광고 회복, 정상 오탐 해소/신규를 비교한다. HCX의 명시적 근거부족 분류와 이진모델 확률 보류는 같은 능력이 아니다.

CPU 시간은 현재 재측정, HCX 시간은 과거 저장 실행이므로 동시 통제 속도 비교나25분 운영 대체 증거로 주장하지 않는다. 범주 계약은 실제 저장 system 지시문에 근거하며 새로운10유형 전체에 대한 HCX 비교로 확대 해석하지 않는다.
