다음사이클에서는관찰한최종들을개발검증으로전환해여러구조를함께선택기준으로쓴다. 이점수를새홀드아웃으로주장하지않고새최종은별도로둔다. 광고문장자체의조합문법을넓히고사전학습가중치를덜바꾸는조건을검증할가치가있다. 동일최종에서선택모델을바꿔가며좋은점수를찾지않는다.
