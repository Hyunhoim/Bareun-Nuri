# 숫자 치환 Goal 4차: 소속 문맥의 표기 역할

2026-09-26. S 단일대상은 개발에서 치환24개와 정상20개를 원래/역순 모두 맞혔지만 모호12개 중7/8개를 과도 확정했다. 새72개에서는 치환26/32, 정상오탐1/24, 모호과도확정16/16으로 단일화만으로 일반화를 확보하지 못했다. S를 운영에 채택하지 않는다. 새자료 오류단어/문구는 수정에 사용하지 않는다.

이번 가설은 새자료 결과를 열기 전에 제안한 질문 전환이다. 기존 S 마지막 지시의 직접 치환 분류를 '이 표기가 현재 소속 문맥에서 어떤 역할로 사용되는가'로 바꾼다. 일반 단어의 뜻을 전달하는 변형 사용/원형 보존이 필요한 식별표기/쓰임 미확인을 기존 substitution/literal/uncertain에 대응한다. 이는 H의 가설대조와 의미상 일부 겹치는 제한적 시도이며 완전히 새로운 방법으로 주장하지 않는다.

변경은 마지막 SYSTEM 지시뿐이다. 같은 개발56개 전부, 동일한 부분/완전 복원가설, 단일요청, 기존3분류 출력, ID 검증·후처리를 사용한다. 인용 생성, 새 출력 필드, 단어·길이·사례 예외, 코드 기반 정상/광고 판정은 추가하지 않는다. 역할 지시를 결과에 맞춰 반복 수정하지 않는다.
