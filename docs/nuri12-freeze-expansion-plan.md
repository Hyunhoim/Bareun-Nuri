# 고정 범위 확대의 사전 기준

사용자 후속 승인에 따라 먼저 진행 중인 full/freeze8 네조건을 마친다. freeze8 결과 확인 전에 확대 기준을 명시한다. 기존 Nuri개선/A대체 관문은 변경하지 않는다.

동일 초기화(full/freeze8),같은epoch/step의6개 비교 중 적어도2개에서 freeze8의 합산광고F1 +2%p 이상·평균macro4 +3%p 이상·불확실→광고 비증가를 모두 충족하고, freeze8 선택체크포인트가 기존 Nuri개선 관문까지 통과하면 방향성 있는 진단 신호로 본다. 통계적 유의성이나 독립 일반화 증명으로 부르지 않는다. 정탐/오탐 교환과 다른 체크포인트의 회귀도 함께 보고한다.

해당 신호가 있으면 그 초기화 조건에서만 freeze4/freeze10을 같은 데이터·순서·lr·2epoch로 비교한다. 중간 체크포인트·선택 기준도 유지한다. 두 초기화 모두 충족하면 기존 사전 선택순위가 높은 쪽을 사용한다. 점진적 해제는 고정4/8/10의 일관된 손익이 확인될 경우 별도 사전 계획으로 검토하며 자동으로 모두 시험하지 않는다.

신호가 없으면 이번 동일자료 범위 확대는 하지 않는다. full이 나아도 freeze8 개선이라고 해석하지 않는다. 기존 개발셋 반복 선택 편향을 보고하고 최종평가를 열지 않는다.
