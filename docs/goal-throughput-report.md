## 저장과 판정 배분

전체 집합·원문·위치·관찰 근거·중단 재개·미확인 요청 재호출 방지 및 출력 계약을 확인했다. 실제 저장16페이지에서도 12회 연속 실행과5회 중단→12회 재개가 동일했다. API0 검사는 모델 정확도의 근거가 아니다.

## 채택 판단

FIFO 수집·브라우저 재사용·HCX none/act4/출력3072는 유지한다. **불변 근거의 디스크 저장 + 활성8페이지/최대2페이지근거 로딩 + 페이지별최대4개 판정 + 남은 작업이 적은 페이지 우선/8턴 대기 보호**를 채택했다. 새 사이트에서 기존31개 정탐을 보존하고, 복제본에서 동일25분 내 의미4개·최종기법2개 정탐이 추가됐다. 명시된 위치의 새로운 정상 오탐은 없고, 기존정탐손실도0이다.

완주 속도의 획기적 향상, 모든사이트의 메모리 감소, 전체 누락 해소를 주장하지 않는다. 사이트에 따라 호출·토큰은 증가할 수 있다. 512는 새64개평균F1하락 때문에 보류하며 미채택 입력축약·캐시·동시2호출도 추가하지 않는다.
