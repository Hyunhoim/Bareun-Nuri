# Filter 1.0 초기 파인튜닝 계획

2026-09-29 사용자 요청. 순정 로컬 KLUE RoBERTa-base에서 새2분류 헤드를 초기화한다. Nuri1.0/D 이어학습이 아니다. 최종26개 내용/정답을 열거나 추론하지 않는다. 원래 자료의 human_reviewed=false 상태는 유지하며 사용자 요청에 따른 합성 파일럿 학습만 허용한다.

훈련96개/40계열, 개발26개/10계열. Codex가 훈련/검증의 원형100개(50계열×2라벨)를 읽어 의미 계약을 재검토했고 라벨 수정 없이 진행한다. 독립 검수로 부르지 않는다. 원문·문맥 토큰화/귀속·라벨 분리와 기존 해시를 확인한다.

seed42, GPU, 전체층 학습, 배치8, AdamW lr2e-5/weight_decay0.01, 최대4epoch·10분 상한. 계열당 총 가중치를 같게 하고 HCX 전달 라벨 오류 비용2배(정상1배)로 둔다. 설정 탐색/후속 재학습 없음. 기존 helper의 입력 형식 및 padding을 재사용한다.

모델 p(HCX)<t이며512토큰 이내일 때만 제외. t=[0,.01,.05,.1,.2,.3,.4,.5]. 각 epoch 개발에서 광고와 근거 부족을 포함한 HCX 라벨 손실0 중 정상 제외 최대 조건을 고른다. 동일 제외 수이면 낮은 개발 CE, 그다음 작은t/이른epoch. 후보가 없으면 전체통과. 선택된 체크포인트를 고정한 뒤 기존221개와2,000개 관찰 자료에 1회 적용한다. 그 결과로 임계값이나 모델을 다시 고르지 않는다.

기존 D는 고정 필터 p(ad)<.0001,p(ordinary)>=.9,argmax ordinary 및 잘림통과를 동일 개발26개에 적용한다. 기존221/2000 D 저장점수도 사용한다. Filter 1.0의 기본0.5 분류와 선택 필터 성능을 분리한다. 지표는 광고/보류 통과, 정상 제외, 전달 F1, CPU 지연이다. 기존 자료 광고 손실이 있으면 운영 미채택. 없더라도 독립 실사이트/25분 종단 효과 확인 없이는 운영 채택하지 않는다.

개발 결과가 높고 관찰 자료가 나쁘면 합성 지름길/분포 차이 위험으로 보고한다. 작은 개발 점수만으로 일반화 개선을 주장하지 않는다. API/운영 소스/push 변경 없음.
