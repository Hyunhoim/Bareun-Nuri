# 숫자·닮은꼴 기법: 실제 수집 입력의 고정 모델 비교

2026-09-29. **운영 변경 없음. 합성자료에서 유망했던 특화 분류기를 바로 채택할 근거는 부족하다.** 이번 검증은 저장 자료 진단이며 새 사이트 종단 또는 독립 최종 평가가 아니다. Goal은 계속 진행한다.

## 범위와 입력 감사

실제 공공사이트 8페이지와 부산 DOM 복제본 20페이지의 기존 5,179후보에서 문자 구간을 추출했다. 원래 코드 미확정 힌트는12구간, 영문·숫자 혼합까지 확장하면26개 요소의80구간이다. 확장 후보 생성도 실험 경로에만 있다. 명확한 코드 확정은 유지한다.

스냅샷 해시와 80구간의 원문·UTF16오프셋·URL·선택자·대상 마킹을 검증했다. 수집 문맥의 잘림 표시와 별개로 분류기 토크나이저에서59개가512토큰을 초과했다. 잘린 입력으로 확정하지 않고 미처리로 보존했다. 따라서 모델 저장기록80건 중 정상적인 판정은21건이다. HCX도 공정한 공통 입력 비교를 위해21건만 호출했으며, 이것이 HCX의 입력 한계라는 뜻은 아니다.

처음 전체80개 HCX 실행은 예약량 사전 검사에서 전송 없이 거부됐다. 공통21개로 실행 범위를 계획에 기록한 뒤 유료 실행했다. 정답은 요청에 포함하지 않았다.

## 확인된 결과

|---|---|---|---|---|---|
| B3T | 미확정 | 미확정 | 미확정 | 미확정 | 치환/치환 |
| V1D30 | 미확정 | 치환 | 치환 | 치환 | 치환/치환 |

정답이 확인된 광고 구간이2개뿐이다. 이 표를 실제 공공사이트 전체의 재현율/F1로 일반화하지 않는다. 합성자료의 높은 분류기 점수가 실제 수집 입력의 실패를 해소하지 못한다는 진단 근거다.

정상 글의 B2C를 역할보강 모델은 치환으로 판단했고 최초/동의는 미확정, HCX는 두 순서 모두 일반 표기로 판단했다. X100은/A2047은은 모두 일반 표기로 판단했다. 정상 글에도 PUBL1C/D3T41L처럼 문자치환 자체는 존재할 수 있으므로 정상 광고의도 라벨을 기법 음성 정답으로 바꾸지 않았다.

HCX는21개 중1개(PUBL1C)가 순서에 따라 치환↔일반 표기로 바뀌었다. 두 모델 동의와 HCX 모두 실제 공공페이지 이메일 계정의 숫자를 치환으로 확정했다. 독립 기법 정답이 없는 오확정 의심 사례로 기록하며 확정 FP로 집계하지 않는다. 이메일 전체는 보고서에 전재하지 않는다.

## 시간·비용과 미검증

HCX 각21구간: 원순10.853초/6호출/6,068토큰, 역순10.414초/6호출/6,067토큰. 총12호출·12,135확인토큰이다. 원응답 및 종료 기록을 보존했다. 광고 의도 판정 비용은 포함하지 않는다.

CPU 모델은 최초18.869초, 역할보강18.320초다. 이 측정은 보호될59개까지 실제 추론한 뒤 판정을 폐기한80개 실행이어서 HCX21개 시간과 직접 우열 비교하면 안 된다. 사전 길이 검사 후 보호 입력을 추론에서 제외하면 불필요한 연산을 줄일 수 있지만59개의 기법 미처리는 해결되지 않는다.

25분 종단, 새 독립 검수 기법 정답, 전체4종 회귀는 이번에 수행하지 않았다. 한국어 조사가 영숫자와 붙은 구간과 긴 상위 요소가 함께 추출되는 문제도 남는다. 단순히 긴 문맥을 자르면 귀속·인용 의미를 잃을 수 있어 아직 수정하지 않았다.

## 다음 실험의 우선순위
