# INT8 중간 출력 진단 사전 계획

2026-09-29. 수치 진단24조건과 세 모델 graph optimization 비교에서 CPU 포화/최적화 주원인 증거를 얻지 못했다. 다음 가설은 양자화한 특정 연산에서 큰 오차가 생겨 누적됐다는 것이다. 가장 큰 의미 회귀가 관찰된 동결 Kc 모델만 먼저 진단한다. 광고 라벨/문장/기존 실패 입력을 읽지 않는다.

기존 seed42 난수 입력 네 배열을 정확히 재생한다. FP32/INT8 그래프의 공통 MatMul, Gemm, LayerNormalization 출력과 logits를 추가 출력으로 노출한다. ORT_DISABLE_ALL로 실행하며, 추가 출력 전후 최종 logits가 기존 결과와 1e-5 이내인지 확인한다. 원본 ONNX는 수정하지 않고 메모리의 복사본만 계측한다. 중간 배열은 NPZ로 보존한다.

각 출력의 최대 절대 오차와 상대 L2 오차, FP32 크기를 전체 목록으로 보고한다. 상대 L2는 참조 노름이 거의0이면 비율 해석을 피한다. 큰 오차가 보이는 위치는 누적 오차가 관찰되는 위치이며 그것만으로 해당 연산이 최초 원인이라고 단정하지 않는다. 토큰 위치의 마스킹 여부와 배치 크기도 함께 보존한다. 양자화 가중치의 역변환 오차를 기록해 가중치 자체의 큰 손실과 활성값/누적 오차를 구분할 단서를 얻는다.

이번 범위는 원인 위치 탐색이다. 추가 학습/재양자화/선별 FP32 예외/임계값 튜닝/광고 평가/API/운영 변경은0. 원인이 구체화되면 별도 통제 실험 가설과 범위를 먼저 고정한다. 그렇지 않으면 미확정으로 보고하며 기존 FP32 후보를 유지한다.

## 중간 출력 확인 후의 분리 실험

123개 공통 출력과74개 가중치 역변환 오차를 관측했다. 계측 전후 logits 차이0. 첫 층부터 오차가 누적됐고 8번 층의 최종 정규화 출력에서 상대 L2가0.40~0.53이었다. 가중치 역변환의 최대 상대 L2는0.0222 미만이다. 이 사실만으로 활성값 양자화가 원인이라고 단정하지 않는다.

다음 두 통제를 결과 확인 전에 고정한다. (1) 기존 INT8 파일의 양자화 가중치를 정확히 역변환하여 FP32 그래프의 해당74개 가중치만 교체하고, 동일 네 난수 배열을 FP32 연산한다. 새 양자화는 하지 않는다. 이 W8A32 역변환 시뮬레이션은 배포용 경량 모델이 아니며 가중치 반올림만의 영향을 분리한다. 원본→가중치만변경→기존INT8의 차이를 보고하며 비선형 상호작용 때문에 오차를 단순 가산 분해하지 않는다. (2) 기존 배치8 입력의 각 행을 동일 길이/동일 마스크로 단독 실행해 FP32/INT8 각각의 묶음 출력과 비교한다. 배치 독립성 차이를 측정하며 의미 정답·속도 개선은 채점하지 않는다. 더 유리한 난수 seed/길이 탐색은 하지 않는다.
