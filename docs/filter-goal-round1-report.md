# 필터 일반화 Goal: 첫 개선 주기 결과

2026-09-29. **목표 미달·Goal 진행 중. 추가 학습 C/F/T는 운영 미채택이며 HCX 운영을 유지한다.** D가 현재 관찰 자료에서 가장 나은 보수적 기준선이다. 공공사이트 전체에 안전하다고 검증된 필터는 아직 아니다.

## 수행 내용

새 혼합의도 대조자료30계열120문장(훈련64/개발24/확인32)을 작성했다. 정상 글과 권유의 앞뒤 순서, 신고·거절 인용, 근거 부족을 포함한다. 운영 수집기로480표시 변형을 읽어 원문·대상 귀속을 확인했고 의미 입력 중복을 제거했다. 기존 누락 문장이나 실제 복제본 제목을 학습에 넣지 않았다. 자료는 작성자 제안 라벨의 합성이며 독립 사람 검수가 아니다.

기존96개와 보강64개를 합친160입력/56계열로 C(이어학습3epoch)와 F(순정4epoch)를 비교했다. 개발26+24로 checkpoint를 선택하고, 이미 관찰한221/2000개를 보정자료로 명시해 임계값을 선택했다. 선택에 사용한 점수를 독립 확인 성능으로 주장하지 않는다.

추가로 정상 페이지 제목에 대한 의존이 발견돼 T(순정4epoch)를 비교했다. 대상·귀속 문맥은 유지하고 정답과 무관한 긴 정상 제목을 라벨 양쪽에 붙였다. 훈련480변형은160입력의 파생이며 독립480상황이 아니다. 개발100개도50입력의 원형/제목 변형이다.

## 관찰된 상한과 임계값 보정

격자에 있는 값만 비교하면 분리 구간을 놓칠 수 있었다. 모델별 보정 자료의 필수전달 최저점수까지 정상 제외 수를 계산했다. 아래는 **관찰 자료에 맞춘 경험적 상한**이며 운영 안전 보장/일반화 상한이 아니다.

| 모델 | 보정 정상 수 | 무손실 경계에서 정상 제외 | 고정 격자에서 선택된 제외 |
|---|---:|---:|---:|
| 기존 Filter1.0 | 1,145 | 170 | 0 |
| C | 1,145 | 332 | 206 |
| F | 1,145 | 176 | 173 |
| T | 1,170 | 761 | 0 |

T는 .02와.05 사이에 분리 구간이 있어 '분리 구간이 없다'는 초기 해석을 정정했다. 추가 사전 보정 문서에 따라 필수전달 최저점수 .0459837876의0.8배인 **.0367870301**을 새로 고정했다. 보정 정상689/1170 제외·전달1151/1151 보존이었다.0.8은 경험적 여유일 뿐 위험확률 상한이 아니다. 원래 t=0 결과는 보존했고 사전 격자 관문을 소급 통과했다고 주장하지 않는다.

## 실제 수집 구조에서의 비교

저장된 실제8페이지1,636개와 부산 복제본20페이지3,543개를 사용했다. 모델 입력512토큰 초과16개와 수집 문맥 잘림 표시739개는 제외를 금지했다. 아래 '제외'는 **후보 수**이며 미라벨 후보를 정상으로 간주하지 않는다.

| 구조 | 실제 후보 제외/1,636 | 복제본 후보 제외/3,543 | 복제본 광고 손실/28 | 근거부족 손실/4 |
|---|---:|---:|---:|---:|
| D + 동일 입력 안전장치 | 104 (6.36%) | 337 (9.51%) | **0** | **0** |
| C 단독 | 855 (52.26%) | 888 (25.06%) | 8 | 4 |
| C와 F가 모두 동의 | 809 (49.45%) | 777 (21.93%) | 6 | 4 |
| C 전체문맥+대상단독 동의 | 2 (0.12%) | 24 (0.68%) | **0** | **0** |
| T + 보완된 임계값 | 1,447 (88.45%) | 1,715 (48.41%) | 7 | 4 |

D는 통제 정상32개 중7개를 제외했다. 실제 사람 검수 정상17개에서는 안전장치 적용 후 제외0이다. D 제외441개 중434개는 미라벨이며 이들 전부가 정상이라고 확정하지 않는다. 수집 문맥 잘림 보호를 추가했으므로 이전D의120/552 제외와 다르다.

C는 보정에서 광고1078·보류48을 보존했지만 실제 복제본에서 실패했다. 긴 정상 정책 제목 아래의 짧은 명사형 광고와 문맥 의존 링크가 주요 누락이었다. 잘못 제외된12개를 제목 제거/대상단독 진단하면 모두 모델 전달점수가 .005 이상으로 바뀌었다. 이는 게이트가 빈 문맥을 자동통과시킨 결과가 아닌 모델 점수 변화다. 제목 영향 가설을 지지하지만 모든 오류 원인을 확정하지 않는다.

대상단독 보조 판단은 실제 손실을 막았으나 제외가 거의 사라졌다. 두 모델 동의도 같은 오류를 공유해 안전성을 확보하지 못했다. T는 새32확인(관찰 회귀)에서 정상13/16 제외·전달16/16 보존, 소비된26회귀에서정상13/13 제외·전달13/13 보존이었으나 복제본에서 실패했다. **합성 회귀 점수 상승을 실사이트 일반화 개선으로 해석하면 안 되는 사례**다.

## 최종자료 사용 기록

C의 모델/임계값 고정 후 당시 미사용26개를1회 평가했다. 광고8개는 보존했지만 근거 부족1개가 제외됐다. 이후 분석에 사용됐으므로 나머지 비교는 모두 관찰 회귀다. 새 최종 세트를 반복 생성하지 않았고 최종 문장을 훈련에 넣지 않았다. `local-benchmark/filter-data-v1/evaluation-status.json`을 현재 상태로 참고한다. 최초 생성 manifest의 평가0회는 생성 당시 기록이다.

## 시간과 기능 안전성

5,179개 C CPU 추론168.79초, T173.63초다. C→F 동의는 후보1,743개에 추가41.11초, 대상단독은추가18.93초가 들었다. 과거 D의 전체 추론166.27초는 참고값이며 새 안전장치 적용 후 종단시간을 측정한 것은 아니다. 실제 HCX 호출/재묶음/25분 속도는 이번에 측정하지 않았다. 후보 제외율을 시간·토큰 절감률로 부르지 않는다.

`local-benchmark/safe-filter-stage.py`는 **D 고정 기준의 별도 실험용 라우팅 단계**다. 정답 판정을 만들지 않고 EXCLUDE/HCX 경로와 원문·문맥·위치·점수를 보존한다. 입력/수집 잘림·문맥 미확인·비정상 점수는 HCX 통과, 원본 ID/순서를 유지한다. 서명에는 모델·코드·입력·기준을 포함하고 바뀐 입력으로의 자동 재개를 거부한다. API를 호출하거나 운영에서 import하지 않는다.

실제 수집 원문40개 및 보호 검사2개로 CPU 실행,13개 중단 후 재개, 기존13개 결과 동일, 중복0, 입력 변경 거부 시 이전 파일 불변을 검증했다. NaN/비정규 확률/513토큰/문맥누락/보류 통과도 검사했다. 근거: `.runtime/safe-filter-stage-check-v2/result.json`. 초기v1 기능검사는 잘림 표식을 시험값으로 고정했으므로 최종 근거는 실제 수집 표식을 연결한v2다. 백엔드/웹 통합 검증이라고 주장하지 않는다.

## 결정과 다음 단계

- C/F/T 및 추가 동의 방식은 운영 미채택. 같은 합성자료의 epoch/임계값 반복 조정으로 더 진행하지 않는다.
- D + 잘림/불확실입력 통과를 기준선으로 보존한다. '안전한 실무 필터 완성'으로 표시하지 않는다.
- 다음 개선은 단순 자료 양 증가보다 **넓은 표현을 배운 기존 모델의 의미 능력 보존**, 실제 길이·제목·짧은 대상 분포의 검수 자료 확보를 분리해 검증해야 한다. 정답 미상 제외를 정상으로 재학습하면 안 된다.
- 독립 검수용 `.runtime/filter11-v1/D-independent-review.csv/json`에 미라벨434후보를 보존했다. 점수/제안 정답은 제외했지만 모델이 선택한 집합이라는 표본 편향은 남는다. 검수 완료로 간주하거나 자동 학습하지 않는다.
