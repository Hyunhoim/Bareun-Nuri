# 일반화 후속: 의미와 무관한 페이지 제목 불변성

제목 제거 진단에서 C의12누락이 모두 전달로 바뀌었지만 대상 단독 동의는 실제 제외2/1636으로 실용성이 사라졌다. 입력 근거를 지우거나 실패 문구를 학습하는 대신 제목에 대한 지름길을 보강자료로 줄인다.

기존 훈련160개의 대상·귀속 문맥·라벨은 그대로 유지하고, 첫 줄 페이지 제목만 독립 작성한 긴 정상 행정 제목으로 대체한다. 제목은 라벨 양쪽에 균등 배치하며 의미를 결정하는 같은 게시물의 앞/뒤 문맥을 삭제하지 않는다. 새 제목은 기존 실제 복제본 제목을 복사하지 않는다. 개발은 다른 제목군을 사용한다. 늘어난 변형 수를 독립 의미 사례로 부풀리지 않는다.

후보 T 하나만: 순정 KLUE, seed42, lr2e-5, 전체층, 배치8, 최대4epoch. 전달 비용2배/계열균등 유지. 훈련 원래160+제목변형 각2개=480. 개발50+별도제목변형50=100. checkpoint/threshold는 앞선 고정 격자와 안전 제외 기준 그대로. 기존 관찰221/2000은 보정용. 초기실험에서 이미 소비한 최종26은 회귀로만 사용하며 새 최종은 만들지 않는다.

보정에서 정상 제외가 개선되면 실제 수집5179개와32확인/26관찰 회귀를 재검증한다. 실제 수집의 제목·명사형 사례를 학습시키지 않는다. 기존 확인을 여러 번 사용하므로 유망하더라도 새로운 독립 일반화 증거로 주장하지 않는다. 실패하면 동일 자료 기반 반복 학습은 종료하고 독립 실제 문맥 라벨 확보로 전환한다.
