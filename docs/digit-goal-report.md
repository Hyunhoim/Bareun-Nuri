## 16차 별도 최종 영향·숫자 구간 귀속 진단 — 미채택

`docs/digit-final-attribution-plan.md`를 별도로 고정하고 정순/역순72회 실제 호출했다. 이전 v7 관문 실패 및 차단된 conditional span80은 수정하지 않았다. 기존 B의 운영7·관찰한 식별자 실패5개 응답을 감사 후 재사용하고, 새 합성 숫자12개의 B 판정과24개 구간의 기존 게시행위 계약을 실제 호출했다. 알려진 실패 중심 진단이고 새로운 일반화 평가가 아니다.
