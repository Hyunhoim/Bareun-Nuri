# 실제 공공 DOM 기반 광고 판정 평가·개선 — 2026-09-25

사용자 요청: 공공사이트 복제본의 이용자 작성 영역에4종 위장 광고와 정상 대조를 균형 무작위 배치하고 현재 운영을 측정한 뒤, 발견한 공통 병목을 병렬 비교해 F1 중심으로 개선한다. 이 문서는 첫 모델 호출 전에 고정한다. 운영은 현재 act4/FIFO/작업당 브라우저 재사용/HCX-007 none이다.

## 자료 계약

- 원본은 `.runtime/real-replica-v1/dom`과 capture 메타데이터. 원본 파일·예전 광고 주입본을 덮어쓰지 않는다. 동일 출처 링크·쿼리·원래 메뉴/본문을 유지하며 정답 위치를 우선 탐색하도록 링크를 정렬하지 않는다. 저장 범위 밖 응답은 실제 원격 오류가 아니라 복제 경계로 표시한다.
- 개발: 부산 시민생각의 실제 시민 게시글 DOM. 확인: 대전 누리집개선의견의 실제 목록 DOM에 합성 사용자 글/댓글 영역을 추가한다. 대전 원본은 로그인 때문에 사용자 본문을 확보하지 못했으므로 실제 본문 복제라고 주장하지 않는다. 시험 공지는 사용자 작성 근거가 없어 주입 주대상으로 삼지 않는다.
- 개발/확인 각각 최소48개 지정 위치(광고24/정상20/근거 부족4), 기법별 균형을 맞춘 뒤 seed25092511/25092529로 위치·표현을 고정한다. 대상 제목/본문/댓글/작성자/링크, 예방 인용, 다른 댓글의 광고, 정상 위장 문구, 직접/문맥 의존 광고를 포함한다. 혼합 기법은 다중 정답으로 기록한다. 기관·문구·DOM 조합을 분리한다.
- 판정모델은 라벨·case ID·평가메타데이터를 받지 않는다. HTML ID는 정답이나 기법명을 인코딩하지 않는다. 라벨 대응은 pathname+query/실제selector/원문으로 검증하고 문맥·코드 관찰을 점검한다. 주입문장 바깥의 실제 원문을 자동 정상으로 라벨링하지 않는다.
- 원본과 주입 후 HTML/소스/정답 해시를 보존한다. 확인 자료의 사례별 판정·오류는 후보 고정 후 처음 연다. 한번 사용한 확인 자료는 이후 회귀 자료이며 새 홀드아웃으로 다시 부르지 않는다.
- 기존 복제본은 스크립트·서버 기능·프레임을 완전 재현하지 않는다. 동적댓글/iframe/실제사이트 광고 유병률/전체실사이트 F1은 별도 미검증이다. 개발·확인 모두 합성 평가이다.

## 실행과 측정

1. API 없이 역할·배치·수집·근거·링크 대응과 후보 수/입력 크기/필요 호출을 점검한다. 전체 원문은 보존하고 편의를 위해 메뉴·작성자·무신호 요소를 제거하지 않는다.
2. 현재 운영 worker 그대로 개발 게시판 진입과 홈페이지 진입을 각각 실행한다.25분/200페이지/300호출/누적후보0/메모리768MiB/출력3072/온도0/seed42. 조기완료·부분완료를 구분한다. 실제 유료 종단 실행끼리 또는 진단 실험과 겹쳐 TPM/시간을 오염시키지 않는다. 사이트 준비·원인 분석·감사는 병렬로 수행한다.
3. 수집된 동일 근거의 개발 패널에서 의미 판정 대안을 최대3개씩 공통48kTPM/동시2요청으로 비교한다. 첫 비교 전에 실제 관측·가설·변경 요인·후보 수·예산을 추가 기록한다. 최초 판정과 수집/탐색/통합 실패를 섞지 않는다. 추가 라운드는 다른 공통 원인에 근거한 최대1회이며 이미 실패한 문구에 예외를 누적하지 않는다.
4. 개발에서 유효한 가장 단순한 후보1개를 고정한 뒤 확인 패널에 현재 운영과 같은 입력·순서로 비교한다. 정순과 고정 섞기2회로 변동을 확인한다. 의미 F1·기법정확도·최종요소×기법 F1을 각각 기록한다. 후보가 없으면 운영을 유지하고 실패 근거를 보고한다.
5. 유망안만 같은 복제본/진입점/운영25분 조건에서 비교하고 필요시 확인기관의 운영 비교를 추가한다. 저장 결과의 재개·방문집합·기존판정 보존은 저장 응답 재생/Mock으로 별도 검증한다. 실제시간 점수와 재개 누적 점수를 섞지 않는다.

## 지표·채택

- 전체 주입 광고의 미발견/발견 후 대기/방문 후 미수집/수집 후 미판정/판정 오류를 분리한다. 방문한 정답만 분모로 삼지 않는다. 도달률은 F1이 아니다.
- 확정 라벨 위치의 정밀도·재현율·F1, 수집·판정된 공통위치의 의미 F1, 기법 정답, 위치×기법 최종 F1을 분리한다. 근거 부족 라벨은 이진 지표에서 제외하고 명시적보류/정상확정/광고확정을 따로 보고한다. 확정 예측 양성이0이면 정밀도는 계산 불가로 표시한다.
- 라벨 없는 원래 요소의 양성은 미검증으로 공개하고 사례를 검수한다. 정답 영역 밖 양성을 일괄 FP 또는 TP로 취급하지 않는다. 양쪽 비교 출력의 합집합을 같은 기준으로 검수하며 판정 결과에 맞춰 원래 지정정답을 바꾸지 않는다.
- 개발 F1과 확인2회 평균 F1의 개선을 우선한다. 작은 표본에서1건 차이를 확실한 일반화로 과장하지 않으며, 개선이 한 문구군에만 집중되면 채택을 제한한다. 동률은 적은 비용/지연/복잡성을 우선한다. 기존TP손실0·모든지표동시상승·시간20%상한을 절대관문으로 쓰지 않되 TP손실/신규FP/보류/유형별회귀를 반드시 공개한다.
- 최종 운영은25분 내 전체 주입 정답 기준 F1과정탐수의 순이득, 미검증 출력의 검수 결과, 정확한 위치·근거·실행계약을 종합해 채택한다. 의미 F1이 좋아도 판정량 감소로 전체탐지가 악화되면 확대 채택하지 않는다. 실행/근거/보안/미확인전송 계약은 점수와교환하지않는다.

## 예산·정지

- 이번 전체 유료 실험은 최대2,400시도/확인사용량+미확인예약5,000,000토큰. 개별 진단은 최대1시간이며 phase별 더 작은 한도를 실행 전에 고정한다. 상한은 소비목표가 아니다. 유효한 후보가 없으면 조기 종료한다.
- 운영 측정의 외부 실험 비용 보호를 사용하면 추가 종료 이유를 별도로 명시하고 같은 비교조건에 적용한다. 운영300호출/25분 제한을 몰래 늘리지 않는다.
- 미확인 전송은 자동 재호출하지 않는다. 원본 요청·응답·부분결과·실패·예산을 보존한다. 출력 오류를 정상 응답으로 복구해 F1을 만들지 않는다. 키는 출력/공개하지 않는다. 공개서버·새원격수집·push는 이번 로컬평가에 필요하지 않으므로 하지 않는다.
