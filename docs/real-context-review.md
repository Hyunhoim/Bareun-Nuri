# 실제 수집 문맥의 사용자 독립 검수

2026-09-28. 사용자가 직접 검수하기로 했다. 모델 예측·에이전트 제안 라벨을 표시하지 않는 검수 화면을 만들었다. 아직 사용자 검수0건이며 학습 가능 상태가 아니다.

부산 시민생각 공개 게시글4개와 대전 시험정보 FAQ1개를 실제 운영 수집기로 읽었다. 일반 링크를 추가 탐색하지 않고 공개 URL5개만 수집했다. 로그인/글쓰기/신고/외부업로드/유료API는 없었다. Web 검색 도구에서 일부 상세페이지가 cache miss였으나 실제 브라우저 수집은 성공했다. 원격 원문과 DOM 수집 근거는 변경하지 않았다.

18항목은 제목·본문·댓글·기관 답변·FAQ·첨부파일 이름에서 추출했다. 공백 제외20자 이상을 선택하고 날짜/이동버튼은 제외했다. 검수 부담을 제한한 목적 표본이며 운영 수집 필터를 변경한 것이 아니다. 같은 게시글의 여러 요소를 독립 원문으로 부풀리지 않는다. 같은 출처·페이지 파생 요소는 이후에도 같은 분할에 둔다.

## 검수 방법

1. `.runtime/real-context-review-v1/review.html` 또는 현재 로컬 검수 화면을 연다.
2. ‘분류모델 실제 입력’을 보고 입력만으로 가능한 판정과 근거를 적는다. 위험 단어/자모만으로 광고를 확정하지 않는다. 불분명한 서비스는 근거 부족으로, 심각한 수집 결함은 제외로 남긴다.
3. 추가 원문/페이지 근거를 펼쳤을 때 판정이 바뀌면 추가근거 판정과 문맥결함 여부를 따로 기록한다. 전체 원문 정답을 잘린 모델 입력 정답과 혼동하지 않는다.
4. ‘검수 JSON 저장’을 누른다. 미완료 항목도 저장되며 완료로 표시되지 않는다. 결과 파일은 `real-context-review-v1-answers.json`이다. 사용자 결과가 들어오면 ID/원문 입력 해시/토큰 표시 해시/미완료/모호한 근거를 확인한 뒤 다음 실험에 사용 가능한 범위를 결정한다. 자동 학습하지 않는다.

## 새로 확인된 입력 병목

기존 KLUE 토크나이저와 실제 직렬화 형식으로 계산했을 때18항목 중2개는512토큰을 넘었다(최대1029). 검수 화면은512한도가 적용된 토큰을 복호화한 실제 모델 읽기를 먼저 보여주고 잘림 여부를 표시한다. 수집 원문과 잘림 전 입력은 별도로 펼친다. 실제 첨부파일 이름에 NFD 자모가 있는 사례도 포함됐으나 광고 여부는 사용자 검수 전 확정하지 않는다.

이 자료는 실제 자연 문맥과 오탐 검수의 출발점이다. 불법광고 양성 표본이 확보됐다고 주장하지 않으며 광고/피해문의 균형도 보장하지 않는다. 공개 제안·FAQ 중심의 선택 편향이 있고5페이지로 전체 공공사이트 일반화를 검증할 수 없다. 합성 광고를 주입해 양성 수를 채우지 않았다. 사용자는 이번 자료의 정답 작성에 참여하지 않았고 모델 예측은 보지 않지만, 한 명의 검수는 다수 검수자 합의나 법적 판정이 아니다.

## 구현 검증과 보존

원문 스냅샷·수집 시각·URL·요소 위치·입력/토큰뷰 해시를 보존한다. 검수 HTML은 외부 스크립트/리소스 없이 텍스트로 렌더링하며 원문의 HTML을 실행하지 않는다. 검수값 미선택 상태,18항목 표시, 잘림경고2건, 입력·JSON다운로드·자동저장복원·JS오류없음을 별도 임시 브라우저에서 확인했다. 자동검사용 라벨은 사용자 결과에 저장/합치지 않았다. 모듈 경로 및 HTML 줄바꿈 오류를 검증 중 수정했고 최종 검사 통과 후 전달했다.

산출물: `.runtime/real-context-review-v1/`의 `capture.json`, `snapshot-*.json`, `review-items.json`, `tokenizer-review.json`, `manifest.json`, `review.html`, `ui-check.json`. 원문 수집과 검수 생성 코드는 `local-benchmark/real-context-capture.cjs`, `real-context-review.cjs`다. 현재 로컬서버는 해당 HTML만 제공하고 원문 스냅샷 디렉터리는 제공하지 않는다. 페이지를 닫기 전에 JSON을 저장해 보관하는 것이 좋다. 운영 모델/학습/판정 결과 변경0이다.
