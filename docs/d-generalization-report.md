# D 일반화 병목 진단 및 제한 개선 실험

2026-09-28. **D 원본 유지. 제목 의존성 완화는 유망한 입력 개선 후보이나 운영 미채택. 추가 학습과 문맥 전체 제거는 미채택. HCX 대체는 검증되지 않았다.**

## 무엇을 비교했는가

D는 `.runtime/klue-audit-learning-v1/run-cpu/model`이며 기존 A에서 학습한 분류모델이다. HCX 운영 모델과 다르다. 원래 입력 2,000개에서 D를 다시 실행해 TP798/FP10/FN202, 저장 예측과 차이 0을 확인했다. 이번 차이는 기준선 재현 실패에 의한 것이 아니다. 모든 판정은 CPU 8스레드·배치8이며 유료 API 호출은 0이다.

2,000개는 광고/정상 각1,000개이고 500개 원문 계열의 기법 변형이다. 이미 분석한 **회귀자료**이며 2,000개 독립 시나리오나 새 최종 평가가 아니다. 추가120개 제목대조와44개 문맥개발도 이미 관찰한 동일 제작자 합성자료다. 개발 개선과 일반화 개선을 구분한다.

근거 부족 정답은 광고 F1에서 제외하는 기존 집계를 유지한다. 별도로 보면 제목 제외 시 근거 부족을 광고로 확정한 수가120자료에서5→6/21,44자료에서1→2/4로 증가했다. 제목 제거의 F1 개선이 보류 판단 개선까지 의미하지 않는다. 추가 학습은 이 값이3/21,0/4로 줄었지만 전체 회귀 광고 손실을 상쇄하지 못했다.

## 확인된 일반화 병목과 해석

1. **비핵심 제목에 대한 민감성.** 동일 대상·소속 문맥에서 제목만 제외해41개 광고를 회복했고, A 대비 D가 잃었던76개 중28개가 포함됐다. 제목 의존성은 실측으로 확인됐지만 제목이 항상 무관하다는 뜻은 아니다. 같은 조작에서 D 정탐9개를 잃었다. 다음 구현은 일반 페이지명과 실제 게시글 제목의 역할을 구분해야 하며 수집 입력의 첫 줄을 무조건 삭제하면 안 된다.
2. **문맥은 필요하지만 사용 방식이 불안정하다.** 전체 회귀에서는 문맥 제거 점수가 올라도 문맥 귀속 자료의TP12→8, FP7→13으로 악화됐다. 주변 문맥 전체 삭제나 키워드 판정으로 바꾸는 것은 해결책이 아니다. 대상에 속한 권유·피해·인용 설명은 유지해야 한다.
3. **표현 복원만으로는 부족하다.** oracle에서도182개 광고를 놓친다. 자모 조건의FN68→45는 개선되지만 혼동 문자 조건은42→45로 악화됐다. 실제 사전 변환의 순효과도 작았다. 표기가 읽힌다는 것과 권유 의도를 판정한다는 것은 다른 문제다.
4. **개발자료의 대표성과 학습 방향 문제.** 추가 학습은44개에서 개선됐으나 전체에서 정탐29개를 잃고 회복0이었다. 이는 개발자료의 점수만으로 선택하면 기존 회귀를 놓칠 수 있음을 다시 보여준다. 동일 합성자료에 더 맞춰 학습하는 위험을 보고했고 반복 설정 탐색은 중단했다. 이것만으로 과적합의 모든 원인을 확정하지는 않는다.
5. **정답·근거 부족 문제는 남는다.** 이전 서비스 문맥이 모호한 정답 검수 항목은 이번에 라벨을 바꾸지 않았다. 사람이 검수한 새 정답 파일은 아직 받지 않았고, Codex가 만든18개 정상 초안은 독립 정답이 아니다. 실제 광고 재현율 검증자료로 사용하지 않았다.

## 추가 학습 계약과 한계

D에서 시작해 기존 훈련256개와 기존8,000개를 배치당2:6으로 샘플링했다. 64step, 배치8, seed42, lr2e-6, 상위4층+분류기만 학습했다. 절반의 입력에서 일반 제목을 중립 제목으로 교체하거나 생략하되 대상·나머지 문맥·라벨은 유지했다. 추론 입력은 원래 전체 문맥이다. 56.62초에 학습했으며 훈련/이번 평가 대상 문자열의 NFC 정확 일치0을 확인했다. 유사 템플릿·의미적 중복까지 없다는 증명은 아니다.

학습안은 제목 변형과 계속 학습이 결합된 한 후보다. 동일 스케줄의 무변형 재학습 대조군은 실행하지 않았으므로 회귀를 제목 변형 단독의 인과효과로 단정하지 않는다. 후보가 전체 F1을 개선하지 못해 승격하지 않았고 추가 하이퍼파라미터 조정은 하지 않았다.

## 결정 및 다음 조건

- 운영 HCX와 D 원본은 그대로 유지한다. D 개선 후보를 운영 HCX 대체로 승격하지 않았다.
- 제목 제외는 **입력 구조 개선 방향의 근거**로 보존한다. 실제 게시글 제목까지 삭제하는 운영 코드는 만들지 않는다. 원문과 역할을 보존한 구조에서 일반 페이지명만 분리하는 제한 후보가 다음 검증 대상이다.
- 추가 학습은 미채택 모델로 보관한다. 기존 합성자료만 더 반복하기보다, 명시 설명이 적은 실제 권유·피해 문의 대조와 제목이 실제 의미 근거인 사례를 사람 검수로 확보할 필요가 있다.
- 독립 평가, 같은 입력의 HCX 비교, 25분 종단·기법통합·재개 검증은 아직 없다. HCX 대체 성능을 주장하지 않는다. 이번 목표는 원인 진단과 한정 개선 실험/채택 판단까지 완료했다.
