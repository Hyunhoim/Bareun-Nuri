# 호출 한도와 의미 입력 부담 분리 검증 (2026-09-25)

## 고정 조건
FIFO / 브라우저 재사용 / bounded store / SRPT active8 aging8 / 페이지당 최대4 순차 HCX-007 none / 출력512 / 25분. 원문, 위치, 관찰 기법, 후보 선별은 변경하지 않는다.

## 1. 호출 한도
300에서600으로 확대한다. 동일 실행의 300회 완료 checkpoint와 immutable batch refs를 저장해 접두부 대조군으로 삼는다. 독립 반복 A/B로 주장하지 않는다. 600회/1500초/200페이지/실험 토큰150만 보호 중 먼저 도달한 한도에서 부분 완료한다. 첫300개 결과 보존, 새 정탐 증가, 신규 정상 오탐 및 미확인 요청 여부를 평가한다. 추가 검사가 가능하고 결과 보존/예산/재개 검증을 통과하면 UI·API·worker 기본 및 허용 상한600을 적용한다. 이는 호출당 지연 개선이 아니라 시간 예산 활용 개선이다. 비용은 증가한다.

## 2. 입력 절감
실제 요청 필드의 중복 비중을 먼저 측정한다. 삭제로 의미를 추측하지 않고, 원래 JSON으로 완전히 복원 가능한 참조 표현 하나만 비교한다. 대상/문맥 경계와 소유 관계를 보존한다. 후보나 페이지를 제외하지 않는다. 실험 계약은 운영과 분리한다.
기존 관찰한 서로 다른 자료의 고정4개 배치에서 A-B-B-A, 출력512와 동일 모델 설정으로 비교한다. 정상/광고/인용/모호 사례 모두 포함한다. 최대208호출, 예약150만 토큰,1시간, 조건 간61초 간격; 종단 실험과 API 동시 실행 금지.
입력 감소15% 이상과 F1 평균 하락1%p 이내, 신규 반복 누락/정상 오탐의 구조적 증가 없음, 형식 실패 없음이 선행 조건이다. 통과하면25분 종단 비교로 확대한다. 미통과면 입력 변경은 미채택한다. 관측 자료를 새 홀드아웃으로 부르지 않는다. 결과에 맞춰 참조 규칙이나 기준을 조정하지 않는다.

### 입력 변경 사전 확정
단순 normalized_text 중복은 실제 후보 입력 문자의 약6.85%로 작다. 모든 원문 값은 그대로 두고 반복 JSON 키만 짧은 별칭으로 표현하는 가역 인코딩 하나를 비교한다. 대응표는 공통 프롬프트에 한 번 포함한다. 복원 후 원래 JSON과 완전 일치를 검사한다. 모델이 읽는 표현 변화의 영향은 별도로 검증해야 하므로 가역성만으로 정확도 보존을 주장하지 않는다. 64개 합성 + 개발/확인 복제본104개, 총168개 관찰 자료를 고정하며42배치×4조건=168호출이다.
