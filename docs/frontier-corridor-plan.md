# Bandit 경로 재개 실험 계획 — 2026-09-23

결과를 보기 전에 고정한다. 이번 범위는 실험용 구현과 오프라인 방문 도달 검증이다. 판정 프롬프트/수집기/운영 FIFO는 변경하지 않고 유료 LLM 호출도 하지 않는다.

## 관측과 가설

- 기존의 연속 탐색은 매10회 중 정해진 슬롯에서 새 경로를 시작하고 최대2회 자식을 따라갔다. 상태를 다른 방문 사이에 유지하지 않아 긴 경유 경로를 끝까지 진행하는 보장이 없었다.
- 문맥 Bandit도 깊은 경로의 발견 지연이 남는다. 즉시 상세 본문 보상만 바꿔서는 이 문제가 해결되지 않았던 진단이 있다.
- 이미 방문한 문서에서 남은 동일 범위 미방문 목적지가 하나뿐이면, 그 경유 관계를 기억해 제한된 슬롯에서 이어가는 방식이 해당 연결 구조에 효과가 있을 수 있다. 모든 깊은 그래프의 해법이라는 주장은 아니다.

## 고정 수정안

- 기존 Bandit 및 문맥 Bandit을 감싸는 하나의 실험 스케줄러. 각 기준선의 학습·보상은 유지한다.
- 선택 시 매5번째 FIFO는 그대로, 매5회 중4번째만 경로 재개 슬롯(최대20%)으로 사용한다. 재개 후보가 없으면 기준선 선택을 사용한다.
- 방문 후 실제 profile.links 중 현재 pending에 남은 서로 다른 URL이 정확히1개면 경로 큐에 등록한다. 따라서 기준은 URL 문자열/태그/정답/광고 여부/특정 깊이가 아닌 관측 연결 관계다. 전체 그래프와 미래 목적지 내용은 보지 않는다.
- 큐와 경유 위치는 JSON 체크포인트 상태로 저장하고 다른 페이지 방문 사이에도 보존한다. 기존 탐색이 경로 목적지를 먼저 방문하면 그 관측을 이용해 이어지는 위치로 갱신한다.
- 한 경로가 재개 슬롯4회를 쓰면 큐 뒤로 이동시켜 다른 경로에 기회를 준다. 이는 독점 상한이며 경로의 깊이를4로 자르는 제한이 아니다. 상태는 남으므로 다음 차례에 이어간다.
- 갈림길(미방문 목적지2개 이상), 막다른 길, 읽기 실패에서는 해당 재개 경로를 종료하고 후보들은 기존 Bandit 대기열에 남긴다. 방문 중복·범위·전체 예산 계약을 지킨다.
- 조건당 비율/회전 횟수는 고정한다. 결과에 맞춰 바꾸지 않는다. 양성 판정·기법 판정은 수정하지 않는다.

## 비교 자료와 기준

- 기존 navigation 6사이트 각127/135페이지, 링크 순서 seed0/11/23/37/51: FIFO, Bandit, 과거 Bandit+경로, 새 Bandit+재개. 예산20/50/100, 전체 탐색 집합도 확인한다.
- 기존 혼합2사이트 각27/28페이지의 고정 문맥 증거: 위4정책 및 문맥 Bandit/문맥 Bandit+재개. 동일5개 링크 순서, 예산12/18/24. seed0의 기존 네 정책 방문 순서가 과거와 같아야 한다.
- 총180개 전체 순서. 링크 순서5개는 같은 사이트의 반복이지 독립 홀드아웃5개가 아니다. 모두 관찰한 합성 진단 자료다. 이전 자료의 detail/광고 결합과 본문 반복 편향도 남는다.
- 알고리즘은 요청한 페이지의 관측치만 받는다. 정답과 전체 연결 그래프는 실행 후 채점에만 사용한다. 미방문은 대기/미발견으로 분리한다. LLM 판정을 하지 않으므로 결과는 도달률이며 F1/정밀도/실제 토큰 절감으로 표시하지 않는다.
- 후속 실제 판정 후보 기준: 두6사이트 분할의50요청 깊은 광고 도달률이 각각10%p 이상 개선, 모든 사전 예산에서 사이트별 평균 전체 광고 도달 비감소, 50요청의 기존 Bandit 광고 위치 손실0. 혼합에서는 문맥 기준선의12/18/24 전체 도달 비감소·기존 광고 위치 손실0 및 깊은 도달이 최소 한 예산에서 증가해야 한다. 둘 중 한 연결 방식만 통과하면 그 범위만 인정한다.
- 종료: 한 후보를 한 번 비교하고 보고한다. 관문을 실패하면 운영 반영하지 않고 원인·반례를 남긴다. 결과 조정 후 유료 확대는 하지 않는다.

## 최소 구현 검증

- 단일 경로·분기·반복 링크·교차 경로·읽기 실패·긴 정상 경로의 구조 검사. 슬롯 상한, FIFO 보존, URL/정답에 따른 우선순위 없음, 직렬화/중단 재개 일치.
- 독립 구조 검사는 임의 합성 그래프의 동작 검사이며 탐지 성능 홀드아웃이 아니다. 정상 막다른 경로에도 예산을 쓰는 비용을 보고한다.
- 정책 파일만 실험 경로에 추가한다. 이미 존재하는 core scheduler 주입을 재사용해 운영 코드를 수정하지 않는다.
