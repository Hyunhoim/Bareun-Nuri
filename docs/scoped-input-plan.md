# 규모 진단 후 단일 개선 가설

실제 비교 전 고정. 운영 C와 scoped-input.cjs만 비교한다. 수집기가 문서 전체가 아닌 범위를 잡았고 잘림이 없으며 대상 외 문맥 단위가 존재하면 모델 입력의 unscoped_nearby만 제거한다. 저장된 원문·주변·문맥·기법·위치는 그대로 보존한다. 범위 불명/잘림/대상 단독이면 기존 입력을 유지한다. 프롬프트·출력·자모 읽기·배치4·none·512는 유지한다.

가설은 무관한 주변 문장의 간섭과 중복 토큰 감소다. DOM 범위 자체가 의미적으로 완전하다는 보장은 없으므로 필요한 설명을 제거해 광고를 놓칠 위험이 있다. 이 위험을 숨기지 않고 반례와 기존 광고 회귀를 검증한다. 특정 단어/ID/라벨로 실행 조건을 정하지 않는다.

소형/중형이 완주하면 의미 판정 개선 우선 후보로, 미완주이면 입력 부담 개선의 한정 후보로 비교한다. 실제 규모 실행과 동시에 API를 사용하지 않는다. 기존48문맥 패널, 복제본 통제64+기존 작성자 정상1의 저장 입력, 새24 대조 문장(교육 인용/실제 거래 인용/짧은 연결/표시 라벨/잘림/문서범위)의 두 순서로 C/S를 비교한다. 새24도 같은 제작자의 공급된 문맥 평가이며 독립 실사이트 증거로 부르지 않는다. 라벨은 모델 입력에서 제외한다.

전체 micro F1, 자료별 TP/FP/FN, 반복 변동, 보류, 호출·토큰·서비스 시간을 평가한다. 기대는 F1 개선과 토큰 감소의 동시 달성이다. 새24와 복제본에서 유의한 반대 방향 손실이 나타나면 전체 평균으로 덮지 않는다. 원문·대상 귀속/안전 계약 실패 또는 지속적인 기존 정탐 손실은 미채택 근거다. 결과에 맞춘 조건/문구 재조정 없이 한 후보로 종료한다. 의미 진단에서 이득이 확인될 때만 동일25분 종단 비교로 확대해 운영 채택을 판단한다.

최대160호출/예약100만토큰/1시간. 통신 미확인 자동 재시도 없음. 두 순서는 독립 표본 수로 부풀리지 않는다. 실패 시 운영 C 유지, 성공 주장이나 불필요한 운영 수정 없음.
