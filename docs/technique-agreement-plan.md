# 두 고정 기법 분류기의 동의 진단

2026-09-29. 기존 특화모델과 역할보강모델의 개발 오류가 다르게 나타났다. 추가학습/임계값조정 없이 두모델이 substitution에 동의할때만 미확정기법을 확정한다. literal/uncertain불일치는 uncertain이다. 코드의 기존확정은 유지한다. 광고의도나HCX판정은변경하지않는다.

이후 이미소비된최종96·개발96·기존112를회귀측정한다. 새홀드아웃으로보고하지않는다. 원래정탐손실, 정상식별자및모호과도확정, CPU추가시간을측정한다. 동일오류를공유할가능성이있으며 동의자체는정답보장이아니다. 합성개발기준(정상≤5%, 모호≤10%)및기존회귀정탐유지를모두통과하면 실제수집검증후보로만남긴다. 새모델추가나결과맞춤게이트변경은하지않는다.
