# 유망 의미 판정의 FIFO 종단 확인

개발64개 비교, 관찰된80개 두 순서/기존76개 회귀, 그리고 별도 새72개 두 순서에서 의미 F1 개선이 확인된 **최종후보 act4 하나만** 실행한다. 첫 passageJson4 평가의 출력 계약 실패와 후속 선정은 `semantic-reference-recovery-plan.md`, `semantic-act4-selection.md`에 기록했다. 미통과 시 이 유료 비교는 실행하지 않는다. 후보 선정 근거는 실행 전 보존한다.

- 동일한 합성 사이트의 시작 URL 1개, 목록+80페이지. 이80개는 이미 관찰한 자료로서 종단 회귀 검사이며 새 홀드아웃이 아니다. 두 조건은 동일 origin에서 O→최종후보 순차 실행한다. 조건 사이 최소61초로 API 사용량 창을 비운다.
- 실제 운영 core의 FIFO·점진 수집/판정·체크포인트·중단 계약과 실제 Playwright 브라우저를 사용한다. 작업당 브라우저1개/페이지별context, 자동클릭 없음, 페이지 종류에 따른 제외 없음.
- 각 조건은 실제 운영과 같은25분/200페이지/300호출, 누적후보수 제한0, RSS보호768MiB, 마감 정리210초. 전체 최대1시간/620시도/3,000,000예약토큰. 조기완료 시 그대로 종료하며25분까지 인위적으로늘리지 않는다. 실행전100호출초안을실제운영300호출과맞췄으며종단결과를보고한변경이아니다.
- HCX-007 none/temp0/seed42/출력3072/52kTPM/순차. O는 현재 core, act4는 `.runtime/semantic-worker-stage`의 승격 검토 core를 사용한다. 후보는 코드 관찰 수집뿐 아니라 체크포인트 저장·출력 통합 비용까지 포함한다. 실험 후 별도 offline 통합과 실제 staged findings가 같은지 확인한다. 운영 원본은 채택 전까지 수정하지 않는다. 두 경로 소스와 승격 사본 전체를 해시로 고정·보존한다.
- 모든 수집후보를 판정한다. 정답은 지정80개(이진정답72/모호8)만 있으므로 **지정대상F1**으로 보고한다. 미방문·미수집·미판정 광고도FN. 정답없는다른위치의 양성은오탐으로단정하지않고미검증수로남긴다.
- 종단 첫 모델 호출 전에 별도 작성자가 응답을 보지 않고 추가 위치의 정답을 작성·해시 고정한다(`.runtime/semantic-e2e-extra-gold-v1`). 원래80개는 변경하지 않는다. URL의 pathname+실제 위치+원문으로 대응을 검증한 위치에 한해 부가 F1과 오탐을 보고한다. 모호한 위치와 대응 실패는 제외 수를 명시한다. 이 부가 검사는 지정80개만의 점수 상승이 메뉴·제목·작성자 등에 대한 회귀를 가리는지 확인하기 위한 것으로, 전체 공공사이트 F1로 확대하지 않는다. 전체 확정 위치의 F1이 악화되면 운영 적용을 보류한다.
- 의미F1·정밀도·재현율·정상검토·근거부족, 기법정답, 요소×기법F1, 실제벽시계/HTTP시간/대기/토큰, 완료·미검사범위·원문/위치보존을 함께비교한다. 기존정탐손실0을기계적조건으로삼지않되 손실수와회복수를공개한다.
- 최종채택은 저장근거의개선이종단에서도유지되고, 지정대상F1과정탐수가운영기준선보다개선되며, 출력/근거/재개계약을보존할때판단한다. 기법정확도의중대한악화나미확인응답은의미F1로덮지않는다. 같은자료추가튜닝은하지않는다.
- 제출시간안의새수집검사이며실사이트광고유병률/전체사이트F1증명이아니다. 두조건이25분전에끝나면25분강제중단타이머의새검증으로주장하지않고, 이전실제타이머검사와새계약의짧은재개검사를구분한다.
