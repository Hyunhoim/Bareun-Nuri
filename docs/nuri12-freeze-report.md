**연구 개선 후보는 순정 모델에서 하위8층을 고정한250step 체크포인트다.** 기존 Nuri 대비 개발 성능 개선을 확인했다. 다만 A의4분류/근거부족 성능에는 미달하므로 A·HCX 대체는 하지 않는다. 최종평가도 열지 않았다.

## 단계별 검증

1. 같은 Nuri 가중치에서 전체/하위8층 고정 추가학습, 같은 순정 초기값에서 전체/하위8층 고정 재학습을 비교했다. 각2epoch/6개 체크포인트, 동일10,000행/순서/batch8. 추가학습 lr5e-6,순정 lr2e-5로 쌍 내 통제했다.
2. 순정freeze8은 동일 시점6개 중3개에서 사전 기준(F1+2%p,macro4평균+3%p,불확실→광고 비증가)을 충족했고 Nuri 개선 관문을 통과했다. 따라서 순정freeze4/freeze10만 추가 비교했다. 추가학습 쪽 신호는0개여서 확대하지 않았다.
3. 확대해도freeze8이 선택됐다. 고정 범위를 줄이거나 늘리는 방식의 추가 이득은 확인하지 못했다. 점진적 해제는 이번에 실행하지 않았다. 즉시 효과를 기대할 반복 확대 근거가 부족하고 개발셋 선택 편향을 키우기 때문이다.

## 해석과 제한

같은 초기값/데이터에서freeze8과full의 차이가 관찰되어 이번 자료에서는 일부 층 고정이 도움이 됐다. 이미 학습한 Nuri의 추가학습에는 같은 이득이 없었다. 그러나1개seed·관찰 개발셋에서 총36체크포인트를 선택한 결과다. 같은 합성 틀·문맥 표기 의존 및 검증 선택 과적합의 우려는 남는다. 이 결과만으로 독립 일반화 개선을 확정하지 않는다.

합성자료의 의미와 귀속을 더 잘 일반화하도록 고치는 작업과 학습 설정 탐색을 분리해야 한다. 이번에는 데이터 문구/라벨을 수정하지 않았다. 모델 크기·추론 구조가 같아서freeze가 운영 추론 자체를 줄이는 변경도 아니다.
