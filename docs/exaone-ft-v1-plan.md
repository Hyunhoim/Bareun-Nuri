# EXAONE LoRA 파일럿 사전 계획

2026-09-29. 사용자 요청에 따라 v3 합성 자료로 학습한다. 자연스러움 검수와 정답 검수를 구분한다. 정답 제안 기반 파일럿이며 운영 반영은 하지 않는다.

- 운영 수집기 + 기존 klue-context를 사용하여 실제 HTML에서 수집한 입력만 사용한다. 대상 위치가 누락되면 임의 문맥으로 보완하지 않고 제외/보고한다.
- 원본 LGAI-EXAONE/EXAONE-4.0-1.2B 가중치, Transformers 4.57.3, PEFT 0.17.1, BF16 GPU. 기존 Q4 CPU 결과와 학습 효과를 직접 혼동하지 않도록 같은 BF16/프롬프트/디코딩으로 전후를 새로 비교한다.
- sextrade 범주 전체를 개발 검증으로 보류한다. 행 분할 없이 그룹 및 공유 문자 계열의 교차를 점검한다. 같은 합성 작성자의 제한된 범주 검증이며 독립 최종 평가가 아니다.
- LoRA q/k/v/o projection, rank16/alpha32/dropout0.05, AdamW 1e-4, 최대3epoch, microbatch1/누적8, seed42. 원문은 잘라서 진행하지 않으며 2048token 초과는 별도 중단 원인으로 처리한다. 학습 안전 상한1시간.
- 기존 10행 그룹 각0.1, 신규2행 그룹 각0.5 가중치로 그룹 영향력을 균형화한다. 모델 입력이 동일한 행은 합치고 가중치를 합한다. 정답이 충돌하면 중단한다.
- 각 epoch 개발 macroF1로 1개 선택, 동점은 광고 F1 후 이전 epoch. 기존 221개는 선택 완료 후 기준선/선택 모델을 각1회 비교한다. 그 점수로 재학습하지 않는다.
- 0광고/1예방인용/2정상·피해문의/3근거부족 공통 계약 유지. JSON 네 가지 출력만 허용하는 동일 constrained greedy decoding. 의미 F1은 확정 정답0/1/2에서 계산하고 정답3은 별도 보류 정확도·광고 오판으로 보고한다. human17은 별도 집계.
- F1 증가, 정밀도·재현율, 기존 정탐 손실·회복, 정상 오탐,4분류 macroF1, 형식 실패·시간을 보고한다. 개선이 있어도 Q4 CPU 및25분 종단 미검증으로 운영 승격하지 않는다. 평가 문구 추가학습·유료 API·봉인 최종 평가 접근 없음.
