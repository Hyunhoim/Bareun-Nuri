# 운영 테스트 phase 1 — 25분 중단·재개·격리 후처리

2026-09-30. 현재 운영 코드를 변경하지 않고 새 실행했다. **모든 발견 페이지와 일반 후보의 검사는 끝났지만, 마지막 재판정 후에도60개 후보가 미판정으로 남았다.** 이를 전체 판정 완료로 표시하지 않는다.

## 실행 범위

- Phase1 v1.2: 지정2,240위치, 광고1,120·정상1,120. 원래2,000개와 공공웹 사례 참고 보강240개다. 실제 게시물2,240건이 아니라 합성 평가 자료이며 이미 관찰한 회귀 자료다.
- HCX-007 none/temperature0/seed42/최대12묶음/출력512/58k TPM, FIFO·SRPT8·aging8, 브라우저 재사용·수집동시5, AntiSpoof1.0 CPU를 유지했다. 모델 입력에 정답을 전달하지 않았다.
- 첫25분 결과를 보존하고 동일 서버·동일 서명으로 남은 일반 작업을 재개했다. 일반 작업 종료 후 사용자 제안의 마지막 재판정을 **별도 연구 실행**으로 비교했다. 학습·프롬프트·운영 소스·원래 정답은 변경하지 않았다.
- 후처리는 HTTP200/stop/완전JSON에서 일부ID만 빠진 확정 불완전 응답만 대상으로, 원래 묶음 그대로 각각1회, 최대60호출·10분을 적용했다. 통신 미확인 요청은 자동 재호출하지 않는다. 원래 운영 체크포인트를 수정하지 않았다.

## 핵심 결과

전체 검사 F1은 **전체 지정 위치×4기법 micro F1**이다. 광고 의도 F1은 전체 지정 위치의 광고/정상 판정이며 미방문·미수집·미판정을 FN에 포함한다. 기법 F1은 **광고 의도를 맞힌 위치에서만** 계산한 조건부4기법 micro F1이다. 세 수치의 분모가 다르므로 서로 대체하지 않는다.

| 범위 | 저장 판정 후보 | 전체 검사 F1 | 광고 의도 F1 | 조건부 기법 F1 |
|---|---:|---:|---:|---:|
| 첫25분 이내 | 2,898 | 60.88% | 60.23% | 97.61% |
| 일반 검사 종료 | 4,998 | 79.93% | 81.96% | 97.61% |
| 마지막 재판정 포함 | 5,010 | 80.04% | 82.10% | 97.61% |

| 전체 위치 광고 의도 | TP | FP | FN | 정밀도 | 재현율 |
|---|---:|---:|---:|---:|---:|
| 첫25분 | 590 | 249 | 530 | 70.32% | 52.68% |
| 일반 검사 종료 | 1,031 | 365 | 89 | 73.85% | 92.05% |
| 마지막 재판정 포함 | 1,034 | 365 | 86 | 73.91% | 92.32% |

마지막 결과에서 **실제 판정 완료한 지정2,119위치만**의 광고 의도 F1은83.96%, 재현율97.18%다. 전체 정답 기준82.10%와 구분한다. 지정 위치 밖 양성420개는 별도 보존했으며 정답 없이 오탐/정탐으로 집계하지 않았다. 따라서 위 정밀도는 사이트의 모든 요소를 독립 검수한 정밀도가 아니다.

## 시간·호출·완료 범위

- 발견151페이지 전부 방문.5,070후보 수집. 일반 후보 중복 요청0, 대기URL0, 시도하지 않은 일반 후보0.
- 첫 구간은25분 경계 직전1496.095초/284호출/2,898판정을 점수로 사용했다. 이후 마감 직후 마지막12판정이 저장되어 구간 종료값은2,910판정/285호출이다. 마감 이후 결과를 첫25분에 넣지 않았다.
- 운영 구간 시간:25분2.563초 + 재개21분27.174초 = **46분29.737초**. 구간 사이 대기0.086초. 첫 구간 초과2.6초는 마지막 요청·저장 정리를 포함하며 엄밀한25분 점수에서 제외했다.
- 마지막 재판정 **37.191초**. 운영 구간과 후처리를 합친 실행시간 **47분6.928초**. 후처리 준비·평가 대기를 포함한 첫 시작부터 실제 경과시간은 **47분22.170초**다. 사람의 분석/보고서 작성 시간은 검사시간에 포함하지 않는다.
- 일반516호출/1,502,067확인토큰 + 후처리6호출/19,888토큰 = **총522호출/1,521,955토큰**. 제공사 가격·계약에 따른 금액은 산정하지 않았다.
- 일반 구간 API 서비스 시간 합2,208.57초, 로컬 할당량 대기 합6.126초. 브라우저 수집 합218.50초는 병렬 작업 합이므로 전체 경과시간에 단순 합산하지 않는다. AntiSpoof 시간은 별도로 계측하지 않았다.

## 마지막 자동 재판정 제안의 실제 효과

6묶음72개 중1묶음12개가 복구됐다. 지정 광고 정탐3개 추가, 지정 정상 오탐 추가0, 기존 저장 판정 변화0. 후처리 전후 공통으로 반환된66개 게시행위 판정도 변화0이었다.

**나머지5묶음은 이전과 같은ID를 다시 누락했다.**60개가 미판정으로 남으며, 이 안에 지정 광고20개가 포함된다. 정상으로 채우거나 반환된 일부를 임의 확정하지 않았다. 동일 요청을 계속 반복하면 해결된다는 근거는 없다.

결론: **일반 검사 후 별도의 제한된 복구 단계를 두는 순서는 타당하지만, 동일 묶음1회 재호출의 효과는 제한적이다.** 이번 결과만으로 완전 복구 기능으로 운영 승격하지 않았다. 연구 helper만 추가했고 현재 운영 자동 재호출 금지 계약은 유지한다. 다음 검증 후보는 마지막 격리 묶음만 더 작은 묶음으로 나누는 제한된 복구다. 묶음 변경에 따른 의미 판정 변화·추가 지연을 별도 검증해야 하며 이번에는 실행하지 않았다.

## 남은 병목

1. **의미 오탐365개:** 자기 신고 문맥의 광고 인용191, 피해자/가족 문의81, 삭제 요청75, 운영 문의18. 원래 합성 정답 기준이다. 반복 문장틀·동일 작성자 편향과 일부 라벨 검수 한계가 있으므로 이 문장들을 그대로 맞추는 튜닝을 하지 않았다.
2. **광고 누락86개:** 정확 위치 미대응36, 격리로 미판정20, 정상 의도 판정27, 의도 보류3. 미방문 광고는0이다. 짧은 제목/작성자/댓글의 `문의`와 자기 본문 목적 연결 등이 의미 누락에 남는다.
3. **위치 대응:** 정확 위치 미대응 총86개(광고36 포함)는 저장된 상위 요소에서 원문을 포함하는 후보가 모두 발견됐다. 따라서86개 모두를 텍스트 수집 유실로 단정하지 않는다. 이번 기본 점수는 사전 고정한 정확 위치 계약을 유지했다.
4. **기법 혼동:** 광고 정탐 위치의 HOMOGLYPH는 TP325/FP38/FN6, F193.66%; JAMO는321/0/0,100%; TRANSPARENT321/0/13,98.02%; OFFSCREEN322/0/6,99.08%. 이는 조건부 진단이며 AntiSpoof의 모든 입력 정확도가 아니다. 스타일 합성 정답과 실제 렌더링 불일치가 과거 감사에서 확인됐으므로 T/O 누락을 전부 코드 오류로 단정하지 않는다. 이번 자동 감사에서도19개 스타일 검토 항목을 남겼다.

공공웹 참고 보강240개만의 의도 F1은99.58%(TP119/FP0/FN1)였다. 그러나 이는24시나리오의 합성 파생 자료이며 실제 공공웹에서 동일 성능을 보장하거나 기존2,000개의 오탐을 상쇄하는 독립 근거가 아니다.
