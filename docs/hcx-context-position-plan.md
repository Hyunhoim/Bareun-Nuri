유료 파인튜닝/HCX005/Qwen 경로는 보류한다. 현재 운영 HCX007 C/none/출력512/최대12묶음은 유지한다.

관측: 최근137개 두순서007 기준선에서 명사형 정상/예방문맥 오탐, 인용 권유 누락, 순서변동이 남았다. 수집된 before/after 관계가 현재 passage에서 동일한 주변 표지로 표현된다. 가설: 원문/순서를 바꾸지 않고 각 주변 문장에 대상 앞/뒤 관계만 표시하면 대상과 문맥 연결이 명확해진다. 위치는 소유권의 증거와 같지 않으며 올바른 귀속 개선은 검증 대상이다.
