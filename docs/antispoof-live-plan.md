# AntiSpoof 운영조건 비교 사전 계획

2026-09-30. 동결운영v1.0과typed연구후보를기존부산복제본dev의닫힌20페이지작업량에서비교한다. 실제브라우저수집/실제HCX007 none/출력512/최대12순차/58kTPM/FIFO/SRPT8/aging8/768MiB근거슬롯/누적후보제한0/시간1500초/최대600호출을사용한다. 페이지200안전상한/현재worker마감유예계약유지. arm당25분과마감구간을분리한다. 양쪽동일링크목록으로탐색을고정하므로자연사이트탐색일반화시험이아니다.

순서는운영→typed,간격61초. API는arm당600호출이하,로컬58kTPM예약과실제worker의예산을적용한다. 최대합1200호출이며시간제한으로통제한다. 키/프로젝트를외부공개하지않고로컬복제본만수집한다. 실패/미확인요청자동재실행금지. 다른진행중API실험을시작하지않는다. 운영파일/자산을바꾸지않고실험 hook에서기법모델과입력서비스만분리한다. 실제worker를실행하며수집후탐색목록만고정프로파일로교체한다.

실행전패키지CPU출력일치216/양성대상연결/저장재개/서명변경거부와worker무네트워크smoke를통과해야한다. 코드·모델·데이터hash를저장하고유상실행은--live명시로만시작한다. profile/gold는기존 관찰자료이며새최종을소비하지않는다.

평가는 전체 통제64 위치를 기준으로 광고 의도/4종 결합/위치 근거/미방문·미수집·미판정 FN/정상 FP/보류·검토량/처리량/CPU 시간/API 호출·토큰을 분리한다. 미라벨 양성을 FP로 단정하지 않는다. HCX 원응답의 변동과 후보 모델 효과는 공통 입력의 후속 고정판정 재생으로 분리하고, 다른 HCX 결과를 모델 개선으로 단정하지 않는다. 첫25분 결과와 재개 누적을 혼동하지 않는다.

채택 근거는 기존 정탐을 보존하면서 최종 기법 F1 또는 정탐 수를 개선하고 정상 오확정/미판정 손실/보류의 중대한 악화가 없는 것이다. CPU44% 증가를 전체 지연44% 증가로 해석하지 않는다. 단일 순서/기존 관찰 합성자료의 한계를 명시하며 악화하면 운영을 유지한다. 독립 검증이 없다면 일반화 달성/Goal 완료로 처리하지 않는다.

## 승인된 새 비교

사용자가 2026-09-30 새 비교 최대 600회×2조건의 API 실행을 승인했다. 기존 실패 실행과 체크포인트는 보존한다. 두 조건 모두 실험 전용 JSON 코드블록+설명 파서를 동일하게 사용한다. 기존 2,096개 해석 보존·1개 복구·14개 계약 검사를 통과한 보완이며 운영 파서는 변경하지 않는다. 새 worker smoke는 해당 응답 형식과 실제 CPU 추론을 함께 검증한다. 응답 처리 파일 해시도 실행 서명에 포함한다.
