## 측정 조건

[사전 계획](collector-six-way-plan.md)에 따라 메모리 임계값 없이 여섯 조건을 각 3회 실행한다. 기존 부산 공공기관 페이지에서 저장한 실제 DOM 복제본 63페이지를 동일 URL 순서로 수집하며, 새 외부기관 요청과 HCX 호출은 없다. 회차마다 조건 순서를 순환하고 각 실행은 새 Node 프로세스와 새 브라우저로 시작한다.

실행 환경은 이 PC의 Windows, Node 24.19.0, Playwright 1.62.1, Edge다. 전체 63페이지 중 15페이지가 후보 1,000개를 넘고 최대 후보 수는 한 페이지 4,336개다. 첫 기준선의 원본 근거 파일 합은 약 1.83GiB, 가장 큰 파일은 약 114.93MiB다. 반복 관측 수를 독립 페이지나 독립 광고 수로 표현하지 않는다. 이 저장량은 수집 원문과 문맥을 포함한 근거 자료의 크기이며 원격 HTML 다운로드 크기가 아니다.

기존 Playwright 수집기와 Edge, 페이지별 독립 context, 원문·문맥·스타일·좌표·iframe·기법 근거를 유지한다. 동시 수는 FIFO 묶음의 최대 크기다. 한 묶음의 모든 수집이 끝난 뒤 순서대로 근거를 저장하고 다음 묶음을 시작하므로, 빈 슬롯을 즉시 채우는 연속 worker pool과는 다른 스케줄이다. 원본은 디스크에 보존하며 끝난 묶음의 snapshot을 전체 실행 동안 누적 보관하지 않는다. 강제 GC나 Node 힙 상한 변경은 없다.

- **평균 메모리:** 수집 시작부터 브라우저 종료까지 유효 표본 구간의 시간 가중 평균을 구하고, 실행별 평균 3개의 산술평균을 사용한다. 종료 후 측정기 정리 대기는 제외한다.
- **최대 메모리:** 같은 수집 구간 안에서 3회 중 가장 큰 관측값이다. 프로세스 생성 시각을 검사한 Node·브라우저·측정기 working set 합이며, 자료를 제공하는 부모 서버와 PC의 다른 프로그램은 제외한다. 공유 메모리가 중복될 수 있어 물리 RAM 필요량과 같지 않다. 약 500ms 휴지와 조회 시간 사이의 순간 피크도 보장하지 않는다.
- **수집 속도:** 브라우저 시작·페이지 수집·근거 파일 저장·비교용 해시 계산·브라우저 종료를 포함한 벽시간의 3회 평균이다. HCX 광고 판정 시간은 포함하지 않는다. 모든 조건의 측정용 저장/해시 로직은 같지만 운영 디스크 저장과 완전히 동일한 부하를 뜻하지 않는다. 중앙값과 범위도 별도로 기록한다.
- **누락:** 새 동시 5개 전체 수집을 기준으로 URL별 후보 ID 및 원문·문맥·스타일·좌표·링크·프레임·기법 근거를 비교한다. 실패나 미완료를 누락 0으로 세지 않는다.

## 해석 범위

이번 결과는 저장 DOM의 고정 URL 전체 수집 진단이다. 실제 서버의 지연·요청 제한·원래 JavaScript와 새로운 URL 탐색 성능을 재현한 실사이트 시험이 아니다. 기준선에 이미 있는 수집 한도, 클릭 후 내용 및 늦은 댓글 미검사는 별도로 남는다. 기준선 대비 누락 0은 웹페이지의 모든 내용이나 모든 광고를 수집했다는 뜻이 아니다.

기존 자료의 반복 측정이며 새 독립 홀드아웃이나 25분 HCX 종단 검증이 아니다. 운영 설정은 변경하지 않는다. 앞선 4GiB 제한 실험은 사용자 요청으로 중단했으며 그 결과를 이번 평균에 합치지 않는다.

전체 1,134페이지·후보 관측 1,318,014건을 원본에서 다시 읽어 저장 해시·후보 개수·고유 ID·완료 시간을 검사했다. 첫 동시5 기준선 자체를 제외한 대조 범위는 1,071페이지·후보 관측 1,244,791건이다. 기준선 대비 미수집 페이지 0, 후보 누락 0, 후보 추가 0, 원문·문맥·스타일·좌표·링크·프레임·기법 등 근거 변경 0이었다. 모든 실행의 실제 최대 동시 수는 설정값과 같았다. 비교 시 비결정적 대기 시간만 제외하고 이슈 목록 순서만 정렬했다.

프로세스 관측 69,787건의 생성 시각·메모리 합계를 확인했으며 포함된 자손의 부모 누락은 0이었다. 부모보다 먼저 생성된 관계의 관측 79건은 측정기가 제외했다. 이 보호는 과거 PID 관계의 오염을 막지만 이전 실험의 이상치 원인을 소급 확정하는 증거는 아니다. 메모리 측정 오류는 0, 실행별 유효 표본 구간 비율은 최소 99.51%, 유효 표본 사이 최대 간격은 1.408초였다. 평균은 처음 유효 표본 이전을 임의로 채우지 않은 구간 평균이며, 최대치는 표본 간 순간 최고치까지 보장하지 않는다.

실험 실행은 총 약 48분 28초였고 이후 원본 감사는 이 시간 밖에서 수행했다. 실행기/감사기 구문, 시간 가중 평균 자체검사, FIFO 순서·동시성·출처·쿼리·예산 취소·완료 snapshot 미누적 검사를 통과했다. 실험 시작 전후의 15개 소스/계획 파일과 동결 복사본 해시가 같고, 그중 운영 소스 9개도 변경되지 않았다. API 호출·새 외부기관 요청·운영 적용은 모두 0이다.
