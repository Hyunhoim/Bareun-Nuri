# 리허설 비교의 사전 회귀 후보 순서

리허설 CE/KD가개발관문을둘다통과하는것을확인했으나이두모델의2,000회귀는아직실행하지않았다. 두방법의목표가새문맥적응과기존판정보존으로다르므로개발최고후보가회귀실패했을때이미고정된다음개발적격후보도검증한다. 추가학습·임계값변경·다른checkpoint재선택은하지않는다.

개발평균/최저F1/낮은step의기존순서로최대2개를미리순서고정한다. 첫후보가회귀통과하면그후보만봉인확인하고종료,실패하면고정된2순위에동일회귀관문을적용한다. 두후보가모두실패하면봉인유지. 회귀통과후봉인확인실패를다른후보로재시도하지않는다. 재현율/F1/4종/불확실성관문수치는변경없다. 추가선택편향은보고서에명시한다.

이는이전실패모델의성공기준을낮추는것이아니라이번리허설의두개발적격방법을사전에정한순서대로검증하는추가실험이다. 각결과는관찰회귀이며독립평가가아니다. 봉인평가는전체과정에서한후보와A 각각1회만실행한다.
