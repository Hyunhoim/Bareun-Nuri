# A 4종 오류 재분석 및 입력 개선 실험

2026-09-28. **A 원본 유지. 불규칙 자모 보조 읽기는 유망 후보로 보존하되 운영 미채택, 페이지 제목 일괄 제외는 미채택.** 추가 파인튜닝은 이번에 수행하지 않았다. 운영 HCX·수집기·탐색 정책은 변경하지 않았다.

## 오류 전수 분석

기존2,000개는4기법별 광고250/정상250으로 구성된다. 500원문 계열을 변형한 관찰 회귀자료이며 독립2,000시나리오가 아니다. A 저장 예측과 이번 원래 입력 재실행 예측은2,000/2,000 일치했다.

오류206위치는85원문 계열에 속한다. 28계열은4종 변형 모두에서 실패했다. 이는 기법별 독립 오류 수와 다르다. 기법은 정답의 관찰층 분류이며 위 표는 **해당 표현에서의 광고 의도 성능**이다. 분류모델이 CSS 투명도나 좌표를 직접 판단한 결과가 아니다.

주요 family별 오류/전체 위치는 정상 도입 뒤 광고26/40, 주소변경13/40, 기존회원 유도13/40, 검색어형 짧은 광고12/40, 도박피해 문의21/40, 성인물피해 문의20/40, 정상결제10/40이다. family는 분석에만 사용하고 모델 입력/판정 조건에 넣지 않았다. 이 분포는 합성 평가 설계의 분포이며 실제 발생률이 아니다.

이전 입력감사에서 원문2,000보존, 객체문자열 손실0, 문맥절단0을 확인했고 이번 tokenizer 절단도0이다. 투명·화면밖 오류의 모델 대상 문자열은 canonical 원문과 모두 같았다. 따라서 이 저장평가에서 이들의 누락을 수집 실패나 탐색 미도달로 설명할 근거는 없다. 실사이트 전체 수집의 완전성을 증명하는 것은 아니다.

## 두 가설을 단독 비교

1. 첫 줄 페이지 제목이 불필요한 의미 단서가 될 수 있어 저장 계약상 제목만 제외한다. 소속 문맥은 유지한다. 실제 게시글 제목과 일반 페이지명이 항상 분리된다는 가정은 운영에 적용하지 않는다.
2. 기존 보조 읽기는 공백으로 나눈 조각이 모두 한 글자일 때만 결합한다. `ㅎ ㅕ ㄴㄱ ㅡ ㅁ`처럼 조각 길이가 섞인 경우를 놓친다. 실험 보조 읽기는 한 칸 공백 자모 조각을 결합한 결과가 완전한 한글2음절 이상이면 모델 입력만 복원한다. 초성 나열/한음절/줄바꿈은 그대로 두며 기존 정규화기를 재사용한다. 원문·DOM·위치·관찰 기법은 바꾸지 않는다.

## 문맥 개발 및 새 안전성 확인

기존 제목대조120개에서 A/제목제외/자모 F1은65.38/68.57/65.38%, 기존 소속문맥44개는48.00/62.50/48.00%다. 자모안은 이 두 자료에서 입력변경0이므로 같은 점수를 자모 안전성 입증으로 주장하지 않는다. 제목제외도44개 오탐7→10으로 증가했다. 근거부족을 광고로 확정한 수는120자료에서14→15/21로 증가했다.

첫 안전성 실행은 NFC보다 읽기를 먼저 적용해 본 실험과 순서가 달랐다. `.runtime/a-generalization-v1/safety/`를 보존하고 **NFC→읽기**로 수정한 `safety-nfc/`만 본 보고서 근거로 사용한다. 두 실행은 새 독립 반복평가가 아니며 앞 결과에 맞춘 문구/변환규칙 변경은 없었다.

## 결정 및 다음 개선

- 제목 일괄 제외: 미채택. D의 제목제외 이득을 A에 자동 적용할 수 없었다.
- 자모 보조 읽기: 표현 해석 개선 후보로 보존. 4종 회귀 F1과 별도 합성 광고F1은 올랐으나 정상피해문의 신규오탐·4분류회귀가 있어 운영 승격하지 않는다.
- 추가 학습: 이번에는 하지 않았다. D에서 이미 같은 합성자료 재학습이 실패했고 이번 결과도 복원 이후 의미판정 병목을 보여준다. 오류문구를 그대로 훈련시키는 추가 학습 대신 새 원문계열의 실제 권유/피해신고/정상결제를 독립 검수한 대조자료가 필요하다.
