# 한글 닮은꼴 기법 고정 모델 진단

2026-09-30. 기존 KLUE 특화 및 KLUE+Unicode 모델을 SHA로 고정한다. 추가 학습/임계값 변경/운영 변경 없음. 기존 encode/predict를 재사용한다.

한글+숫자/영문/CJK 대체의8표기(6개 기본 어휘)에 각각 권유/예방 인용/원래 식별값/정보 부족을 작성해32개 대조를 구성한다. 별도16개는 순수 자모8·일반/교육/코드8의 경계 진단이다. 동일표기 대조와 같은 어휘의 변형은 독립 사례수로 부풀리지 않는다. 문장·표기와 라벨은 예측 전에 고정하며 정답 읽기·그룹·라벨·ID는 모델 입력에 넣지 않는다. 표준에 없는대응을 추가하지 않는다.

정답은 작성자 의도에 따른 합성 정답이며 사람 검수/실사이트분포/독립제작자 평가 아님. 새 문장이지만 기존문제에 맞춰 설계한 진단이므로 새 최종홀드아웃으로 부르지 않는다. 기존 학습문장 완전중복과 대상표기중복을 확인한다.

CPU8threads/batch8, 원래/역순/원래3회. 모든 입력 보존/512길이 보호. 주지표는 core32의 substitution strict F1·치환 재현율·literal/uncertain 오확정·기존정탐 손실, 부지표는16경계 오확정 및 보류. 광고상황16개(위장8+원래식별자8)의 조건부 결과도 별도 집계하되 **gold로 선택한 대조진단**이며 실제HCX양성 연결실험으로 주장하지 않는다. 이번엔 HCX호출0.
