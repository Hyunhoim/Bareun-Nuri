# 숫자 위치별 역할 P — 제한적 구조 진단

## 새 가설

기존 M은 토큰 전체의 분류 정의만 바꿨다. P는 숫자 위치마다 영문자 치환·원래 값 유지·근거 부족을 출력하고 코드가 토큰 분류와 복원을 합성한다. 실제 수량·버전 숫자와 문자 치환이 섞인 토큰을 한 분류로 바로 답하면서 생기는 혼동을 줄이는지 확인한다. 실패한 R/M/N/마스킹 지시는 누적하지 않는다.

P 입력은 원토큰·소속 문맥과 원문 기준 숫자 위치, 해당 숫자의 유한한 일반 문자 대응이다. 전체 단어 복원 후보 목록은 제공하지 않는다. 따라서 **입력 표현과 출력 분해를 함께 바꾸는 구조 비교**이며, 순수한 지시문 한 문장 효과로 해석하지 않는다. 광고 의도·운영 코드는 변경하지 않는다.

## 계약과 API0 안전 검사

- 숫자 위치는 원토큰의 UTF-16 인덱스로 기록한다. 다른 문자는 그대로 보존한다.
- 위치별 출력은 해당 숫자의 허용된 대체 영문자 하나, `keep`, `unknown` 중 하나다. 문자 대응은 기존 `readings(singleDigit)`를 재사용한다.
- 위치 개수·원숫자·인덱스·허용 문자·대상 ID 위변조 및 임의 필드는 거부한다.64개보다 많은 숫자 위치는 사전 거부하며 잘라서 확정하지 않는다.
- 하나 이상이 문자 치환이면 substitution, 모두 keep이면 literal, 문자 치환 없이 unknown이 남으면 uncertain이다.
- 하나라도 unknown이면 복원 문자열은 null이다. 문자 치환과 다른 위치 unknown이 함께 있으면 분류는 substitution이지만 복원은 미완료로 기록한다. 치환 여부와 정확한 복원 성공을 혼동하지 않는다.
- 한글·서로게이트 포함 위치, 혼합 치환, 미확정 합성, 다중 위치·허용 문자·ID 오류, dense overflow를 API0로 검사한다.

## 제한 실행

첫 진단은 이미 관찰한 `.runtime/digit-definition-v4` 전체48개(순수 치환12·혼합 치환12·정상 식별자12·모호12)에 P만 원래 순서로48회 호출한다. 기준 S는 `.runtime/digit-definition-v4-live-v1/00-holdout-S`, `03-holdout-S`의 원요청·원응답·저장 판정·소스 해시를 다시 검증하여 사용한다. 두 기준선의 동일 여부도 감사한다. 저장 S와 새 P 비교이므로 동시기 대조가 아니다.

- HCX-007 / none / temperature0 / seed42 / 출력1024 / 58k TPM / 최소1초 간격. 시작 전61초 대기.
- 첫 실행48회, 상한60회·예약1,000,000토큰·전체1시간·조건10분. 첫 예약 추정89,659토큰.
- 위치 `.runtime/digit-position-pilot-v1`. 입력·정답·계획·코드·기준선 파일 동결, 원요청·원응답·위치 결과·합성 분류 보존.
- 자동 수리·재시도·미확인 요청 재호출·덮어쓰기 금지. 오류가 생기면 원본을 보존하고 전체 완료 점수로 보고하지 않는다.

## 이번 단계의 사전 관문

P는 기준 S보다 strict F1이 개선되고, 정상 식별자의 치환 오탐과 모호 사례 과확정이 늘지 않으며, 혼합 치환 재현율이 개선되어야 한다. 또한 치환 양성24개 중 정확한 복원 성공이20개 이상이어야 한다. 기존 S의 개별 정탐 손실·획득은 모두 보고하되 이 제한 진단의 절대 탈락 조건으로 삼지 않는다. 이 기준은 P 실행 전에 정하며, 과거 실패한 실험을 소급 통과시키지 않는다.

strict F1은 모호 사례를 치환으로 확정한 것도 오탐으로 계산한다. 숫자별 역할 정확도는 위치 정답을 도출할 수 있는 치환·정상 사례에서 별도로 계산한다. 모호 사례의 각 숫자 역할을 임의로 정답화하지 않는다. 정확한 복원 점수는 영문 대소문자를 접어 비교하되 원문 비숫자 보존은 코드에서 별도 검사한다.

첫 관문을 통과한 경우에만 **프롬프트 변경 없이** 역순 P48회를 `.runtime/digit-position-reverse-v1`에 별도 실행할 수 있다. 실행기는 `--reverse`와 첫 감사의 통과 결과를 요구하며 자동으로 호출하지 않는다. 역순도 같은 관문을 확인한 뒤에만 미사용 독립 확인 자료를 검토한다. 실패 시 동일 문구에 맞춘 예외·지시 수정으로 반복하지 않는다.

## 운영과 일반화 해석

여기의 S는 숫자 기법 실험 기준선이며 실제 운영 광고 정탐과 다르다. 후속 운영 채택에서는 **기존 운영 정탐 보존**이 별도 절대 요건이며, 다른 기법 회귀와25분 전체 광고 기준 성능도 확인해야 한다. 이번48개는 새 홀드아웃이 아니고, 위치 대응 선택지가 다시 익숙한 단어를 유도할 위험이 남는다. 역할을 나눴다는 이유만으로 문맥 부족이나 정확한 복원 문제가 해결됐다고 주장하지 않는다.
