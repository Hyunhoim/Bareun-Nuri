# 동시3 반복 검증 결과

2026-10-01. **동시3은 이번 사전 반복검증 기준을 통과했다. 후속 운영 통합 후보를 동시2에서 동시3으로 변경 권고한다. 운영 코드 자체는 변경하지 않았다.**

## 방법

사용자의 명시적 재검증 요청에 따라 새 디렉터리에서2→3→3→2 순서로 실제 HCX96호출을 실행했다. 이전 동시5의 미확인 요청은 기록을 변경하거나 재개하지 않았다. 동일24요청/238후보, 최대12묶음/none/512/temperature0/seed42/58k공유예약/61초창/1초발송간격을 유지했다. 조건 사이61초 냉각은 아래 처리시간에 포함하지 않았다.

정확도는 exact gold95위치(광고50/정상45)에 대해 계산했다. 나머지143개는 미라벨이며 정상으로 간주하지 않는다. 이미 관찰된 Phase1 회귀자료로서 새로운 일반화 평가나 전체사이트F1이 아니다.

평균 동시2는83.7105초, 동시3은77.136초로 **7.85% 단축**됐다. 비교쌍별 이득은11.50%와3.90%다. 두 비교쌍 모두 빠르고 평균5% 초과라는 사전기준을 통과했지만, 매번5% 이상 빨랐다는 뜻은 아니다. 첫 동시2의 API service합107.34초는 마지막동시2의97.90초보다 길었다. 서버·네트워크 변동이 있어 평균이득 전체를 동시성의 고정 효과로 단정하지 않는다.

동시3 반복 사이226개 확정후보의 게시행위가 모두 같았다. 동시2 반복 간 미라벨2개의 광고/정상 판정변동이 있었으며, 동시3과첫동시2의 차이도 이2개다. 정답위치의 정탐손실/새오탐은0이다. 작은 표본의 반복일치만으로 전체입력에서 판정이 결정적이라고 주장하지 않는다.

네 조건 모두 같은12후보 묶음1개가 불완전응답으로 격리됐다. FN6중5개는 격리광고,1개는 의미누락이다. 이번 변경으로 불완전 응답이나 기존 의미 오류를 해결한 것은 아니다. 미판정 광고는 FN에 포함했다.

## 채택 판단과 한계

이번에 요구한 동시3 반복 검증은 완료됐고 사전기준을 통과했다. **후속 통합 후보는3요청을 권고한다.** 기존에관측한동시4는3보다약1초빨랐고동시5는미확인응답으로중단됐으므로, 이번 결과만으로4/5확대를권하지않는다. 동시5가본질적으로불안정하다고입증한것은아니다.

운영승격은별개다. 현재단일inflight및격리요청번호귀속을요청별영구상태로바꾸고, 역순응답·중단·재개·중복방지를검증해야한다. 이후동일25분조건에서전체광고기준F1/정탐수/미판정을확인한다. 저장요청24개에서의7.85%를전체사이트완료시간에곧바로적용하지않는다. 앞선516개시간모사는토큰한도로장시간의추가이득이작을수있음을보여줬다.
