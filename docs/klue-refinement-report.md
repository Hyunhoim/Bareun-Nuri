# KLUE RoBERTa 학습 자료 보강 결과

2026-09-28. 운영 변경 없음. 추가 유료 API 호출 0. 학습·검증 선택 1회, 선택 후 기존 자료 평가 각 1회.

## 결론

데이터 보강과 학습량 확대 후 기존 128개 광고 F1은 70.00%에서 84.85%, 기존 137개에서는 53.33%에서 71.84%로 개선됐다. 실험 후보로 보존하지만 HCX-007 운영 대체는 권하지 않는다. 기존 정탐 손실과 신규 오탐이 있으며, 독립 최종 평가 및 25분 종단 검증은 하지 않았다.

사용자 요청에 따라 이전 최종 128개는 이번부터 관찰한 회귀 자료로 전환했다. 점검한 정답을 훈련하거나 체크포인트 선택에 사용하지 않았지만, 이미 관찰한 문제를 참고한 설계이므로 새 홀드아웃 일반화 증거가 아니다. 결과 확인 후 추가 재학습하지 않았다.

## 변경과 검증

- 기존 훈련 384행(고유 입력 224개), 검증 128행(고유 80개)에서 중복 제거·대조 자료 추가 후 훈련 1,104개, 검증 420개로 확대했다.
- 실제 권유와 예방 인용, 주변 광고와 정상 메타데이터, 다른 댓글의 경고와 현재 광고, 짧은 연결 문구, 근거 부족을 함께 구성했다. 대상/문맥 입력 형식은 기존과 동일하다.
- 새 학습·검증의 광고 문구와 설명 표현을 나눴지만 공통 생성 구조가 남는다. 사람이 검토한 실제 광고 데이터가 아니라 합성 자료다. 복제본 52개는 회귀 대상과 겹쳐 전부 제외했으므로 새 실제 DOM 자료 포함은 0개다.
- 훈련 라벨 분포는 광고456/인용360/일반267/보류21, 검증168/132/99/21이다. 보류의 다양성이 특히 작고, 이름 변경·문구 조합에 의한 행 증가를 독립 사례 증가로 해석하면 안 된다.
- KLUE 원본부터 full fine-tuning, seed42, AdamW 2e-5, batch8, 최대512토큰. 최대8회·검증 macro F1 우선/동률 loss·2회 연속 미개선 종료를 미리 고정했다. 8회 동안 동률 loss가 계속 개선돼 8회차를 선택했다. 학습 128.15초, GPU 최대 할당 약2.09GiB.
- 검증 macro F1은 72.76→99.60→100%; 3~8회차 모두100%다. 검증이 너무 쉬운 합성 패턴을 공유할 위험을 보여주며 실제 성능100%를 뜻하지 않는다.
- 학습량과 자료를 함께 변경했으므로 각각의 독립 효과는 분리하지 않았다.

## 기존 128개 비교

광고32/인용32/일반32/근거부족32. 광고 지표에서 근거부족32는 제외하고 4분류 지표에는 포함한다. 128행은 고유 입력80개이므로 통계적으로 독립인128문장으로 취급하지 않는다.

| 지표 | 이전 KLUE | 보강 KLUE |
|---|---:|---:|
| TP / FP / FN |28 / 20 / 4|28 / 6 / 4|
| 정밀도 |58.33%|82.35%|
| 재현율 |87.50%|87.50%|
| 광고 F1 |70.00%|84.85%|
| 4분류 macro F1 |77.92%|92.18%|
| 예방 인용 오탐 |8|6|
| 일반 문구 오탐 |12|0|
| 보류 정답 |32/32|32/32|
| CPU 판정 시간 |3.66초|3.89초|

기존 정탐4개를 잃고 다른4개를 회복했다. 주된 개선은 주변 광고를 목록/수정일/이동 문구에 잘못 귀속한 오탐12개 및 예방 인용 오탐2개 해소다. 신규 정상 오탐은0개다. 반면 명시적 경마·화투 권유4행을 인용으로 오분류했다. 손실4행 중 입력 중복이 있어 독립 실패4종을 뜻하지 않는다.

과거 동일128개 HCX-007 광고 F1은96.97%로, 새 KLUE84.85%보다 높다. 이번 HCX 재호출은 없으며 두 모델의 입력 직렬화가 달라 순수 모델 역량의 동일조건 비교는 아니다.

## 기존 137개 비교

광고60/정상65/불확실12. 이 자료는 이진 정답이므로 4분류 macro F1은 해석하지 않는다.

| 지표 | 이전 KLUE | 보강 KLUE |
|---|---:|---:|
| TP / FP / FN |24 / 6 / 36|37 / 6 / 23|
| 정밀도 |80.00%|86.05%|
| 재현율 |40.00%|61.67%|
| 광고 F1 |53.33%|71.84%|
| CPU 판정 시간 |3.99초|4.28초|

기존 정탐4개 손실/새17개 회복, 기존 정상 오탐3개 해소/신규3개 발생이다. 짧은 신청·구매 연결 문구와 실제 거래 권유 인용 등을 추가 탐지했다. 신규 정상 오탐은 날짜2개와 구매 금지 안내1개다. 명확한 권유를 포함한 도박 광고와 띄어쓰기 없는 판매 문구의 누락이 남는다. 같은 경마 문구가 다른 페이지 제목에서 회복/손실로 갈린 사례도 있어 주변 문맥 영향은 여전히 불안정하다.

**입력 품질 제한:** 기존137개 전부의 context에 `[object Object]`가 들어 있다. 기존 `klue-data.cjs`가 객체인 nearby를 문자열 배열에 넣어 join한 결과다. 기존 모델과 새 모델에 같은 저장 입력을 사용해 전후 비교는 유지했지만, 완전한 문맥을 제공한 성능 또는 모델 한계로 해석하지 않는다. 동결 원본을 수정하지 않았다. 다음 실험은 구조화된 nearby를 보존하는 별도 입력 버전을 만들어 이전·새 모델 양쪽을 비교해야 한다.

## 속도·과적합·다음 판단

CPU8스레드/배치8/FP32, 워밍업 후 판정만 측정한 단회 값이다. 모델 로드·토큰화·브라우저 수집은 제외한다. 두 자료 모두512토큰 잘림0. 모델 크기와 추론 구조는 같고 시간은 소폭 증가했으므로 추가 속도 개선으로 주장하지 않는다.

현재 결과는 학습 데이터 개선 가능성을 지지하지만 일반화 해결의 증명은 아니다. 공통 합성 템플릿, 적은 보류 예시, 관찰한 평가 자료 재사용, 검증100%와 회귀 성능의 큰 차이가 과적합 위험이다. 보류32/32도 단순한 합성 설명을 배운 결과일 수 있다. 같은 오류 문구를 추가해 다시 맞추는 작업은 하지 않았다.

다음은 기존137개의 입력 결함을 별도로 검증하고, 실제 수집 경계와 사람이 검수한 정답을 포함한 별도 개발 자료를 확보한 뒤, 문장·사이트·템플릿을 분리한 새 최종 세트를 잠가 1회 평가하는 순서가 적절하다. 모델 대체 전에는 동일25분 전체 광고 기준 F1과 재개 계약도 필요하다.
