# 2순위 확인의 출력 계약 분리

2026-09-23. `stage-3-digit-ablation-plan.md`의 자유 문자열 계약으로 control의 두 분할과 no-readings의 두 분할이 중단됐고, single-dev도 같은 계약 오류로 중단됐다. 원문과 동일한 복원을 치환이라고 반환하거나 문자 대응 범위를 벗어나는 출력이 관측됐다. 기존 결과를 수정하거나 지우지 않는다.

이 상태에서는 새 출력 계약의 불안정성과 배치 효과를 구분하기 어렵다. 사용자에게 한계를 보고하고 **2순위의 확인에 한해서 이전에 완주한 기존 digit-contract.cjs의 enum 출력 계약으로 복귀**한다. 실패 단어에 맞춰 prompt/규칙/라벨을 변경하지 않는다. 자유 출력 실험은 원래 예정대로 종료하고 별도로 집계한다.

이 추가 계획은 enum 조건의 첫 호출 전에 고정한다. enum-control(기존 계약, 배치 4)과 enum-single(동일 계약, 배치 1)을 기존 dev/evaluation 각각 한 번씩 실제 호출한다. 과거 저장 결과만을 대조군으로 삼지 않는다. 기존 디렉터리는 보존하며 같은 상위 실행 디렉터리에서 **앞선 실패를 포함한 전체 220회/250,000토큰 상한**을 계속 적용한다. 예정 추가 기본 호출은 22+88=110회다. 잔여 한도가 부족하면 미검증으로 종료하며 한도를 높이지 않는다.

모델·추론·seed·temperature·입력·순서·지연 설정은 원계획과 동일하다. 출력 형식만 기존 계약으로 복귀하고, 두 enum 조건 간 차이는 배치 크기뿐이다. 원계획의 치환 TP>=14, literal20/20 및 FP0, uncertain8/8, 쌍 불일치0, 잘못된 복원0, 대조군 탐지 유지 관문을 그대로 적용한다. 낮추지 않는다. 두 진단 분할을 통과해야만 잔여 한도 내 새 자료·순서 안정성·306개 회귀 검토를 진행할 수 있다. 한도 내 충분한 후속 검증이 불가능하면 채택하지 않는다.

기존 88개 반복 사용의 과적합 우려가 있어 이 확인 이후 추가 프롬프트/단어 예외 조정은 하지 않는다. 같은 작성자의 합성 자료이며 독립 실사이트 일반화 증거가 아니다. 자유 출력 조건과 enum 조건은 묶어 순수 배치 효과로 보고하지 않는다. 이 설계 보완은 최초 계획부터 고정된 비교인 것처럼 표현하지 않는다.
