# 두 기법 후속: 치환 밀도와 표기 역할

2026-09-30. 최초4학습 종료 후, `kc-continue`가 새 개발624에서는100%이나 기존112회귀에서 기존H정탐48중30개를 잃었다. 최초 모델은 미채택이며 `candidate-selection.json`을 덮어쓰지 않는다. 최초 봉인624는 아직 평가하지 않았다.

관측: 기존 회귀의 단일 숫자/키릴 문자 치환에서 누락이 많고 전각은 상대적으로 보존된다. 가설: 학습 생성기가 대응 문자를 모두 바꾸어 치환 개수/비율이 지름길이 됐다. 먼저 새 개발 어휘의 동일 문맥에서 단일/전체 치환을 비교한다. 과거 실패 단어를 학습하지 않는다.

후속은 새 기본/추가40어휘에서 치환 위치와 개수를 변화시킨 자료를 만든다. 한 표기를 권유/교육/원래 식별값/정보 부족에 교차한다. 역할 학습을 함께 보강하므로 효과가 확인되어도 치환 밀도 단독의 인과효과라고 주장하지 않는다. 표기 밀도 진단은 별도로 남긴다. 원래 식별값은 합성 작성 근거이며 실제 상표/등록부의 독립 검수가 아니다.

개발12어휘와 문장틀 분리, 최종12어휘의 추가 도전 자료는 학습 전에 봉인하며 기존 final624를 수정하지 않는다. 최종 확인은 최초624와 추가 도전을 합쳐 선택모델+고정 기준선으로1회만 수행한다. 같은 제작자 한계를 유지한다.

최초 `kc-continue`를 고정 출발점으로 기본+추가1695와 새 보강을 lr1e-5/seed42/batch8/FP32로 최대2epoch 추가 학습한다. 개발 선택은 기존624와 새 대조 개발의 양성macroF1 평균, 두패널 최저값, 정상/보류 오확정, 이른epoch 순이다. 먼저 이 한 후보만 검증한다. 최초 후보 및 기존모델과 비교하고, 회귀를 보고 임계값/예외를 바꾸지 않는다. 개선 실패 시 동일 자료를 반복 학습하지 않고 원인과 미달 상태를 보고한다.

예산 추가 학습1회/최대30분, API0, 운영수정0. 후보가 기존정탐보존·오확정 억제를 함께 만족하지 못하면 연구 중 상태를 유지하고 운영을 바꾸지 않는다.
