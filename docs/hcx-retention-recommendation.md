# HCX 유지 권고와 실험 보존 상태

2026-09-30. 사용자의 “그냥 HCX유지가 정답인듯?”에 대해, 현재 프로젝트에서는 HCX 유지를 권고했다. 분류모델 개발 Goal의 중단 여부는 별도 질문의 답변 대기 상태이며, 중단이 확정됐거나 Goal을 달성했다고 기록하지 않는다. 추가 학습·진단은 시작하지 않았다.

최신6조건 비교에서 KcELECTRA는 실제 공통 광고10개 중 정탐0→3, 기존 문맥204개·표현2000개에서 정탐 손실0의 이득이 있었다. 그러나 정상 오탐 증가와 문맥F1 하락으로 사전 기준에 미달했다. KLUE는 정탐 손실, KoELECTRA는 큰 정상 오탐 증가가 있었다. HCX는 같은 공통 입력의 확정형 광고10개를 탐지했으나 근거 부족 사례를 광고로 확정하는 한계가 남았다. 자료는 AI 주석의 소규모 관찰/회귀이며 독립 운영 성능은 아니다.

로컬 분류모델은 CPU 추론 속도의 이점을 보였지만 현재 입력에서 판정 품질의 대체 조건을 충족하지 못했다. 이는 프로젝트별 비교 근거이며 모든 로컬 모델이 열등하다는 결론이나 서버 하드웨어만으로 설명한 결과가 아니다. 실험은 모델 선택의 근거로 보존한다. 세부 수치·원예측·사전 기준은 `semantic-real-addition-report.md` 및 해당 보고서의 실행 기록을 따른다.

현재 소스에서 HCX-007/none, worker 출력512·예약58,000TPM, 페이지별 최대12개 묶음이 유지됨을 확인했다. 운영 코드 변경이나 새 API 호출은 하지 않았다. 이 소스 확인은 새25분 종단 검증을 뜻하지 않는다.

후속 형식 진단은 `semantic-format-diagnostic-plan.md` 및 `.runtime/semantic-format-diagnostic-v1`에 원래 훈련210개와 표기 대조를 포함한468개 입력만 준비돼 있다. 모델 추론·새 학습·라벨 변경·새 성능 결과는 없다. 기존 실험과 모델 파일을 삭제하지 않았다.

Goal의 원래 목표인 실제 입력에서 HCX 대체가 유망한 분류모델과 채택 근거는 미완료다. HCX 유지를 권고했다는 사실로 목표를 달성한 것으로 재정의하지 않는다. 사용자가 중단을 확정하면 Goal을 paused로 전환하고 연구를 멈춘다.
