# 숫자 후보 힌트 제거 N — v5 미사용 자료의 동시기 S/N 비교

## 확대 근거와 자료 용도

개발56개에서 N은 저장 S의 치환 정탐24개·정상 오탐0개를 두 순서 모두 유지했고, 모호 사례 과확정은 각 순서8→7개였다. 이는 관찰 자료 및 재사용 S를 이용한 제한적 진단이다. 동일한 N 프롬프트로 미사용 자료에서 새 S/N 쌍을 실제 호출한다. 실패한 R/M/마스킹 지시나 단어 예외를 추가하지 않는다.

`.runtime/digit-mask-holdout-v5`의48개는 원래 마스킹 방식의 조건부 확인용으로 제작됐지만 마스킹 모델은 이 자료에서 실행되지 않았다. N 개발 관문 통과 후 **이 계획에서 S/N 비교 용도로 전환한다.** 데이터와 기존 manifest는 변경하지 않으며, 용도 변경은 이 계획에만 기록한다. 사전 독립 봉인의 입력·정답·생성기 해시를 유지한다. 정답의 역할 라벨을 광고 의미 정답으로 사용하지 않는다.

## 고정 변경 요인

S는 원래 compact 단일 판정이며 N은 개발 실험과 동일하다. 원문·대상 표기·소속 문맥·unchanged·대상 ID와 compact3분류 출력은 보존한다. N에서는 복원 후보 관련 입력3필드와 이에 의존하는 지시2문장만 제거한다. 상세 차이는 `docs/digit-nohint-plan.md` 및 동결된 `digit-nohint-methods.cjs`를 따른다. 후보 제거와 후보 존재를 요구하던 지시 제거가 함께 일어나므로 순수 입력 필드 효과로만 해석하지 않는다.

## 실행·보존 규칙

- S 원래48회 → N 원래48회 → N 역순48회 → S 역순48회. 모든 요청은 대상1개, 네 조건 모두 새 실제 응답을 받는다.
- HCX-007 / none / temperature0 / seed42 / 출력1024 / 로컬58k TPM / 최소1초 간격, 조건 시작 전61초 대기.
- 예정192회, 상한220회, 예약 상한1,000,000토큰. 사전 추정364,936토큰. 전체1시간·조건10분 상한.
- 출력 수리·자동 재시도·미확인 요청 재호출·기존 디렉터리 덮어쓰기 금지. 오류는 원본 보존 후 미완료로 보고한다.
- 저장 위치 `.runtime/digit-nohint-v5-live-v1`. 계획·코드·입력·정답·독립 봉인·개발 기준선 기록을 실행 전 동결하고 원요청/원응답/판정을 보존한다.
- 네 조건이 모두 끝나기 전 정답에 따른 결과 분석이나 프롬프트 변경을 하지 않는다. 완료 후 자료는 관찰한 평가 자료가 된다.

## 사전 통과·종료 기준

각 순서에서 같은 순서 S의 치환 정탐을 모두 보존하고 정상 표기의 치환 오탐이 증가하지 않아야 한다. 두 순서 합산 모호 사례 과확정이 감소하고, 평균 strict F1과 3분류 macro F1도 개선되어야 한다. nominal F1, 정상 확정·보류, 순서별 최저값, 정탐 손실·획득, 토큰·시간도 보고한다. strict F1은 모호 사례를 치환으로 확정한 것도 오탐에 포함한다.

통과할 때만 기존 운영 의미 판정·다른 기법 회귀와 25분 제출 조건의 후속 검증을 별도 설계한다. 실패하면 N 확대를 종료하며 같은 실패 문구에 맞춘 추가 프롬프트 변형을 하지 않는다. 이 실행은 운영 자동 승격을 승인하지 않는다.

## 해석 한계

48개는12개 단어 계열의 상관된 대조 자료이며 실제 사이트의 발생 비율을 대표하지 않는다. 원문·어휘가 분리돼도 같은 제작자의 합성이라는 한계가 있다. 숫자의 문자 치환 분류를 평가하며 정확한 복원 문자열은 출력·검증하지 않는다. HTML 수집, 광고 의도 F1, 최종 탐지 F1, 25분 처리량은 이번 텍스트 판정 실험에서 측정하지 않는다. 과거 저장 S 비교와 이번 새 쌍 비교를 혼합해서 평균내지 않는다.
