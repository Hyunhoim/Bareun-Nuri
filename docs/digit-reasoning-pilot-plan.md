v7의 B 재현율 관문 실패를 유지하며, B·합의C·새 예시를 누적하지 않는다. 새 가설은 고정 A가 문맥 역할을 적용할 추론 자원이 부족한지 확인하는 것이다. 운영 코드는 변경하지 않는다.

이미 관찰한 v7에서 순수치환3·혼합치환3·정상 식별6(광고문맥3/일상업무2/예방1)·모호6을 선택하고 기존 운영 양성2개를 더한20개다. v7 생성기의 원래 역할/순서에서 광고·업무·예방 계층을 확인하고 각 계층 안에서는 SHA256('digit-reasoning-pilot-v1:'+node_id)의 오름차순으로 선택한다. 전체 순서도 별도 고정 SHA256 키로 정한다. 특정 실패 단어나 결과로 선별하지 않는다. 라벨은 이 진단 표본 선택에만 사용하고 모델 입력은 기존 node_id/token/target_text/context 투영으로 제한한다. 선택목록을 실제 호출 전 manifest에 기록한다. 새 홀드아웃 또는 v7 전체 성능으로 주장하지 않는다.
