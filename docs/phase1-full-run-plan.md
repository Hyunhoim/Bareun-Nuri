# Phase 1 운영 전체 실행 계획

2026-09-30. 최신 운영 코드 그대로, 장애주입/학습/프롬프트 변경 없이 새 실행한다. 데이터와 운영 소스 해시를 고정하고 정답은 worker에 전달하지 않는다.

- 첫 구간25분/600호출/200페이지/누적 후보 제한0. 첫 구간 저장 결과·체크포인트·25분 내 마지막 저장 지점을 별도로 보존한다.
- 미완료 일반 작업은 같은 서버 주소·실행서명으로 재개한다. 후속 구간은 최대60분/600호출/200페이지씩, 안전상한 총3구간(최대145분·1800호출). 예상보다 작업이 커 상한에 도달하면 미완료 사실을 보고한다. 별도 변경 없이 호출/시간 한도로만 끝난 작업은 재개 가능하다. 전송 불명/거부된 재개/형식 실패는 자동 재호출하지 않는다.
- 격리 요청의 별도 재판정 여부는 사용자 답변에 따른다. 운영 checkpoint를 조작해 자동 재호출하지 않는다. 원래 결과와 별도 재판정은 구분한다.
- 사용자 후속 제안에 따라 일반 작업 종료 후 확정 불완전 응답만 별도 마지막 재판정으로 비교한다. 원래 묶음·입력·설정을 유지하고 묶음당1회, 최대60호출·10분으로 제한한다. 재실패는 미판정 유지, 통신 미확인 요청은 제외/중단한다. 연구용 결과를 별도 저장하며 현재 실행 중인 운영 소스와 체크포인트는 수정하지 않는다.
- 지표 정의를 미리 고정한다: 전체 검사 F1은 전체 지정 정답 위치×4종 기법 micro F1(미방문/미수집/미판정 포함). 광고 의도 F1은 전체 위치 이진 판정과 실제 판정 완료 위치를 각각 보고한다. 기법 판정 F1은 광고를 정탐한 위치에서4종 micro F1이며 조건부 지표임을 명시한다. 기법별 지표와 위치 단위 탐지도 보조 보고한다.
- 시간은 첫25분 결과, 재개 후 누적 실행시간, 구간 사이 대기를 포함한 실제 총시간을 구분한다. 마감 후 저장 판정은 첫25분에서 제외한다. 데이터는 이미 소비된 합성 회귀 자료이며 독립 최종 평가나 실제사이트 전체 정확도가 아니다. 미라벨 양성을 정상으로 간주하지 않는다. 기존 알려진 정답/수집 한계도 유지한다.
