# Firecrawl 검토 종료 — 사용자 폐기 결정

2026-09-23 사용자가 Firecrawl 폐기를 지시했다. 도입·추가 실험·재실행을 중단한다. 운영 FIFO와 기존 문맥 Bandit 실험 후보는 변경하지 않는다. 이 기록은 Firecrawl의 보편적 성능 열위를 입증한 결과가 아니다.

## 유효한 제한 결과

dev-101 합성 사이트 한 개에서50페이지 두 반복만 정상 비교됐다. 두 방식 모두 광고24개 중8개(33.33%) 도달, 깊은 광고0개, 도달한 광고 위치 집합도 같았다.

|방식|첫 실행|두 번째 실행|문서 요청 수|
|---|---:|---:|---|
|문맥 Bandit|38.47초|38.39초|50 / 50|
|Firecrawl Crawl|87.39초|73.94초|54 / 58|

Firecrawl 반환100개 문서의 body DOM은 원본과 일치했다. 일부 엔진의 광고 차단 해제 옵션 미지원 경고가 있었다. 따라서 정적 본문 보존 확인을 실제 동적 페이지·iframe·4종 탐지 수집기 대체 검증으로 확대하지 않는다. 위 수치는 광고 위치 도달률이며 F1·정밀도가 아니다.

100페이지 조건은 localhost.run의 임시 도메인이 중간 변경되면서503 오류가 발생해 무효다. 당시 Firecrawl은62개 응답을 반환했지만 오류 페이지도 포함돼 전부 성공 방문으로 세면 안 된다. 대응 Bandit도 첫 요청503으로 중단됐다. 이 쌍은 비교 순위/평균에서 제외한다. 다른3사이트와 예정된 전체 비교는 실행하지 않았다.

## 비용과 정리

- Firecrawl 본 실험162크레딧(정상50+50, 무효 조건62), 연결 시험2크레딧, robots 진단1크레딧: **총165크레딧**.
- 계정 잔여1,025→860크레딧을 확인했다. HCX 호출0회.
- 중단 시 API의 활성 Crawl 목록은0개였다. 임시 SSH 터널 종료 및 합성 서버18990포트 비활성을 확인했다. Cloudflare 터널도 앞서 종료했다.
- 실험 원본은 `.runtime/firecrawl-trial-v1`, 접속 진단은 `.runtime/firecrawl-smoke-*` 및 `.runtime/firecrawl-robots-diagnostic`에 보존한다. `infrastructure-invalid.json`이 무효 조건과 보존할 정상 조건을 명시한다. 기존 `comparison.json`의100페이지 행은 유효 성능 비교로 사용하지 않는다.
- 실험 실행 코드는 운영에서 사용하지 않으며 폐기 보관소로 이동한다. API 키는 사용자가 등록한 설정이므로 임의 삭제하지 않는다. 추가 실행/자동 재개하지 않는다.
