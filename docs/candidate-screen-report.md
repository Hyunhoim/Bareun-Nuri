## 비교 구조

페이지 탐색·수집·원문·문맥·스타일·위치는 바꾸지 않는다. C의 실제 입력을 그대로16개씩 HCX-007 none에 제공해 상세 판정 필요 여부(keep)를 선별하고, 남은 후보만 기존4개/출력512 C로 판정하는 안이다. 선별 출력 상한은1024다. 태그/기법 신호가 없다는 이유로 제외하지 않으며 불확실하면 유지하도록 지시했다. 제외는 정상 확정이 아닌 상세 판정 미실시다. 정답과 평가용 ID 규칙은 모델 입력에 전달하지 않았다.

먼저 대형3543후보의 페이지 내 동일 근거를 오프라인 검사했다. C 의미 입력(node_id 제외), 본인/조상 스타일, signals, 프레임이 모두 같은 후보는0개였다. 이는 엄격한 동일 근거 검사이며 부분 문자열/근사 중복은 검사하지 않았다. 근사 중복을 안전하다고 간주하지 않았다.

## 원인과 기존 C 손실

실제 원문과 귀속 문맥은 모델에 모두 제공됐다. 누락은 수집 실패가 아니다. 주요 제외 사례는 다음과 같다.

- 불법 거래 설명 아래의 짧은 신청 링크를 일반 UI로 간주한 것으로 해석되는 누락.
- 귀속되지 않은 예방 문구 옆의 실제 모집 문장 제외.
- 거래 문맥을 가진 판매 명사구, 실제 참가를 요청하는 인용 형식 제외.

이는 관측한 입력/출력에 근거한 원인 가설이다. 내부 추론은 관찰하지 않았다. 모델이 문제를 충분히 구분하지 못한 상태에서 선별 단계에 배치만 크게 주면, 기존 의미 판단 병목이 선별에서 반복될 수 있다.

추가 합성24개 전체를 기존 C로 두 순서 실제 판정해 손실을 분리했다(광고12/정상12).

| 조건 | TP / FP / FN | 정밀도 | 재현율 | F1 |
|---|---|---:|---:|---:|
| 원순서 C 직접 판정 | 9 / 2 / 3 | 81.82% | 75.00% | 78.26% |
| 위 C 결과에 선별 제외 적용 | 7 / 1 / 5 | 87.50% | 58.33% | 70.00% |
| 변경순서 C 직접 판정 | 9 / 5 / 3 | 64.29% | 75.00% | 69.23% |
| 위 C 결과에 선별 제외 적용 | 9 / 5 / 3 | 64.29% | 75.00% | 69.23% |

원순서에서 **기존 C가 잡은 광고2개를 선별이 먼저 버렸다.** 오탐1개 감소보다 정탐 손실이 커서 F1이8.26%p 낮아졌다. 변경순서는 광고 손실이 없었다. C 자체에도 누락과 변동이 있다.

위 선별 적용 값은 실제 C 응답에 선별 마스크를 적용한 저장 판정 기반 진단이다. 남은 후보를 재배치해 다시 호출한2단계 종단F1이 아니며25분 결과도 아니다. 선별 관문 실패로 종단 확대를 중단했다.

## 작업량과 지연

137개 진단 자료에서 상세판정4개씩의 호출을 계산하면 C35회, 선별11회+남은 상세판정은 원순서33회/변경순서35회다. 예상 호출 감소는5.71%/0%에 그친다. 동일 로컬 추정기의 예약토큰은97805→123235(+26.00%),97800→128061(+30.94%)다. 선별에 전체 근거를 읽히고 남은 후보에서 다시 읽히는 비용이 있다.

이는 광고·대조 사례 비중이 높은 진단 패널의 **예상** 호출/예약토큰이다. 정상 메뉴가 많은3543후보 전체의 비용 절감률 또는 실제 과금/종단 지연으로 확대하지 않는다. 전체 예상25% 절감 관문 계산과25분 실제 실행은 앞선 안전성 관문 실패로 시행하지 않았다.

실제 선별22호출/69880토큰/110.85초, C 추가진단12호출/16738토큰/24.81초다. 합계 **34호출/86618토큰**, 모두HTTP200·검증 완료, 미확인 요청0·자동재시도0. C 진단 전61초 사용량 창 분리는 위 실행시간과 별도다. 이는 비교 실험 사용량이며 개선안의25분 운영 비용이 아니다.

## 보존과 한계

- 실제274개 선별 입력이 운영 C의 initialEvidence와 완전히 같은지 확인했다. 수집 원문/복원/문맥/링크를 삭제하지 않았다.
- 원본137후보가 저장 자료와 같고 실행 소스 해시가 유지됐음을 확인했다. 운영 파일 변경0.
- 후보ID 중복/누락·잘못된 bool·출력 순서 정렬 검사를 통과했다. 원응답과 제외 기록을 별도로 보존했다.
- 기존 자료는 회귀·진단용이다. 추가24개도 같은 제작자의 합성 대조이며 독립 실사이트 일반화를 증명하지 않는다.4개의 짧은 신청 문구가 같아4개 독립 언어 유형으로 세지 않는다.
- 복제본만 보면 광고 보존이 좋아도 문맥 대조에서는 실패했다. 복제본에 맞춘 기준 완화나 해당 실패 문구 전용 예외를 넣으면 과적합 위험이 있다. 프롬프트 재조정은 하지 않았다.
- 선별 후 배치 변경, 전체4종 기법 최종F1, 실제25분 지연, 재개 통합은 미검증이다. 관문 실패 때문에 운영 통합하지 않았다.
