# Filter 1.0 파인튜닝·개발검증

2026-09-29. **학습과 개발검증 완료. 정상 제외 능력은 유망하지만 광고2개 손실이 있어 운영 미채택**이다. 최종평가26개는 열거나 평가하지 않았다. 추가학습·재선택 없이 이번 결과를 고정했다.

## 학습

순정 로컬 KLUE RoBERTa-base의 사전학습 가중치를 사용하고 EXCLUDE/HCX 2분류 헤드를 새로 초기화했다. 기존 Nuri1.0/D를 이어학습하지 않았다. 입력은 기존 `판정대상: ...\n문맥: ...` 형식이다. class0=제외, class1=HCX전달이며 기존4분류의0=광고와 혼용하지 않는다.

훈련96입력/40계열, 개발26입력/10계열. seed42, 전체층 AdamW lr2e-5, weight decay0.01, 배치8,4epoch. 계열별 가중치를 보정하고 전달 라벨 손실에2배 비용을 줬다. RTX4060 Laptop GPU 학습 루프 및 체크포인트 저장 약5.99초, 최대 PyTorch 할당2.24GB다. 환경 로딩/전체 검증까지의 총 작업 시간과 다르며 긴 실제 입력의 학습 속도를 뜻하지 않는다.

훈련/개발 원형 문구의 라벨 계약을 Codex가 재검토했다. 라벨 수정은 없었고 독립 사람 검수로 주장하지 않는다. 원자료의 human_reviewed=false/training_ready=false 상태를 바꾸지 않은 사용자 요청 합성 파일럿이다.

## 선택과 개발 결과

사전 격자 t=0/.01/.05/.1/.2/.3/.4/.5에서 p(HCX)<t이면 제외한다. 개발 전달 라벨 손실0 중 정상 제외가 최대인 checkpoint/threshold를 선택했다. 4epoch, t=0.05가 선택됐다. 선택 후 과거 관찰자료 점수로 기준을 바꾸지 않았다. 입력512토큰 초과는 항상 통과한다.

| 자료 | 모델 | 정상 제외 | 광고 통과 | 근거 부족 통과 |
|---|---|---:|---:|---:|
| 개발26 | Filter 1.0 | 13/13 (100%) | 8/8 | 5/5 |
| 개발26 | D 고정 필터 | 5/13 (38.46%) | 8/8 | 5/5 |
| 기존221 | Filter 1.0 | 44/120 (36.67%) | 64/64 | 37/37 |
| 기존221 | D 고정 필터 | 2/120 (1.67%) | 64/64 | 37/37 |
| 기존2,000 | Filter 1.0 | 523/1,000 (52.3%) | 998/1,000 (99.8%) | 해당 없음 |
| 기존2,000 | D 고정 필터 | 335/1,000 (33.5%) | 1,000/1,000 | 해당 없음 |

D는 p(ad)<.0001, p(ordinary)>=.9, argmax ordinary 및 잘림 통과라는 이전 고정 조건이다. D의 조건은 과거2,000개에서 정했으므로 해당 자료에 선택 편향이 있다. Filter 1.0은 새 개발26개로만 선택했다. 위 비교를 독립적인 동등 홀드아웃 승부라고 부르지 않는다.

선택 필터의 **전달 여부 F1**은 개발100%, 기존221개72.66%, 기존2,000개80.65%다. 정상도 HCX로 전달하면 이 지표에서는 FP지만 최종 광고 오탐은 아니므로 HCX 광고판정 F1과 비교하면 안 된다. 기본0.5 argmax는 개발 근거 부족1개를 제외해 전달 F196%였다. 광고/보류 보존을 위해 선택한0.05가 중요하다.

## 남은 누락

2,000개에서 잘못 제외한 광고2개는 같은 문장 계열이다.

> 주민 모임 잘 끝났어요. CASINO 현금 칩 충전 원하시는 분 따로 연락받습니다.

정상 소식 뒤에 붙은 실제 권유다. OFFSCREEN/HOMOGLYPH 표현에서 수집된 모델용 대상 문장은 같고, 제목 문맥은 `주민 질문 상세`/`주민 의견 상세`로 달랐다. p(HCX)는0.02875/0.01027로 선택 기준0.05보다 낮았다. 두 기법을 못 관찰해서 누락됐다고 해석하지 않는다. 분류기는 스타일을 보지 않으며, 정상 도입부와 뒤 권유의 혼합 의도를 정상으로 제외한 의미 오류다. 정확히 어떤 단어/귀속이 원인인지는 추가 대조 없이 확정하지 않는다.

정상 제외가 D보다188개 늘었지만 광고2개는 HCX로 넘어가지 못한다. 이는 개발자료100%가 넓은 문맥에 그대로 일반화되지 않는 관찰이다. 합성 설명/짧은 문맥 지름길과 작은 개발 규모의 위험이 남는다. 두 문장에 맞춰 학습하거나 관찰 결과를 보고 threshold를 내리는 사후 변경은 하지 않았다.

## 시간·채택

CPU8스레드 배치8 추론은 개발26개0.60초, 기존221개8.37초, 기존2,000개44.52초다. 기존221개 중 잘림4개는 모두 통과했다. 모델 로딩·수집·HCX를 포함한 종단 시간은 아니다. D 개발 추론은0.57초이며 두 모델의 아키텍처 규모는 같아 Filter1.0 자체가 더 빠른 구조라고 주장하지 않는다.

**운영은 변경하지 않는다.** 초기 데이터가 필터 목적을 학습시키는 방향은 확인했지만, 독립 일반화 및 광고 보존 기준을 통과한 것은 아니다. 다음 단계는 단순 epoch 증가보다 정상 도입부+권유, 짧은 댓글, 설명 없는 대상, 명확한 정상의 다양한 대조 자료를 별도 어휘/상황으로 보강하는 것이다. 기존 누락 문장 자체를 추가학습하지 않는다. 새 최종평가를 소비할 시점은 아니다.
