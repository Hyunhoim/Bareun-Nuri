# 두 기법 입력·문맥 형식 진단

2026-09-30. **학습 부족보다 문장 틀의 일반화가 현재 우선 병목이다.** 고정 Kc-density-role와 H임계값.20으로 개발 역할대조300개만 진단했다. 최종860을 열거나 재학습하지 않았다. 운영/모델 변경0, API0.

## 정보 제거 대조

동일 표기를 권유/교육/원래 식별값/근거부족으로 배치한 개발자료에서 아래는 각75개 중 H present 수다. 원문·Unicode·문맥을 제거한 조건은 원래 문제와 다르므로 실제 탐지 F1로 해석하지 않는다.

|입력|권유|교육|식별값|근거부족|
|---|---:|---:|---:|---:|
|전체|73|23|0|1|
|Unicode 근거 제거|5|0|0|0|
|별도 context 제거|72|1|0|0|
|표기+Unicode만|3|3|3|3|
|표기·Unicode 제거, 주변 문장만|0|0|0|0|

전체입력에서 교육75개는23확정/3부재/49보류다. 같은 표기의 실제 치환이라는 정답은 권유와 같지만 판정은 크게 달랐다. 별도context를없애면교육확정이1개로더감소했다. 그context는'학생의문자표현실습기록'이라는실험작성문구다. 이는문자근거부재가아니라문맥표현과판정의상호작용을보여준다.

Unicode 제거시73→5,23→0이며표기를아예없애면양성0이다. 따라서 '광고문맥만으로항상답한다'고단정하지않는다. 반대로Unicode가필요했다는사실만으로시각대응을올바르게추론했다고볼수도없다. 특정입력형식에의존했을가능성도남는다. 표기만으로모두같은판정을하는것은역할정보가없어진개입에서당연할수있으며실제정밀도로보고하지않는다.

## 학습자료와의 차이

실제 사용된 후속 역할자료944개(관찰어휘silver계열제외)를 별도로 점검했다. 권유/교육/식별값/근거부족 각각236개를 **argmax로236/236** 맞혔다. 정답평균확률은각각.999859/.999850/.999865/.999138이다. 학습의권유-교육쌍present확률차이는평균0.00000980에불과했다.

따라서동일학습자료의epoch증가나동일쌍에대한일관성손실추가는지금의일반화오류를해결할근거가약하다. 학습에서이미그조건을만족한다. 새개발교육문장틀에서만보류가증가하는현상과함께보면생성틀의지름길/문맥표현일반화실패우려가크다. 인과전체를한번의제거실험으로확정하지않으며, 모델용량한계로도단정하지않는다.
