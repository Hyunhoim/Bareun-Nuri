# D 보존형 제외 경계 진단

2026-09-29. 추가 학습 전에 기존 표현을 보존한 D에서 제외 경계를 점검한다. 운영 변경과 새로운 최종평가는 하지 않는다.

비교는 고정 D(.0001 광고 점수/.9 일반정보 점수), 동일 게이트의 광고 경계 보정, 일반정보 외 점수 합계 경계의 세 조건이다. 보정 자료는 이미 관찰한 2000+221개다. 일반정보 argmax, 입력 길이512 이하, 유효한 점수와 문맥을 공통으로 요구한다. 실제 수집 문맥 잘림은 무조건 HCX 전달한다.

일반정보로 예측한 필수전달(광고 또는 근거 부족)의 최소 점수를 경험적 무손실 경계로 계산한다. 두 보정 조건 모두 경계의0.8배를 고정한다. 이 여유는 위험확률 보장이 아니다. 정상 제외 증가와 알려진 필수전달 손실0을 동시에 만족할 때만 다음 독립 검수 후보로 둔다. 실제 수집 점수를 보고 임계값을 다시 조정하지 않는다. 미라벨 제외를 정상 제외로 세지 않는다.

모든 자료는 관찰한 회귀다. 좋은 결과여도 운영 채택 근거가 아니며, 새 모델 학습이나 안전성 확정으로 해석하지 않는다. 추가 추론/API0인 저장 점수 실험이며 속도 향상은 측정하지 않는다.
