# 제목 영향 진단 후 대상 단독 보조 판정

실제 복제본 C의 잘못 제외한 광고8·근거부족4에서 제목을 제거한 진단 입력은12개 모두 모델 전달점수가 기존 .005 이상으로 바뀌었다. 빈 문맥을 안전게이트에 넣어 자동 통과시킨 결과가 아니라 모델 점수 자체를 비교했다. 장문의 정상 제목이 표적의 의미 판정을 덮는 가설을 뒷받침하지만 모든 입력의 원인을 확정하지 않는다.

제목/문맥을 운영 근거에서 제거하지 않는다. 고정 C(.005)의 전체 입력이 EXCLUDE일 때만 동일 모델에 대상 문구만 담은 보조 입력을 판정하게 한다. 보조 점수도 .005 미만일 때만 EXCLUDE. 추가 학습·새 임계값 선택 없음. 두 입력 모두 잘림/손상은 통과. 대상 단독 판단은 원래 설명/인용을 놓칠 수 있으므로 정상도 HCX로 더 보내는 보수적 비용이 있다. 최종 광고 판정을 바꾸지 않는다.

보정/32확인/소비된26최종/수집5179개에서 회귀를 진단한다. 소비된 최종은 새 일반화 검증으로 부르지 않는다. 실제 절감은 전체 문맥단계 비용+추가 대상단계 비용으로 보고한다. 특정 제목/단어/사례 예외나 무신호 일괄제외는 없다. 이 방식이 관찰 안전성은 통과해도 별도 정답 검수와 실제25분HCX 연결 검증 전 운영 미채택이다.
