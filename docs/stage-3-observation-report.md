# 3단계 관찰 기법 분리 — 독립 모듈 구현, 전체 통합 채택 보류

검증일: 2026-09-23(KST), 시작 계획은 2026-09-22에 등록했다. **광고 의도는 고정한 채 4종 관찰과 위치 근거를 기록하는 모듈을 구현했다. 확정 가능한 범위의 독립 검사는 통과했지만 숫자 닮은꼴 치환 9건이 미확정으로 남아 전체 통합은 채택하지 않는다. 웹 worker는 기존 경로를 유지한다.** 2단계 미해결 오류가 해결됐다는 의미가 아니다.

## 구현 범위

- `agent/src/core/techniques.cjs`: 원문 문자 범위와 텍스트 노드별 렌더링 근거를 관찰한다. 확정 기법, 부분 범위, 미확정 근거를 구분하며 광고 정답·의도·주변 광고 문구를 판정 조건으로 사용하지 않는다.
- `collect(url,{observeTechniques:true})`: 후보 배열과 기존 모델 입력을 유지하고 최상위 `technique_observations`만 추가한다. 기본값은 꺼져 있다. 부모의 opacity/display, 실제 글자색·배경·크기, 텍스트 사각형, iframe 바깥 조상의 은닉을 기록한다. 후보 위치는 기존 URL/선택자/`>>>` 프레임 경로를 사용한다.
- `agent/experiments/observe.cjs`: 저장된 의미 판정과 관찰의 오프라인 통합. 의미 판정 필드는 보존하고 확정 기법만 연결한다. 정상의 관찰은 findings로 승격하지 않는다. 일부 텍스트만 숨긴 경우 의미 귀속이 불명확하므로 해당 스타일을 자동 findings에 넣지 않는다. 미확정 기법은 별도 `technique-diagnostics.json`에 남긴다.
- `agent/experiments/techniques.test.cjs`: 70개 브라우저 대상, 프레임 조상, 입력 불변성, 원문 범위, 검토/광고 판정 보존과 출력 위치를 검사한다. 기존 `npm.cmd test --prefix agent`에 포함했다.

닮은꼴 문자에는 NFKC 호환 문자와 [Unicode 16.0.0 confusables](https://www.unicode.org/Public/security/16.0.0/confusables.txt) 중 그리스·키릴 문자에서 ASCII 영문으로 대응하는 85개 항목을 사용했다. `confusables-latin.json`에 출처·원본 해시·라이선스를 포함했다. 일반 외국어 전체를 닮은꼴 위장으로 확정하지 않으며, 숫자 혼합은 별도 해석이 필요한 상태로 남긴다. 이 표는 고의적 위장이나 불법성을 입증하지 않는다.

## 고정한 기준선과 평가 방법

실험 전에 `isolated`의 저장된 응답과 수집 스냅샷, 의미 판정 소스·정규화·worker·출력기의 해시를 고정했다. `contextual`, `attributed`, `direct` 미채택 보완안은 사용하지 않았다. `collect.cjs`의 변경은 선택적인 별도 관찰 수집에 한정하며 모델용 후보 배열의 동일성을 브라우저 검사에서 확인했다.

기준선의 알려진 누락도 유지된다. 진단 63개는 TP 9 / FP 0 / FN 16, 근거 부족 검토 2/2다. 306개 패널은 TP 119 / FP 0 / FN 1이다. 이는 고정한 응답의 성능이며 과거 최고 결과가 아니다.

실제 LLM을 다시 호출하지 않고 저장된 의미 판정을 재사용했다. 따라서 이번 의미 지표의 동일성은 의도한 계약 보존의 증거이며 모델 반복 안정성의 새 검증이 아니다. 관찰용 스타일은 현재 로컬 사이트를 다시 브라우저로 수집했다. 원래 306개 후보의 URL·위치·원문을 모두 일치시켰고 기존 의미 입력은 교체하지 않았다.

독립 검사는 먼저 70개 대상으로 수행했다. 이후 코드 검토에서 iframe 자체가 화면 밖으로 배치된 경우의 근거를 보완하고 새 소스를 고정했다. 이전 해시도 보존했다. 그 뒤 별도 문구·태그·스타일 조합 40개와 화면 밖 iframe 1개를 검사했고 오류 0건이었다. 광고/예방 문맥 변화, 모호한 숫자·자모, 부분 스타일, 조상과 자식의 덮어쓰기, 일반적인 스크롤 아래 콘텐츠를 포함했다. **같은 개발자가 만든 합성 검사이며 실제 웹 홀드아웃이 아니다.** 최종 소스로 전체 자동 검사도 다시 통과했다.

## 분리 지표

### 광고 의도 — 변경 없음

| 자료 | 변경 전 TP / FP / FN | 변경 후 TP / FP / FN | 의미 F1 |
|---|---:|---:|---:|
| 기존 진단 63개 | 9 / 0 / 16 | 9 / 0 / 16 | 52.94% |
| 기존 패널 306개 | 119 / 0 / 1 | 119 / 0 / 1 | 99.58% |

광고 여부뿐 아니라 의미 검토 상태·이유·기존 부가 의미 근거도 동일함을 비교했다. 63개 진단에는 최신 텍스트별 스타일 자료가 없어 기법 정확도를 측정하지 않았다. 오래된 스냅샷을 스타일 정상으로 추정하지 않고 미확정으로 기록했다.

### 관찰 기법 — 정상 문구의 기법도 포함

기존 300개 라벨 요소의 `observed` 정답으로 평가했다. 306개 중 나머지 6개는 의미 정답만 있으므로 기법 정확도 분모에 넣지 않았다. 기법 조합까지 완전히 일치한 요소는 **291/300**이다.

| 기법 | TP / FP / FN | 정밀도 | 재현율 | F1 |
|---|---:|---:|---:|---:|
| HOMOGLYPH | 61 / 0 / 9 | 100% | 87.14% | 93.13% |
| JAMO | 70 / 0 / 0 | 100% | 100% | 100% |
| TRANSPARENT | 70 / 0 / 0 | 100% | 100% | 100% |
| OFFSCREEN | 70 / 0 / 0 | 100% | 100% | 100% |
| 전체 요소×기법 | 271 / 0 / 9 | 100% | 96.79% | 98.37% |

### 최종 결과 — 광고 의도와 기법·위치를 결합

정답 광고 요소×기법 160쌍에 대해 URL·위치·기법이 모두 일치해야 TP로 셌다. 출력 원문은 수집 원문을 사용했다. 패널의 정상 186개에서 추가 findings는 없었다.

| TP / FP / FN | 정밀도 | 재현율 | 최종 F1 |
|---:|---:|---:|---:|
| 150 / 0 / 10 | 100% | 93.75% | **96.77%** |

누락 10건은 **기존 광고 의도 누락 1건(JAMO) + 닮은꼴 기법 미확정 9건**이다. 다른 기법이 함께 확정된 광고의 findings는 유지했다. 미확정을 정답으로 세거나 이진 지표에서 빼지 않았다. 의미 전용 기준선은 기법 findings를 만들지 않았으므로 이를 ‘기존 최종 F1 0%에서 개선’으로 비교하지 않는다. 이번 수치는 전체 3,824개 수집 후보의 사이트 전체 정확도도 아니다.

## 남은 문제와 과적합 우려

9개 누락은 모두 `B0NUS`라는 **하나의 숫자 치환 표현을 여러 광고·HTML 위치에 배치한 사례**다. 서로 독립적인 아홉 종류의 실패를 발견한 것은 아니다. 해당 단어 예외나 모든 영문·숫자 혼합의 일괄 HOMOGLYPH 판정은 추가하지 않았다. 일반 식별번호와 숫자 치환을 구분하는 일반적인 근거가 필요하다. 이 한 표현을 보고 규칙을 재조정하면 과적합할 우려를 사용자에게 보고했다.

기법 검토 기록은 21개(광고 의도 11개·정상 10개)다. 숫자 치환 9개와 visibility/클리핑 관련 근거 12개로 구성된다. 이는 의미 판정의 검토 상태 증가가 아니다. 독립적으로 확정 가능한 기법은 유지하되 불완전한 렌더링 관찰을 완료로 숨기지 않았다.

복잡한 배경 이미지·그라디언트·필터·글자 그림자, 일부 텍스트의 의미 귀속, 수집되지 않는 생성 콘텐츠는 여전히 검토가 필요하다. 문자 변형은 수집된 의미 단위에 연결하므로 한 후보에 서로 다른 발화가 섞이는 수집/문맥 오류까지 해결하지 않는다. 각 기법 70/70은 이 패널에서의 결과이며 모든 HTML·CSS·자모 변형에 대한 보장은 아니다.

## 비용과 실행 범위

- 추가 API 호출 **0회**, 추가 토큰 **0**. 유료 실행의 비용·지연 개선을 측정한 실험은 아니다.
- 최종 관찰 수집: 로컬 101페이지·3,824후보, **154.22초**. 기존 의미 판정을 적용한 평가 패널은 이 중 306개다.
- 306개 관찰 재계산 약 **35.71ms**, 통합 계산 약 **6.45ms**(각 한 번의 로컬 측정, 파일 읽기·브라우저 시간 제외). 관찰 재계산 시간은 `.runtime/stage3-observation/timing.json`에 별도로 남겼다.
- 관찰 부가 자료의 JSON 직렬화 크기는 전체 후보 약 **16.28MB**, 평가 패널 약 **3.23MB**다. 반복 조상 스타일을 저장하므로 저장량 부담이 있다. 메모리 최고 사용량은 측정하지 않았으며 중복 압축·병렬화는 이번 범위에 포함하지 않았다.
- iframe 기하 보완 전 첫 수집(156.69초)도 보존했지만 최종 지표에는 수정 후 다시 수집한 자료만 사용했다.

## 채택 판단과 재현

확정 가능한 기법의 독립 관찰 모듈과 비교 도구는 구현·검증했다. 그러나 실제 회귀 패널에서 필수 닮은꼴 기법 누락이 남아 **전체 기법 통합 채택은 보류**한다. 웹 worker 전환, 프런트·백엔드 변경, 4~5단계, 커밋·push는 시행하지 않았다. 2단계 기준선을 완전한 탐지기로 간주하지 않는다.

```powershell
# API 없는 자동 검사
npm.cmd test --prefix agent
# 저장된 의미 판정과 관찰 자료의 오프라인 결합: 새 출력 폴더 필요
node agent/experiments/observe.cjs .runtime/stage3-observation/panel306/observed-evidence.json .runtime/stage3-observation/panel306/baseline-decisions.json .runtime/stage3-observation/panel306/replay-new
# 로컬 실험 자료가 있는 이 작업 공간에서 분리 지표 재계산
node .runtime/stage3-observation/evaluate.cjs
```

계획은 `docs/stage-3-observation-plan.md`, 계약은 `docs/contracts.md`에 있다. `.runtime/stage3-observation/`에는 기준선/소스 해시, 고정 응답, 추가 합성 검사 라벨·HTML·결과, 관찰 수집 원문, 분리 지표 `summary.json`, 단계별 진단을 보관한다. 이 디렉터리는 Git 제외 대상이다. 정답 파일은 오프라인 채점기에서만 읽었다.

Graphify는 실험 연결 관계 확인에 사용했으며 레거시 노드 ID 경고가 있어 실제 호출·데이터 흐름은 소스로 교차 확인했다. 그래프를 실행 검증의 대체 근거로 삼지 않았다.
