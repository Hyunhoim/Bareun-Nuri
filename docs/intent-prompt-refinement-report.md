2026-10-01. **정의 정리＋문맥 기준(K)을 후속 검증 후보로 선택한다. 운영 채택은 아직 하지 않는다.** 관찰 자료의 두 구성 모두 F1이 상승하고 같은 구성의 기준선 정탐은 모두 보존했다. 대조 예시(E)는 두 번째 구성에서 정탐4개를 잃어 제외한다. 프롬프트를 결과에 맞춰 추가 수정하지 않았다.

A=운영, P=직전 보강, D=분류 정의만 변경, K=D+문맥 적용 기준, E=K+3가지 짧은 대조 예시. D는 기존 인용보도 정의에 피해 상담·신고·삭제 요청을 명시하고 현재 게시자의 권유 여부를 구분한다. K는 직접 연결된 본문·링크 설명 활용, 다른 댓글 귀속 금지, DOM 인용값/보조 읽기의 의미를 명시한다. 대상 입력·출력 스키마는 전 조건 동일하다.

K는 이번 사전 진단 기준(두 구성F1상승, 기존 정탐 손실0, 새 댓글 광고 누락/근거부족 광고 확정0)을 통과했다. **정의 명확화와 제한된 문맥 기준은 유망하며, 예시 추가는 보류한다.** 독립 자료와25분 조건을 검증하지 않았으므로 운영은 기존대로 유지한다. 특히 신고 인용 오탐은 대부분 남고 다른 구성에서의 안정성도 미확정이다.
