# 공통 H 확률 임계값의 제한 진단

2026-09-30. `kc-density-role` 가중치는 고정한다. 학습 추가 없이 기존 개발624+보강 개발300에서만 H present 확률을 확인한다. 기존112회귀의8누락/정상2·보류1오확정, 한글의오확정증가는 평가 결과로 남기며 이 정답으로 임계값을 고르지 않는다.

원래 argmax를 기준으로, present 확률이 공통 t 이상이면 H를 present로 승격하는 조건을 t=0.05/0.10/0.20/0.30으로만 비교한다. 기존 present를 내리지 않고 JAMO는 변경하지 않는다. 대상 문구/ID/어휘/URL/Unicode패턴별 예외는 없다.

선택은 기존 개발 양성macro와 보강 개발 H F1의 평균이 기준보다2%p 이상 개선되고, 두 자료 합산 정상오확정 증가<=3 및 근거부족오확정 증가<=3인 후보 중 평균F1최대/더 높은임계값 순이다. 미충족이면 argmax 유지하고 종료한다. 위 조건은 이 새 진단의 조건이며 앞선 실패를 통과로 소급하지 않는다.

후보를 고정한 뒤 회귀를 재측정하고, 최종은 원래624+추가236에서 모델+보정 계약을1회 확인한다. 실패 후 다시 임계값을 고르지 않는다. API0/학습0/운영수정0. 확률은 보정된 실제 정확도 확률이라고 주장하지 않는다.
