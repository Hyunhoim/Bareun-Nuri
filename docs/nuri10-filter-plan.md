# Nuri1.0 정상 제외용 필터 진단

2026-09-29. 사용자 지정으로 A를 Nuri1.0으로 부른다. D는 비교 후보이며 재학습/운영 변경/유료 API 호출 없이 점수 분포를 진단한다. Ponytail 원칙에 따라 기존 토크나이저 입력·모델 로딩을 재사용한다.

- 개발: 이미 관찰한4종2,000개, 기법별 광고250/정상250. 새로운 홀드아웃이 아니다.
- 확인: 기존221개(의미 개발204+사람 검수 정상17). 이것도 관찰 자료이며 독립 일반화 증거가 아니다. 2,000개에서 선택한 기준을221개 결과로 다시 조정하지 않는다.
- CPU8스레드·배치8. 대상/문맥 원문 및 기존 입력 형식 유지. 모델별 전체4분류 softmax를 저장한다. softmax는 보정된 정답 확률이 아니다.
- 제외 조건: 입력512토큰 이내, argmax=일반정보(2), p(일반정보)>=q, p(광고)<t. 보류 argmax=3, 예방인용 argmax=1, 잘림, 비정상 입력은 통과. 실제 gold가 근거 부족인지 여부는 필터 입력에 사용하지 않는다.
- 고정 격자 t=[0,0.00001,0.0001,0.001,0.005,0.01,0.02,0.05,0.1,0.2], q=[0.9,0.95,0.99,0.999]. 각 모델 개발 광고 손실0에서 정상 제외가 가장 큰 조건 선택. 동률은 더 작은t, 더 큰q. 전체 통과를 선택할 수 있다.
- 개발 정상 제외10% 미만이면 확대 가치 부족. 확인에서 광고 손실/기존 HCX 정탐 손실이 생기면 운영 채택하지 않는다. 자료가 작아 손실0도 안전성 보장이 아니다.
- 관찰된 argmax 광고누락의 p(광고)/p(일반정보) 분포, 기법별 광고 통과율·정상 제외율, 입력 잘림, CPU 시간을 보고한다. 확인221개의 기존 HCX 결과를 이용한 연결 점수는 저장결과 재생 가정이며 새로운 묶음 판정 결과가 아니다.
- 후보 제외율을 API 비용/시간 절감률로 부르지 않는다. 실제 묶음 변화·토큰·시간은 유망한 조건의 후속 연결 실험에서만 확정한다. 이번 결과로25분 운영을 승격하지 않는다.
