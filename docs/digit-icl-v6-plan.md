# 고정 ICL 미사용 v6 동시기 비교 계획

개발 진단의 원래·역순 관문을 모두 통과할 때만 실행한다. 두 개발 실행의 전체 소스·설정·자료 해시를 그대로 확인하고 원래 S와 고정 예시 8개 ICL 계약을 수정하지 않는다. 예시 교체·순서 탐색·이전 실패 지시 누적은 금지한다. v6는 새로운 12개 단어 계열·다양한 소속 문맥의 48개이며 별도 독립 봉인 검사를 통과해야 한다. 각 pure/mixed/identifier/ambiguous 12개와 혼합 접두·접미 각 6개는 제작/독립 검토 계약으로 확인한다. 실행기는 정답을 읽지 않고 입력 필드 node_id/token/target_text/context 및 48개, 비어 있지 않은 context 24개 이상만 검증한다.

동일 시기 S→I→역순 I→역순 S, 각 단일 후보 48회/총 192회다. HCX-007 none, temperature0, seed42, 출력1024, 58,000 TPM 예약, 1초 간격, 요청180초 제한을 유지한다. 조건 사이61초, 조건10분/전역1시간, 총 호출 보호220회/예약 상한100만 토큰이다. 실제 예약 예상은 API0 preflight로 기록한다. 소스·훈련·입력·정답 파일을 해시로 봉인하고 각 조건 시작 전 검증한다. 미확인 요청/계약 실패의 자동 재호출은 하지 않는다. root는 `.runtime/digit-icl-v6-live-v1`이며 dry run은 쓰기를 하지 않는다.

전체 네 조건 완료 후에만 정답과 예측을 열어 비교한다. 각 순서에서 I가 S 대비 정상 FP 비증가, strict F1 증가, 모호 과확정 감소, 혼합 숫자 TP 비감소를 모두 만족해야 한다. 개별 실험 S 정탐 손실·회복을 빠짐없이 보고한다. 실제 운영 광고 정탐 보존은 별도 후속 절대 요건이다. 비용·토큰·실행시간·순서 변동과 전체/역할별 지표를 함께 보고한다. compact 출력은 읽기를 선택하지 않으므로 정확 복원을 평가했다고 주장하지 않는다.

실패하면 고정 예시·프롬프트 수정으로 이 자료를 다시 최적화하지 않고 종료한다. 성공해도 새로운 합성 어휘·문맥 평가이며 실제 사이트 유병률이나 광고 의도 성능, 25분 운영 효율의 증명이 아니다. 2개 훈련 계열의 상관성과 명시적 합성 단서에 대한 과적합 위험을 공개한다. 운영 적용 전에는 운영 정탐 보존 및 동일25분 종단 검증을 별도로 수행해야 한다.
