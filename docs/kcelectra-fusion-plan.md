# KcELECTRA A/D 학습 방향 융합

2026-09-29. 사용자 요청은 유망한 HCX 대체 후보 가설을 지속 검증하는 것이다. 성능 향상을 보장하거나 평가 점수에 맞춰 무한 튜닝하지 않는다. 기존 HCX 운영은 유지한다.

1. A의 원래8000훈련/NFC/FP32/batch8/lr1e-5/seed42/임베딩+하위8층고정/3epoch를 KLUE-base와KcELECTRA에 적용한다. A의 원래개발관문→최저광고F1→평균F1 기준으로선택한다. KLUE 재현이 이전가중치와비트동일할것을요구하지않되차이를보고한다.
2. 선택 Kc체크포인트에서 D의기존DOM문맥훈련256개를사용한다. 평가문장추가없음. 동일lr5e-6/128업데이트에서 D전용, D50%+A50%, D12.5%+A87.5%를비교한다. step64/128에서개발선택. 문장틀반복과 작은D데이터의과적합위험을보고한다. 원래A개발+ D개발64+문맥120/44에서최저광고F1→평균광고F1→macro평균을선택기준으로한다.
3. 후보동결뒤2000관찰회귀를CPU8threads/batch8로실행한다. F1/정탐손실/신규오탐/4종별/문맥/지연을함께비교한다. A대비회귀F1+1%p 또는F1유지와오탐20%감소·재현율하락1%p이내, 문맥패널최저F1개선,4종하락2%p이내를후속독립평가진입기준으로한다. 이는운영승격기준이아니다.
4. 융합이실패하면개발오류의공통원인을확인한후새가설을한차례씩사전등록한다. 후보는라벨/입력결함감사,기존능력보존용학습제약,분류목적변경이다. 평가문장학습/임계값무제한탐색은금지. 검증된원인없이모델/자료를확대하지않는다. HCX비교는유망후보고정후동일한별도자료에서수행한다.

GPU단일직렬실행,각학습최대40분,실패시진단보존·자동재시작없음. 학습·개발의완전입력중복검사와가중치/자료해시기록. 관찰개발/회귀를새홀드아웃이라부르지않는다. 최종독립평가는선택완료후1회이며자료생성자/검수독립성한계를명시한다. 운영승격には25分종단검증이필요하다. 이번학습에유료API없음.
