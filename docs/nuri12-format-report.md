## 통제 및 검증

피해문의 라벨만 바로잡은 훈련 복사본을 두 조건에서 동일하게 사용했다. 두 모델 모두 순정 초기화 seed42, embeddings+하위8층 고정, 학습률2e-5, batch8, 동일순서250step=2000회 노출이다. 1만개 전량 새 학습으로 부풀리지 않는다. 후보만 원래 필드명 또는 두 동의어 조합을 라벨과 무관하게 배정했다. 대상/주변 문맥/귀속/라벨은 그대로이며 평가용 필드명 표현은 학습 변형과 다르다.

기준선은 이전 라벨 수정 실험의204개 예측 전량과 일치했다. 초기화 해시, 동결층 불변, 학습/평가 입력 직접중복 없음, 저장 후 재로딩 예측 일치를 확인했다. 훈련 입력 잘림0. 정상17개는 학습하지 않았다. 신규 두 학습은 각각20.32/20.35초, 전체 측정64.61초, 유료API0이다. 모델용량/추론구조는 그대로이고 단회GPU17개 추론0.18~0.20초를 CPU배포속도 또는 속도향상으로 해석하지 않는다.

## 병목 해석과 결정

의미를 보존한 필드명 변형에 대한 민감도는 실제 관측됐으나, 훈련 필드명 다양화만으로 해결되지는 않았다. 신규 후보는 기존정탐4개를 잃고 정상오탐2개가 늘었으며 실제 정상17개에서도 오탐9개가 추가됐다. 형식 다양화가 일반화 개선이라는 가설을 이번 짧은 학습조건에서는 지지하지 않는다. 모든 증강 방법이 무효라거나 충분히 수렴한 학습 결과라고 확대 해석하지 않는다.

실제 정상17개 중 입력이 잘린4개에 대한 기존freeze8 오탐은0이다. 라벨수정 기준선 오탐5개는 모두 잘리지 않은 입력에서 발생했다. 따라서 해당 오탐을512토큰 잘림만으로 설명할 수 없다. 새후보는 잘린4개/잘리지 않은10개 모두 오탐해 길이 문제와 의미학습 문제를 구분해야 한다. 원문/문맥 손실 문제는 남지만 길이 확대를 이번 의미오탐의 해결책으로 단정하지 않는다.

기존freeze8의 실제 정상오탐0/17은3출처 목적표본에 한정되며, 다른 개발자료의 오탐27·누락13·근거부족 광고확정31을 가리지 않는다. 이전 라벨 오류가 있는 모델을 점수가 높다는 이유로 정답 계약으로 삼거나 새 운영으로 승격하지 않는다.

동일 개발204의 반복사용에 따른 과적합 우려가 있다. 이 결과는 관찰자료 회귀/원인진단이며 새로운 독립 일반화 성능이 아니다. 실패 후 필드명 동의어를 바꾸며 반복 튜닝하지 않고 종료한다. 다음 데이터 개선은 실제 권유와 피해문의/예방 설명의 대상 귀속을 구별할 수 있는, 기존 평가 문구와 분리된 대조자료와 검수를 우선한다. 정상17개만 추가학습하지 않는다. 최종 봉인 평가·운영코드·기존모델은 변경하지 않았다.
