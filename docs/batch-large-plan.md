# 12/16/20개 비교 사전 계획

2026-09-26. 이전137후보 전체를 그대로 비교한다(광고60/정상65/모호12). 관찰 자료의 회귀 실험이며 독립 일반화 증명이 아니다. 운영4개/58k는 변경하지 않는다.

원래 순서O와 그룹별 역순R, 각2회. O12/O16/O20/R20/R16/R12/R12/R16/R20/O20/O16/O12 순으로 비교한다. HCX007 none/temperature0/seed42/출력512/58k/순차/1초간격 고정, 매조건61초창분리. 조건10분/전체1시간/400호출·예약150만토큰 이내, 예상요청을 실행 전에 계산한다. 입력·ID·문맥·그룹 경계·마지막 잔여 후보를 보존한다.

실패 처리는 자동복구하지 않는다. HTTP200 원응답이 완전히 저장된 출력잘림/형식실패는 그 조건만 중단하고 다음 조건을 측정한다. 이미 전송한 요청은 반복하지 않는다. 미확인 통신/429/한도변경/실행불변식 오류는 전체중단. 실패조건의 부분점수를 전체F1로 비교하지 않으며 완료율과 출력오류를 따로 보고한다.

목표는 비교이지 즉시 운영채택이 아니다. 12개 대비 평균F1,순서별 최저F1,정밀도/재현율,반복정탐 손실과 새정탐,오탐,모호성,실시간/호출/토큰/출력길이를 본다. F1 개선을 중심으로 속도와 회귀의 손익을 제시하며 기존정탐1개 손실만으로 자동 탈락시키는 이전25분 관문을 이번 비교순위에 재사용하지 않는다. 출력오류가 있는 조건은 운영권고할 수 없다. 유리한 순서만 골라 채택하거나 결과 확인 후 프롬프트·상한·순서를 바꾸지 않는다. 25분 종단 검증 및 운영변경은 이 비교에 포함하지 않는다.
