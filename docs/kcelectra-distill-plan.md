# A/D 교사 증류 독립 가설

2026-09-29. 융합/개발임계값선택은A대비회귀미달. 같은정답자료에서도A/D가학생보다잘일반화한판단분포가있다는가설로증류를시험한다. 광고훈련행은A,나머지훈련행은D의4클래스로짓을사용한다. 훈련정답에의한교사선택이며추론에는정답/교사모델을쓰지않는다. 교사는오류가있으므로정답CE를유지한다.

선택된K_base에서하위8층고정,lr5e-6,batch8,seed42,256updates. 매묶음D자료2+A자료6을고정샘플링한다. control은CE,distill은CE+0.5*T²*KL(teacher||student),T=2. 동일배치순서/초기값/업데이트,64/128/256개발평가와원래융합의개발선택. 교사로짓은훈련행만계산하며평가문구학습금지. 데이터/교사체크포인트해시기록. 손실유한성검사.

모두완료후2000회귀CPU비교. 원래후속관문유지. 같은개발재사용으로선택편향이있고새홀드아웃증거아님. 실패하면이자료에서증류계수/온도를다시튜닝하지않는다. GPU최대40분/조건,API0/운영변경0.
