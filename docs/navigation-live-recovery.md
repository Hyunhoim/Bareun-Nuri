# 외부 통신 장애 후 단일 새 비교 실행

2026-09-23. 성능 비교 결과를 확인하기 전 운영 장애 대응을 기록한다.

- v1의 첫 dev FIFO는 2회 정상 응답(32/436후보, 12,280토큰) 뒤 ECONNRESET, 기존의 제한적 재시도에서 ENOTFOUND로 실패했다. 정확도 비교에 사용할 완성된 조건은 없다.
- 로컬 DNS 재확인과 대상 API의 TCP 443 연결이 성공하여 외부 연결이 복구됨을 확인했다.
- v1은 덮어쓰거나 재개하지 않는다. v2에 동일한 고정 수집 증거를 복사하여 A 전체를 한 차례 새로 실행한다. 앞선 32개 응답도 재사용하지 않는다. 실패 요청의 서버 처리 여부는 불명확하며 usage 없는 두 시도 예약량을 계속 예산에 포함한다.
- 기존 50페이지·모델·프롬프트·배치·순서·900초/40회 실행 상한과 채택 기준을 유지한다. 전체 220시도/1,800,000토큰 한도는 v1+v2 합산이다. 운영 장애 시간/호출은 정책의 성공 실행 시간과 구분하여 최종 보고한다.
- 새 비교에서 다시 통신/계약 실패가 발생하면 추가 재시작 없이 실제 비교 불완전으로 보고하고, 외부 API가 필요 없는 B 검증만 마친다. 성공으로 보이도록 부분 F1을 제시하지 않는다.
