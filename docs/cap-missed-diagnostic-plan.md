# 추가 도달 후 누락의 상한 영향 진단

출력512 복제본 실행에서 새로 판정한 자모 광고3개가 의미FN이었다. 아직 판정기회를받지못한3072의FN과모델오류를혼동하지않기위해,두실사이트실행이끝난뒤해당3개를포함한512의실제요청묶음을그대로재생한다.

ABBA(3072/512/512/3072),최대12호출/예약20만/600초. 512실제요청의원문/문맥/배치동료/순서를그대로보존하고상한만변경한다. 미확인/형식실패시중단하며재시도하지않는다. 새로운문구수정,복원,프롬프트개선은없다.

평가는관찰한누락3개의설명용진단이다. 형제후보중원래정답이없는대상은정상으로가정하지않는다. 각조건반복별세대상의판정과전체묶음변동을보고한다. 이결과를새홀드아웃이나전체사이트F1로사용하지않고사전25분채택기준을변경하지않는다.
