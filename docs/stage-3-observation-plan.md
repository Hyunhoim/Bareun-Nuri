# 3단계 독립 관찰·통합 검증 계획

2026-09-22, 구현·평가 전 등록. 2단계 완료를 선언하지 않고 관찰 기법 모듈을 별도로 검증한다.

## 기준선과 범위

- `isolated`의 저장된 기본 판정·원문·위치를 해시로 고정한다. 진단 63개 기준선 TP 9 / FP 0 / FN 16, 근거 부족 검토 2/2. 306개 비교 기준선 TP 119 / FP 0 / FN 1이다. 최고 기록과 현재 고정 응답을 혼동하지 않는다.
- `contextual`, `attributed`, `direct` 미채택안은 연결하지 않는다. 광고 의도 프롬프트·모델·정규화·판정·검토 상태를 수정하지 않는다. 이번 비교는 유료 재호출 없이 저장 응답을 재생해 의미 판정의 확률적 변동을 제거한다.
- 최초에는 관찰 결과만 별도로 기록한다. 독립 검사 통과 후 실험용 출력 경로에서 광고 의도와 결합한다. 웹 worker의 기본 경로 전환은 이번 범위에 포함하지 않는다.

## 관찰 계약

- 필수 4종은 원본 HWPX 붙임1의 HOMOGLYPH, JAMO, TRANSPARENT, OFFSCREEN이며 최종 단위는 URL + location + technique이다.
- 명확한 유니코드 문자 변형·자모열, 실제 텍스트의 색·배경·불투명도·크기·표시·배치를 관찰한다. 일반 그리스어/키릴어 문장이나 숫자 혼합만으로 치환을 확정하지 않는다. 숫자 치환과 불완전한 자모 등 해석이 필요한 경우 미확정 근거로 남긴다. 이를 정상으로 검증됐다고 표시하지 않는다.
- DOM/스타일 관찰에는 텍스트 범위와 근거의 소유 요소를 보존한다. 다른 자식이나 조상의 글자색·글자 크기를 대상의 실제 스타일로 오인하지 않는다. opacity/display처럼 자손에 영향을 주는 속성과 상속 후 덮어쓸 수 있는 속성을 구분한다.
- 일반적인 스크롤 아래 콘텐츠를 화면 밖 은닉으로 보지 않는다. visibility/clip/filter 등 4종 예시 밖이거나 관찰이 불충분한 CSS는 검토 근거로 기록하고 임의로 확정 코드를 붙이지 않는다.
- 구형 스냅샷에 텍스트별 스타일·배경 이미지 등 필요한 정보가 없으면 제한을 기록한다. 지원하지 않는 렌더링을 관찰 완료로 주장하지 않는다.
- 관찰 기법이 있어도 광고 의도를 변경하지 않는다. 광고 판정이 있으나 기법이 없거나 미확정이면 진단으로 보존한다. 정상의 관찰 결과도 별도 기록한다. 부분 범위 기법을 후보 전체 광고 근거에 자동 연결하지 않는다.

## 채택·종료 기준

1. API 없는 브라우저 검증: 4종 양성·대조군, 부모/자식 스타일 덮어쓰기, 복합 기법, 제목·본문·댓글·인라인 분할·iframe의 원문/위치 귀속, 문맥의 광고/정상 변화에 대한 관찰 불변성을 검사한다. 테스트 라벨은 관찰 모듈에 전달하지 않는다.
2. 확정 관찰 범위의 기법별 누락·오탐 0, 모든 대상의 위치·원문 일치, 명시한 모호/미지원 사례의 검토 기록, 광고 의도/검토/이유/입력 불변을 독립 통과 기준으로 삼는다. 실패 시 구현 결함과 설계 한계를 구분하며, 라벨에 맞춘 단어·URL 예외를 금지한다.
3. 소스 고정 후 별도 HTML·텍스트 조합으로 한 차례 추가 검사한다. 동일 작성자가 만든 합성 검사이므로 독립적인 실제 웹 홀드아웃으로 주장하지 않는다. 수정하면 해당 자료도 회귀 자료로 전환한다.
4. 독립 검사 통과 후 기존 63개·306개 저장 응답을 재생하고 광고 의도 F1, 관찰 기법 지표, 최종 URL/위치/기법 지표를 분리한다. 관찰 정답이 없는 정상 항목의 기법 정확도를 추정하지 않는다. 불확실·부분 귀속으로 보류된 실제 광고 기법은 최종 지표에서 누락으로 센다.
5. 의미 판정은 완전히 같아야 한다. 통합 결과에 새로운 기법 오류나 위치 전이가 남으면 통합 채택을 보류하고 별도 관찰 모듈만 유지한다. 2단계의 기존 의미 오류를 관찰 결과로 덮지 않는다.

기술적 검증과 일반화 성능 향상 주장은 분리한다. 호출·토큰 증분, 코드 처리 시간, 자료 크기와 미검증 범위를 보고한다. 4~5단계는 시행하지 않는다.
