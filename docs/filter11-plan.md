# Filter 1.0 후속 안전성·제외율 개선 계획

사용자 Goal: 광고 손실을 막으면서 정상 제외를 늘리는 실무 필터 후보. 절대적인 모든 사이트 무손실 보장은 할 수 없으며 정답이 있는 범위의 경험적 상한만 측정한다.

기준선 Filter1.0 t=.05와 D 고정 필터를 보존한다. 기존 누락 문장/평가 문장은 훈련에 넣지 않는다. 새 독립 상황의 정상 소식+거래 권유, 인용/피해신고, 애매한 모집을 실제 수집기로 읽어 대조한다. 학습/개발/확인 상황은 분리한다. 작성자는 같으므로 새 합성을 외부 독립 검수로 주장하지 않는다.

후보는 최대2개: (C) Filter1.0 이어학습 lr5e-6 최대3epoch, (F) 순정에서 보강자료 학습 lr2e-5 최대4epoch. 기존96개와 새 훈련을 함께 사용하고 계열 균등/전달 비용2배를 유지한다. GPU 순차 학습으로 자원 충돌을 피한다. 새 개발과 기존 개발26에서 안전한 제외 수로 checkpoint를 고른다.

기존 관찰221/2000개를 이제 보정 자료로 명시한다. checkpoint 선택 후 고정 격자 t=[0,.0001,.0005,.001,.002,.005,.01,.02,.05,.1,.2,.3,.4,.5]의 광고/근거부족 손실0 조건에서 정상 제외가 최대인 임계값을 선택한다. 모델끼리도 해당 제외 수로 선택한다. 이는 이전 확인 자료를 재사용한 개발 선택이며 새로운 일반화 증거가 아니다. 데이터/임계값 효과를 따로 보고한다. 기준선에도 같은 보정을 적용해 추가 학습의 이득을 확인한다.

선택 후 새 HTML 확인, 실제 수집5179개(정답은통제64+사람17개만), 미사용 최종26개를 딱1회 검증한다. 확인에서 전달대상 손실이 발생하면 운영 승격하지 않는다. 정답 없는 제외 후보는 정상으로 간주하지 않고 검수 파일에 보존한다. 512토큰 초과/빈 입력/문맥 결손은 통과하며 원본근거·ID·순서와 미판정 후보는 보존한다. 공개 실사이트의 실제 악성광고 정답을 확보했다고 주장하지 않는다.

필터는 실험용으로만 구현한다. 같은 입력 반복 실행/중단 후 재개/누락 ID/손상 점수/긴 입력의 강제 통과를 검증한다. 유망할 경우 이후 실제HCX/25분 연결 검증이 필요하며 이번 CPU 단독시간으로 종단 절감을 주장하지 않는다. 최종자료를 보고 반복 조정하거나 모든 조건에 맞을 때까지 무제한 재학습하지 않는다. 알려진 손실이 새자료에서 계속되면 원인과 남은 범위를 기록하고 운영 미채택을 유지한다.
