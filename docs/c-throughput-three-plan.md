# C 기준 처리량 세 후보 독립 병렬 검증

2026-09-26 사용자 승인. C/FIFO/브라우저 재사용/SRPT8·aging8/출력512/none/배치최대4/25분·600회 운영을 기준선으로 고정한다. 세 작업은 별도 실험 파일과 출력 경로에서 병렬 진행한다. 코드·API 사용량을 공유하는 종단 유료 실행은 병렬로 섞지 않는다.

1. 페이지 안의 원래 배치를 앞/중간/뒤 세 구간으로 나누어 순환한다. 배치 동료·내부순서를 보존하며 대상 라벨·단어·태그로 우선순위를 정하지 않는다. 저장 실행에서 미판정7개가 기다린 원인과 동일 호출 예산의 추가/손실 광고 위치를 먼저 확인한다.
2. 다음 FIFO 페이지 수집1개만 판정 대기와 중첩한다. 실제 수집 시간과 admission 가능한 시점을 확인해 이득의 상한을 구한다. 새 메모리 슬롯/중단/취소/재개/예외와 배치 순서 보존 비용을 함께 고려한다. 무조건적 미리읽기나 active8 확대는 다른 변경이므로 하지 않는다.
3. 전체 요청과 귀속/스타일/관찰 근거가 완전히 같은 요청의 확인된 결과만 재사용한다. ID/URL/문맥/배치 동료를 제거해 적중률을 높이지 않는다. 실제 exact 적중률0이면 캐시를 구현·도입하지 않는다. 미확인 응답 재사용/재호출 금지.

우선 API0 기록 진단·오프라인 실행·중단재개 검증으로 효과와 위험을 분리한다. 기존 관찰 자료는 회귀·진단이며 새 홀드아웃으로 부르지 않는다. 1번은 기존 정탐 손실보다 광고 판정 기회 순증가가 있어야 실제 판정 확대를 검토한다. 작은 손실은 무조건 탈락시키지 않되 유형별 손실·새 오탐과 시간조건의 순이득이 필요하다. 2번은 측정상 절감 가능한 시간과 추가 판정 기회를 산출해 복잡도에 비해 실용적 이득이 있는지 판단한다. 3번은 정확요청 적중이 있어야 확대한다.

운영 승격은 유망한 후보에 한해 동일25분 전체광고(미방문·미판정 포함) 정탐/F1, 정상 오탐, 비용, 메모리, 정확한 중단/재개 보존을 확인한 뒤 진행한다. 실제 호출 확대가 필요하면 후보와 예산을 별도 고정해 기록한다. 예상 이득이 없거나 상한이 작고 기존 손실 위험이 더 크면 유료 확대 없이 종료한다. 실패한 안을 결합하거나 결과에 맞춰 구간 수/예외를 반복 조정하지 않는다. 채택안이 없으면 운영 C를 유지한다.
