# C 기준 처리량 세 후보 병렬 검증

2026-09-26. 사전 계획 `c-throughput-three-plan.md`. 의미 판정 C/FIFO/SRPT8·aging8/출력512/none/최대4개 배치/25분을 기준으로 세 후보를 병렬로 분리 검증했다. **세 후보 모두 미채택이며 운영 C를 유지한다.** 후보1은 실제 25분 실행까지, 후보2·3은 저장 자료의 이득 상한과 보존 검증까지 시행했다. 효과 근거가 부족한 비동기 구현·캐시는 추가하지 않았다.

## 후보2: 수집·판정 대기 중첩 — 미채택

과거 C25분 실행의20페이지 수집은33.599초다. 첫페이지를 제외한 전체 수집31.792초가 절대 절감상한이다. 직전 API 대기 하나와만 짝지으면25.895초, 활성8페이지·현재근거슬롯을 유지하며 빈슬롯에서만 단일prefetch하면11.416초(25분의0.761%)가 상한이다. 이 상한은 실제 비동기 구현의 검증된 속도 개선값이 아니다.

역사평균 API시간과 전체벽시간으로 환산하면 보수안은 약3회 추가판정에 해당하는 산술 예시다. 기존7미판정 광고는 해당 페이지에만 기회를 몰아도최소4회부터더필요했다. 미래응답시간·새페이지admission은달라지므로 이 환산을 미래TP/F1보장으로 해석하지 않는다.

기존467배치의 페이지선택·ID·내부순서,20페이지admission·최종offset·active상태 재생을 통과했다. 현재자료의 이득상한에 비해 비동기상태/메모리/취소/재개 복잡도가 커 실제비동기구현과유료확대없이 종료했다. 느린원격사이트에서는수집비중이달라질수있다. `overlap-diagnostic-report.md`와 `.runtime/overlap-diagnostic-v1` 참고. 추가API0.

라벨 밖 양성8개는 기존 C와 같은 위치·같은 요청 본문이었다. 광고를 포함하는 중첩 부모4, 실제 광고 문단3, 기존 정상 ‘작성자’ 오탐1이다. 중첩 부모를 독립 정탐으로 더하지 않는다. 이 작성자 위치를 공통 정상으로 추가한 사후 민감도 F1은 C76.60%, 순환안73.47%이며 전체 사이트 정밀도는 아니다. 통제 정답과 사후 검토를 구분한다.

실제 전송455회는 모두 확인됐고 미확인0, 확인 토큰785,748이다. 장부456번째는 전송 전 시간 예산 종료로 API 호출에 포함하지 않는다. 마지막 응답 후 약27초를 전송 전 대기하다 종료했고 정리 포함 벽시간은1,501.35초였다. 따라서 호출 수 감소를 처리 속도 향상으로 해석하지 않는다.

### 채택 판단과 한계

운영 코드는 변경하지 않았다. 실험 코드는 별도 경로에 보존했고 추가 유료 재실행·결과 맞춤 튜닝·push는 하지 않았다. 순환안은 더 많은 통제 정상까지 판정했지만 전체 광고 판정 기회를 늘리지 못했다. 남은 병목은 제한된 토큰 예산에서의 작업 배분과 정상 인용의 의미 판정이며, 이번 자료만으로 특정 새 해법의 효과를 주장하지 않는다.

동일 자료에 순서·구간 비율을 계속 맞추면 과적합 위험이 있다. 이번 결과는 관찰한 복제본의 진단이며 새로운 홀드아웃·실사이트 일반화 검증이 아니다. 후보2의 중첩 이득은 느린 원격 사이트에서 달라질 수 있고 후보3의 중복0도 모든 사이트에 대한 결론은 아니다.
