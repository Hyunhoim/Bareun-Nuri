# 실제 측정에서 발견된 JSON 응답 형식 병목

규모 중형 C가197번째 응답에서 중단됐다. HTTP200/stop과 원응답은 존재하지만, 완전한 decisions JSON 뒤 설명 문장이 붙어 기존 JSON.parse 계약을 실패했다. 이는 네트워크 미응답과 다르며 자동 재호출하지 않는다. 원본 실패 실행을 보존한다. 기존 scoped-input 의미 후보는 이 신뢰성 병목 검증 뒤로 보류하며 현재 유료 실행0이다.

변경은 응답 포장 해석뿐이다. 선두의 완전한 JSON 객체 하나와 뒤의 일반 설명만 허용하며, 앞 설명·추가 JSON/배열/코드블록·중복 키·잘린 JSON·스키마/후보ID 불일치는 거부한다. 응답의 분류값을 추론/수정하거나 기본 정상으로 대체하지 않는다. 기존 형식 검증은 그대로 적용한다. 원응답은 계속 보존한다. 같은 사례 전용 정규식이나 정답 수정은 금지한다.

먼저 과거 정상 응답 전체에 대해 새 파서와 기존 결과의 완전 일치 및 이번 실패 응답의 후보ID/열거값 검증을 API0 재생으로 확인한다. 모호·악성·잘린 응답은 네트워크stub 검사로 확인한다. 중단된 중형은 자동 재호출/임의 체크포인트 해제 없이 별도 새 실행에서 같은 입력으로25분 재측정한다. 대형 기준선도 별도 유지한다. 필요 시 새 대형25분을 측정한다. 동일 실제 요청에서 바뀐 판정과 새로 판정 가능해진 위치를 구분한다.

채택은 정상 결과 보존·엄격한 실패 처리 유지·실제25분 중형 완료 또는 더 높은 유효 판정량·새 의미 회귀 여부 확인을 근거로 한다. 모델에 보내는 요청은 바뀌지 않으므로 과거 응답 재생으로 의미 보존을 직접 확인할 수 있으나 실호출 간 변동은 별도 보고한다. 계약 변경 시 코드 서명을 갱신해 이전 실패 체크포인트를 자동 이행하지 않는다.
