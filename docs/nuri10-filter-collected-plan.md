# 수집 후보 정상 제외 필터 후속 진단

2026-09-29. Nuri1.0/D의 v1 선택 임계값을 고정한다. 재학습·임계값 탐색·운영 변경·API 호출 없이 저장된 실제 공공사이트 스냅샷 전체와 부산 복제본20페이지 전체를 비교한다. Ponytail 원칙으로 기존 CPU 추론과 문맥 직렬화를 재사용한다.

- 실제 자료: real-context-review-v1 및 nuri-1.2-human-review-v1의 snapshot-*.json. URL+위치 중복은 최초1회로 제한한다. 사람 검수17개의 정확히 같은 위치·원문만 정상 라벨로 연결한다. 나머지는 정답 미상이다.
- 복제본: scale-large-live-v1/snapshots 전체. controlled64 정답은 node_id로 연결하고 원문을 대조한다. 미라벨 후보를 정상으로 간주하지 않는다. HCX 기존 정탐 손실은 완주한 scale-medium-envelope-v1의 통제 위치로만 확인한다.
- 입력: 기존 contract.initialEvidence 및 klue-scoped-context 직렬화. 대상/문맥 유지. 512토큰 초과는 필터 제외 금지. 실제 의미 영역은 DOM 태그/역할에 따른 참고 분류이며 임계값/라벨에 사용하지 않는다.
- 모델별 전체/페이지별/영역별 후보 제외 수, 중복 입력을 하나로 셌을 때 제외 수, 확인 라벨의 광고 손실·정상 제외·보류 제외, CPU 시간 보고. 필터 손실이 있으면 운영 미채택. 손실0이어도 정답 미상 제외분과 표본 한계로 안전성 확정 금지.
- 제외 후보 전부 검수 가능한 JSON 보존. 기존 입력을 재사용하는 관찰 진단이며 새 홀드아웃이 아니다. 실제 API 요청 절감/재배치 F1/25분 종단 속도로 주장하지 않는다.
