### 운영 반영 및 안전성

`judgment.cjs` R SYSTEM, `quarantine-recovery.cjs`, `bounded-scan.cjs`, `bounded-scan-store.cjs`, worker의 복구 진행/서명, Spring 재개 허용조건 및 프런트의 복구 상태 안내를 반영했다. HCX007/none/512/일반최대12/동시3/58kTPM/FIFO/수집5/AntiSpoof1.0은 유지한다. 완료결과는 저장하며25분에 멈추면 사용자가 이어서 검사할 수 있다. 일반검사가 완료된 시점에 남은 예산이 있으면 자동 복구한다.

복구 대상은 **응답이 확인된 불완전 묶음**으로 한정한다. 통신 미확인 요청을 자동 재전송하지 않는다. 4개씩1회, 작업당최대60소묶음이며 재실패는 미판정으로 보존한다. 기존서명CP는 자동변환하지 않는다. 새복구자료와 원래격리응답을 모두 보존하고, 완료된 격리 문제는 해결표시해 화면의 미해결 건수에서 제외했다.
