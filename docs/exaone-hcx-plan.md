2026-09-29. 추가 학습이나 운영 변경 없이 저장된 동일 221개 입력을 사용한다. 이전 EXAONE Q4_K_M CPU 결과와 비교한다. 개발 204개 중 확정 167개의 광고 이진 F1, 근거 부족 37개, 사용자 검수 정상 17개를 분리한다. 기존 관찰 자료이므로 신규 홀드아웃이 아니다.

단일 후보: 공통 system/user 문자열과 라벨 0~3을 그대로 사용한다. HCX-007 none/temperature0/seed42/출력32/Structured Outputs. EXAONE는 GBNF이므로 출력 제약 구현은 다르다. 221개 + 앞선 EXAONE의 고정 반복12개. 순차58kTPM/61초창/최소1.05초 및58RPM 보호. 서비스 응답시간과 로컬 제한 대기를 따로 기록한다.
