# 운영 C 규모별 처리 범위 진단

2026-09-26, 실행 전 고정. 기존 실DOM 복제본의 소형(목록+첫3상세), 중형(목록+10상세), 대형(기존20페이지)을 사용한다. 광고 정답에 따라 페이지를 선택하지 않는다. 원문/문맥/스타일/후보는 줄이지 않는다. 각 페이지에서 고정된 해당 규모 전체 주소를 발견하도록 실험 navigation inventory만 교체한다. 따라서 탐색 알고리즘이나 자연 링크 깊이 평가가 아닌 닫힌 작업량의 처리 가능 범위 진단이다. 운영 탐색 범위는 변경하지 않는다. 원본 서버/Playwright로 실제 수집한다.

프로파일에 페이지·후보 수와 모델 입력 문자 길이의 합계/평균/p50/p95/최대를 고정한다. 문맥 길이는 저장된 자연 분포를 사용하며 의미를 바꾸는 인위적 절단/반복은 하지 않는다. 세 축의 독립 인과효과를 주장하지 않는다.

기준선 C/none/출력512/순차최대4/600호출/25분/SRPT8·aging8/브라우저 재사용. 세 조건은 공통 API 한도를 공유하므로 순차 실행하고 각 전61초간 사용량 창을 비운다. 조건당 토큰 안전상한150만, 최대30분 정리 보호. 미확인 요청 자동 재호출 금지. 모두 완주하면 조기 종료한다. 모형 실행으로 집합·정답 대응을 먼저 확인한다.

각 조건 포함 페이지에 속한 모든 통제 광고를 분모로 미수집/미판정도 FN에 포함한다. 후보 판정 완료율, 완주 여부, 정밀도/재현율/F1, 의미 누락, 정상 오탐, 호출/토큰/지연을 보고한다. 정답 밖 양성은 별도 검토하고 전체 사이트 정밀도로 부르지 않는다. 과거 대형25분 결과는 참고이며 새 닫힌 작업량과 혼합하지 않는다.

진단 후 작은 조건에서도 미판정이 크면 처리량 개선을, 작은·중간이 완주하면 의미 판정 개선을 우선한다. 대형만 미완주이면 부분완료/재개를 유지한다. 개선안은 관측된 공통 원인 하나에 한정하고 변경 전 별도 비교 기준을 고정한다. 새 평가를 통과하지 못한 변경은 운영에 반영하지 않는다. 알려진 인용 오류에 맞춘 반복 문구 튜닝은 금지한다. 이번은 관찰 자료 재활용이며 새 홀드아웃이 아니다.
