# 수집 후 후보 선별 사전 계획

2026-09-26. 운영 C + 응답 포장 개선을 기준으로 한다. 운영 파일은 변경하지 않는다.

가설: 같은 수집 근거를 16개씩 HCX-007 none으로 선별해 명확한 비대상 후보를 상세 판정에서 제외하면, 기존 최대4개 C 판정의 작업량을 줄일 수 있다. 페이지/태그/기법 신호만으로 제외하지 않는다. 원문, 문맥, 링크, 복원 입력을 보존하고 선별 결과를 별도 기록한다. 제외는 정상 확정이 아니라 상세 판정 미실시다.

먼저 비용 없는 동일 근거 중복 검사를 한다. 이후 기존 문맥 대조48개, 복제본65개, 이전에 준비했지만 유료 실행하지 않은 문맥 대조24개를 사용한다. 마지막24개는 같은 제작자의 합성 문맥 검사이며 독립 실사이트 홀드아웃이 아니다. 각 그룹 원순서/해시순서에서 선별16개/출력1024를 실행한다. 기존 C는4개/출력512이며 선별 통과 후 변경하지 않는다. 선별도 동일 원문과 모든 C 입력을 받는다. 전체 수집 원본은 보존한다. 긴 입력은 제외하지 않고 상세 판정에 남기는 방향이며 이번 소규모 관문은 저장된 단일 후보 근거를 사용한다.

확대 관문: 두 순서 각각 전체 광고 선별 재현율98% 이상, 기존 운영 정탐의 반복 제외0, 근거 부족 사례를 명확한 정상으로 제외하지 않음. 관문 실패 시 한 가설 비교로 종료하고25분 실행은 하지 않는다. 모델 형식/통신 실패는 자동 재시도하지 않는다. 최대32선별 호출/30만 토큰/1시간, 순차 요청, 계정TPM52000.

통과하면 전체3543후보의 선별+남은 상세 판정 예상 호출이 기존899호출보다25% 이상 감소하는지 확인한다. 이것도 통과하면25분 실제 비교로 확대한다. 채택은 선별 포함25분 전체 정답 F1/TP 유지 또는 개선, 호출/지연 감소, 기존 광고의 반복 손실 및 기법/귀속 회귀 없음이 조건이다. 제외/미판정/미방문도 전체 광고 FN에 포함한다. 결과에 맞춘 관문 완화나 반복 프롬프트 수정은 하지 않는다.

예상 위험: 선별은 별도의 의미 판정이므로 짧은 링크, 자모, 예방 문맥 옆 광고를 먼저 버릴 수 있다. 기존 정답을 본 사례에 대한 성능은 회귀 근거다. 25분 확대 전 결과만으로 종단 F1 또는 지연 개선을 주장하지 않는다.
