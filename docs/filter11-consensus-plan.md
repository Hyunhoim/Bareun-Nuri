# 제한적 추가 가설: 불일치 시 HCX 전달

C가 새 최종자료의 근거 부족1개를 매우 낮은 전달 점수로 제외했다. 이는 확인 후 관측이므로 해당 최종자료는 이제 관찰 자료다. 새 최종평가를 만들거나 임계값을 그 사례에 맞추지 않는다.

공통 가설은 작은 합성학습에서 생긴 단일모델 확신 오류다. C와 순정 재학습F가 **각자의 이미 고정한 임계값(C .005/F .2)에서 모두 제외**하는 경우만 제외하는 한 가지 보완을 진단한다. 추가 학습/튜닝/OR조건 없음. 보정자료에서 교집합145개, 전달 손실0이라는 비용/제외 상한을 먼저 확인했다. 실제 수집에는 C 제외 후보만 F에 보내는 순차 cascade로 추가CPU 비용을 측정한다.

32확인/소비된26최종의 재측정은 회귀 진단이며 새 독립 검증이 아니다. 전달 손실이 있으면 이 보완도 미채택. 없어도 독립 실사이트 광고 정답/HCX 종단 효과를 검증했다고 주장하지 않는다. 단순히 이 후보가 관찰된 안전성 문제를 완화하는지와 대가를 기록한다.
