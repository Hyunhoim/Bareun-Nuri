# 권유 유지·피해 문의 구별 제한 실험

2026-09-28. 기존 관찰2,000개의 정탐 손실76개는 원인 진단에만 사용한다. 해당 문구/변형/정답을 학습 또는 모델 선택에 사용하지 않는다. 독립 사람 검수 자료가 없는 상태이므로 아래는 합성 개발 실험이며 운영 승격을 하지 않는다.

1. 이전 손실의 예측 이동, 원문 계열, 기법, 실제 대상/문맥을 감사한다. 관측과 의미 혼동·표현 해석 등의 가설을 구분한다. 비공개 계열명을 의미 근거로 쓰지 않는다.
2. 기존 문맥 대조 자료의 중복 입력을 제거한다. 추가로 피해 호소로 시작하지만 현재는 실제 권유하는 글과, 같은 서비스에서 피해 상담을 구하는 글을 새 문장으로 작성해 실제 DOM에서 수집한다. 계열별 train/development 분리는 유지한다. 원래168자료는 provisional 상태를 보존하며 이번 사용은 에이전트 재검수 후 제한 진단에 한정한다.
3. A는 기존 frozen8 후보. B/C는 동일 A에서 시작, upper4+분류기만 학습, lr2e-6, batch8, seed42, 각64업데이트. B는 매배치 새자료4+과거 훈련4, C는 새자료2+과거 훈련6. 업데이트 수/모델/옵티마이저는 같다. 새자료 노출 감소와 복습 증가가 함께 바뀌는 혼합비 실험이며 두 효과를 분리했다고 주장하지 않는다. 재생 자료는 기존 train만 사용한다.
4. 새로운 그룹 개발자료의 광고F1→macro4→기존 A 우선 순으로 하나만 선택한다. 개발자료는 원래12계열 중4계열 및 새로운4개 혼합 의도 대조쌍이며 같은 작성자 합성이다. 3/5-fold CV를 했다고 주장하지 않는다. 짧은 원문 계열 수가 부족해 한 번의 제한 비교만 수행한다.
5. A가 선택되면 변경 없음으로 종료한다. B/C가 선택되면 선택 후에만 저장2,000개를 단회 추론한다. F1 증가를 주요 진단 이득으로 보되 TP/FP/FN/기존정탐손실/새정탐/보류/시간을 모두 보고한다. F1이 오르더라도 독립 최종 평가와25분 종단 평가 전에는 HCX 운영을 교체하지 않는다. 결과를 보고 학습률/비중을 추가 변경하지 않는다.

GPU 가용 시 사용, 불가 시 CPU8threads. 각조건 학습20분·회귀10분·전체1시간 안전상한. API0. 모델/입력/예측/코드/설정 해시를 보존한다. 실제 게시물·독립 평가·정답 검수 완료를 주장하지 않는다. 오류 사례를 학습에 직접 넣지 않아도 같은 작성자의 문법에 적응할 위험은 남는다.
