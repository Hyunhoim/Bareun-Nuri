# 출처 선택을 부차 출력으로 분리하는 마지막 개발 비교

act16은기존64개에서인용오탐을없앴지만광고링크8개를누락했다(F185.71%). 근거선택을포함한passageJson4는같은64개F1100%이나16호출이다. 따라서출처필드를유지하되명시적인'선택없음'을허용하는계약을16개/8개배치에서한차례비교한다.

- publication_act와입력자료/분류지침은유지한다. evidence_ids=[]는선택하지않았다는뜻이며실제출처를선택한것처럼표시하지않는다. 존재하지않는출처/다른후보ID/중복/추가필드/분류값오류는계속거절한다. 코드의raw_text/location보존은출처선택과무관하게유지한다.
- 새reference16/reference8조건을개발64개에서실행한다. 최대12요청/250,000예약토큰/1시간. none/temp0/seed42/출력3072, 공유48kTPM/2병렬.
- 과거실패응답을새규칙으로다시채점하지않는다. 새출력계약의새응답만집계한다. 빈출처율도별도보고한다.
- 개발F1최대후보1개만선택하고1%p이내는적은호출·토큰을우선한다. 기존passageJson4도후보다. 개발프롬프트탐색은여기서종료하고새80개2회와기존76개로검증한다. 새자료실패시같은자료를맞추는프롬프트수정은하지않는다.
