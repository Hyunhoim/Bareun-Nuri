# Phase1 동시 3요청 실제 25분 검사 결과

## 결론

기존 순차 운영의 첫 25분 대비 판정 후보 수가 **30.26%**, 광고 정탐 수가 **36.44%** 늘었다. 전체 광고 기준 의도 F1은 **60.23% → 71.46% (+11.23%p)**다. 검사 범위 확대 효과가 크며 의미 모델 자체의 개선은 아니다. 기존 정탐 3개 손실과 동일 위치 정상 3개 오탐 전환이 있어 정확도 완전 보존을 주장하지 않는다. 동시 3요청은 유망한 실행 구조이나 이번 작업에서는 운영 소스를 변경하지 않았다.

## 조건과 범위

- 기준선: `.runtime/phase1-full-1790774023853`의 첫 25분. 동시 2가 아닌 순차 운영이다.
- 후보: `.runtime/phase1-parallel25-1790789676712`. 실제 Playwright 수집, HCX API, CPU AntiSpoof, 디스크 저장 포함.
- Phase1 v1.2: 151페이지, 정답 위치 2,240개(광고 1,120·정상 1,120). 미방문·미판정 광고도 FN에 포함한다.
- 동일 URL, HCX-007 none/출력512/최대12개 묶음/58k TPM, FIFO·기존 수집기·AntiSpoof 유지.
- 활성 페이지에서 최대 3요청을 예약하여 함께 실행하고 순서대로 커밋하는 실험 구조다. 3요청 경계에서 수집을 보충하므로 수집·판정 교차 시점도 달라진다. 지속적으로 빈 슬롯을 채우는 구현은 아니다.
- 과거 순차 실행과 새 실행의 비교로, 시간대가 같은 무작위 대조 실험이 아니다. 관측 개선 전부를 동시성만의 인과효과로 확정할 수 없다. 이미 관찰한 Phase1의 회귀·처리량 실험이며 새 독립 일반화 평가가 아니다.

## 정탐 손실과 오탐

- 새 정탐 218개: 미방문 광고 163개, 수집 후 미판정 광고 53개, 기존 의미 누락 회복 2개.
- 기존 정탐 손실 3개: `/site-4/page-037.html`의 `71e820bf96a9d4`, `9d60b750bf9caf`, `88ad872f500b69`. 모두 의미 부정으로 바뀌었다.
- 새 오탐 84개: 기존 미판정 위치 81개, 기존 정상 판정 위치 3개. 기존 오탐 5개가 해소되어 순증은 79개다.
- 같은 요청 입력에서도 출력 변동이 있었다. 동시성 때문에 의미 성능이 나빠졌다고 단정할 수 없지만 기존 정탐 보존 실패는 그대로 기록한다.

남은 광고 FN 315개는 미방문 185, 수집 후 미판정 69, 방문했으나 해당 정답 위치와 수집 위치가 대응되지 않은 34, 의미 부정 24, 의미 보류 3이다. 위치 대응 실패 34개를 모두 원문 자체의 수집 소실로 단정하지 않는다.

## 지연 및 종료

마지막 3요청 중 하나가 69.169초 걸렸고 다른 둘은 약 4.9초에 끝났다. 모든 응답을 기다린 뒤 순서대로 커밋하여, 먼저 끝난 두 요청의 24후보도 마감 전 결과로 게시되지 못했다. 마지막 36후보 전체를 첫 25분 지표에서 제외했다. 이는 긴 단일 응답과 묶음 완료 대기가 결합한 병목이다.

진행 중 요청 정리까지 실제 실행은 약 25분 36초였다. 정리 후 누적 TP815/FP328/FN305, 의도 F1 72.03%이나 첫 25분 성과로 사용하지 않는다. 최종 상태는 부분 완료/time_budget, 미확인 요청 0이다. 총 375호출·확인 토큰 1,097,463개이며 마감 후 정리분을 포함한다. 전체 사이트 완주는 아니다.
