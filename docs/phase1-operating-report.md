# 운영 테스트 phase 1 — 현재 운영 기준선 결과

2026-09-30. **전체 평가는 완주하지 못했다.** 25분 조건으로 시작했지만 14분 18초에 HCX 응답 누락으로 중단됐다. 새 공공웹 보강 240개는 아직 판정하지 못했으므로, 이번 결과가 그 보강 자료의 성능까지 검증한 것은 아니다.

## 실행과 보존

- 실제 운영 worker 그대로: HCX-007 / none / temperature0 / seed42 / 최대12개 묶음 / 출력512 / 예약58k TPM. FIFO, SRPT8·aging8, 수집 동시성5, AntiSpoof1.0 CPU.

- 25분·200페이지·600호출·누적 후보 제한0. 실제 42페이지 수집, 전체 후보1,895개 중1,659개 판정 저장. 지정 정답 위치2,240개 중790개를 정확 위치로 매칭했고686개 판정을 저장했다.
- API160회 / HTTP200 160회 / 확인 토큰474,657(입력434,343·출력40,314). HTTP 성공과 판정 계약 검증 성공은 다르다.
- 원본 `.runtime/phase1-operating-1790735149471`. 미확정 체크포인트 보존. 자동 재호출·재개·학습·운영 수정·push 없음.
- 생성 당시와 달라진 worker/bounded-scan은 실행 전에 새 해시로 고정했다. 그 이후 운영18파일 불변 및 원래 정답/HTML 보존을 확인했다. 원래 v1.2 전체는 `dataset-v1.2-sealed.zip`으로 봉인했다.

## 핵심 점수

**지정 정답 위치 기준**이다. 정답 밖의 추가 양성102개는 별도 목록으로 보존했으며 전부 오탐 또는 정탐으로 간주하지 않는다. 따라서 아래 정밀도는 페이지 전체 모든 요소의 정밀도가 아니다.

| 전체2,240개: 미검사도 FN | 342 / 134 / 778 | 71.85% | 30.54% | **42.86%** |
| 판정 완료 지정686개만 | 342 / 134 / 13 | 71.85% | 96.34% | **82.31%** |

전체 FN778의 구성: 미방문702, 수집했으나 미판정52, 정확 위치 미매칭11, 의미 정상판정9, 의미 보류4. 정확 위치 미매칭은 아래 상위 요소 수집 감사를 함께 봐야 한다.

25분 이전에 실행이 실패했으므로 첫25분 경계와 종료 시 저장 판정은 동일하다. **시간 예산만으로 발생한 미완주나 25분을 모두 사용한 처리량 결과로 해석하지 않는다.** 정상 완주했을 때의 F1은 아직 알 수 없다.

|---|---:|---:|---:|
| 전체 정답 기준 | 69.23% | 31.14% | **42.96%** |

## 병목과 우선순위

### 1. 응답 완전성 실패가 실행 전체를 멈춤

160번째 요청은12개였지만 응답에는11개만 있었다. 빠진 대상은 푸터 `게시판 이용 안내`였다. `finish_reason=stop`, 출력273토큰/상한512이므로 이번 실패는 출력 상한에 의한 잘림이 아니다. 응답에 다른 ID가 끼어든 것도 아니다.

운영은 잘못된 결과를 저장하지 않기 위해12개 묶음 전체를 커밋하지 않고 `One judgment per candidate required; unconfirmed_inflight`로 중단했다. HTTP 응답은 저장되어 있고 상태는 `responded`다. 통신 결과를 모르는 네트워크 실패와 구분한다.

원응답을 오프라인 재생하여 앞선1,659개 저장 판정이 원응답과 완전히 같은지 확인했다. 오류 응답의11개를 운영 결과로 임의 승격하거나 빠진 답을 정상으로 채우지 않았다.

다음 검토는 완전한 ID 집합 검증을 유지하면서 불완전 응답을 격리·보존하는 처리 계약이다. 재호출·부분 커밋·재개 정책은 별도 검증이 필요하며 이번 측정에서는 변경하지 않았다.

### 2. 광고 인용·피해 문의·삭제 요청을 실제 권유로 오판

기존 정상 대조331개 중134개가 광고로 판정됐다. 구성은 광고 신고 맥락77개, 피해 문의28개, 삭제 요청26개, 운영 문의3개다.

- 같은 작성자의 신고 설명과 광고 인용: 판정79개 중77개 오탐.
- 피해 문의:67개 중28개 오탐.
- 삭제 요청:70개 중26개 오탐.
- 합법적 문의:58개 중 오탐0.

예: 인용 뒤에 “저도 이 글 보고 돈 보냈어요. 신고할 때 대화 캡처만 있어도 되나요?”가 붙은 정상 문의를 광고로 판정했다. 대상 자체에 피해 설명이 있는 사례도 있으므로 전부 수집 문맥 누락으로 설명할 수 없다. 다른 사례에서는 신고 설명이 실제 HCX 요청의 주변 문맥에 전달되어 있었다.

정답 밖에서 푸터 `게시판 이용 안내`를 광고로 본 사례도5개 관찰했다. 해당 입력의 `unscoped_nearby`에는 앞 본문 광고가 포함될 수 있다. 경계 밖 참고 문맥과 묶음 간 간섭이 원인 후보지만, 동일 입력 대조 재호출을 하지 않았으므로 인과관계는 미확정이다.

### 3. 짧은 표기와 자기 본문의 권유 관계

의미 누락13개 중10개가 짧은 문의형 표기+자기 본문 시나리오였다. `성매매 DМ 문의`, `유심 DМ 문의`, `보너스 문의` 등을 보류/정상으로 판정했다. 저장된 입력에는 판매·예약·가입을 권하는 자기 본문이 전달되어 있었다.

나머지3개는 일반 광고 본문/정상 서두 뒤 권유 등이다. 제목·작성자·본문의 역할 관계와 실제 게시 목적을 함께 해석하는 능력이 남은 병목이며, 자모 복원만의 문제로 단정하지 않는다.

### 4. AntiSpoof의 JAMO/HOMOGLYPH 혼동과 숫자 표기 누락

HCX가 맞힌 광고342개만 조건부로 보면, 순수/부분 자모14개에 HOMOGLYPH를 추가 오확정했다. `ㅌㅗㅌㅗ`, `ㅅㅓㅇ매ㅁㅐ`, `ㅇㅠㅊㅜㄹㅇㅕㅇㅅㅏㅇ` 등이 해당한다. 모델의 표기별 출력에서 JAMO와 HOMOGLYPH를 둘 다 확정한 것을 확인했다.

반대로 `토토 가입창 0PEN 했습니다…`는 광고 의도는 정탐했지만 `0PEN`의 HOMOGLYPH를 놓쳤다. 모델은 해당 표기를 정상으로 분류했다. 숫자 치환이 해결되었다고 볼 수 없다.

이 조건부 부분의 원래 정답 기준 H F1은93.56%, J F1은100%다. 정상 의도 사례·미판정·미방문을 제외한 수치이므로 전체 모델 일반화 성능으로 주장하지 않는다.

### 5. 지연은 이번에는 API 할당량 대기보다 실제 응답 시간이 큼

API 서비스 시간 합713.94초, 사용량 제한 대기 합0.018초였다. 요청당 평균 서비스 시간 약4.46초다. 브라우저42페이지 수집 시간 합63.01초이며 병렬 수집이므로 합을 전체 벽시간에 단순 합산하지 않는다. AntiSpoof 시간은 이번에 별도로 계측하지 않아 정확한 비중을 주장하지 않는다.

새 보강240개는 FIFO 목록 뒤쪽에 있어서 도달 전 실패했다. 이번 결과로 이 구간의 F1이나 정상 완주 처리량을 추정하지 않는다.

## 평가자료·위치 감사: 운영 오류와 구분

후속 로컬 브라우저 DOM 재구성에서 저장 후보의 선택자 오류0, 원문 차이0이었다. 지정 작성자30개는 텍스트가 없는 것이 아니라 `작성자 + 이름` 상위 요소로 수집됐다. 원래 정확 위치 점수는 유지하고 이30개를 증거 기반으로 대응시킨 사후 민감도를 별도 산출했다.

- 추가 대응30개 중24개 판정 완료. 조건부710개 의미 F1 **82.55%**(TP350/FP134/FN14).
- 14개 위치의 합성 기법 정답과 렌더링 불일치를 확인: 링크 기본 파란색이 조상 글자색을 덮어쓰는10개, 조상1px 아래 제목이1px보다 크게 렌더링되는4개.
- 위치 대응 및 명확한 스타일 정답 불일치만 사후 보정한 판정 완료 부분의 결합 기법 F1은 **81.12%**. 원래80.11%를 숨기거나 정답을 덮어쓰지 않는다.
- 이 감사 조건에서 **HCX가 맞힌 광고만** 보면 J/T/O는 모두 일치하고 H는14추가/1누락이 남는다. 이는 작은 조건부 진단이며 새 홀드아웃 성공이나 코드의 보편적100% 성능이 아니다.

재측정 전에 이 렌더링 정답과 요소 대응 계약을 고정해야 한다. 오답처럼 보인 사례를 모두 모델 개선 목표로 삼으면 잘못된 라벨에 맞춰 과적합할 위험이 있다.

## 해석의 한계와 다음 순서

기본 자료410개 조건부 의미 F1은82.66%, 문구 보강 자료276개는81.79%다. 서로 독립된 실제 사이트 표본이 아니고 동일 제작자의 파생 합성 사례다. 정상 광고 인용 그룹의 반복 형식에 맞춰 프롬프트를 수정하지 않는다. 일부 짧은 작성자 표기와 신고 문맥의 정답은 독립 사람 검수도 필요하다.

**다음 순서는 평가자료 렌더링·위치 정답 감사 고정 → 불완전 응답의 실행 중단 문제 검증 → 같은 버전 전체 재측정 → 문맥 판정·자모/H 혼동을 분리한 개선 비교**가 적절하다. 이번에는 채택 변경을 하지 않았다. 알려진 실패 응답을 자동 재호출하지 않는다.

자료는 최초 측정 후 관찰/회귀 자료로 전환했다. 새 공공웹 보강240개가 미판정이라는 사실과 전체 평가 실패를 유지한다.
