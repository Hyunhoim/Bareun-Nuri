# 임시 문장 복원 보조 입력 비교 (사전 계획)

운영 코드는 변경하지 않는다. 전체 대상의 광고 의도 판정에 자동 생성한 숫자 치환 문장 가설을 보조 입력으로 넣으면 누락이 감소하는지 검증한다. 토큰 단독 게시행위 판정과는 다른 실험이다.

- 기존 저장 후보 137개와 경계 대조 16개, 총 153개. 기존 자료이므로 진단/회귀 실험이며 미사용 홀드아웃이 아니다. 경계 16개는 모두 실제 광고를 포함한 복합 대상이며, 숫자 표기 자체는 예방 인용 또는 식별자일 수도 있다.
- A: 현재 운영 judgment 계약 그대로. B: 같은 계약에 원문을 변경하지 않고 자동 완전 치환한 문장 가설을 보조 입력으로 추가한다. 가설은 사실이나 기법 확정 근거가 아니라는 지시 한 문장을 추가한다. 따라서 입력+해석 지시 묶음의 효과이며 입력만의 효과로 주장하지 않는다.
- 기존 completeReadings를 재사용한다. 일반 영숫자 토큰만 치환하며 완전 문장 조합 최대 8개, 넘으면 복원 실패를 명시하고 원문을 유지한다. 정답으로 읽기를 선택하지 않는다. 원문/주변 문맥/좌표/관찰 사실을 보존한다.
- 12개 배치, HCX-007 none, temperature 0, seed 42, 출력 512. 정순/역순 각각 A/B를 동일 묶음으로 비교한다. 공통 실행기의 2개 동시 요청과 공유 48k TPM 제한을 사용한다. 실제 순차 운영 속도나 25분 처리량으로 해석하지 않는다.
- 52회 호출, 예약 토큰 최대 800,000, 1시간 상한. 미확인 요청 자동 재호출 없음. 각 요청/응답/소스 해시 저장.
- B 자체와 A 양성을 유지하는 A OR B 보조 후보 방식을 각각 평가한다. 정상/광고/근거부족, 숫자 보유 여부, 경계 역할별로 구분한다. 음성 또는 복원 실패를 정상 확정 근거로 쓰지 않는다.
- 다음 단계 진입 근거: 두 순서 모두 OR 방식의 의미 F1 상승 및 추가 정탐, 기존 양성 보존, 정상 오탐과 근거부족 양성의 증가 없음. B 단독 회귀도 보고한다. 이 파일의 수치 기준을 결과 후 변경하지 않는다.
- 광고 의도 양성만으로 숫자 치환 기법을 확정하지 않는다. 경계의 식별자/예방 인용을 기법으로 승격하는 반례를 별도 집계한다. 의미 이득 없이 기법 미확정만 남으면 운영 채택하지 않고 종료한다. 통과하더라도 독립 자료와 25분 운영 검증 전 채택 확정하지 않는다.
