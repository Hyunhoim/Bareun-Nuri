# 2단계 직접 3분류 실험 결과 — 미채택

2026-09-22. **새 개선안은 정상 오탐과 불확실성 처리 기준을 통과하지 못했다. 기본 웹 worker와 `isolated`를 유지한다. 남은 2단계 문제는 해결되지 않았으며 3단계를 시작하지 않았다.**

## 변경과 비교 범위

[사전 계획](stage-2-direct-verdict-plan.md)에 따라 여러 중간 의미 분류 대신 대상 표시가 있는 문맥을 읽어 광고·정상·근거 부족을 직접 판단하는 계약을 구현했다. 근거 위치는 후보 내부에서만 선택하며 원문은 코드가 복원한다. 실패한 기존 보완안 위에 추가 단계를 쌓지 않았다.

`agent/experiments/direct-contract.cjs`는 실험 전용이며 기본 worker나 `run.cjs`의 운영 경로에서 호출하지 않는다. 기존 `isolated`의 저장된 판정 중 광고와 확정 인용은 보존하고, 보완 대상 45개에만 HCX-007을 실제 호출했다. 진단 63개는 광고 25개·정상 36개·근거 부족 2개이며 이미 분석한 개발 자료다.

단일 후보와 배치 4 조건은 같은 기본 응답, 수집 근거, 프롬프트, 후보별 입력, 통합 규칙을 사용했다. HCX-007, 추론 none, temperature 0, seed 42, 출력 한도 3,072토큰이다. 판정 소스의 해시를 최초 호출 전에 고정했고 두 실행 종료 후 변경이 없음을 확인했다. API 요청 로그에서 대상 표시·문맥·3분류 지침·JSON 스키마가 실제로 전달됐음을 확인했다.

기본 판정 행은 이 실행의 고정 비교 응답이며 과거 모든 자료에서의 최고 성능을 뜻하지 않는다. 기본 단계의 광고 9개는 두 조건 모두 그대로 유지됐고 문맥 의존 광고 16개를 추가로 찾았지만, 기존 정상 판정을 광고로 바꾸는 회귀가 발생했다.

근거 부족 2개는 이진 F1에서 제외하고 필수 검토 기준에 별도로 포함했다. 단일 조건은 두 개 모두 광고로, 배치 조건은 하나를 광고·하나를 정상으로 확정했다. 검토 0개는 불확실성이 해결됐다는 뜻이 아니다. 정답 포함 여부, 후보 누락·중복, 근거 위치와 기존 광고 보존 검사에는 문제가 없었다.

두 조건의 최종 판정은 2개가 달랐다. `문의 처리 완료`는 단일 조건에서 정상, 배치 조건에서 광고였다. 서비스가 특정되지 않은 가입 안내는 단일 조건에서 광고, 배치 조건에서 정상이었으며 둘 다 요구된 검토 판정에 실패했다. 한 번씩 실행한 결과이므로 배치 효과의 재현성이나 순서 안정성을 입증하지 않는다.

## 확인한 병목과 해석의 한계

1. **한 후보 내부의 대상·문맥 귀속 오류가 남았다.** 작성자, 조회수, 게시일, 분류, 기록 번호, 담당 부서, 의견 수, 자료실 목록, 시민 의견 등 정상 대상에 주변 도박·불법 촬영물 권유를 옮겨 붙였다. 단일 후보에서도 발생하므로 후보 간 배치 혼동만으로 설명할 수 없다. 수집된 대상과 문맥은 전달됐고, 오류는 응답의 의미 판정에서 관찰됐다.
2. **일반적인 이용 안내와 불법 서비스 권유의 구분이 무너졌다.** 제공 상품·서비스가 확인되지 않은 결제·가입 안내를 근거 부족으로 남기지 못했다. 출력 형식과 근거 위치의 유효성만 검사해서는 의미적 충분성을 보장하지 못한다.
3. **단순한 직접 3분류는 이번 조건에서 기존 문제를 해결하지 못했다.** 이전 `attributed` 진단 결과 TP 25 / FP 1 / FN 0보다 정상 오탐이 악화됐다. 다만 이전 안과는 입력 표현·계약·추론 설정도 달라져 특정 변경 하나의 원인 효과로 단정하지 않는다. HCX-007 자체가 이 문제를 해결할 수 없다는 결론도 아니다.

총 **57회·41,543토큰**, 모든 호출 HTTP 200으로 완료했다. API 금액은 과금 내역을 확인하지 않아 환산하지 않았다. 단일 후보의 지연에는 속도 제한에 따른 대기가 포함되며 순수 모델 처리 시간과 다르다. 배치 조건은 호출과 토큰을 줄였지만 정확도 기준을 통과하지 못했다.

기본 단계 8회·74.08초의 응답은 재사용했으므로 이번 비용에 합산하지 않았다. 두 조건은 전체 사이트 재수집이나 전체 Pipeline 연속 실행이 아니며, 위 시간은 보완 단계의 실측치다. 대회 4종 기법·사이트 전체 F1·실제 공공 웹사이트 일반화는 측정하지 않았다.

`npm.cmd test --prefix agent`가 통과했다. 새 검사는 근거 위치 제한, 정답 메타데이터 제외, 불확실 판정 유지, 기존 광고·인용 보존, 요청 내부 ID 복원과 HCX 요청 형식·한 번의 형식 재요청을 확인한다. 오프라인 계약 검사의 통과와 실제 의미 판정의 실패를 구분한다.

## 종료 판단과 남긴 증거

주 실험인 단일 후보 조건이 사전 관문을 실패했다. 계획된 배치 비교까지만 완료하고 **306개 확대 검사·새 홀드아웃·반복 실행은 진행하지 않았다.** 실패 문구별 예외나 프롬프트 재조정도 하지 않았다. 따라서 일반화 성능 개선이나 안정성 확보를 주장하지 않는다.

과적합이 확정된 것은 아니지만, 같은 진단 자료를 반복 분석한 상태에서 추가 조정을 계속하면 개발 사례에 맞출 위험이 크다. 이러한 우려와 정상 회귀를 사용자에게 보고했다. 추가 재시도를 하려면 기존 실패안의 연장이 아닌 별도 가설·새 평가 설계가 필요하다. 이번 실행은 그 추가 실험을 시작하지 않는다.
