# 5단계: 페이지 우선순위 독립 검증 계획

2026-09-23. 결과를 보기 전 고정한다. 2·3단계 미해결 문제, 4단계 미채택, 운영 Pipeline을 유지한다.

## 가설과 범위

현재 collect는 FIFO 탐색이며 worker는 전체 수집 완료 후 후보 16개씩 판정한다. 페이지 한도 초과는 오류다. 따라서 순서만 변경한 이번 실험은 조기 광고 출력, 부분 결과 반환, 실제 시간 제한 내 탐지 개선을 구현하지 않는다.

가설: 이미 방문한 문서의 링크 문구·URL·링크 주변 DOM 구조만으로 게시물 접근을 우선하면, 같은 방문 페이지 수에서 더 많은 광고 라벨 위치에 도달할 수 있다. 목적지 본문·정답·사례 ID·광고 단어는 우선순위에 사용하지 않는다. 대상 페이지를 방문하기 전 그 페이지의 링크를 미리 보지 않는다.

## 고정 비교

- A: 기존 FIFO와 같은 최초 발견 순서. B: 우선순위 내림차순, 동점은 최초 발견 순서. B는 네 번의 선택마다 가장 오래 대기한 URL을 하나 선택해 낮은 우선순위도 진행시킨다. 어떤 URL도 분류 때문에 제외하지 않는다.
- 점수: 링크 문구에 게시판/게시글/댓글/문의/의견/참여 또는 영어 대응 forum/community/discussion/comment/post가 있으면 2점, URL 경로 토큰 board/bbs/forum/post/article/comment/reply/community 또는 board/bbs 쿼리 키가 있으면 1점, 링크가 article/role=article/role=comment/tbody 안에 있으면 1점. 중복 링크는 대기 URL의 최대 점수만 갱신한다. 문구 예외·숫자 ID·사이트 클래스 사용 금지.
- 기존 canonical/inScope를 재사용한다. 중복·순환·범위 밖 URL 처리와 최종 도달 집합을 비교한다. 아직 방문하지 않은 URL에 대한 목적지 특성은 사용하지 않는다.
- 기존 101페이지 저장 증거를 유지한다. 링크 전체가 저장되지 않았으므로 고정된 로컬 테스트 사이트를 브라우저로 다시 읽어 링크 그래프를 기록한다. 같은 수집기의 readDocument/settlePage를 재사용하고 원문·selector 순서를 기존 저장본과 대조한다. 불일치·누락 링크 목적지가 있으면 실험을 불완전으로 표시하고 확장하지 않는다.

## 지표와 관문

1. 모든 도달 페이지 집합과 후보 수 보존, 최초 방문 전 링크 노출 금지, 순환·정규화·범위 검사, 낮은 우선순위 진행 보장.
2. 기존 자료의 10/25/50페이지에서 광고 라벨 도달률과 정상 라벨 도달 수, 4기법별·제목/본문/댓글 등 위치별 도달률, 첫 광고 페이지 순번, 전체 방문 수. 분모는 전체 정답이며 방문한 자료만을 분모로 쓰지 않는다.
3. 호출·토큰·F1·정밀도는 이번 무호출 실험에서 측정하지 않는다. 광고 페이지 도달은 LLM 탐지 성공이 아니다. 페이지 수는 시간이나 후보 수가 동일하다는 뜻이 아니므로 누적 후보 수도 보고한다.
4. 후속 실제 호출 검토 관문: 적어도 두 예산 지점에서 광고 도달률 +5%p 이상, 어떤 예산에서도 전체 광고 도달률 감소 없음, 표본이 있는 위치·기법별 감소 5%p 이하, 전체 도달 집합 보존. 또한 게시판 밖 광고와 정상 게시판이 포함된 대표성 있는 별도 자료가 필요하다. 현재 같은 작성자의 기존 합성 게시판 자료만으로 운영 채택하지 않는다.
5. 추가 작은 그래프 검사는 기능·반례 검사다. 정상 게시판이 광고 없는 우선 작업을 늘리는 경우, 일반 페이지의 광고, 뒤늦게 발견되는 페이지, 불투명 URL, 순환을 포함한다. 새 실사이트 홀드아웃이나 성능 추정으로 보고하지 않는다.
6. 한 가지 점수·대기 정책만 비교한다. 실패/무효과면 프롬프트·가중치·사이트 예외를 결과에 맞춰 고치지 않고 종료한다. 실제 HCX 호출은 위 선행 관문 통과 후 별도 예산을 고정한 경우에만 실행한다.

## 재현성

실험 소스, 계획, 운영 소스, 저장 증거, 사이트 공개 파일·라우팅·정답 해시를 결과 측정 전에 고정한다. 정답은 채점 단계만 읽으며 탐색 함수는 그래프와 시작 URL만 받는다. 산출물은 `.runtime/stage5-priority/`, 실험 소스는 `agent/experiments/priority*.cjs`. 운영 수집기·판정기·worker에 연결하지 않는다.
