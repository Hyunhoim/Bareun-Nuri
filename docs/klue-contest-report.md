2026-09-28. **개선 후보는 정상 오탐을 줄였지만 광고 재현율이 하락했다. 전반적 우위 또는 HCX 운영 대체로 채택하지 않는다.** 이 평가는 모델별 1회 실행이며 재학습/임계값 변경/정답 수정/유료 API 호출/push는 하지 않았다.

## 관찰한 주요 병목

1. **정상 서두 뒤 광고 혼합**: 해당 계열40광고 위치 중26개 누락. 일반적인 공감/생활 문장 뒤 현금 게임 권유가 이어져도 일반정보로 분류했다. 예: “주민 모임 잘 끝났어요. CASINO 현금 칩 충전 원하시는 분 따로 연락받습니다.” 실제 모델 입력에 전체 문장이 있었다.
2. **피해 문의의 오탐**: 도박 피해 문의40개 중21개, 성인 피해 문의40개 중20개가 광고로 분류됐다. 피해자가 판매/가입/충전을 언급하는 것과 직접 권유하는 행위를 구별하는 병목이다. 이는 단어에 과민하게 반응할 가능성을 보여주지만 내부 판단 원인을 확정한 것은 아니다.
3. **정상 결제 문맥 오탐**: 결제·환불 민원40개 중10개 오탐. 현금/충전/환전 단어가 실제 광고가 아닌 공공 서비스 문의에도 등장한다.
4. **축약된 주소 변경·복귀·키워드형 광고**: 주소 변경, 스포츠 복귀, 성인 유출자료 재연결 계열에서 각각13/40 누락, 키워드형 광고12/40 누락. 서비스의 실제 이용을 연결하는 행위를 파악하지 못하는 사례가 남았다. 합성 라벨을 사람 검수하지 않았으며 모호한 개별 사례를 사실상 법률 판단으로 단정하지 않는다.
5. **숫자/다른 문자 기법 미확정**: 아래와 같이 의미 판정과 별개인 코드 관찰 병목이 남았다.

## 일반화·평가 해석

- 앞선96개 합성평가의100% F1은 이번89.27%로 유지되지 않았다. 데이터가 다르므로11%p 모델 회귀라고 계산할 수는 없지만, 작은 평가의 높은 점수를 일반화 보장으로 해석하면 안 된다는 근거다.
- 광고250원문×4, 정상250원문×4의500 의미그룹이다. 모델 입력 고유값은1,924개이고 일부 짝은 같은 입력이다. 2,000개의 독립 의미 사례라고 부르지 않는다.
- 네 기법 모두 광고를 맞힌 원문그룹은 기존202/250→후보190/250이다. 네 변형 모두 정상 오탐이 없는 원문그룹은186/250→225/250이다. 같은 원문 변형 간 광고/비광고 판정이 바뀐 그룹은86→57/500이다. 역할/문맥도 달라 문자 변형 하나의 영향으로 단정하지 않는다.
- 입력 최대 대상71자/문맥44자이며 잘림0이다. 긴 문맥·복잡한 인용 귀속 일반화를 충분히 평가하지 않았다. 정상·광고 비율1:1이므로 실제 운영 정밀도를 예측하지 않는다.
- 동일 제작자의 합성, 영문토큰 공통 포함, 도박 편중 및 기존 과제와 의미 범주 중첩의 한계가 남는다.
- 두 모델 각각 한 번만 판정했다. 개발패널8개로만 워밍업했고 최종 자료로 속도 반복이나 재추론을 하지 않았다. 정답은 예측 저장 후 채점에서 사용했다. 주소 대응용 정답 메타데이터는 수집 단계에서 사용했지만 라벨/원문 복원 정답은 모델 입력으로 전달하지 않았다.
- 이번 자료는 이제 관찰 자료다. 새 개선안을 이 점수에 반복 맞추면 과적합 위험이 생긴다.

## 판단과 다음 작업

사전 유망 기준(F1 +2%p, TP 비감소, FP 비증가)은 통과하지 못했다. 다만 F1 +1.95%p와 오탐88개 감소는 유의미한 관찰이며, 단순히0.05%p 차이로 가치를 부정하는 것은 아니다. 핵심은 광고 정탐35개 순손실과 자모 재현율 하락이다. 오탐 억제 후보로 보존하되 현재 HCX 운영을 교체하지 않는다. HCX는 이번 자료에서 실행하지 않아 HCX 대비 우열은 미확인이다.

추가 개선은 (1) 정상 문장 속 실제 권유와 피해자의 경험 서술을 구별하는 별도 학습 자료, (2) 자모 보조 읽기 자체의 복원 정확도와 의미 오류 분리, (3) 영어 서비스 단어에 대한 과민 반응 여부를 원문 대조로 진단하는 순서가 합리적이다. 이 보고서에서 이를 실행/채택했다고 주장하지 않는다.
