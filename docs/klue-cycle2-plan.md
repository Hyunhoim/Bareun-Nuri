# KLUE 두 번째 사이클: 담화 범위와 기존 지식 보존

첫 사이클의 새 합성 F1은 높았지만 기존 DOM152의F1이75→65.12%로 회귀했다. 일반 정상 문장의 범위 부족/학습 중 기존 지식 손실을 공통 원인 가설로 둔다. 이전 최종은 회귀로 전환했으며 다시 새 최종처럼 사용하지 않는다.

새 훈련은 교육/접근성/행정/행사/상태/질문/부가정보의 평서문·짧은 요소를 늘리고 불법 권유·예방 인용·같은 문구의 서로 다른 문맥을 함께 넣는다. 이전 최종·기존137/152의 정확한 문구를 복사해 학습하지 않는다. 이전 훈련은 혼합해 보존하되 이전 검증/최종 정답을 훈련에 넣지 않는다. 모두 합성/기존 합성 자료이며 사람 검수라고 주장하지 않는다.

동일한 혼합자료·NFC·최대512·batch8·seed42·lr2e-5에서 원본 KLUE부터 학습하는 B와 이전1104보강 모델에서 이어 학습하는 R을 비교한다. 모델당최대3epoch,검증macro4 F1 우선/광고F1 동률보조/동률이른epoch,2회무개선또는정확히100%시종료,모델당30분상한이다. 새검증으로모델을선택하며같은점수면B를선택한다. 기존회귀는선택후비교한다.

최종은별도어휘와다른문맥배치로봉인하고두모델의비교후선택한1개와기존보강기준선만각1회예측한다. 워밍업은검증자료를쓴다. 새최종광고F1>=90%·기준선대비>=5%p·재현율>=90%·macro4>=85%를유지한다. 첫사이클에불충분했던보류를별도보고하고최종보류정확도>=80%,확정정상/인용오탐률<=10%도실행전고정한다. 최종은한번이며그결과를보고같은자료로재튜닝하지않는다.

이전회귀137/152에서는정탐손익과F1을모두보고한다. 기존보강모델대비F1이2%p넘게하락하면새합성관문통과만으로전체일반화목표완료로처리하지않는다. 이보호조건은첫사이클실패를교훈으로두번째사이클실행전에고정한다. HCX운영/25분종단은이번학습으로승격하지않는다.

최종 자료 사전 감사: 학습전생성한원안512개는첫사이클최종과일부광고표현계열을공유했다. 모델예측전원안을사용하지않기로하고,새offer12/CTA6/예방6/모호6 표현으로sealed-inputs/labels512개를별도봉인했다. 이전미개봉파일은삭제하지않으며정답을이용한모델선택이나성능비교를하지않는다. 훈련/검증해시는그대로다. 실제예측은sealed512개에서만각모델1회수행한다. 생성중고유조합부족으로실패한v1/v2는모델학습전빈작업디렉터리이며v3만사용한다.
