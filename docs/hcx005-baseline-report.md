# 미튜닝 HCX-005 기준선 검증

## 결론

현재 운영 HCX-007을 유지한다. HCX-005의 즉시 운영 교체 및 바로 유료 PEFT 착수는 권하지 않는다. 사전 파일럿 투자 기준의 출력 유효성과 F1 근접 조건을 실패했다. 다만 미튜닝 성능으로 튜닝 효과의 상한을 증명할 수는 없다. 학습 불가능이 아니라, 학습 비용을 쓰기 전에 출력 계약을 간단하게 만든 별도 제한 진단이 먼저라는 판단이다.

## 고정 조건

기존 관찰 자료 137개(광고60/정상65/근거부족12), 원래/역순, 최대12묶음, 동일 system/user 메시지, temperature0/seed42/출력512. HCX007 none과 HCX005 비추론 API를 비교했다. API 차이는 HCX005의 maxTokens 및 thinking 생략뿐이다. 양쪽 모두 프롬프트 내 JSON 스키마와 로컬 검증을 사용했고 제공사 Structured Outputs는 사용하지 않았다.

007원순서→005원순서→005역순→007역순, 순차48회, 한시간 안전 상한, 사전 추정예약261728토큰/상한300000, 58k TPM/61초창/최소1초간격. 입력·소스 해시 및 응답 보존. 네트워크 실패 자동 재호출 금지. 운영코드·키 내용 변경, 모델 학습, push 없음.

| 모델/순서 | 유효 후보 | TP/FP/FN | 정밀도 | 재현율 | F1 | API 합산 시간 |

| 007 원래 |137/137|54/7/6|88.52%|90.00%|89.26%|58.43초|
| 007 역순 |137/137|59/11/1|84.29%|98.33%|90.77%|57.63초|
| 005 원래 |5/137|1/0/59|100%*|1.67%|3.28%|71.44초|
| 005 역순 |0/137|0/0/60|계산불가|0%|0%|89.69초|

*005의 정밀도100%는 양성1개뿐이므로 성능이 우수하다는 뜻이 아니다. 형식 실패 광고는 FN, 형식 실패 정상은 미판정이며 TN으로 세지 않았다. 근거부족12개는 이진 F1 분모 밖이다. 005의 낮은 F1은 의미 이해력 단독 점수가 아니라 현 출력 계약에서 사용 가능한 판정의 점수다.

007 평균 API시간58.03초, 005 80.56초로 약38.84% 느렸다. 로컬 quota 대기는0초였다. 제공사 내부 대기/시간대 영향까지 분리한 속도 인과 추정은 아니다. 확인 토큰은007 79524,005 78563, 총158087이다. 원화 비용과 크레딧 적용은 계산하지 않았다.

## 주요 병목과 보조 진단

005는24묶음 중1개만 엄격 형식 통과,007은24/24다. 문자열 enum만 반환하는 구조 오류와 닫는 괄호 누락이 반복됐다. 모든48응답 HTTP200, finishReason=stop이며 length 종료는0이다. 따라서 출력512 도달에 따른 잘림으로 분류하지 않는다.

사후 참고 진단으로 기존 평가기의 enum 문자열→publication_act 객체 포장만 적용했다. 괄호·ID·값을 복구하지 않았고 운영/사전 채택점수에는 반영하지 않았다. 005 원래77개, 역순36개만 읽을 수 있었으며 각각5/9묶음은 불완전 JSON으로 남았다. 이 부분집합은 형식 성공에 의해 선택돼 전체 모델 성능을 대표하지 않는다.

| 동일 유효 부분집합 | 005 TP/FP/FN·F1 | 007 TP/FP/FN·F1 |
|---|---|---|
| 원래77개 |23/6/12·71.88%|29/5/6·84.06%|
| 역순36개 |6/0/6·66.67%|12/3/0·88.89%|

즉, 형식만 고치면 모든 차이가 사라지는 상황은 아니다. 읽을 수 있는 응답에서도 이용 권유 CTA, 인용 형식의 실제 광고, 복제본 광고의 누락과 정상 명사형/교육 문맥 오탐이 관찰됐다. 구체적인 ID별 오류는 audit.json에 보존했다. 숫자치환 기법 판정의 개선은 이번 의미 전용 실험으로 확인할 수 없다.

007에도 원래/역순 양성 여부가 바뀐 후보16개가 있다. 005의 strict 양성 변경1개는 대부분 미판정인 결과여서 안정성 우위로 해석하면 안 된다. 같은 순서 반복은 시행하지 않아 배치 구성과 모델 변동을 분리하지 못한다.

## 투자 판단과 후속 조건

튜닝 전 간단한 출력 계약(짧은 ID와 고정 enum 등)을 별도 변경으로 제한 비교해 HCX005의 형식/의미 기준선을 확보하는 것이 먼저다. 이번 오류 사례만 맞추는 프롬프트 반복 수정은 하지 않는다. 계약 변경은 007에도 동일 적용해 모델 간 비교를 유지한다. 이 단계가 회복되지 않으면 PEFT는 보류한다.

회복될 경우에도 학습/평가를 단어 계열·문장·사이트로 분리한 소규모 PEFT 파일럿만 고려한다. 형식 준수와 광고/인용/정상/보류 구분을 동시에 학습할 수 있다는 것은 가설이지 관측 결과가 아니다. 반복 사용한137개를 학습시킨 뒤 같은137개 점수 상승으로 일반화를 주장하면 과적합 위험이 크다.

실제 운영 채택은 별도 평가와 같은25분 종단 조건으로 검증해야 한다. 이번에는 크롤러·4종 기법 통합·첫25분 전체광고F1을 측정하지 않았다. 과거 'HCX005가 운영 부담상 우선 후보'였다는 추천과 이번 성능 실측의 미채택 결론을 구분한다.
