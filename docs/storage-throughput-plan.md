# 저장 지연 API0 비교 계획

운영 동시3 코드를 동결 복제하고 Phase1의 저장 근거·요청 단위 최종 판정을 재생한다. HCX/수집/AntiSpoof 추론 시간을 제거한 재생이므로 전체 검사 속도 향상으로 해석하지 않는다. Phase2와 운영 소스는 변경하지 않는다.

가설: 요청별 안전 checkpoint를 그대로 두고 같은 wave의 중간 전체 결과 출력을 생략하면 최종 판정·재개를 보존하면서 저장 비용이 감소한다. 후보는 `progress`에서 inflight가 없는 wave 경계에만 전체 publish하며, 수집·최종 종료 publish는 유지한다. 중간 진행 이벤트와 checkpoint는 모두 유지한다.

기준: 동일 batch history/최종 판정·기법/출력 내용(경과시간 제외), API0, 격리 유지, durable 상태 재개 및 미확인 거부. 세 번 교차 재생의 storage 시간과 읽기/쓰기량을 비교한다. 25분 채택 성능은 상위 실험에서 별도 검증하며 재생만으로 승격하지 않는다. CPU 모델 실측은 별도 구간으로 구분한다.
