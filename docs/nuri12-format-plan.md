# Nuri 필드 표현 민감도 개선 실험

2026-09-29. 운영 HCX는 유지한다. 과거 평가 문구와 사용자 검수17개를 학습하지 않는다.

가설: 학습 직렬화의 고정 필드명 의존을 줄이면 미사용 필드명에서도 판정이 안정된다. 대상/문맥 원문, 귀속 표기, 라벨은 바꾸지 않는다. 피해문의 라벨을 수정한 1만개 복사본에서 동일한 첫2000개 노출만 사용한다.

통제: 순정 KLUE/seed42/embeddings+하위8층 고정/lr2e-5/AdamW/batch8/250step. 기준선과 후보를 이번 환경에서 둘 다 실행한다. 후보만 원래 필드명과 두 동의어 조합을 라벨과 무관하게 배정한다. 비교용 필드명 동의어는 학습에 쓰지 않는다. 총GPU실험 안전상한600초, 유료API0.

평가: 관찰 개발204의 기존 입력 F1, TP/FP/FN, 패널별 성능, 근거부족→광고, 미사용 필드명 변경의 판정 변동. 사용자 검수17개는 이진 정상 오탐만 측정한다. 1/2 세부 라벨 충돌을 임의 수정하지 않는다. 최종 봉인 자료는 읽지 않는다.

후속 검증 자격: 기준선 대비 F1 +2%p 이상, 필드명 변동 감소, TP 감소없음, 근거부족→광고 증가없음, 실제 정상17개 오탐 증가없음. 기존 유망freeze8/A와도 비교한다. 통과해도 운영 승격이 아니라 다른seed/독립자료 확인 대상으로만 간주한다. 실패하면 동일자료에 맞춰 문구를 반복 수정하지 않고 종료한다. 과거개발204 반복사용 편향과 정상17개가3출처에 불과한 한계를 보고한다.
