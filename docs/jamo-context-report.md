## 같은 300회 호출 접두부 확인

### 결론

사전 기준의 F1 순이득과 기존 정탐 보존을 확인했고, 추가 정상 오탐1개를 반영해도 이득이 남는다. 따라서 **C만 채택 권고**한다. 특정 문구·URL·라벨 예외가 없는 일반 자모 복원이고 추가 LLM 호출이 필요하지 않다는 점도 근거다. 정확도와 속도가 모두 개선됐다는 결론은 아니다. 종단 토큰은0.77% 늘었고 호출도5회 늘었다. 같은300회 처리 시간도 단축되지 않았다.

D는 비용이 늘면서 재현율 이득이 작고 단일 조건에서도 손실이 있어 미채택한다. C+D 결합, 운영 단일 후보 판정, 추가 추론·재판정은 적용하지 않았다. 운영 적용 시에도 원문·관찰 기법을 유지하고 모델의 보조 읽기만 교체하는 범위가 이번 검증과 일치한다.

이번 새 유료 실행 합계는 **779호출 / 1,260,271 확인 토큰**이다. 이전 기준선 비용은 이 합계에서 제외했다. 계획된 비교 후 추가 유료 튜닝·push·운영 코드 적용은 하지 않았다. 최종 비교 자료는 `.runtime/jamo-context-live-audit.json`, 종단 평가 `evaluation.json`, 별도 오탐 검토와 최종 검증 기록에 보존한다.
