# D 혼합 문맥 보존 진단

2026-09-29. 기존 D와 이미 고정된 경계 보정 D를 비교한다. 모델/임계값/프롬프트 변경 없음. 실제 수집에서 제외한 문구를 12개 서로 다른 대상 기준으로 해시 순서로 고른다. 본문이 길어 입력 한도를 넘으면 기존 보호로 전달하고 모델 성공과 구분한다.

네 독립 합성 권유 문장을 각 정상 대상 앞/뒤 및 대상에 귀속된 주변 문맥에 배치한다. 동일 권유 문장을 예방 인용으로 전환한 대조군을 둔다. 총192입력=광고144/예방48. 원래 사이트 게시글이라고 주장하지 않는다. 원본 대상과 제목을 재사용한 입력 수준 진단이며 실제 DOM 실행 또는 새 독립 최종평가가 아니다. 검수되지 않은 원래 문구를 정상 학습 라벨로 사용하지 않는다.

광고 한 개라도 제외하면 해당 구성은 안전성 회귀 실패로 기록한다. 예방 사례를 HCX로 넘기는 것은 오류가 아니라 절감 기회 미사용이다. 결과를 본 뒤 경계를 맞추지 않는다. CPU8threads/batch8 한 번, 추가학습/API0. 새 진단 문장은 학습에 사용하지 않는다.
