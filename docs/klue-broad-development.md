# 개발검증 표현·문맥 범위 보강

2026-09-28. 이번 작업은 모델 재학습보다 개발검증 자료의 대표성 결함을 먼저 줄이는 것이다. 모델 점수를 본 뒤 문구/정답을 바꾸지 않는다. 기존 평가2,000개는 관찰 회귀 자료로 보존하며 새 자료에 복사하지 않는다.

## 실행 전 계약

- 짧은 권유, 혼합 의도, 인용 형식, 다른 작성자 귀속, 비교적 긴 본문의5축을 각8원문으로 구성한다. 정상/피해 문의/교육 인용/불확실 사례를 함께 둔다.
- 40개 원문 각각을 자유 게시판 / 피해 상담 접수 / 이용 안내 제목에서 수집한다. 같은 대상·소유 문맥에 제목만 달라져도 정답은 유지된다. 제목 자체가 실질적인 서비스 근거인 다른 상황까지 제목을 무시하라는 규칙은 아니다.
- 원문·소유 문맥·다른 댓글 배제를 실제 수집기로 검사한다. 제목만 바뀐 대조의 나머지 모델 입력은 같아야 한다. 누락이 있으면 수작업으로 입력을 보충하지 않는다.
- 모든 자료는 개발검증 전용이다. 향후3개 그룹 분할 비교를 위해 같은 원문의 모든 제목 변형을 같은 fold에 배정한다. fold가 있다고 교차검증을 수행했다고 주장하지 않는다. 현재40원문과3개 제목 변형120입력을 구분한다.
- 실제 게시물 수집/독립 사람 검수 자료가 아니다. 같은 작성자의 합성이고 원인 진단에 맞춰 설계했으므로 독립 최종 평가로 사용하지 않는다. 정답은 근거가 명시된 에이전트 검수 초안이다.
- 모델 호출/추론/학습은 이번에 하지 않는다. 새 자료의 F1을 보고 문구를 재작성하는 과정을 막고, 정답·입력·분할·소스를 먼저 해시 고정한다.

## 점수 해석 계약

추후 비교는 광고 F1/P/R와4분류 Macro F1, 축별TP/FP/FN, 피해 문의 오탐, 실제 권유 누락, 보류 정확도/남용을 함께 보고한다. 제목3변형의 판정 변경률과 같은 원문에서 가장 불리한 제목 조건을 별도로 본다. 120입력을 독립120원문처럼 신뢰구간에 사용하지 않는다. 기존 평가의 높은 점수와 새 어려운 패널의 낮은 점수를 동일 모집단의 성능 변화로 해석하지 않는다.

의미 판정 자료이므로 기법 정확도나 크롤링 도달률까지 검증하지 않는다. 모델 입력에 포함되지 않는 URL/라벨/그룹/검수 설명으로 판정하지 않는다. 실제 표기 위장과 동적 HTML, 매우 긴 문맥은 추가 검증 범위로 남는다.

## 완료 결과

|구성|원문 계열|제목 변형 포함 입력|
|---|---:|---:|
|짧은 권유·정상·생략문|8|24|
|정상/피해 서두 뒤 권유와 피해 문의|8|24|
|인용 형태의 실제 권유와 교육·피해 인용|8|24|

|비교적 긴 본문의 권유·정상·생략|8|24|
|합계|40|120|

원문 기준 광고14/교육인용7/정상·피해문의12/근거부족7이다. 이 비율은 통제 진단을 위한 구성이지 실제 공공사이트의 광고 비율 추정이 아니다. 원문 전체와120개 수집 입력은 해시 고정했고 아직 모델 점수를 확인하지 않았다.

실제30HTML페이지에서 대상 원문120/120 보존, 소유 문맥18/18 전달, 다른 작성자 문맥24/24 제외를 통과했다. 같은 페이지의 다른 대상 본문도 문맥으로 섞이지 않았다.40계열 모두 제목을 제외한 대상·문맥 동일성을 확인했다. 이를 제목 영향 진단에 사용할 수 있으며 제목 무조건 삭제를 운영에 적용한 것은 아니다.

그룹 분할은13/14/13계열이며, 각 fold에5축과4라벨이 모두 포함됐다. 같은 원문의3제목은 같은 fold에 속한다. 이것은 차후 비교를 위한 분할만 만든 것이며 교차검증 학습을 실행하지 않았다. 이번 전체 자료는 개발용이므로 미사용 최종 평가셋이라는 명칭을 쓰지 않는다.

모델 입력은120개 모두 고유하며 기존 실제 토크나이저에서17~105토큰,512 잘림0이다. 따라서 longer축도 장문 잘림/수천자 문맥을 검증할 만큼 길지는 않다. 이전 훈련 풀3종과 기존2,000개 평가 원문을 대조해 정확히 같은 대상 문구는0개다. 과거 훈련 대상에 대한 공백 제거·NFKC 문자3그램 Jaccard 최대치는0.25였다. 이 표면 유사도 검사는 의미/생성 문법의 독립성을 증명하지 않는다.

## 남은 대표성 한계

명확한 서비스와 행위를 갖춘 합성 문장이 여전히 많고 같은 작성자의 언어 습관을 공유한다. 은어·영문 접두어·더 자연스러운 비문·실제 게시물 출처·독립 검수·긴 문맥·동적 댓글을 충분히 대표하지 못한다. 따라서 기존 개발검증보다 다루는 실패 축은 넓어졌지만 운영 분포의 대표성이 확보됐다고 확정하지 않는다. 과적합 위험은 남으며, 이후 새 모델에 이 패널 점수만 최적화하지 않는다.

다음 비교에서는 새 학습보다 기존 모델과 미채택 후보를 고정 입력으로 먼저 비교해, 이번 개발패널이 기존 정탐 손실을 드러내는지와 제목 변경에 따른 판정 변동을 확인할 수 있다. 그 결과는 개발 진단이며 독립 일반화 증명으로 바꾸어 부르지 않는다. 이번에는 모델 추론·학습·유료API·운영변경·push 모두0이다.
