# 근거 선택 출력·의미 전용 판정의 제한 비교 — 2026-09-25

사용자가 미채택 병목의 추가 개선 실험을 요청했다. 기존 운영 기준선으로부터 다른 공통 원인 가설을 비교한다. 과거 문맥 구조화안을 운영에 연결하거나 오류 문구에 맞춰 예외를 추가하지 않는다. 과거64개와76개는 모두 관찰한 진단/회귀 자료다.

## 가설과 조건

HCX 공식 Structured Outputs 지원 목록에는 string minLength가 없고 pattern은 미지원이다. 지원되지 않은 제약으로 빈 문자열을 막는다고 가정하지 않는다. 출처: https://api.ncloud-docs.com/docs/en/clovastudio-chatcompletionsv3-so (2026-09-25 확인). Context7에는 이 HTTP API의 스키마 문서를 찾지 못해 공식 문서를 사용했다.

첫 가설은 자유 설명 문자열과 실제 근거가 연결되지 않는 출력 계약의 문제다. 근거 유형(enum)과 해당 후보 입력의 원문/문맥 위치(enum 배열, minItems1)를 선택하게 한다. 유형과 선택한 실제 원문으로 표시 이유를 구성한다. 이것은 빈 답에 사후로 일반 문장을 채우는 복구가 아니라 새 출력 계약이며, 선택 근거의 타당성을 별도로 채점한다. 코드가 유효한 근거 위치를 강제해도 의미적 뒷받침을 보장하지는 않는다.

두 번째 가설은 한 요청에서 광고 의도와 기법을 함께 생성하는 책임의 간섭이다. 의미 전용 조건은 같은 입력에서 기법 출력과 기법 판정 지시만 제거한다. 기존 코드 관찰은 별도 통합하며 미확정을 숨기지 않는다. 실제 인과 효과는 출력 계약/역할 변경 단위이며 각 문장의 영향을 분리했다고 주장하지 않는다.

- O1/O2: 운영 입력·공통 출력의 반복 대조.
- J: O의 모든 입력에 대상/주변 문맥의 출처 ID를 추가한 공동 판정 대조. 기존 SYSTEM/스키마 유지. 미채택 비교 조건이다.
- E: J와 동일 입력, 공동 판정 유지, 근거 유형/근거 ID 출력 계약만 변경.
- S: E와 동일 입력·근거 계약, LLM의 기법 판정 책임만 제거. 의미만 생성하고 기법은 별도 코드 관찰에서 얻는다.

J→E와 E→S의 비교를 분리한다. E가 실패해도 사전 고정한 S를 독립적인 역할 비교로 끝까지 평가하되, 결과를 보고 새 보완안을 덧붙이지 않는다. 빈 근거 보호를 운영에서 제거하지 않으며 자동 복구 호출은 없다.

## 자료·순서·관문

1. 기존 새 개발32+확인32를 이제 진단64로 사용한다. 각32의 순서는 그대로 유지하고 O1→J→E→S→O2를 비교한다. 최대16개, HCX-007 none/temperature0/seed42/3072출력, 순차 호출을 유지한다.
2. 알려진 정상/광고의 의미F1·FP·공통 기존 정탐 보존, 정상 검토, 근거 부족의 명시적 uncertain 정확도, 원문·문맥 귀속, 기법/최종 F1, 비용·지연을 나눠 평가한다. needs_review가 빈 문자열 때문인 경우 명시적 uncertain으로 세지 않는다.
3. 유망 조건은 두32개 각각 기존 공통 광고 손실0, FP 비증가, F1 비감소, 정상 검토 비증가, 명시적 uncertain 최소3/4, 근거 선택 적합률90% 이상, 코드 관찰 적용 후 기법/최종F1 비감소를 충족해야 한다. 기존 예방 인용 FP의 합계가 절반 이하로 줄어야 한다. 토큰·지연은 느린 기준선 대비20% 이내, 호출 증가0. 보류로 정상 FP만 숨긴 것은 실패다.
4. E/S 중 통과한 조건만 기존76 회귀에서 O1→후보→O2로 재확인한다. 둘 다 통과하면 정상 검토/의미F1/비용 순으로 하나만 선택한다. 회귀에서도 기존 광고 손실0·FP/정상 검토 비증가·기법/최종 F1 비감소·토큰/지연20% 이내를 요구한다. 렌더링 근거가 없는 과거28개는 미검증으로 남긴다.
5. 이 진단과 회귀를 통과한 경우에만 새 표현·구조의 미사용 확인 자료와25분 종단 비교를 별도 고정 계획으로 진행한다. 진단만으로 운영 채택하지 않는다. 실패하면 운영 기준선을 유지하고 같은 자료에 추가 조정하지 않는다.

근거 선택 정답은 평가에만 사용한다. 대상 원문을 식별하는 t, 수집된 주변 문맥 c0...만 입력에 전달하고 정답·사례 분류는 전달하지 않는다. 예방 인용/문맥 의존 링크는 해당 설명을 담은 수집 문맥을 선택해야 하며, 일반 광고/정상/근거 부족은 대상 원문을 선택해야 한다. 잘못된 의미 판정은 근거 ID가 유효해도 근거 적합 정답으로 인정하지 않는다. 근거 부족은 명시적 uncertain이어야 한다.

유료 최초 상한40시도/예약 포함550,000토큰/1시간. 조건 간61초 속도 보호 대기는 측정 지연에서 제외하고 조건 내부 대기는 포함한다. 전송/형식 자동 재시도0. 소스·입력·라벨을 해시로 고정하고 원본 요청/응답을 저장한다. 실행 실패·미확인 전송을 자동 반복하지 않는다. 새로운 모델·탐색 정책·수집 규칙은 추가하지 않는다.
