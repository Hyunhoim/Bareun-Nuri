# 출력 신뢰성 두 변경 비교 — 사전 계획

2026-09-30. 운영 코드를 수정하지 않고 연구 경로에서 검증한다. 기존 실패 체크포인트/160번째 요청은 재호출하지 않는다. 과거 Phase1은 관찰/회귀 자료이며 독립 평가가 아니다.

1. Structured Outputs: Phase1에서 정상 완료한159개 묶음 중 SHA256 순서로18개 고정 선택. 후보/순서/의미 지시/none/seed42/온도0/출력512/예약58k 동일. A는 현재 promptJson, B는 공식 responseFormat을 사용해 스키마 전달 위치가 다르다. A-B-B-A 각18호출, 총72호출·최대500,000 확인토큰·20분 안전상한. 호출 한도/미확인 오류 시 자동 재호출 없이 종료. 완전 응답 비율, 지정 정답 위치 F1·TP손실·FP증가, 반복 변동, 서비스/대기/토큰을 비교한다. 누락 시 해당 응답의 모든 후보를 미판정으로 처리한 결과도 보고한다.
2. 격리: HTTP200/정상 종료/완전 파싱된 JSON의 알려진 ID 부분집합만 격리 가능하다. 중복/낯선 ID/잘림/잘못된 값/전송 불명은 기존대로 거부한다. 실패 응답과 유효 반환값은 별도 보존하며 정상 판정으로 채우지 않는다. 최소 구현은 실패 페이지의 남은 판정을 보류하고 다른 페이지를 계속한다. 페이지 offset/기존 판정은 그대로이며 재개해도 보류 페이지를 자동 재호출하지 않는다. 후속에 해당 페이지를 다시 판단하는 기능은 범위 밖이다.
3. 비교 기준: B의 형식 오류0, 의미 F1 하락1%p 이내·회차별 기존TP손실1개 이하/새FP1개 이하, 중앙 서비스 지연 증가20% 이내를 얕은 확대 조건으로 고정한다. 통과해도 희귀 누락 해결을 확정하지 않고 동일25분 운영 조건에서 재검증해야 승격 가능하다. 통과하지 못하면 추가 유료 확대 없이 종료한다.
4. 격리는 완료 결과 불변·원본/미판정 보존·거짓 완료0·중복 호출0·옛서명/미확인 재개 거부를 검증한다. 페이지 단위 보류가 과도한 미판정을 만들 수 있으므로 범용 완성안으로 주장하지 않는다. 실제25분 승격 근거 없으면 운영에 적용하지 않고 채택 가능 조건만 보고한다.
