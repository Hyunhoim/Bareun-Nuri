# AntiSpoof 대상 구간 판정층 독립 비교

2026-09-30. 직전 구간대조 학습은 개발개선/기존회귀/HCX결합 절충을 확인한 진전이다. 다음 요인은 데이터가 아니라 판정층 입력이다. 목표는 대상 밖 기법의 귀속 오류와 기존 정탐 손실을 함께 줄이는 것이다.

같은 운영 v1.0 가중치에서 시작하고 직전 `scope`와 동일3035행/seed42/lr1e-5/batch8/전체학습/최대2epoch/H.20 조건을 유지한다. Electra encoder는 전체 문맥을 읽되, 분류층에는 문장 첫 토큰 대신 **표시 대상에 속하는 토큰 hidden state의 평균**을 넣는다. 새로운 임베딩이나 층·외부 의존성을 추가하지 않는다. 기존 head는 그대로 시작하지만 입력 표현이 바뀌므로 이것은 추가 학습이 필요한 별도 아키텍처다. 저장 가중치만 기본AutoModel로 읽으면 해당 방식이 재현되지 않으므로 pooling 계약을 별도 저장한다.

대상 마스크는 모델 입력의 문자 offset으로 생성한다. 마커가 없거나 중복되거나 토큰 경계를 가로지르면 입력 오류로 거부한다. Unicode 보조근거와 주변 문맥은 encoder에 그대로 제공한다. 입력 토큰ID·attention mask가 기존 방식과 같은지 확인한다. 모델은 라벨·id·group_id를 받지 않는다.

개발선택 점수와 유망 기준은 `antispoof-scope-plan.md` 그대로다. 후보 선택 후 기존 관찰회귀·고정HCX결합의 정탐/오탐/보류를 비교한다. 데이터 증가나 임계값 재조정은 하지 않는다. 개발 점수만 높아지면 운영에 반영하지 않는다. 단일seed·동일 생성자 합성의 한계와 NFD의UNK 문제를 유지한다.

안전 상한은 학습30분, API0, 운영변경0이다. 기존 최종860에 접근하지 않는다. 새 최종자료를 만들지 않는다. 코드/입력마스크 검사를 통과해야 학습을 시작한다. 유망하면 CPU 반복 지연과 실제 운영 입력 연결·25분 평가를 이어가되, 실패하면 후보를 보존하고 원인에 따른 다음 요인만 별도로 검토한다.
