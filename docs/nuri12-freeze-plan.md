# Nuri 1.2 추가 학습·freeze 비교 사전 계약

기존 선택2epoch를 기준으로 추가학습 full/freeze8(lr5e-6), 순정 재시작 full/freeze8(lr2e-5)를 비교한다. 한 쌍 내 초기 가중치·새 head seed42·입력 순서·배치8·AdamW .01·FP32·clip1·최대2epoch를 맞춘다. freeze8은 임베딩과 하위8개 transformer layer를 고정한다. dropout은 두 조건 동일하게 train모드로 유지한다. 별도 자료나 평가 문구를 학습하지 않는다. GPU 한 대에서 순차 실행,조건당20분/전체80분 상한이다.

개발204행/세패널과 입력형식은 이전 그대로다. 각epoch의250/625/1250step에서 체크포인트를 평가한다. 조기 과적합 이전 상태도 비교하되 검증 반복 선택 편향을 명시한다. 신규 최종평가는 열지 않는다.

Nuri 개선 관문: 합산 광고F1이 기존보다2%p 이상 높고, 패널 macro4 평균 비감소, 광고재현율 비감소, 각패널 광고F1 하락2%p이내, 불확실→광고 비증가. A 대체 탐색 관문은 추가로 A의 합산F1·macro4평균 이상, A재현율−2%p이상, 불확실→광고 A이하다. 순위는 A관문→Nuri관문→합산F1→macro4평균→작은step. 관문 실패를 사후 성공으로 바꾸지 않는다.

A관문을 통과한 개발 최상위1개만 기존2000회귀로 확대한다. 회귀 F1 A이상·재현율하락2%p이내·각4기법F1하락2%p이내를 사용하고 정탐손실/회복·정상오탐을 별도로 보고한다. 이미 관찰한 자료이므로 새 일반화 증명은 아니다. Nuri만 개선하면 연구 체크포인트 개선으로 한정하며 A/HCX 교체를 하지 않는다.

모든 조건이 실패하면 이 동일자료 freeze/epoch 탐색을 종료하고 결과를 보고한다. 데이터의 문장틀 의존이 남아 있는데 같은 검증을 보며 무한 조정하지 않는다. 유망 조건이 나오면 저장재로딩·코드/데이터 불변·freeze층 불변을 검증하고 결과를 보고한다. 유료API0/최종평가0/운영변경0이다.
