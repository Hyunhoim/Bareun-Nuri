# 동결 분류기의 입력 형식 진단

2026-09-30. 직전 Goal turn은6조건 학습·실제 및 회귀 평가 완료라는 진전이다. 같은 관찰31개의 실패를 재학습하지 않고, 원래 훈련자료의 형식 민감성과 라벨 범위를 진단한다. 목적은 다음 학습의 공통 원인 가설을 좁히는 것이며 새 정확도/독립 홀드아웃/운영 채택 실험이 아니다.

증강 전210개 모두 http(s) URL 문자열이 없으며 `[URL]` 포함은 광고9·정상7이다. 실제 수집과의 분포 차이는 확인됐지만 그것이 누락의 원인이라는 인과 증거는 아직 없다. 성인 영상 홍보만을 양성으로 둔 실원문4개는 최근 입력 근거 기준과 범위를 재검토할 대상으로 표시한다. 예방 인용은 별도로 판단하고, 같은 출처라는 이유로 정상·광고 라벨을 일괄 변경하지 않는다.

모델은 `.runtime/semantic-real-addition-gpu-v1/evaluation-contract.json`에 동결된 기존/추가군 각3개다. 훈련·checkpoint 선택·임계값 변경 없이 CPU FP32/8threads/batch8로 진단한다. 유료API0, 외부 URL 방문0, 운영 수정0, 전체 추론 안전 상한600초다.

원래 훈련210개를 baseline으로 두고 다음 입력을 만든다. 이들은 학습 원문의 조건부 표기 대조이므로 점수를 일반화로 소개하지 않는다.

- paragraph: target을 HTML escape 후 `<p>...</p>`로 감싼다. HTMLParser로 가시문자를 되읽었을 때 원문과 정확히 같은지 검사한다. context는 보존한다.
- url_short/url_long: target/context의 `[URL]`만 서로 다른 길이의 예약 `.invalid` 가상 주소로 치환한다. placeholder가 주소를 나타낸다는 가정 아래 목적 의미 보존을 의도한 변형이며 실제 링크 목적을 검증한 것은 아니다.
- anchor: `[URL]`을 해당 표시가 가시문자로 남는 `<a href="...">[URL]</a>`로 감싼다. 가시문자 복원이 정확한지 검사한다. 주소 목적은 가상이며 새 의미 정답을 생성하지 않는다.

모든 변형은 라벨과 무관한 동일 규칙이다. source_id/case_id/URL별 예외를 모델 입력 또는 추론 코드에 넣지 않는다. 원본 보존, 변형 ID·부모 연결·원문 일치·입력 해시를 검사한다. 모델별 baseline/변형 양쪽이512토큰 이내인 쌍만 주 flip 통계에 포함하고, 잘림 때문에 빠진 쌍은 별도로 기록한다. 추가군22개나 실제 관찰31개는 이 형식 진단의 부모로 사용하지 않는다.

주 지표는 baseline→변형 판정 전환 수/방향, 절대 광고 확률 변화, 원문 라벨별 전환 수다. 학습 라벨 자체가 미검수/합성임을 유지하며 원문의 판단이 맞았다는 가정으로 새 F1을 계산하지 않는다. 높은 flip은 형식 민감성의 증거일 뿐 실제 누락 원인의 확정이 아니다. 낮은 flip도 실수집의 긴 링크 목록·잡음·귀속·미지 주소에 대한 강건성을 입증하지 않는다.

종료 기준은 모든6개 동결 모델과 모든 준비된 쌍의 실행 또는 명시된 시간 상한이다. 결과에 맞춰 변형·주소·임계값을 다시 선택하거나 같은 실제 실패 입력에 HTML 제거를 반복 적용하지 않는다. 다음 학습/전처리 실험이 필요하면 별도 계획에서 의미 근거 보존과 정상 회귀를 함께 검증한다.
